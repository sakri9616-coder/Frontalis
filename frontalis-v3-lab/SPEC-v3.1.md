# frontalis-v3-lab 実装仕様 v3.1（v3.0 への差分）

v3.0 の実装（SPEC.md）への理念優先の批評（全文は `reviews/critique-v3.0.md`）で、次の三点が確認されました。

- **受け止め方が人格に依存しない。** 感じた価値 f は生得の効用と一時的な欲求の状態 h だけで決まる。h と気分を揃えると、人格間の f の差は 0.000 になる。
- **評価基準が形成されない。** 未見の共同作業者への価値は、履歴中の効果表 M の平均と cos 0.999 で一致する（M の写し）。教師を生得の Δu だけにしたため、v3 は「生得の効用の予測」を学ぶだけになっていた。これは 3-F の固定 base と同じ形の失敗である。
- **ニューラルネットが使われていない。** R/K/X のテストで、事前ヘッドは閾値（50 件）に届かず一度も使われていない。

v3.1 の目的は、**自己増幅を起こさずに、経験が評価基準そのもの（何をどれだけ良い・悪いと感じるか）を変え、その変わった基準が次の経験の受け止め方と学習を変える**ことです。v3.0 の判定基準は残します。ただし T2(a)・T2(c) は「人格ではなく状態を測っていた」ため主判定から外し、記録として残します。新しい判定基準（第3節）は、ここで実装前に固定します。

## 1. 設計の変更

### 1.1 欲求の関心の重み a（評価基準の形成 1）
- 人格ごとに欲求の重み a ∈ R⁵（初期値は全て 1、和は常に 5）を持つ。
- 更新: `a ← normalize( a + η_a ( |Δu| / mean(|Δu|_run) − a ) )`。η_a = 0.02。`|Δu|` は生得の効用の変化の大きさ（外生）で、mean は全欲求の移動平均。**a の目標に価値ネットの出力は入らない**（補題1）。
- 意味: 人生で大きく揺さぶられた欲求ほど、その人格にとって重要になる（関心の形成）。正負のどちらで揺さぶられたかは問わない。この方向（感作）は設計上の仮説で、README に明記する。
- 用途: 感じた価値、モデルベース価値、価値の読み出し（like）で、欲求ごとの量を a で重み付けて合計する。

### 1.2 条件づけられた価値 C（評価基準の形成 2。生得の効果を持たない結果型・概念・相手が、経験の随伴関係から価値を得る）
- 対象は「手がかり」です。手がかりとは、事象に含まれる概念、参加者（個体・類）、結果型です。C は手がかりの特徴に対する線形の重みで、v3.0 の人モデル・状況モデルとは別の重みです。
- TD(0) で学ぶ。事象 t を見た後、次の事象 t+1 を見たときに、事象 t の手がかり z_t を更新する。
  - 目標: `y_t = r_{t+1} + γ · C_frozen(z_{t+1})`、`r = Σ_k a_k Δu_k`（その事象の a で重み付けた生得の効用）。
  - 更新: `C += α_C (y_t − C·z_t) z_t / (z_tᵀ z_t)`。α_C = 0.1、γ = 0.6。
  - C_frozen は事象 t+1 の時点の C の写しで、勾配を止める。
  - 同じ「文脈の連続」（session id が同じ、または指定がなければ連続する事象）の間だけ TD をつなぎ、途切れたら次の価値を 0 とする。
- 意味: 「褒められた後に裏切られる」人生では、生得の効果を持たない「褒められる」が負の価値を帯びる。随伴関係が違う人生では、正の価値を帯びる。**どの手がかりがどんな価値を帯びるかは、設計者ではなく経験の随伴構造が決める。**
- 自己増幅の制御: γ < 1 のブートストラップ（縮小）。目標の r は C に依存しない。

### 1.3 受け止め方（感じた価値）を学習状態に依存させる
```
f = tanh( ( Σ_k a_k Δu_k                         生得の効用（関心の重み a で重み付け）
          + λ_C · Σ_{x∈手がかり} C(x)               条件づけられた価値（この事象に含まれるものへの好悪）
          + η_ref · ( Σ_k a_k Δu_k − Q )            予期との差（参照点依存）
          ) / s_f  + β m )
```
- λ_C = 1.0、η_ref = 0.5、s_f = 0.5、β = 0.3。
- f は読み出しで、どの学習の目標にも入らない。人モデル・状況モデルの目標は v3.0 のまま（外生の Δu ベクトル）。C の目標は r と C_frozen（γ < 1）。a の目標は |Δu|。
- 根拠: 主観的な幸福は、受け取った報酬だけでなく、期待と予測誤差に依存する（Rutledge et al. 2014, PNAS 111(33), 12252–12257。文献照合は後で行う）。

### 1.4 曖昧な結果の解釈（既存の人格が経験を評価する）
- 結果は、単一の型の代わりに解釈の候補を持てる: `{"interpretations": {"credit_taken": 0.5, "credit_shared": 0.5}, "actor": "friendA", "magnitude": 0.8}`。確率は LLM の素の読み（人格を知らない）。
- NPN は、信念で解釈の重みを決める: `w_I ∝ q_LLM(I) · P_belief(I | actor, context)`（正規化）。
- 効果の計算（Δh、Δu、帰属、価値の教師）は、この重みでの混合で行う。
- **信念の計数は曖昧な結果では更新しない**（既定）。解釈が信念を自己訓練するループを作らないためである。明確な結果だけが信念を変える。曖昧な結果からも計数する設定は、実験条件（`interpretation_counts`）として残す。
- 意味: 「手柄を取られる」と予期している人格は、同じ曖昧な出来事を取られたと受け止め、その受け止め方で学ぶ（誤解は誤解のまま価値に残る）。明確な反証は信念を変える。

### 1.5 ニューラル事前ヘッドの実際の利用
- 閾値 50 件の解禁を廃止する。類の事前平均を `prior_cls = ρ_h · head + (1 − ρ_h) · m_gen` で混ぜる。`ρ_h = n_head / (n_head + 30)`、n_head はヘッドの学習標本数。
- 比較のための基線を実装する: `head_kind ∈ {"mlp", "linear", "knn1", "none"}`（既定 mlp）。線形はロジスティック回帰、knn1 は既知の類のうち埋め込みが最も近い類の率。

### 1.6 埋め込みは NPN が所有する（LLM からの独立）
- 概念・類・文脈の埋め込みは、初めて現れたときに lexicon（または外部の埋め込み関数）から**写して状態に保存**し、以後は状態の値を使う。LLM や埋め込みモデルを交換しても、既存の人格の座標は変わらない。未知の語は、lexicon にない場合ゼロベクトルとして状態に登録し、警告を記録する。
- 保存・復元の対象に含める。

### 1.7 類の集中度 κ_e の経験ベイズ推定
- 類ごとに κ_e を格子（0.3〜50 の対数 12 点、弱い対数一様事前）の上の周辺尤度（Beta–Binomial、`math.lgamma`）の事後平均で推定する。個体が 2 人未満の類では事前（κ_e = 2）のまま。
- 目的: 「上位の層の有効標本数は相手の数」（docs/04 第4.2節）を、固定の κ ではなく推定で実現する。

### 1.8 確率的な経験史の生成
- `data/make_histories.py` を、乱数種ごとに異なる経験史を生成する関数にする（人格の型ごとに、世界の真の確率から結果を抽出する）。乱数種 20 本が独立な標本になるようにする。R/K/X の固定の履歴は、デモ用として残す。
- 経験史には `optional: true` の申し出（参加者との共同作業の誘いなど）を含める。

## 2. 変えないもの
- 人モデル・状況モデルの階層カルマン（教師は外生の Δu ベクトル、帰属 φ で分割）。
- 信念ネットの階層とスコープ帰属。
- 保存・復元・決定性・台帳。
- アブレーション: 既存のものに加えて `no_concern`（a = 1 固定）、`no_conditioning`（C を使わない）、`no_reference`（η_ref = 0）、`no_interpretation`（曖昧な結果を LLM の確率のまま混合し、信念を使わない）。

## 3. 新しい判定基準（実装前に固定。v3.0 の T1〜T10 は維持し、T2(a)(c) は記録扱い）

乱数種 0〜19 で、それぞれ別の経験史を生成します。

| ID | 検証内容 | 合格条件 |
| --- | --- | --- |
| U1 入れ替え（主判定） | 人格の型 R・K・X の経験史で育てた後、欲求の状態 h と気分 m を全員同じ値（基準値）に揃え、同じ新しい経験を評価する。次に、学習した状態（W、Σ、C、a、信念）だけを人格間で入れ替える | (a) h と m を揃えても、f の人格間の最大差が 0.10 以上（20 本の平均）。(b) 学習した状態を入れ替えると、f の差の 80% 以上が状態と一緒に移る |
| U2 随伴による価値の形成 | 生得の効果を持たない手がかり（`praise`）が、経験史 H1 では後の害の前に、H2 では後の支えの前に現れる。それ以外の統計は同じ | `praise` の条件づけられた価値 C の符号が、H1 で負、H2 で正（20 本中 18 本以上）。`no_conditioning` では差が 0 |
| U3 効果表 M への頑健性 | 効果表 M の各要素を ±30% の乱数で揺らす（種ごとに別）、または結果型の名前を一貫して置換する | U1(a) の f の人格間の順位と、U2 の符号が、元の M のときと 80% 以上の本で一致 |
| U4 解釈 | 曖昧な「案が使われなかった（手柄を取られた／共有された）」を、K 型と R 型が受け止める | K 型の「手柄を取られた」の解釈の重みが、R 型より 0.2 以上大きい（20 本平均）。明確な反証（手柄を共有された）を 8 回与えると、K 型の信念 P(credit_taken) が 30% 以上下がる |
| U5 閉ループ | 共同作業の申し出（optional）を 40 回、各人格に与える | K 型の接近率が R 型より 0.15 以上低い（20 本平均）。回避した申し出からは信念が更新されない（計数が不変） |
| U6 自己増幅なし（拡張） | 全機構を有効にして、同じ経験史を 2000 経験まで延長し、状態に 1e-3 の摂動を入れて共通乱数で再生する | 全ての値が有界（|C| < 10、a の各成分 < 5）。最終状態の摂動の比 ‖Δ最終‖/‖Δ初期‖ が 20 本の中央値で 1 以下 |
| U7 NN の寄与の正直な比較 | T8 の課題を `mlp`、`linear`、`knn1`、`none` で比べる。さらに R/K/X の経験史で、ヘッドが類の事前に与えた重み ρ_h の値を報告する | 判定: mlp の誤差が none の 0.7 倍以下（T8 と同じ）。linear・knn1 との比較は合否にせず、数値を報告する（NN が勝たない場合は「勝たない」と書く） |
| U8 全体の評価の持続 | T4 の課題を、価値の like ではなく全体の予期 Q で測る | m = 8 と 32 で、Q の持続が 0.7 以上、可塑性が 0.7 以上 |
| U9 LLM からの独立 | 状態を保存した後、lexicon を別の座標（回転したベクトル）に替えて復元し、既知の類・概念を評価する | 評価が完全に一致する（埋め込みは状態が所有している） |

**事後変更の規則は SPEC.md と同じです。** 閾値を緩めてはいけません。結果を見て設計や係数を変えた場合は、CHANGELOG に「何を・なぜ・変更前の結果」を書きます。
