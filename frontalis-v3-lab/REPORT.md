## 0. 要約

- 経験 JSON を入力に、評価（予期 Q、感じた価値 f、帰属、解釈、感情の手がかり）→ 学習 → 次の評価と選択、までを実行する最小実装です。保存・復元は完全一致で再現できます。
- 三つの版で作りました。各版の結果は次のとおりです。
  - v3.0: 理念優先の批評で「NPN の最小フレームとは呼べない」と判定されました。受け止め方が学習した状態に依存せず、価値が効果表の写しで、ニューラルネットが使われていなかったためです。
  - v3.1: 受け止め方を学習状態に依存させ、評価基準（関心の重み a、随伴による条件づけ価値 C）を経験から形成し、曖昧な出来事を信念で解釈するようにしました。
  - v3.2: 形成された評価基準が、次の学習（a → 欲求ごとの学習の精度）と行動（C → 予期 → 接近・回避）を変えるようにしました。
- **「人格が形成された」「循環が成立した」とは主張しません。** 前提は三つです。関心の重みの方向（感作）は設計上の仮説で、効果表 M と経験史の世界の確率表は設計者が書いたものです。
- 主張できることは、次の四つに分けて書きます。
  1. 評価基準（a、C）は経験から形成され、受け止め方 f を変えます（U1、U2）。
  2. a と C を入れ替えると、その後の価値の学習が変わります（W1 0.113）。ただしこれは C → 選択 → 経験の経路を含む合計です。a 単独の経路（学習の配分の変化）は 0.040 で、基準 0.05 を単独では満たしません。
  3. C は選ぶ時点の接近確率を変えます（open-loop の差 0.27）。しかし閉ループの 40 回では消去され、W2 は不合格です。「C が持続する回避を作る」とは言えません。
  4. 全機構で自己増幅せず、有界です（W6）。

## 1. 目的と守ったこと

- 人格の正本は NPN の状態です。LLM は意味抽出（この実装では構造化された経験 JSON がその出力に当たる）を担い、数値や感情の判断を出しません。
- **価値ネットの更新目標に、価値ネット自身の出力を入れません。** 価値の教師は欲求の効用変化 Δu（信念の責任 φ で分割）です。条件づけの教師は r + γ·C_frozen（γ < 1）、関心の重みの教師は |Δu| です。
- 信念（結果の予測）と価値（結果の評価）は、別のパラメータと別の誤差で学びます。
- 全人格は同じ初期状態・同じ係数です（`NPN(seed)` に人格を指定する引数はありません）。人格の差は経験史だけから生じます。

## 4. 不合格と原因

1. **U8**: 過去の持続と、設計上正当な二つの性質を混ぜて測っていました。一つは場面の価値の可塑性（良い相手 N と過ごした「音楽の場」そのものが好ましくなる）、もう一つは欲求の状態への依存（安全が満たされると同じリスクの重みが下がる）です。v3.2 の3つの切り替えを全て外すと、改訂2の後の値（0.567 / 0.411）に完全に戻ります。m=8 については、C → Q と mixture を一つずつ外す実験で、それぞれ約 0.05 ずつ下げていました。m=32 はほぼ変わりません（0.411 → 0.419）。
2. **U8′ の可塑性（m=8）0.621**: モデルベースの部分（0.564）で、8 回では信念の更新が遅いためです。
3. **W2**: 選ぶ時点の効果は大きい（学習なしで評価した接近確率の差 0.27）。しかし閉ループでは、受けた申し出で「褒められた後に何も起きない」ため C が消去されます（最初の 20 回の差 0.175 → 最後の 20 回 0.090）。基準は消去を想定していませんでした。
4. **W4(a)**: 結果を見た後の診断では、解釈の重みは credit_taken と credit_shared の**比**で決まるのに、基準は credit_taken の**率**だけを見ていました。経験した比との相関は 0.872 ですが、これは事後に定義した値です。
5. **既知の制約（expectedFailure）**: T2(c)、T1 の元の版（状態の結合）、T9 の元の版。

## 5. オーケストレーターの判断（第8節の問いへの回答）

1. **W4(a)**: 比による定義（相関 0.872）を「事後に定義した参考値」として記録します。判定は不合格のまま変えません。
2. **W2**: 閉ループの 40 回の判定は不合格のまま記録します。選ぶ時点の効果（open-loop の差 0.27）は、仕組みが働いていることの参考値として併記します。消去は仕様の想定漏れで、実装の誤りではありません。基準を変えると事後変更になるので変えません。消去を含む新しい基準は、別の ID で事前に固定し直す必要があります。
3. **a → R_k の効果が小さい（4%）**: 観測雑音 R と新しい個体の事前分散の比に依存します。係数の変更になるので、この版では変えません。「関心が学ぶ量を変える経路はあるが、小さい」と記録します。
4. **knn1 の leave-class-out 版**: 未実施です。現状の結論は「NN は最近傍に勝たない」のままにします。

## 3. 価値の再帰属: 事実の訂正と当時の主観（Y 系）
- 訂正の経験で信念の観測を取り消して直し、当時の f・φ・Δu・感情は台帳に当時のまま残します（Y5 合格）。価値は自動では消さず、確信が高いほど動きにくいカルマン更新を 1 回だけ行います。
- 結果: Y1（信念が対照に近づく割合）は 0.772 で不合格（基準 0.8）。原因は、個体の信念は 0.97〜0.99 まで直るものの、文脈の部分が混合の読み出しに残ることです。Y2（訂正の直後に残る嫌悪の割合）は 0.3025 で、帯の端での合格です。Y3〜Y7 は合格です。
- **批評が指摘した問題:**
  1. 訂正は「新しい経験」として評価されていません（f や安堵は読み出しだけで、学習に入らない）。
  2. 再評価の強さ w_reapp を全人格で共通にしたため、固執の強さが 1 つの定数で決まり、個人差がありません。
