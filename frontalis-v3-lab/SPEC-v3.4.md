## 1. 原則（固定。v3.3 の原則を引き継ぐ）

1. 制御するのは計算機構の破綻であって、形成される人格の非合理性ではない。固執、嫌悪の持続、反証への抵抗、過剰な反省は、それ自体では故障としない（研究思想 §7、SPEC-v3.3 §8.1）。
2. **故障の定義は計算機構の破綻に限る。** 本書では次の 6 つだけを故障とする。F5・F6 と F1 は、研究思想 §7 が挙げる 3 つの例（無関係な経験によって全ての価値が崩れる、学習が飽和して何も変化しない、数値が発散する）にそれぞれ対応する。
   - F1 非有限、または宣言した範囲の外に出る（発散）。
   - F2 学習規則が、自分の定義どおりに動いていない（第 8 節の不変量で検査する）。
   - F3 変化や分岐の原因を、記録から再構成できない。
   - F4 当時の主観的な記録（台帳の当時の f・φ・Δu・感情）が書き換わる。
   - F5 無関係な価値の崩壊: 訂正や後続の経験で、それと無関係な読み出し（第 8 節 RA12）が崩れる。
   - F6 学習の飽和: 経験が与えられても、規則が状態を動かさない（ロックイン。第 8 節 RA8）。
3. 「どう変化すべきか」という正解を固定しない。判定は**変化の向きが人格ごとに違うか、その違いがどの状態から来るか**を問う。どちらの向きが正しいかは問わない。
4. 学習率や係数の大きさが変わっただけでは、人格形成の証拠にしない（研究思想 §6）。主判定（RA1）は変化の**向き**で測る。
5. 判定基準は実装前に固定する。結果を見てから閾値・条件・入力を変えない。変えた場合は別の条件として記録し、元の結果を残す。
6. 性質と呼ぶには経験史への依存を示す必要がある（critique-v3.3 §4(b)）。分類は 3 区分にする。
   - 故障: F1〜F4 のどれかが破れた。
   - 経験史に依存する性質: 値が経験史の条件の間で、事前に定めた幅以上に変わる。
   - **設計仮説と矛盾する性質**: 故障ではないが、経験史に依存しない（設計の意図に反して、全人格で同じ値になる）。再設計の対象として記録し、合格とは呼ばない。

## 3. 不合格と過剰訂正の原因仮説（実装前に固定。Stage 1 で検証する）

ここでの仮説は、結果を見る前の予測として記録する。当たっても外れても、そのまま報告する。検証の結果を見て M1〜M3 の設計（第 4 節）を変えることはしない。変える場合は凍結後の変更として記録する。

- **RC-OC（過剰訂正）**: v3.3 の再評価は、訂正ごとに「現在の予測 + Δ_e」を観測とするカルマン更新を 1 回行う。人モデルには層ごとの過程雑音 q（ind 1e-4 など）があるので、Σ は定常値より下がらず、利得は N によらずほぼ一定になる。そのため、吸収される量はおよそ N × 利得で増える。一方、元の誤帰属が価値に残した量は、追跡型の推定なので N で飽和する。この食い違いで、N が大きいと反対側へ行く。加えて、予測空間の利得は ind だけでなく共有の特徴（people・cls・emb）の分も足される。
  - 予測 RC1: v33 条件で、再評価の更新のときだけ q = 0 にすると、残る割合の N に対する傾きの絶対値が 50% 以上小さくなり、N = 16 でも残る割合が 0 以上になる。
  - 予測 RC2: N ごとの「訂正の予測空間の利得の和」と「吸収された割合 1 − r(N)」の相関が 0.9 以上。
  - 予測 RC3: v33 条件で吸収された変化の 30% 以上が、共有の特徴（people・cls・emb）に乗る。未見の同じ類の相手 A2 への好悪も動く。
- **RC-Y2（個人差がない）**: 再評価の強さは w_reapp という 1 つの定数で、経験史に依存する入力（確信・情報源の信用・現在の評価）が無い。そのため残存の量は、すべての人格でほぼ同じになる。
- **RC-Y1（事実の訂正の不足）**: CHANGELOG N.2 の特定どおり。8 回の訂正を逐次に処理すると、取り消した後の責任 φ が場面（文脈）の側に寄り、文脈の計数が残る。比較の対照は、同じ時点で同じ再推定を受けていない。
- **RC-loop（研究思想 §6 の欠落）**: 訂正の f・安堵・罪悪感は台帳に書かれるだけで、どの状態も変えない。したがって「受け止める直前の評価状態 → 学習の向き」の経路は、構造上存在しない。

## 4. 設計（v3.4 の再評価）

**設計の出発点（v3.3 の Y 系の 2 つの中心的な問題）。**
1. 訂正の主観的評価（f・安堵・罪悪感）が学習に入らない。研究思想 §6 の中核（受け止める直前の評価状態が学習の方向を変える）が、構造上検査されていない。→ M3（第 4.4 節）と RA3。
2. 再評価の強さが、全人格に共通の定数 w_reapp に集約されている。人格の差は経験史から生じる、という原則（README「全人格は同じ初期状態・同じ係数」、研究思想 §5）に反して、残存の量に個人差が出ない。→ M1・M2（第 4.2・4.3 節）と RA4。

既存の学習則は守るべき構造ではない（研究思想 §12）。v3.4 は再評価の規則を置き換えるが、v3.3 の規則は条件 C-v33 として残し、置き換えの理由を本節と第 3 節に残す。内部軸（5 欲求、結果型、効果表 M）と信念の構造は変えない（変えない理由: Y 系の問いは再評価の規則にあり、同時に変えると原因を切り分けられない）。

設定 `reappraisal_mode` を追加する。既定は `"v33"`（v3.3 の挙動をビット単位で保つ）。v3.4 の判定は `"v34"` で行う。既定を変えるかは Stage 6 の報告の後に別に判断する。

### 4.1 訂正を新しい経験として扱う

- v34 では、訂正は時間の中で起きる新しい出来事である。訂正ごとに、
  - 出来事の時計（条件づけの時刻、J の減衰）を 1 進める。想起の掃引の予定は `n_experiences` のままにする（掃引の時期を対照と揃えるため）。
  - 訂正そのものの評価（第 4.4 節）を作り、`exp_log` と台帳に kind = `correction_experience` として追記する。
  - 気分 m を、訂正の驚き δ_c = f_c − tanh(Q_前 / s_f) で、通常の経験と同じ式で更新する。
- 当時の記録（台帳の「経験」の項目と `exp_log` の `original_outcomes`）は変えない（v3.3 の Y5 を引き継ぐ）。
- これは v3.3 の解釈 T.2（訂正は時計を進めない）を v34 で変える、事前に登録した設計の変更である。

### 4.2 M1: 含意された変化を、信用で重み付けて吸収する（w_reapp の置き換え）

訂正 i（参照先の経験 j、情報源 s）について、v3.3 の手順 1（信念の取り消しと追加）の後に次を行う。

1. **含意された変化 D_i。** 経験記録から価値ネットを 2 回再生する（v3.3 の `_replay_values` と同じ規則。h は H0 から、a と φ_o は当時のもの）。V⁽ⁱ⁾ は訂正 1..i を反映した事実、V⁽ⁱ⁻¹⁾ は訂正 i の前の事実で再生する。
   - 参加者 e ごとに D_i(e) = pred_{V⁽ⁱ⁾}(e) − pred_{V⁽ⁱ⁻¹⁾}(e)（人モデル、5 欲求）。
   - 経験 j の文脈と概念について、D_i(sit)（状況モデル）。
   - 2 つの再生の差なので、再生と実際の学習の差（割り引き、想起など）は打ち消される。D_i は、価値ネット自身の出力ではなく、記録された教師だけから決まる。
2. **もっともらしさ LLR_i。** 経験 j を取り消した後の信念 B₋ⱼ で、訂正後の事実と当時の事実の対数尤度の差をとる: LLR_i = log p(y_訂正後 | B₋ⱼ) − log p(y_当時 | B₋ⱼ)。y は、どちらかの版に現れた結果型ごとの、参加者・自分・世界の発生の指示変数（p_person と p_sw のベルヌーイ）。当時の結果が曖昧だった場合は、当時の解釈の重み w_out を柔らかい指示変数に使う。事実のモデル（信念）だけを使い、価値ネットの出力を使わない。
3. **情報源の信用 κ̄_s = α_s / (α_s + β_s)。** 情報源ごとに Beta(1, 1) から始める（全人格で共通の初期値）。更新は M2（第 4.3 節）だけで起きる。
4. **吸収率 g_i = σ(logit κ̄_s + LLR_i) ∈ (0, 1)。** 経験史（κ̄_s を作った検証の経験、LLR_i を作った信念）だけから決まる。人格ごとに違いうる。
5. **吸収。** 対象（各 e と状況）ごとに Δ = g_i D_i を、予測をちょうど Δ だけ動かす最小の変化として W に加える。欲求 k ごとに W_k += Σ_k z (zᵀ Σ_k z)⁻¹ Δ_k。変化は事後共分散 Σ に沿って、個体・類・埋め込みの特徴に配分される。Σ が経験史で違えば、同じ Δ でも配分（＝向き）が違う。Σ は変えず、過程雑音も足さない。
6. 吸収されなかった分 (1 − g_i) D_i を「未吸収の残り」として台帳に記録する（状態ではなく説明のための記録）。
7. 条件づけ C と関心の重み a は変えない（v3.3 と同じ。感情的な痕跡は新しい随伴でしか変わらない）。
8. 台帳に記録するもの: D_i、LLR_i、κ̄_s、g_i、対象ごとの ΔW、未吸収の残り。

g_i ∈ (0, 1) なので、吸収チャネルだけで含意された変化を超えることは構造上ない。過剰訂正が起きた場合、それは記録された他の経路（第 4.4 節の解釈の変化、後続の経験）から来たことになり、台帳から再構成できなければ F2/F3 の故障とする。

### 4.3 M2: 情報源の信用を経験から形成する

- 訂正 i の対象 e が、訂正の後に初めて、曖昧でない結果を伴う学習した経験に参加者として現れたとき、1 回だけ検証する。
- LLR_ver = log p(y_新 | 現在の信念) − log p(y_新 | 訂正 i の観測を当時の事実に戻した信念)。戻した信念は写しの上で作り、本体は変えない。
- 情報源 s の Beta を α_s += σ(LLR_ver)、β_s += 1 − σ(LLR_ver) で更新する。訂正 1 回につき検証は最大 1 回。
- κ̄_s が変わるのはこの検証の出来事だけ（不変量 H3）。

### 4.4 M3: 訂正の主観的評価が、次の学習に作用する経路

訂正ごとに、現在の状態から訂正の評価を作る（v3.3 の読み出し T.8 を拡張する）。

- Q_前・Q_後: 参照先の状況の予期（吸収の前と後）。f_c = tanh((Q_後 − Q_前) / s_f + β m)。安堵 = min(1, f_c)（f_c > 0 かつ Q_前 < 0 のとき）。
- **自分の読み違いの割合 own_i** = 訂正で変わった結果のうち、当時の型を人格自身の解釈が決めていた（曖昧な結果で、解釈の最大の型が訂正後の型と違う）ものの割合。報告の誤り（曖昧でない誤った結果）なら 0。
- **罪悪感 guilt_i** = own_i · tanh(Σ_{e: like_前(e) < 0} max(like_後(e) − like_前(e), 0) / s_f)。like は現在の a で重み付けた好悪で、現在の評価状態に依存する。
- **自分の解釈への信頼 τ。** 類 × 文脈ごとに τ ∈ [τ_min, 1]、初期値 1、τ_min = 0.2、η_τ = 0.5（全人格で共通）。読み違えた結果の行為者の類と文脈について、τ ← τ_min + (τ − τ_min)(1 − η_τ guilt_i)。τ が変わるのは罪悪感の出来事だけ（不変量 H3）。
- **次の学習への作用。** 曖昧な結果の解釈の重みを w_I ∝ q_LLM(I) · P_belief(I | actor, context)^τ にする（τ = 1 で v3.3 と同じ）。罪悪感を経験した人格は、その類と文脈で自分の事前の読みに頼る程度が下がる。どちらの型の解釈が下がるかは、その人格の信念の内容（経験史）で決まる。解釈の重みは次の経験の教師（Δu の φ 分割）を変えるので、**評価状態 → 罪悪感 → τ → 次の経験の受け止め方 → 次の学習**という循環ができる。
- 方向を固定しない。罪悪感が自分の読みへの信頼を下げる、という形は設計仮説である（メタ認知的な確信の較正に類する。文献の照合は未了。第 12 節の §8 の表を参照）。代わりの形（信頼を変えない τ ≡ 1）は条件 A-τ-off として比較する。

### 4.5 補題 1 の限定的な例外（明示）

v3.3 までは「価値ネット自身の出力は、どの更新の目標にも入らない」（docs/04 補題 1）を守ってきた。v34 では次の 1 本の経路だけを例外として許し、検査する。

- 経路: 価値ネットの出力（like、Q）→ 罪悪感 → τ → 解釈の重み → 後の経験の教師。
- 有界性の根拠: τ は [τ_min, 1] の中で単調に下がるだけで、価値ネットの出力で上がることはない。そのため、この経路は正帰還の循環を作れない。
- M1 の g_i は信念（事実のモデル）だけ、D_i は記録された教師だけから決まり、価値ネットの出力を使わない。
- 例外を設けること自体が、ユーザーの判断を要する設計の選択である（第 13 節の J1）。

## 5. 経験史と乱数種（実装前に列挙して固定）

### 5.1 乱数種

v3.3 は、テストに種 0〜19（`tests/helpers.py` の SEEDS）、ベンチマークに 0〜19、診断に 0〜9 を使った。v3 ラボの全 `.py` で 3400〜3599 の数値は使われていない（2026-10-16 に grep で確認）。

| 用途 | 種 | 規則 |
| --- | --- | --- |
| 評価 | **3400〜3439（40 本）** | 判定にだけ使う。実装中は実行しない |
| Shapley 分解（RA2(b)） | 3400〜3419（評価の部分集合） | 計算量のため |
| 変異テスト（RA11） | **3450〜3459（10 本）** | 評価より前に実行する |
| 開発・スモークテスト | **3490〜3499（10 本）** | 実装中に数値を見てよい。判定には使わない |
| ブートストラップ | 乱数 `default_rng([34990])`、10,000 回 | 固定 |

## 7. 測定

### 7.1 読み出しベクトル R（8 成分。すべて学習しない評価）

r1 like(A)、r2 like(A2)、r3 like(O)（エンティティプローブ、文脈 project_meeting）、r4 P(credit_taken | A)、r5 P(credit_taken | A2)（`p_person`）、r6 曖昧な A の出来事の「取られた」の解釈の重み、r7 同じく A2、r8 状況 {project_meeting, authorship, A と O} の予期 Q。

### 7.2 効果の定義

- 訂正の因果効果 CE = R(COR → FOL | 条件) − R(訂正なし → FOL)。同じ種・同じ履歴の枝どうしで差をとるので、背景の違いそのものは打ち消される。
- 直後の効果 CE_imm = R(COR の直後) − R(訂正なしの枝の同じ時点)。
- 後続の学習 L_fol(条件) = R(FOL の後) − R(COR の直後)。
- 残る割合 r = d_post / d_pre。d_pre = like(A)_誤帰属 − like(A)_対照（COR の直前）、d_post = 同じ差の COR の直後。

### 7.3 正規化と統計

- 各成分を、主要因計画の C-v34 の全個体の CE の標準偏差で割る（全条件で同じ値を使う）。標準偏差が 1e-9 未満の成分は除き、除いたことを記録する。
- 分析の単位は種ごとの個体。比率は Wilson の信頼区間、平均・余弦は種を単位にしたブートストラップのパーセンタイル区間（10,000 回）。主判定 RA1・RA3 は Bonferroni で 97.5% 区間、それ以外は 95%。
- 主要因計画: ERR 2 × BG 3 × SRC 3 = 18 セル × 評価の種 40 = 720 個体（N = 8、M = 0）。
- N の掃引: N ∈ {2, 4, 8, 12, 16} × M ∈ {0, 4} × BG 3 × ERR 2 × SRC-none × 40 種 = 2,400 個体（条件 C-v34、C-v33、diag-q0、C-retro、C-nocorr）。

### 7.4 状態の群（RA2(b) の Shapley 分解）

G1 価値（人・状況の W と Σ、経験記録 `exp_log`）、G2 信念（計数・記録・ヘッド）、G3 関心の重み a、G4 条件づけ C、G5 v3.4 の状態（κ の Beta、τ）、G6 欲求の状態 h と気分 m。入れ替えは、同じ種で特徴の名前の並びが完全に一致する 2 個体の間だけで行う。一致しない組は除き、その数を報告する。

**結論の規則（事前に固定）**
- RA1 が不合格: 「同じ訂正で人格ごとに向きが違う学習」は、この機構と経験史の範囲では示せなかった、と書く。閾値も経験史も変えない。
- RA3 が不合格: 「主観的評価 → 次の学習」の経路は、構造としてはあるが効果が小さい（または無い）と書く。
- RA1 が C-v33 でも合格: 向きの違いは既存の階層カルマンの Σ から来ていて、v3.4 の機構の寄与ではない、と書く。
- どの判定でも、「人格が形成された」「循環が成立した」とは書かない（v3.2 批評の条件 (iii) を引き継ぐ）。書けるのは、各判定が示した範囲だけである。

### §9 歴史上の人物
