## 1. 原則（固定。v3.3 の原則を引き継ぐ）

1. 制御するのは計算機構の破綻であって、形成される人格の非合理性ではない。固執、嫌悪の持続、反証への抵抗、自己正当化、過剰な反省、過剰な訂正は、それ自体では故障としない（研究思想 §7、SPEC-v3.3 §8.1）。
2. **故障の定義は計算機構の破綻に限る。** 本書では次の 6 つだけを故障とする。F1・F5・F6 は、研究思想 §7 が挙げる 3 つの例（数値が発散する、無関係な経験によって全ての価値が崩れる、学習が飽和して何も変化しない）にそれぞれ対応する。
   - F1 非有限、または宣言した範囲の外に出る（発散）。
   - F2 学習規則が、自分の定義どおりに動いていない（第 8 節の不変量で検査する）。
   - F3 変化や分岐の原因を、記録から再構成できない。
   - F4 当時の主観的な記録（台帳の当時の f・φ・Δu・感情）が書き換わる。
   - F5 無関係な価値の崩壊（第 8 節 RA12）。
   - F6 学習の飽和: 経験や訂正が与えられても、規則が状態を動かさない（第 8 節 RA8）。
3. 「どう変化すべきか」という正解を固定しない。判定は**変化の向きが人格ごとに違うか、その違いがどの状態から来るか**を問う。どちらの向きが正しいかは問わない。
4. 学習率や係数の大きさが変わっただけでは、人格形成の証拠にしない（研究思想 §6）。主判定（RA1〜RA3）はすべて変化の**向き**で測る。
5. 判定基準は実装前に固定する。結果を見てから閾値・条件・入力を変えない。変えた場合は別の条件として記録し、元の結果を残す。
6. 性質と呼ぶには経験史への依存を示す必要がある（critique-v3.3 §4(b)）。分類は 3 区分にする。
   - 故障: F1〜F6 のどれかが破れた。
   - 経験史に依存する性質: 値が経験史の条件の間で、事前に定めた幅以上に変わる。
   - **設計仮説と矛盾する性質**: 故障ではないが、経験史に依存しない（設計の意図に反して、全人格で同じ値になる、または境界値が挙動を決めている）。再設計の対象として記録し、合格とは呼ばない。
7. **統計の単位は種（評価では n = 40）。** 同じ種の複数のセル（背景・情報源・誤りの由来）は経験史の乱数を共有するので、独立な標本として数えない。セルをまとめる集計は、先に種ごとに平均してから種の間で行う。

## 3. 不合格と過剰訂正の原因仮説（実装前に固定。Stage 1 で、評価に使わない診断用の種で検証する）

ここでの仮説は、結果を見る前の予測として記録する。当たっても外れても、そのまま報告する。検証の結果を見て M1〜M3 の設計（第 4 節）を変えることはしない。

- **RC-OC（v3.3 の過剰訂正）**: v3.3 の再評価は、訂正ごとに「現在の予測 + Δ_e」を観測とするカルマン更新を 1 回行う。人モデルには層ごとの過程雑音 q（ind 1e-4 など）があるので、Σ は定常値より下がらず、利得は N によらずほぼ一定になる。そのため、吸収される量はおよそ N × 利得で増える。一方、元の誤帰属が価値に残した量は、追跡型の推定なので N で飽和する。この食い違いで、N が大きいと反対側へ行く。加えて、予測空間の利得は ind だけでなく共有の特徴（people・cls・emb）の分も足される。
  - 予測 RC1: C-v33 で、再評価の更新のときだけ q = 0 にすると、残る割合の N に対する傾きの絶対値が 50% 以上小さくなり、N = 16 でも残る割合が 0 以上になる。
  - 予測 RC2: N ごとの「訂正の予測空間の利得の和」と「吸収された割合 1 − r(N)」の相関が 0.9 以上。
  - 予測 RC3: C-v33 で吸収された変化の 30% 以上が、共有の特徴（people・cls・emb）に乗る。未見の同じ類の相手 A2 への好悪も動く。
- **RC-Y2（個人差がない）**: 再評価の強さは w_reapp という 1 つの定数で、経験史に依存する入力（確信・情報源の信用・現在の評価）が無い。
- **RC-Y1（事実の訂正の不足）**: CHANGELOG N.2 の特定どおり。8 回の訂正を逐次に処理すると、取り消した後の責任 φ が場面（文脈）の側に寄り、文脈の計数が残る。比較の対照は、同じ時点で同じ再推定を受けていない。
- **RC-loop（研究思想 §6 の欠落）**: 訂正の f・安堵・罪悪感は台帳に書かれるだけで、どの状態も変えない。「受け止める直前の評価状態 → 学習の向き」の経路は、構造上存在しない。

## 4. 設計（v3.4 の再評価）

**設計の出発点（v3.3 の Y 系の 2 つの中心的な問題）。**
1. 訂正の主観的評価（f・安堵・罪悪感）が学習に入らない。研究思想 §6 の中核（受け止める直前の評価状態が学習の方向を変える）が、構造上検査されていない。→ M3（第 4.4 節）と RA3。
2. 再評価の強さが、全人格に共通の定数 w_reapp に集約されている。人格の差は経験史から生じる、という原則（README「全人格は同じ初期状態・同じ係数」、研究思想 §5）に反して、残存の量に個人差が出ない。→ M1・M2（第 4.2・4.3 節）と RA4。

既存の学習則は守るべき構造ではない（研究思想 §12）。v3.4 は再評価の規則を置き換えるが、v3.3 の規則は条件 C-v33 として残し、置き換えの理由を本節と第 3 節に残す。内部軸（5 欲求、結果型、効果表 M）と信念の構造は変えない（変えない理由: Y 系の問いは再評価の規則にあり、同時に変えると原因を切り分けられない）。全人格に共通の定数（η_τ、τ の境界、Beta(1, 1)、λ_g）は置くが、これは v3.3 以来の「全人格は同じ初期状態・同じ係数から始まり、差は経験史だけから生じる」という設計に従う。判定はこれらの定数の値ではなく、経験史による違いを問う。

設定 `reappraisal_mode` を追加する。既定は `"v33"`（v3.3 の挙動をビット単位で保つ）。v3.4 の判定は `"v34"`（と変種 `"v34_or"`）で行う。既定を変えるかは Stage 5.5 の後に別に判断する。

### 4.1 訂正を新しい経験として扱う

- v34 では、訂正は時間の中で起きる新しい出来事である。訂正ごとに、
  - 出来事の時計（条件づけの時刻、J の減衰）を 1 進める。想起の掃引の予定は `n_experiences` のままにする（掃引の時期を対照と揃えるため）。
  - 訂正そのものの評価（第 4.4 節）を作り、`exp_log` と台帳に kind = `correction_experience` として追記する。
  - 気分 m を、訂正の驚き δ_c = f_c − tanh(Q_前 / s_f) で、通常の経験と同じ式（m ← 0.8 m + 0.2 δ）で更新する。
- 当時の記録（台帳の「経験」の項目と `exp_log` の `original_outcomes`）は変えない（v3.3 の Y5 を引き継ぐ）。
- これは v3.3 の解釈 T.2（訂正は時計を進めない）を v34 で変える、事前に登録した設計の変更である。この変更だけの効果を、条件 A-clock-off（訂正が時計と気分を進めない v34）で分離する。

### 4.2 M1: 含意された変化を、信用ともっともらしさで重み付けて吸収する（w_reapp の置き換え）

訂正 i（参照先の経験 j、情報源 s）について、v3.3 の手順 1（信念の取り消しと追加）の後に次を行う。

1. **含意された変化 D_i。** 経験記録から価値ネットを 2 回再生する（v3.3 の `_replay_values` と同じ規則。h は H0 から、a と φ_o は当時のもの）。V⁽ⁱ⁾ は訂正 1..i を反映した事実、V⁽ⁱ⁻¹⁾ は訂正 i の前の事実で再生する。
   - 参加者 e ごとに D_i(e) = pred_{V⁽ⁱ⁾}(e) − pred_{V⁽ⁱ⁻¹⁾}(e)（人モデル、5 欲求）。
   - 経験 j の文脈と概念について、D_i(sit)（状況モデル）。
   - 2 つの再生の差なので、再生と実際の学習の差（割り引き、想起など）は打ち消される。D_i は、価値ネット自身の出力ではなく、記録された教師だけから決まる。
2. **もっともらしさ LLR_i。** 経験 j を取り消した後の信念 B₋ⱼ で、訂正後の事実と当時の事実の対数尤度の差をとる: LLR_i = log p(y_訂正後 | B₋ⱼ) − log p(y_当時 | B₋ⱼ)。y は、どちらかの版に現れた結果型ごとの、参加者・自分・世界の発生の指示変数（p_person と p_sw のベルヌーイ）。当時の結果が曖昧だった場合は、当時の解釈の重み w_out を柔らかい指示変数に使う。事実のモデル（信念）だけを使い、価値ネットの出力を使わない。
3. **情報源の信用 κ̄_s = α_s / (α_s + β_s)。** 情報源ごとに Beta(1, 1) から始める。更新は M2（第 4.3 節）だけで起きる。
4. **吸収率。** 主条件 C-v34 では g_i = σ(logit κ̄_s + LLR_i) ∈ (0, 1)。変種 C-OR では上限を置かない（第 4.6 節）。
5. **吸収。** 対象（各 e と状況）ごとに Δ = g_i D_i を、予測をちょうど Δ だけ動かす最小の変化として W に加える。欲求 k ごとに W_k += Σ_k z (zᵀ Σ_k z)⁻¹ Δ_k。変化は事後共分散 Σ に沿って、個体・類・埋め込みの特徴に配分される。Σ が経験史で違えば、同じ Δ でも配分（＝向き）が違う。Σ は変えず、過程雑音も足さない。
6. 吸収されなかった分 (1 − g_i) D_i を「未吸収の残り」として台帳に記録する。
7. 条件づけ C と関心の重み a は変えない（v3.3 と同じ。感情的な痕跡は新しい随伴でしか変わらない）。
8. 台帳に記録するもの: D_i、LLR_i、κ̄_s、g_i、対象ごとの ΔW、未吸収の残り。

C-v34 では g_i < 1 なので、吸収の経路だけで含意された変化を超えることはない。これは C-v34 という 1 つの条件の性質であり、過剰な反省や過剰な訂正を研究から締め出すものではない。過剰な訂正は C-OR（第 4.6 節）で性質として扱う。

### 4.3 M2: 情報源の信用を経験から形成する

- 訂正 i の対象 e が、訂正の後に初めて、曖昧でない結果を伴う学習した経験に参加者として現れたとき、1 回だけ検証する。
- LLR_ver = log p(y_新 | 現在の信念) − log p(y_新 | 訂正 i の観測を当時の事実に戻した信念)。戻した信念は写しの上で作り、本体は変えない。
- 情報源 s の Beta を α_s += σ(LLR_ver)、β_s += 1 − σ(LLR_ver) で更新する。訂正 1 回につき検証は最大 1 回。
- κ̄_s が変わるのはこの検証の出来事だけ（不変量 H3）。計数が増えるほど 1 回の検証で動く量は小さくなる（信用の固定化）。固定化は性質として報告し、規則が働いているか（反対向きの検証で κ̄ が動くか）だけを RA8(d) で検査する。
- M2 は規範的なベイズ更新である。評価状態による検証の歪み（恨みや確証の偏り）は入れない。理由: M3 の状態依存を、M2 の状態依存と混ぜずに識別するため。歪みを持つ変種は後続の候補とする（草稿の改訂記録）。

### 4.4 M3: 訂正の主観的評価が、次の学習に作用する経路（双方向）

訂正ごとに、現在の状態から訂正の評価を作る（v3.3 の読み出し T.8 を拡張する）。like は現在の a で重み付けた好悪で、like_前・like_後は吸収の前と後。

- Q_前・Q_後: 参照先の状況の予期。f_c = tanh((Q_後 − Q_前) / s_f + β m)。安堵 = min(1, f_c)（f_c > 0 かつ Q_前 < 0 のとき）。
- **自分の読み違いの割合 own_i** = 訂正で変わった結果のうち、当時の型を人格自身の解釈が決めていた（曖昧な結果で、解釈の最大の型が訂正後の型と違う）ものの割合。報告の誤り（曖昧でない誤った結果）なら 0。
- **罪悪感 guilt_i**（誤って嫌っていた）= own_i · tanh(Σ_{e: like_前(e) < 0} max(like_後(e) − like_前(e), 0) / s_f)。
- **後悔 regret_i**（誤って好んでいた）= own_i · tanh(Σ_{e: like_前(e) > 0} max(like_前(e) − like_後(e), 0) / s_f)。
- **自己正当化 defend_i** = own_i · (1 − g_i) · tanh(Σ_e Σ_k a_k \|D_i(e)_k\| / s_f)。自分の読みを否定する訂正のうち、自分が受け入れなかった分（信用が低い、または他の知識と合わない）が大きいほど、訂正は自分の読みへの挑戦として受け止められる。
- **自分の解釈への信頼 τ**（類 × 文脈ごと、初期値 1）。読み違えた結果の行為者の類と文脈について、
  log τ ← clip(log τ + η_τ (defend_i − guilt_i − regret_i), log(1/3), log 3)、η_τ = 0.5。
  - 受け入れた訂正（罪悪感・後悔）は τ を下げ（自分の事前の読みに頼らなくなる）、受け入れなかった訂正（自己正当化）は τ を上げる（自分の読みに固執する）。**どちらの向きになるかは、g_i（情報源の信用ともっともらしさ ＝ 経験史）と like の変化（現在の評価状態）で決まり、開発者は向きを決めない。**
  - τ が変わるのは訂正の出来事だけ（不変量 H9）。1 回の変化は \|Δ log τ\| ≤ η_τ。
- **次の学習への作用。** 曖昧な結果の解釈の重みを w_I ∝ q_LLM(I) · P_belief(I | actor, context)^τ にする（τ = 1 で v3.3 と同じ）。τ < 1 では事前の読みへの依存が弱まり、τ > 1 では強まる。どちらの型の解釈が増えるかは、その人格の信念の内容（経験史）で決まる。解釈の重みは次の経験の教師（Δu の φ 分割）を変えるので、**評価状態 → 訂正の主観的評価 → τ → 次の経験の受け止め方 → 次の学習**という循環ができる。
- τ は類 × 文脈ごとの状態なので、A と A2（同じ類、同じ文脈）には同じ τ が効く（設計による）。A と A2 の読み出しの差（r6 と r7）は信念の個体・類の違いから来る。τ の鍵の特異性は、別の文脈での A2 の読み出し r9 で点検する。
- **安堵と f_c の経路。** 安堵と f_c は気分 m だけに入る（第 4.1 節）。v3.3 の構造では、気分は f と驚き δ（読み出し）にしか入らず、どの学習の教師にも入らない。したがって **f_c と安堵が学習に与える効果は、構造上ゼロである。** これを、気分だけを切る条件 clamp-mood で後続の学習がビット単位で変わらないこと（RA3(4)）で確かめる。気分から学習への経路（例: 気分に一致した解釈）を足さない理由: (1) 気分は毎経験で更新されるので、その経路は毎経験で働く「価値ネットの出力 → 教師」の循環になり、研究思想 §6 が警告する自己評価の増幅を、訂正の出来事の数で抑えられない。(2) τ の経路の因果的な識別を保つ。(3) 気分に一致した判断の文献は未照合。後続の候補とする。

### 4.5 補題 1 の限定的な例外（明示。コーディネーターの判断 J1: 受諾、τ は双方向・有界）

v3.3 までは「価値ネット自身の出力は、どの更新の目標にも入らない」（docs/04 補題 1）を守ってきた。v34 では次の経路だけを例外として許し、検査する。

- 経路: 価値ネットの出力（like）→ 罪悪感・後悔・自己正当化 → τ → 解釈の重み → 後の経験の教師。
- τ は上下に動くので、この経路は循環を作りうる（例: 自己正当化 → τ が上がる → 事前の読みをさらに強く使う → 好悪がさらに負になる → 次の訂正でさらに自己正当化）。この循環は §7 の固執として研究の対象であり、故障ではない。
- 有界性の根拠: τ は訂正の出来事でだけ変わり（回数は訂正の数で上限がある）、1 回の変化は η_τ 以下、τ ∈ [1/3, 3]。訂正の間は τ が一定なので、通常の経験の学習は補題 1 のままである。
- M1 の g_i は信念だけ、D_i は記録された教師だけから決まり、価値ネットの出力を使わない（C-OR の G_e を除く。第 4.6 節）。

### 4.6 変種 C-OR: 上限のない吸収（過剰な反省）

- g_i^OR = σ(logit κ̄_s + LLR_i) · (1 + λ_g G_e)。G_e は対象 e についての受け入れた訂正の罪悪感と後悔の累積（訂正のたびに加算し、減らさない）。λ_g = 0.25。g に固定の上限は置かない（罪悪感を伴う訂正が続くほど大きくなりうる）。
- g > 1 では、含意された変化を超えて吸収する（過剰な反省・償いの方向）。これは故障ではなく、**経験史に依存する性質として**扱う（RA14）。故障とするのは、F1（非有限、\|W\| ≤ 10 の範囲外）、F2（g と吸収の不一致）、F3（台帳から再構成できない）だけ。
- C-OR では、価値の出力（like）が G_e を通じて吸収量にも入る（補題 1 の例外の 2 本目）。C-OR は主条件ではなく変種なので、主判定には使わない。

## 7. 測定

### 7.1 読み出しベクトル R（9 成分。すべて学習しない評価）

r1 like(A)、r2 like(A2)、r3 like(O)（エンティティプローブ、文脈 project_meeting）、r4 P(credit_taken | A)、r5 P(credit_taken | A2)（`p_person`）、r6 曖昧な A の出来事の「取られた」の解釈の重み（project_meeting）、r7 同じく A2（project_meeting）、r8 状況 {project_meeting, authorship, A と O} の予期 Q、r9 曖昧な A2 の出来事の「取られた」の解釈の重み（music_session）。

価値の部分 V = {r1, r2, r3, r8}、予測と受け止め方の部分 P = {r4, r5, r6, r7, r9}。

### 7.2 効果の定義

- 訂正の因果効果 CE = R(COR → FOL | 条件) − R(訂正なし → FOL)。同じ種・同じ履歴の枝どうしで差をとるので、背景の違いそのものは打ち消される。
- 直後の効果 CE_imm = R(COR の直後) − R(訂正なしの枝の同じ時点)。
- 後続の学習 L_fol(条件) = R(FOL の後) − R(COR の直後)。
- τ の経路の効果 Δτ_b = L_fol(C-v34) − L_fol(clamp-τ)。背景 b ごと。
- 残る割合 r = d_post / d_pre。d_pre = like(A)_誤帰属 − like(A)_対照（COR の直前）、d_post = 同じ差の COR の直後。

### 7.3 正規化と統計

- **正規化**: 各成分を、主要因計画の全個体の **COR の直前の R** の標準偏差で割る。COR の直前の状態は全条件で同じなので、条件に依存しない尺度になる（草稿 1 は C-v34 の CE の標準偏差で割っていた）。標準偏差が 1e-9 未満の成分は除き、除いたことを記録する。
- **単位は種（n = 40）**。各セルの値は種ごとの 1 個体。2 つの背景の比較は、同じ種の対で行う。
- 平均と余弦の区間は、種を単位にしたブートストラップのパーセンタイル区間（10,000 回）。比率は種を単位にした Wilson の区間。
- **主判定 RA1・RA2・RA3 は Bonferroni で 98.33% 区間**（α = 0.05 / 3）。それ以外は 95%。
- **「向きが違う」の定義（RA1〜RA3 で共通）**: 2 つの平均ベクトル μ と μ′ について、(a) ある成分で μ と μ′ の符号が逆で、両方の区間が 0 を含まない、または (b) cos(μ, μ′) の区間の上限が 0.5 未満。
- 主要因計画: ERR 3（interp、report、report-x）× BG 3 × SRC 3 = 27 セル × 評価の種 40 = 1,080 個体（N = 8、M = 0）。
- N の掃引: N ∈ {2, 4, 8, 12, 16} × M ∈ {0, 4} × BG 3 × ERR 3 × SRC-none × 40 種 = 3,600 個体。各個体を C-v34、C-OR、C-v33、C-retro、C-nocorr の 5 条件で実行する（計 18,000 回の実行）。

### 7.4 状態の群（RA2 の報告。Shapley 分解）

G1 価値（人・状況の W と Σ）、G2 信念と経験記録（計数・記録・ヘッド・`exp_log`）、G3 関心の重み a、G4 条件づけ C、G5 v3.4 の状態（κ の Beta、τ）、G6 欲求の状態 h と気分 m。草稿 1 では `exp_log` を G1 に入れていたが、val-swap（信念と記録を固定）と揃えるため G2 に移した。

**結論の規則（事前に固定）**
- RA1 が不合格: 「同じ訂正で人格ごとに向きが違う学習」は、この機構と経験史の範囲では示せなかった、と書く。閾値も経験史も変えない。
- RA1 が合格し RA2 が不合格: 向きの違いは、価値の評価状態ではなく、信念・経験記録（何を事実と受け止めたか）から来る、と書く。
- RA3 が不合格: 「主観的評価 → 次の学習」の経路は、構造としてはあるが、人格ごとに向きを変えるほどには働いていない、と書く。
- RA1 が C-v33 または A-τ-off でも合格: その向きの違いは M3 の寄与ではない（既存の階層カルマンの Σ、または M1 の寄与）と書く。
- どの判定でも、「人格が形成された」「循環が成立した」とは書かない（v3.2 批評の条件 (iii) を引き継ぐ）。書けるのは、各判定が示した範囲だけである。

## 10. 後続の予告: X 系（NN の役割）

### 12.1 Stage 5.5: §4 の LLM を介した検査（定義を今決める。実行は Stage 5 の後、既定モードの変更の判断と X 系の事前登録より前）

- 対象: 評価の種 3400〜3439 の ERR-interp・SRC-none の BG 3 セルから、COR の直後の状態。

- プロンプト: 1 つの固定の文面（場面の説明、ツールの返り値、「申し出を受けるか、理由を 2 文で」）を、全ての状態で同一にする。温度 0。モデルは実行時にユーザーが許可したもの（API の使用には、その時点でユーザーの許可が要る）。
- 測定: 入れ替えの前後で、LLM の選択（受ける／受けない）が変わった割合と、その変化が NPN の接近の確率の変化と同じ向きか。言語の質は採点しない。結論は「NPN の状態の違いが、同一の LLM の判断に伝わったか」に限り、「人格」「形成」とは書かない。
- 判定: 報告のみ。予定の呼び出し数は 40 種 × 3 背景 × 2 状態 = 240 回。
