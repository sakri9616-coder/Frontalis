# frontalis-v3-lab: NPN 最小実装 v3.3

経験によって人格が形成される外部ニューラルネットワーク（NPN）の、**実際に動く最小実装**です。
経験の入力 → 評価 → 学習 → 次の評価への反映、までを実行し、テストで検証します。

- 仕様: [`SPEC.md`](SPEC.md)（v3.0。判定基準 T1〜T10）、[`SPEC-v3.1.md`](SPEC-v3.1.md)（v3.1 の差分。判定基準 U1〜U9）、[`SPEC-v3.2.md`](SPEC-v3.2.md)（v3.2 の差分。判定基準 W1〜W7）、
  [`SPEC-v3.3.md`](SPEC-v3.3.md)（v3.3 の差分。第 1 節 NN の再検証 X1〜X4 と第 4 節 消去 E1〜E9 を実装済み。第 2 節 価値の再帰属 Y、第 3 節 選択による関心学習 Z は未実装）。いずれも実装前に固定
- 設計の根拠: `docs/04-learning-mechanisms.md`（精度配分・階層型フレーム v3）
- 結果: [`REPORT.md`](REPORT.md)　仕様からの変更の記録: [`CHANGELOG.md`](CHANGELOG.md)

## 目的

研究思想の中心は、次の循環です。

1. 既存の人格が経験を評価する。
2. その評価と経験した結果によって人格が更新される。
3. 更新後の人格が、次の経験を以前とは異なる仕方で受け止める。

この実装は、その循環を最小の部品で作り、次を満たすかを調べるためのものです（研究思想 第1・4・6節）。

- 人格の正本は NPN の状態です。入力は、LLM の意味抽出の出力に相当する**構造化された経験 JSON**で、数値や感情の判断は LLM に任せません。
- **価値ネットの更新目標に、価値ネット自身の出力を入れません。** 教師は「欲求の効用変化 Δu を、信念の責任 φ で分けたもの」だけです（docs/04 補題1）。
- 結果の予測（**信念**）と結果の評価（**価値**）は、別のパラメータ・別の誤差で学びます。
- 人格の差は、ラベルや初期値ではなく**経験史**から生じます。全人格は同じ初期状態・同じ係数から始まります（`NPN(seed)` に人格を指定する引数はありません）。

### v3.1 で変わったこと

v3.0 は、理念を優先する批評で「NPN の最小フレームとは呼べない」と判定されました（受け止め方 f が学習状態に依存しない／価値が効果表 M の写しになっている／ニューラルネットが使われていない）。
v3.1 は、自己増幅を起こさずに、**経験が評価基準そのもの（何をどれだけ良い・悪いと感じるか）を変え、その変わった基準が次の経験の受け止め方と学習を変える**ことを目指します。

| 節 | 変更 | 何が変わるか |
| --- | --- | --- |
| 1.1 | 欲求の関心の重み **a** | 人生で大きく揺さぶられた欲求ほど重くなる（感作）。感じた価値・MB 価値・好悪の読み出しを重み付ける |
| 1.2 | 条件づけられた価値 **C**（TD(0)） | 生得の効果を持たない手がかり（`praise` など）が、経験の随伴関係から価値を得る |
| 1.3 | 受け止め方 **f** | `f = tanh(((Σ a_k Δu_k) + λ_C ΣC + η_ref(Σ a_k Δu_k − Q)) / s_f + β m)`。学習した状態に依存する |
| 1.4 | 曖昧な結果の**解釈** | `w_I ∝ q_LLM(I) · P_belief(I \| actor, context)`。同じ出来事を、人格の信念で違うように受け止める |
| 1.5 | 事前ヘッドの**実際の利用** | 50 件の解禁を廃止し `prior_cls = ρ_h·head + (1−ρ_h)·m_gen`、ρ_h = n/(n+30)。基線（linear / knn1 / none） |
| 1.6 | **埋め込みは NPN が所有** | 初めて現れた語の埋め込みを状態に写して保存。LLM や埋め込みモデルを替えても既存の人格の座標は変わらない |
| 1.7 | **κ_e の経験ベイズ推定**（改訂: 類 × 結果型ごと） | 「上位の層の有効標本数は相手の数」を固定の κ でなく推定で。どの型が個体間でばらつくかは型ごとに違う（Kemp et al. 2007） |
| 1.8 | **確率的な経験史の生成器** | 乱数種 20 本が独立な標本になる（`data/make_histories.py`） |
| 改訂 2 | **想起・再帰属**（オーケストレーター承認） | 責任 φ を経験の時点で凍結せず、K_r = 10 経験ごとに信念の帰属をやり直す（docs/04 第5節 手順7）。価値ネットの教師の分割は再帰属しない（非対称） |

### v3.2 で変わったこと

v3.1 への理念優先の再批評の判定は「限定つきで可」でした。期待・解釈・選択の軸では循環が動きますが、**評価基準（関心の重み a、条件づけ価値 C）が次の学習や行動を変える経路がない**ため、
研究思想 §6 の中心仮説「学習の方向は、その経験を受け止める直前の評価状態によって変化する」が評価基準の軸では成り立っていませんでした。v3.2 はこの経路を作ります。

| 節 | 変更 | 何が変わるか |
| --- | --- | --- |
| 1.1 | **a → 学習の精度** | 欲求 k の観測雑音を `R_k = R / a_k` にする。大事な欲求ほど精度高く・速く学ぶ。Σ は欲求ごと（形 (5, n, n)）。a の目標は \|Δu\|（外生）で W に依存しない（a → W の一方向だけ） |
| 1.2 | **C → 予期 Q → 選択** | `Q = U_val + λ_CQ ΣC(手がかり)`、λ_CQ = 1。手がかり = 概念・参加者・申し出に付いている結果の型（`announced`）。「褒められた後に害を受けた」人生では、褒め言葉を伴う申し出を避ける |
| 1.3 | **a の方向は実験条件** | `concern_direction`: `sensitize`（既定。揺さぶられた欲求ほど上がる）／ `habituate`（下がる）。どちらが人に近いかは主張しない |
| 1.4 | **ヘッドの重みは予測性能で決まる** | `head_kind = "mixture"`（既定）: mlp・linear・knn1・none（一般の率）を、前向きの対数尤度の移動平均の softmax で混ぜる。NN は予測が良いときにだけ寄与する |
| 1.5 | **ランダムな世界** | 人格の型を手で書かず、結果型ごとの確率を Beta(1, 3) から引く（`data/make_histories.py` の `random_world`） |

v3.2 の追加は、3 つの切り替え（`no_precision_weighting`、`no_cq`、`head_kind="mlp"`）で完全に外せます（外すと v3.1 の数値に戻る）。
**v3.2 の結果（REPORT.md、CHANGELOG の B・F 節）**: W1・W3・W5・W6 は合格、W2（C → 行動）は 0.133 で不合格（選ぶ時点の効果は 0.27 だが、40 回の閉ループで C が消去される）、
W4 は (a) 0.521 で不合格・(b) 0.698 で合格。U8 は不合格のまま、事後に定義した U8′ は持続が合格で可塑性（m = 8）が不合格。W7: どの課題でも非パラメトリックな knn1 が最も予測が良く、MLP は勝たない。

## 1 回の経験で起きること

`experience(exp)` は次の順に進みます（SPEC 第6節＋v3.1）。

1. スキーマ検証。
2. **予期**（結果を見る前）: 信念の予測 → `V_MB`, `V_MF`（a で重み付け）, `ω`, `U_val`、**`Q = U_val + λ_CQ ΣC(手がかり)`**（v3.2）。曖昧な結果は、ここで信念により解釈の重みが決まる。
3. `optional: true` なら、接近確率 `σ(4 (Q + 0.05))` で接近・回避を選ぶ。**回避したら、回避したことだけ台帳に記録して終わり**（学習しない。信念の計数は不変）。
4. 欲求の変化 Δh、効用変化 Δu（5 欲求のベクトル）、結果ごとの寄与、感じた価値 `f`（生得＋条件づけ＋参照点）、驚き `δ`、感情。
5. **信念の更新**: 責任 φ（人のせい／場面のせい）→ 計数、スコープの事前 π、型の大きさ、リプレイ緩衝・類ごとの生の計数 → （10 経験ごとに）類を除いたヘッドの学び直し（v3.3。目標は観測そのもの）。**曖昧な結果の型は観測なし**（計数しない）。参加者が行為者の観測は記録に残り、**10 経験ごとに想起**（下）で帰属をやり直す。
6. **価値の更新**: Δu を φ で人モデルと状況モデルに分け、それぞれカルマン更新（**欲求 k の観測雑音は R/a_k**、a はこの経験を受け止める直前のもの。v3.2）。**条件づけ C を TD(0) で更新**（直前の事象の手がかりを、この事象の `r + γ C_frozen` へ。v3.3: 潜在原因ごとに、手がかりが現れたときの文脈と時刻で事後を求め、事後が最大の原因だけを更新して試行の履歴に加える（局所 MAP）。台帳に割当の記録を残す。手がかりなしで嫌悪の結果が起きたら、その結果を原因に帰属して 1 つの原因に試行を加える = 復位）。
7. **関心の重み a**、欲求の状態 `h`、気分 `m` の更新。
8. 台帳に記録（経験 id、各特徴の ΔW、ΔC、a、φ、Δu、Q、f、δ）。

`appraise(exp)` は 2〜4 だけを計算し、**状態（乱数を含む）を一切変えません**。`probe(p)` も学習しません（未登録の語の埋め込みを読んでも、登録はしません）。

  "participants": [{"id": "friendA", "class": "collaborator"}],
  "outcomes": [
    {"type": "connection", "actor": "friendA", "magnitude": 1.0},
    {"type": "achievement", "actor": "self", "magnitude": 0.8},
    {"type": "credit_taken", "actor": "friendA", "magnitude": 0.8},
    {"type": "taught", "actor": "friendA", "magnitude": 0.6}
  ],
  "optional": false,
  "session": "day-12",

- `actor` は `"self"`、`"world"`、または参加者の id。`magnitude` は 0〜1。`type` は下の効果表の語彙に限り、未知の型はエラーです。
- **曖昧な結果**（v3.1）: 単一の型の代わりに解釈の候補を持てます。確率は LLM の素の読みです（人格を知らない）。
  `{"interpretations": {"credit_taken": 0.5, "credit_shared": 0.5}, "actor": "friendA", "magnitude": 0.8}`
- `session`（任意）: 文脈の連続。条件づけの TD は、同じ session（またはどちらも未指定）の連続する事象の間だけつなぎます。途切れたら次の価値を 0 とします。
- `context`・`concepts`・参加者の `class` は、lexicon にない語でも受け付けます。**ゼロベクトルとして状態に登録し、警告を記録します**（結果の型と actor は未知ならエラー）。個体の `class` は途中で変えられません。
- `optional: true` のとき、NPN が予期 Q（C を含む）に基づいて接近・回避を選びます。
- `announced`（任意、v3.2）: 申し出に前もって付いている結果の型のリスト（例: 褒め言葉を伴う申し出は `["praise"]`）。予期 Q の手がかり `type:praise` になる。結果そのものではない（結果は `outcomes` に書く）。
- `outcomes` は空でもよい（何も起きなかった経験。欲求の状態が基準へ戻るだけ）。

## 効果表 M（生得・固定）

欲求は 5 つ: **R** 関係性、**C** 有能感、**A** 自律、**S** 刺激、**Sa** 安全。
結果 1 つの欲求の変化は `Δh = magnitude × M[type]`、事象の欲求の変化は `Δh = Σ_o magnitude_o · M[type_o]` です（曖昧な結果は解釈の重みでの混合）。
基本の大きさ 0.30 は docs/04 の玩具（gM = 0.3）と同じ。安全の効用は不足側の二乗罰で傾きが小さいので、安全の行は大きめ（0.60）にしてあります。

表は `npnv3.innate.m_table_markdown()` が生成します。最上位の価値の軸＝欲求の種類・M・効用は設計者の所与で、経験からは生まれません（docs/04 第8節 1）。
M は NPN ごとに引数 `effect_table` で差し替えられます（U3 の頑健性検査用。保存・復元の対象）。

- 欲求の状態: `h0 = 1`、`h ← clip(h + Δh, 0, 6)`、続いて `h ← h + 0.1 (1 − h)`。
- 効用: 成長欲求 R, C, A, S は `u(h) = 3 (1 − exp(−h/3))`。安全は `u(h) = −½ max(1 − h, 0)²`。
- 事象の効用変化（ベクトル）: `Δu_k = u_k(h_k + Δh_k) − u_k(h_k)`。結果 o の寄与は `Δu_k · Δh_{k,o} / Δh_k`（`Δh_k = 0` なら 0）。寄与の合計は `Δu_k` に等しい。

## 数式の要約

### 信念（`belief.py`）

- 単位: 個体 ind ← 類 cls ← 一般 gen（人の層）、文脈 ctx ← 世界 world（文脈の層）。各単位・各型 k に計数 (n1, n0)。
- 個体 `p_ind = (κ_e m_cls + n1) / (κ_e + n)`、類 `m_cls = (κ_c prior_cls + Σ w_i r_i) / (κ_c + Σ w_i)`、`w_i = n_i / (n_i + κ_e)`。
  **類の有効標本数は個体の数で上限が決まる。** 一般 `m_gen` は、類の生の率 `Σ w_i r_i / Σ w_i` を重み `W_cls/(W_cls + κ_c)` で集計し、事前 Beta(1, 4) を `κ_g` 分加える。文脈の層も同じ形。`κ_c = κ_g = 4`（固定）。
- **κ_e（v3.1。設計の改訂でオーケストレーター承認）**: 格子（0.3〜50 の対数 12 点）上の Beta–Binomial 周辺尤度の事後平均。類全体の値κ_c は全型をまとめた尤度、**型 k の値は log κ の事後 ∝ 型 k の尤度 × N(log κ_c, 1.0²)**（データの少ない型は類全体の値へ縮約）。正の計数が 1 つもない型は κ_c。個体が 2 人未満の類は κ_e = 2。文脈の層の κ_e は 2 のまま。`kappa_per_type=False` で類ごとに 1 つ（改訂前）。
- **事前ヘッド（v3.3、既定 `head_kind = "mixture"`）**: ヘッド h ∈ `mixture_heads`（既定 linear・knn1・none。mlp・knnk も選べる）は、類 c の事前平均 `prior_h(c)`（型ごとの率）を出す。
  **どのヘッドも、予測する類 c 自身の観測を使わない（leave-class-out）。**
  - `none`: c を除いた他の類をまとめた生の計数の率 `(Σ n1 + κ_g m0) / (Σ n + κ_g)`（κ_g = 4、m0 = 0.2）。
  - `knn1` / `knnk`: c を除いた、データのある類のうち埋め込みが最も近い 1 個 / 3 個（距離の逆数の重み付き平均）の率 `(n1 + 2 g)/(n + 2)`（g = 上の全体の率）。計数は観測 y とマスクだけの**生の計数**（責任 φ は入らない）。
  - `linear` / `mlp`: c を除いたリプレイ緩衝（直近 500 件の観測）で、**初期値から**全バッチ勾配降下 300 回（学習率 0.5、乱数を使わない）で学び直したモデル（ヘッドは 8+8 次元 → ロジスティック回帰 / 16 tanh の MLP → 19 ロジット）。
    学び直しは `head_retrain_every = 10` 経験ごと（想起と同じ周期）。全データのモデル（未見の類に使う）と、既知の類ごとのモデルを作る。出力バイアスは、そのモデルが見るデータの全体の率から始める。
  **重みは転移性能で決まる**: 各ヘッドが、その参加者の類を除いた出力で、新しい観測を見る前にその類の観測を予測した対数尤度（観測されたセル `y log p + (1−y) log(1−p)` の和。階層の計数は通さない）の移動平均（速さ max(1/(n+1), 0.05)）を記録し、
  類の事前は `prior_cls = Σ_h w_h · prior_h`、`w = softmax(移動平均 / 1)`（ベイズのモデル平均の簡約）。観測が 0 件のときは `m_gen`。
  **ヘッドの出力は c の観測に依らないが、重み w は c の観測を評価の対象にして決まる**（交差検証による選択。X1 が検査するのはヘッドの出力）。
- **事前ヘッド（単一ヘッド。基線）**: `head_kind = "mlp" | "linear" | "knn1" | "knnk" | "none"` では `prior_cls = ρ_h · head + (1 − ρ_h) · m_gen`、`ρ_h = n_head/(n_head + 30)`（`no_head=True` は none = 階層の一般の率 `m_gen` のまま。v3.2 までと同じ）。head は上の類を除いたヘッド。**目標は観測 y であり事後平均ではない**。
- スコープ帰属: `φ_person ∝ π_{k,person} Bern(y; p_ind)`、`φ_ctx ∝ π_{k,ctx} Bern(y; p_ctx^person)`。計数は φ で重み付けして加え、π（Dirichlet(1,1)）の計数にも φ を加える。
  予測 `P(y_{e,k}=1) = π̄_person p_ind + π̄_ctx p_ctx^person`。
- **想起・再帰属（設計の改訂 2）**: 参加者が行為者の観測（個体・文脈・型ごとの y・マスク・当時の φ）を記録として持つ（保存・復元に含む）。`reattribute_every = 10` 経験ごとに全記録を 1 回掃引する。
  各観測について、**自分の寄与だけ**（人 φ、文脈 1−φ、π）を計数から引き（retract）、今の信念（個体の率・文脈の率・π）で φ を計算し直して足し直す（reassign）。オンライン EM の 1 ステップ（leave-one-out、掃引内は同時更新、類と世界の水準は掃引の間固定）。
  1 観測の寄与の和は常に 1、計数の総和は不変。曖昧な型は記録のマスクが 0。
  **非対称: 価値ネット（人モデル・状況モデル）の教師の分割は再帰属しない**（教師は経験の時点の φ のまま凍結。カルマンの更新の再生は未実装）。信念の側だけが後から訂正される。`no_reattribution=True` で無効。
- **曖昧な結果（v3.1）**: 解釈の重み `w_I ∝ q_LLM(I) · P_belief(I | actor, context)`。効果（Δh, Δu, 帰属, 教師）は重みでの混合で計算する。**信念の計数は曖昧な結果の型では更新しない**（観測なしとしてマスク。解釈が信念を自己訓練するループを作らない）。実験条件 `interpretation_counts=True` で、重みで計数する。`no_interpretation=True` は w_I = q_LLM(I)（信念を使わない）。

### 価値（`value.py`）

- 人モデル: 特徴 `people`(0.01) + `cls:<c>`(0.04) + `ind:<id>`(0.25) + 類の埋め込み 8 次元(各 0.02)。
  状況モデル: `world`(0.01) + `ctx:<c>`(0.1) + `concept:<x>`(各 0.1) + 概念埋め込みの平均 8 次元(各 0.02)。（括弧は事前分散）
- カルマン更新（**v3.2: 欲求ごとの共分散 Σ_k と観測雑音 R_k = R / a_k**、R = 0.01）: `K_k = Σ_k z / (zᵀΣ_k z + R/a_k)`、`W_k += K_k (Δu_k − zᵀW_k)`、`Σ_k ← Σ_k − K_k zᵀΣ_k`、続いて関与した特徴の対角に過程雑音 q（ind 1e-4、cls・ctx・concept 2e-5、people・world・埋め込み 5e-6）。
  **教師は重みなしの Δu のまま**（a は教師には入らず、精度 1/R_k と読み出しに使う）。a の下限は 1e-3。予測分散は `(1/5) Σ_k a_k² zᵀΣ_k z`（a = 1 かつ Σ が共通なら v3.1 の zᵀΣz と一致）。
  **注意**: 新しい個体の事前分散（0.25）が R（0.01）よりずっと大きいので、W の変化に対する a の効果は小さい（W1 の a だけの入れ替えで 4%）。確信（事後分散）には 2 倍ほど効く。
- 教師の分け方: 参加者 e には `Σ_{o: actor=e} φ_person(o) · contrib(o)`、状況には `Σ_{o: actor∈{self, world}} contrib(o) + Σ_{o: actor=参加者} φ_ctx(o) · contrib(o)`。人と状況の教師の和は事象の Δu に等しい。
- **新しい個体は類の価値を継承する**（加法の階層。個体の偏差の事前平均は 0）。
- **関心の重み a（v3.1。方向は v3.2 で実験条件）**: `a ← normalize( a + η_a (目標 − a) )`、η_a = 0.02、和は 5。`|Δu|` は生得の効用の変化の大きさ（外生）で、a の目標に価値ネットの出力は入らない。
  `sensitize`（既定）: 目標 = `clip(|Δu_k| / run, 0, 5)`。人生で大きく揺さぶられた欲求ほど重くなる（正負を問わない感作）。`habituate`: 目標 = `clip(run / max(|Δu_k|, run/5), 0, 5)`。揺さぶられた欲求ほど軽くなる。**どちらが人に近いかは主張しない**（実験条件。主張は「a が経験から形成され、受け止め方と学習を変える」まで）。`mean(|Δu|_run)` は全欲求の `|Δu|` の平均の移動平均（速さ 0.05。SPEC に値の指定がなく、実装時に決めた）。
- **条件づけられた価値 C（v3.1。v3.3 で潜在原因つき）**: 手がかり x = 事象の概念・参加者の個体と類・結果型。事象 t+1 を見たとき、事象 t の手がかりを
  `y_t = r_{t+1} + γ C_frozen(z_{t+1})` へ更新する（α_C = 0.1、γ = 0.6、`r = Σ_k a_k Δu_k`）。目標の r は C に依存せず、γ < 1 のブートストラップは縮小。
  - **single_cause（K = 1。v3.2 と同じ算術）**: 手がかりごとに 1 つの重み C。`C += α_C (y_t − C·z_t) z_t / (z_tᵀ z_t)`。文脈にも時刻にも依存しない。
  - **潜在原因 revised（v3.3 既定。設計の改訂後。Gershman, Blei & Niv 2010 の距離依存の CRP の簡約）**: 手がかり x ごとに最大 K = 5 個の原因 k。各原因は価値 `C_{x,k}`、文脈の集中度 `β_k`、**割り当てられた試行の履歴**（時刻 t_i、文脈）を持つ。
    原因の事前の重み `w_k = Σ_{i∈k} (t − t_i + 1)^(−d) · (n_k(c) + β_k)/(N_k + β_k S)`（d = 1。N_k = 文脈の分かっている試行の数、S = x が見た文脈の数（c が新しければ +1））。新しい原因の重みは α = 0.5。
    `β_k` は原因が作られた順序で決まる（**設計上の仮説**: 後から学んだ情報（消去）は、最初に学んだ情報（獲得）より文脈に依存する。Bouton 2004 の簡約）: 手がかりの最初の原因は β_first = 5（広い。未見の文脈にも確率を残す）、2 番目以降は β_later = 0.2（狭い）。
    **応答**（Q と f に入る）`C(x | 文脈, t) = Σ_k p(k) C_{x,k}`、`p(k) = w_k/(Σ w + α)`（新しい原因の価値は 0）。
    **事後** 事前 × `N(y_x; C_{x,k}, σ_r²)`（σ_r = 0.15。y_x は他の手がかりの応答を引いた、この手がかりが説明すべき目標）。**学習は局所 MAP**: 事後が最大の原因（新しい原因を含む）だけを `C += (α_C / 手がかりの数)(y_x − C)` で更新し、その原因の履歴に (t, 文脈) を加える
    （Anderson 1991 の合理的分類モデルの近似）。新しい原因の事後が最大なら作る（満員なら現在の質量 `Σ(t − t_i + 1)^(−d)` が最小の原因を再利用し、その履歴を捨てる）。
    **復位**: 手がかりなしで嫌悪の結果（`r = Σ a_k Δu_k ≤ −0.05`）が起きたとき、その結果が**どの原因から来たか**を、除外した手がかり（その事象と直前の事象の手がかり）以外の全ての（手がかり, 原因）の尤度 `N(r; C_{x,k}, σ_r²)` で推論し、
    「どの原因でもない」（`N(r; 0, σ_r²)`）より大きい中で最大の 1 つに、試行 (t, 文脈) として加える（**価値は更新しない**）。全手がかりに一律では効かない。事前の重みは同点のときだけ使う（質量の大きい価値 0 の消去の原因が嫌悪の結果を吸収するのを避ける）。
    **割当の記録**: 手がかりの経験ごとに、台帳の `assignment` に、時刻・文脈・事前（時間の項・文脈の項・計数の項・α）・尤度・事後・MAP の原因（番号 uid、新しく作ったか）・学習前後の C_k を残す。復位は `reinstate`（推論した原因・事後）。
    `NPN.explain_response(cue, context, t)` は、応答を原因ごとの重み p(k)・価値 C_k・寄与 p(k)·C_k と、p(k) の要因に分けて返す（学習しない）。
  - **潜在原因 spec_literal（SPEC-v3.3 4.2 のとおり。`lc_design="spec_literal"`。改訂前の既定）**: 原因の事前 `p(k) ∝ N_k · (n_k(c) + β)/(N_k + β S) · exp(−(t − t_k)/τ)`（β = 1、τ = 30 経験）。柔らかい事後で全原因を更新（`ΔC = (α_C/手がかりの数) · 事後_k · (y_x − C_k)`）。
    復位は、負の価値（`C < −0.02`）を持つ全ての原因の `t_k` を現在に更新。E3〜E6・E9 が不合格だった設計で、改訂前の数値の再現用。
  - 時刻 t は NPN が数える経験（学習した ＋ 回避した）の通し番号。revised で SPEC 6 節が値を固定したもの: d = 1、α = 0.5、β_first = 5、β_later = 0.2（結果を見る前に固定）。SPEC に値の指定がなく実装時に決めたものは「実装時の解釈」。
- **MB 価値**: 信念の予測確率で結果の集合を 64 回サンプル（乱数は経験 id と設定の種から作る）。各サンプルで `Σ_k a_k (u_k(h + Δh) − u_k(h))` を平均。
  分散 `σ²_MB = Var_サンプル / 64 + Σ_{e,k} g_k² Var_k(e) + Σ_k g_k² Var_k(文脈)`。`Var` は個体・類・一般・文脈・世界の Beta 事後分散 `m(1−m)/(κ + n_eff + 1)` の和、`g_k` は型 k の結果が平均の大きさで 1 回起きたときの（a で重み付けた）効用変化（デルタ法で確率の不確実性を価値の尺度に直す）。
- **調停**: `ω = σ²_MB / (σ²_MB + σ²_MF)`、`U_val = ω V_MF + (1 − ω) V_MB`。`σ²_MF` は上の予測分散の和。確信の高い方に重みが寄る。
- **予期 Q（v3.2）**: `Q = U_val + λ_CQ Σ_{x∈手がかり(s)} C(x)`、λ_CQ = 1。手がかり = 概念・参加者の個体と類・`announced` の型（選択の前に分かるものだけ）。接近確率は `σ(4 (Q + 0.05))`。
  ループ: C → Q → 選択 → 経験 → C。標本の偏りによる有界な正帰還（熱いストーブ: 避けると C を訂正する経験が来ない）。申し出を受けて何も起きなければ C は 0 へ戻る（消去）。U5・U6・W6 で有界を検査している。
  Q に人に帰属する部分 `Q_person = ω V_MF,person + (1 − ω) V_MB,person`（V_MB,person は同じサンプルで「全体の価値 − 自分・世界が起こす分だけの価値」）を読み出せる（U8′）。
- **感じた価値（読み出し。目標にはしない）**: `f = tanh( ((Σ_k a_k Δu_k) + λ_C ΣC + η_ref (Σ_k a_k Δu_k − Q)) / 0.5 + 0.3 m )`、λ_C = 1、η_ref = 0.5。
  予期との差の項は、主観的な幸福が報酬だけでなく期待と予測誤差に依存することに基づく（Rutledge et al. 2014, PNAS 111(33), 12252–12257。文献の照合は未了）。
  驚き `δ = f − tanh(Q / 0.5)`、気分 `m ← 0.8 m + 0.2 δ`。
- **感情**（言語化用の手がかり。強度は 0〜1）:
  喜び = `max(f, 0)`、失望 = `min(1, −δ)`（δ < 0 かつ Q > 0）、安堵 = `min(1, δ)`（δ > 0 かつ Q < 0）、
  怒り = `tanh(Σ_{行為者が参加者} φ_person · max(−寄与の和, 0) / 0.5)`、悲しみ = `tanh(Σ max(−寄与_関係性, 0) / 0.5)`、興味 = `tanh(Σ max(寄与_刺激, 0) / 0.5)`。

### 埋め込みの所有（`lexicon.py`）

`data/lexicon.json` は、類・文脈・概念それぞれの **8 次元の属性ベクトル**（social, cooperation, competition, creativity, hierarchy, warmth, risk, novelty）を、**手で意味を持たせて**置いた**供給源**です。
v3.1 では、語が初めて学習に現れたとき（`experience()`）に、供給源の値を**NPN の状態へ写して保存**します。以後は状態の値だけを使います。供給源（lexicon、実運用では LLM 側の凍結した文埋め込み）を
別の座標に替えても、登録済みの語の評価は変わりません（`NPN.load(dir, lexicon=別の座標)`、U9）。lexicon にない語はゼロベクトルとして登録し、警告を `npn.warnings` に残します。
保存ファイルには lexicon の中身は入らず、所有する埋め込みの値だけが入ります。T8 の転移は、設計者が置いた類似度（「バンド仲間」は「共同作業者」に近い）に依存します。

## 実装時の解釈（SPEC に明記がない点）

CHANGELOG の「仕様の解釈」にも書きました。主なもの:

- 参加者に帰属される結果が 1 つもない経験でも、その参加者の人モデルは教師 0 で更新する（「この相手は今回何ももたらさなかった」という観測）。
- `fixed_teacher`（3-F 型）では、参加者の教師は帰属 φ を使わず「行為者がその参加者の結果の寄与の和」とし、`W[ind:参加者] += 0.1·教師`、状況は `W[ctx] += 0.1·教師`。
- `flat_value` では、人モデルは `ind:` 特徴のみ（0.25）、状況モデルは `ctx:` と `concept:` の特徴のみ（各 0.25）。
- 文脈の層は個体と同じ κ_e（2、推定しない）、世界は一般と同じ κ_g（4）と事前 Beta(1, 4)。
- 条件づけ C の手がかりは、概念・参加者の個体と類・結果型（曖昧な結果は候補の型すべて）。回避した申し出は TD の連鎖を動かさない。
- エンティティのプローブに文脈がないときは、事前ヘッドの文脈入力に、登録済みの文脈の埋め込みの平均（なければゼロ）を使う。
- （v3.3）ヘッドの学び直しは `head_retrain_every`（10）経験ごと。参加者のいない経験も数える。v3.2 の毎経験のミニバッチ SGD は廃止した（単一ヘッドも同じ学び直し）。
- （v3.3）潜在原因の部品で SPEC に値の指定がなかったもの: 文脈の Dirichlet 予測の疑似計数 β = 1（spec_literal）、「負の価値」の閾値 C < −0.02（spec_literal の復位）、「嫌悪の結果」の閾値 Σ a_k Δu_k ≤ −0.05、
  新しい原因の価値 0、満員のときの再利用（spec_literal は `N_k exp(−(t−t_k)/τ)` が最小、revised は現在の質量が最小）、時刻 t_k は事後が最大の原因だけ更新。結果を見る前に決め、その後変えていない。
  設計の改訂（revised）の実装時に、結果を見る前に決めたもの: 時間の単位は経験の通し番号、文脈の Dirichlet は各文脈に疑似計数 β_k を置く形、「最初の原因」はその手がかりで最初に作られた原因、復位の選択は尤度のみ（同点のとき事前の重み）。詳細は CHANGELOG の J.8。
