## 判定（`run_f.py`）
- β ∈ {2, 4} ごとに、次の 4 つをすべて満たすこと。
  1. Pa 対 Pb で積が負になる数 ≥ 30/40
  2. 再試験で積が負になる数 ≤ 10/40
  3. 前者が後者より多く、2 割合の検定で p < 0.01
  4. β = 0 の数が偶然の範囲（2 項検定で p ≥ 0.01）
- 差が 0 の数は別に報告する。
- F-align（特徴と要素のそろい）は記述だけで、除外の基準にはしない。

## 凍結前の追記（`CRITIQUE-v11-prefreeze.md` の条件。結果を見る前）
1. 分母は 40 に固定する。差が 0 の対は、主判定では「逆でない」に数える。0 を除いた率は副次の報告だけに使い、判定には使わない。
2. β = 0 の検定も、0 を含む 40 を分母にする。検査入力が特徴を拾わない世界では同じ符号に偏るので、β = 0 の「逆」の期待値は 20 より下がる（概算 16 前後）。その偏りの向き（逆が減る側）を承知の上で、p ≥ 0.01 を採る。
3. 較正の下限 1e-6: 中立で 90 パーセンタイルが 0 の特徴は、微小な h でも「ある」と判定される。この特徴は「普段の強さの半分」の規則の例外として固定し、下限に当たった特徴の数を報告する（`run_f.py` の units_at_calibration_floor。β = 0 の Pa の個体で数える）。
