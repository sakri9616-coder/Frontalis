# PREREG-v10.1: PREREG-v10 の改訂（2026-10-23、評価の前）

凍結前の理念批評（`CRITIQUE-v10-prefreeze.md`）が、走らせる前の論理の矛盾を見つけたので改訂する。結果はまだ誰も見ていない。v10 の §1・§2・§4 はそのまま有効で、§3 をこの文書で置き換える。

## 改訂の理由
- v10 の G3a は、再試験（同じ前半・別の流れ）で符号が逆になる数を p = 0.5 の 2 項検定にかけ、偶然の範囲（p ≥ 0.01）なら合格としていた。
- 再試験の役割は、符号が前半の世界で決まり、流れでは決まらないことの確認である。だから、逆になる数は 0 に近いはずである。v10 の規則は向きが逆で、事前の予想（K = 3 は通る）と両立しなかった。
- v10 の G3b は、Pa と Pb に同じ乱数の流れを使いながら、80 回を独立と扱っていた。

## §3 判定（置き換え）
- **G3a**（K ∈ {3, 5}、β ∈ {2, 4} ごと）: 次の 4 つをすべて満たすこと。
  1. Pa 対 Pb で符号が逆になる数 ≥ 30/40
  2. 再試験で逆になる数 ≤ 10/40
  3. 前者が後者より多く、2 割合の検定で p < 0.01
  4. β = 0 の Pa 対 Pb の逆になる数が偶然の範囲（2 項検定で p ≥ 0.01、おおよそ 12〜28/40）
- **G3b**: Pb には、前半・後半とも別の乱数の流れを与える（`[seed, 7]`、`[seed, 6]`）。これで 80 回は独立になる。判定は v10 のとおり（β = 0 より高く、p < 0.01）。
- コードは `probes/credit/run_g.py` と `sim_credit.py`（この改訂を反映した版）。

## 報告の注意（批評 §5）
- G3a で読めるのは、「履歴に依る手柄の割り振りが、同じ経験の列から学ぶ向き Δc を逆にする」ことである。次の範囲の限定を、報告の本文に書く。
  - V の差は小さい。
  - 新しい出来事は、阻止を突くように開発者が組んだ。
  - o と要素は開発者が与えた。
  - 網も LLM も無い。
- G3b は「後半の鍵が、前半の残差を増幅した」と書く。「理由のある変化」「自己の主張」とは呼ばない。
- β*_late は良い要素の部分ブロックでの近似で、格子幅は 0.25 である。K = 5 の 2.0 は (1.75, 2.0] を意味する。設計 §3.2 の 3（批評の概算）と、ここでの 2.75 の違いも併記する。
- K = 5・β = 2 は、規則どおり通過か不通過かで報告し、再解釈しない。
