## 判定（`judge_dyad_transfer.py`）
40 種がそろったときだけ判定する。M_分野 = −[Δboost(分野) − Δboost(青のどちらでもない物)]（Δ は t = 1500 − t = 0、雑音のない入力、各分野の物の平均）。各量は「合格」（正の種が 30/40 以上かつ 0 を除いた符号検定 p < 0.01）、「逆向きの合格」（負の種が 30/40 以上かつ同じ p）、「どちらでもない」。
- **健全性**: ネットワークの X2（t = 0）で V(赤・四角・高) > 0、V(青・丸・高) < 0、V(青・四角・低) < 0 のすべてを満たす種が 36/40 以上、かつ X2·W で丸の分野の boost が下がった種が 30/40 以上。満たさなければ D1〜D4 を解釈しない。
- **D1**: X2·W の M_低。
- **D2（主）**: M_低 の X2·W − X2·Q。
- **D3（主）**: M_低 の X2·W − X2r·W。
- **D4（主）**: X2·W の M_低 − M_赤。

## 読みの規則（設計 §8.6。判定のスクリプトが `reading` に書く）
- D2・D3・D4 がすべて合格のときに限り、「相手が外れた経験から学んだ言葉の割り引きが、学んだ『悪さ』の表し方を通って、相手が一度も勧めていない、自分が悪いと評価する分野へ移った（評価の水準での準備）」と書く。「判断基準の獲得」は、このときに限り「自分が悪いと評価する物への相手の言葉を割り引く、という関係が、経験から獲得され、未見の分野へ移った」と書く。
- D2 が合格で、D3 か D4 が合格でないとき: 「相手が外れた経験は、低の分野の言葉の効きを、対照と比べて下げた。それが自分の悪さの表し方を通ったかは示せなかった」（示せなかったもの: D3 なら学んだ評価の寄与、D4 なら悪さへの固有性）。
- D2 が合格でないとき: 「相手が外れた経験による、低の分野への割り引きの移転は示せなかった」。D1 は入力の構造による広がりと区別できないので、移転の根拠にしない。
- D2 が逆向きの合格のとき: 「相手が外れた経験の後、低の分野の言葉の効きは、対照と比べてむしろ上がった」。
- D3・D4 が逆向きの合格のときは、その向きをそのまま書く。
- 「食い違いそのものから学んだ」「自己」「人格」「主張」とは、どの結果でも書かない。
