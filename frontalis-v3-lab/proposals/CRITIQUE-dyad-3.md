## 要旨
1. **問いに答えるか**: 部分的。答えるのは、関係の移転の一部（E1）、基準の入れ替え（E5）、除去後の変化（E3 の符号の記録）。ただし E2 と E5 は λ で、E4 は c と 0.208 の大小で、結果が先に決まる。中心の問い「形ができた後どう変わるか」に対して、この版が持つ変化の道は 2 つだけである。λ < 1 なら消え、λ > 1 なら前半の符号に鍵がかかる。「組み替わる」を起こすのは、雑音による飛び移りしかない。
2. **すり替え**: 隠れたすり替えはない。ただし E4 を「自己の主張」と呼ぶのは過大で、中身は「c がしきい値 0.208 を越えるか」である。c = −0.2 は境界との差が 0.008 しかなく、学習の雑音で結果が決まる。
3. **(a) 指示を中身として満たすか**: 形式としては満たす。目標が今の見方に依り、m が g で変わる。sim4 の ref 項（負のフィードバック、固定点 −1/3）とは本質的に違う。正の符号で飽和があり、複数の固定点を持つからである。しかし、思想が名指しした型そのものでもある。思想 176 行は「自己評価を更新目標としてそのまま増幅するだけでは、固定された初期評価の自己強化に留まる可能性がある」と書く。思想が求めるのは 178 行の「学習済みの人格が新しい経験を解釈することで、次の評価基準が実質的に変化するか」で、第 3 版にはその道がない。
4. **(b) 平均場**: 数値は正しい（批評役が再実行して再現した）。ただし、設計に書かれていない前提が 1 つある。P の学習の目標は o のまま（第 2 版のとおり）なので、V の有効な目標は q·m + (1−q)·P になる。そのため固定点は g = c + q·λ·tanh(g) で、双安定の条件は q·λ > 1 である。
   - 良いと見た手がかりは q が高いので、鍵がかかりやすい（自己強化）。
   - 悪いと見た手がかりは q ≈ ε なので、有効な λ ≈ ελ になる。しかも x は関わったときしか見えないので、g は凍結する（回避による凍結）。
   - つまり「保つ」は、正と負で非対称になる。また、相手の言葉が g に入る道は初回の Ṽ だけなので、E4 で相手の言葉はほとんど効かないと予想される。
5. **分岐の道**: λ を両方報告すること、新しい種、試運転で量を見ないことは適切。残る分岐は 2 つ: E4 の c の選び方と、「組み替わる」が未定義なこと。
6. **(c) 何に求めるか**: 思想は予測できないことを求めていない。平均場で予測できることは欠陥ではない。問題になるのは、予測の中身が研究の主張と一致してしまうとき（主張＝保つか消えるか＝λ）だけである。中身を探す場所は、優先順に次の 4 つ。
   - (i) **文脈に依る意味**: 同じ手がかりが、文脈によって良くも悪くもなる舞台にし、g を次元の組に対して非線形にする。これだけが、鍵と消去のほかに第 3 の変化（組み替え）を許す。
   - (ii) **反応する相手**: AI の関わり方に応じて相手が変わる。1 次元の平均場で閉じず、1:1 の目的に一番近い。
   - (iii) **λ 相当の学習**: 係数の変化にすぎないので、それだけでは証拠にならない。
   - (iv) **機構の検証と位置づける**: 第 3 版はこう位置づけるべき。
7. **(d) λ > 1 は妥当か**: 妥当。頑固さや自己確証は個性の範囲で、故障ではない（tanh で有界）。不当になるのは、結果を見た後に λ や c を足すこと、c をしきい値のすぐ内側に置いて「主張した」と語ることである。
