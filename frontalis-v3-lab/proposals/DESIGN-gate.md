# DESIGN-gate（第 1 版）: 理由があるときと同じ速さで変われるのに、理由が無いときは育ちの評価を保てるか — 予測の外れで守りが緩む定着（2026-10-24。批評 `CRITIQUE-gate-1.md`・`CRITIQUE-v15-prefreeze.md` を受けて第 1.3 版）

## 0. どこがニューラルネットワークで、何を経験から学ぶか（最初に書く）
- **評価のネットワーク**は v14 と同じである（`probes/npn/npn_consol.py`。凍結のまま変えない）。
  - トークンごとの MLP（D16 → 32 → 32 → 1）。
  - 手柄の割り振りは、アテンション softmax(β · v) として入る。
  - 損失は Σ(v_i − α_i · o)²。SGD で学ぶ（学習率 0.01、勾配の上限 1.0）。
- **定着**も v14 と同じである。重要度 Ω は、ネットワーク自身の勾配の 2 乗の積み上げ（時定数 1000 回）。λ = 10 で、行列ごとに相対化する。
- **この版で足すもの: 予測の外れによる守りの緩み**（`probes/npn/npn_gate.py`）
  - 経験ごとに、ネットワークの予測 p = Σ v（学ぶ前）と、外れ e = o − p を計算する。
  - **ふつうの外れの大きさ** m を、経験から学ぶ: m ← 0.99 m + 0.01 e²。
  - **驚き** s = e² / m（m を更新する前の値で割る）。いつもよりどれだけ外れたか、である。
  - 重みの可塑性: f = 1 / (1 + λ · Ω/mean(Ω) · exp(−s/κ))。κ = 1。
  - 予測どおりの経験では、直近の評価を支えた重みは守られる。いつもよりずっと外れた経験では、その 1 回だけ守りが外れる。
  - 驚きは、ネットワーク自身の予測と自分の外れの記録で決まり、開発者が要素で指定しない。ただし、驚きは**内容を区別しない単一の数**である。どの要素の予測が外れたかも、良い方に外れたか悪い方に外れたかも区別しない。「何に驚くか」を学ぶのではなく、「どれだけ外れたか」を 1 つの数で測っている。
  - これは、開発者が形を書いた学習規則（係数 κ と ρ_s の 2 つ）であり、比較対象ではなく被験の機構である（批評 問い 5）。人格の中身（何を好むか）を書いたものではない。
- 信頼のネットワーク、選択の規則、記録の窓 30、世界は、v14 と同じである。手書きの部分（選択の softmax と加点、Q の既定値 0.5、記録の窓、アテンションの関数の形、o）も同じである。

## 1. 主題の問い
主題は「1:1 で AI が自己を主張できるか」である。この版が問うのは、v14 で残った次の問いである。

> 理由が無ければ育ちの評価を保ち、理由があれば変わる。この両立は、学習の速さという 1 本のつまみでは決まらないか。

v14 では、学習率を 1/10 にしただけのネットワーク（slow）が、定着とほぼ同じだけ保った（`probes/LOG-dev.md` P62）。速さを下げれば保てるが、理由があっても変わるのが遅くなる。速さを上げればその逆になる。保持と変化は、1 本のつまみの両端だった。

この版は、**理由があるときに変わる速さをそろえたうえで**、理由が無いときにどちらが育ちの評価を保つかを比べる。そろえる相手は、普通のネットワークの学習率を合わせたもの（match）である。外れで緩む仕組みが match より保てば、「経験の種類によって、変わりやすさ自体が変わる」ことが、行動の前の評価の水準で示せる。

### 報告の言い方（先に決める）
- S1 が通ったときに書けるのは、次までである。「理由（予測の大きな外れ）があるときの変わる速さが同じ普通のネットワークより、理由の無い偏った経験の中で、育ちの評価を保った。」この文には、次の限定を必ず付ける（批評 問い 3）。
  - 「同じ速さ」は、o が +1 から −0.5 に変わる 1.5 の跳びの理由についてだけである。小さな理由では驚きが κ を超えず、gated は守られたまま遅くなりうる。
  - 速さをそろえたのは「理由あり・勧めなし」の条件である。S1 を測る「理由なし・勧めあり」の条件では、実際の歩幅は gated のほうが小さい（D5 で示す）。これは機構の狙いどおりだが、「同じ速さのネットワーク」はこの条件には当てはまらない。
  - 驚きは内容を区別しない単一の数である。
  - match は、定着なしの普通のネットワーク none そのものである（§5）。none は、試作で gated が保ち方で上回った唯一の対照である。
  - S1 だけなら、可塑性 f ≤ 1（gated はどの重みも none より速くは動かない）からほぼ従う。主張は S1 と S2 の組（同じ速さで変われること）で成り立つ。
- 「自己」「主張」「圧力に耐えた」とは書かない。v14 と同じく、勧めは評価に直接は作用しない。働くのは、経験の分布の偏りである。
- 「理由」は、この版では「予測の大きな外れ」である。世界の o の書き換えで作る。相手との関係から来る理由ではない。

| 型 | 何が起きるか | どの量で見るか |
| --- | --- | --- |

## 3. 世界と手順（v14 と同じ）
- 要素: 協力（+1）、出来栄え（+1）、無理な働き方（−0.5）。トークンは固定のランダムなベクトル（D16）に雑音（0.1）を足して来る。
- 選択肢: C、Q、N、W（v14 と同じ確率）。
- 形成期は 2000 回（C だけで協力好き、Q だけで出来栄え好き）、やり取りは 3000 回。β = 4、τ = 3、γ = 4。
- 理由のある条件: 500 回目から、協力の o を −0.5 にする。γ = 0（勧めなし）と γ = 4 の両方で走らせる。
- **変わるまでの時間**: 理由が始まってから、協力の評価が初めて 0 を下回るまでの回数。10 回ごとに記録する。2500 回のうちに下回らなければ 2500 とする。

## 4. 試作（種 0〜7。評価の種ではない。結果を見て選んだので全部書く）
3 本ある。どれも Colab の CPU で走らせた。
- **試作 1**: 外れの門 exp(−s/κ)。κ = 1・4・16 を試した。
- **試作 2**: 驚き s に「外れの勾配のうち、守っている重みに掛かる割合」φ をかけた。新しいものを学ぶときにも、共有の重みを通じて守っている重みに勾配が掛かり、守りが外れる回数がかえって増えた。取り下げた。
- **試作 3（この版）**: 試作 1 の形に戻し、κ = 1 を選んだ。

試作 1 の結果（κ = 1）は次のとおりである。
- 協力好き・勧め Q・理由なしの、終わりの協力の評価:

  | --- | --- |
  | gated（この版） | 1.00 1.01 0.99 0.14 0.41 0.19 0.19 0.92 |
  | gshuf（緩む時を乱した対照） | 0.95 0.82 1.06 0.08 0.92 1.13 0.30 1.07 |
  | slow（v14） | 1.01 0.87 0.98 0.05 0.94 1.10 0.14 1.00 |
  | consol（v14） | 1.07 1.00 1.05 0.24 0.85 0.50 0.37 1.09 |
  | none（定着なし） | 0.64 0.70 0.30 0.14 0.30 0.06 0.04 0.79 |
- 理由のある条件（γ = 0）で変わるまでの時間:

  | gated | 240 160 130 80 90 50 100 110 |

- 読めること:
  - gated は、none に近い速さで変わった。理由が無いときの保ち方は、none より上（8 種中 7 種で高く、1 種で同じ）だが、slow には届かない種があった（種 4・5）。

## 5. 速さをそろえた対照 match の学習率（評価の前に決める）
- 開発の種 79000〜79007 で、gated と、学習率 L の普通のネットワークを、理由のある条件（γ = 0）だけで走らせる。L は 0.003・0.005・0.007・0.01 の 4 通り。
- **変わるまでの時間の中央値**が gated に最も近い L を、LR_MATCH として凍結する。見るのは変わるまでの時間だけで、理由が無いときの保ち方（S1 の量）は走らせない。
- **結果**（`probes/p63_calib_lr*_s*.txt`）: 変わるまでの時間の中央値は、gated が 65 回、普通のネットワークが L = 0.003 で 175 回、0.005 で 105 回、0.007 で 90 回、0.01 で 60 回だった。0.007 の台は最初の転送に失敗したので、凍結前の批評の指摘どおり、同じ手順で走らせ直した（手順の完遂で、結果を見た後の変更ではない）。走らせ直しでの gated の値は、最初の 3 台と 8 種すべて同じだった。
- **LR_MATCH = 0.01** とした。これは定着なしの普通のネットワーク（none）そのものである。外れで緩む仕組みは、理由があるときは、定着なしとほぼ同じ速さで変わる（比 65/60 = 1.08）。したがって、評価では none を match として使い、match を別には走らせない。S1 は「gated > none」になる。
- 開発の試運転は、この較正（gated と普通のネットワークを、開発の種 8 個で走らせた。値はすべて有限）で兼ねた。
- **試作との食い違い**（凍結前の批評 2）: 試作の種 0〜7 では、変わるまでの時間の中央値は gated 105 回、none 70 回で、比は約 1.5 だった。開発の種では 65 回と 60 回で、比は 1.08 である。8 種の中央値は種によって大きく揺れる（gated の種ごとの値は、試作で 50〜240、開発で 40〜190）。また、別の VM で走らせると結果が変わることがある（§4）。どちらが本当の比に近いかは分からない。評価の種で比が 1.1 を超え、S2 が満たされない見込みは小さくない。
- **普通のネットワークの学習率の曲線**（凍結前の批評 4）: none（0.01）・slow（0.000975）に加えて、普通のネットワークを学習率 0.003・0.005・0.007 でも評価の種で走らせる（`PLAIN`。理由なしの保ち方と、変わるまでの時間だけ）。記述 D1 で 5 点の曲線を描き、gated がその上にあるかを見る。

## 6. 量（v15。評価の種 79100〜79139 の 40 種）
すべて同じ種での対の比較である。合否の基準は、S2 を除いて「30/40 以上、かつ 0 を除いた符号検定で p < 0.01」に揃える。
- **S1（主。速さをそろえたうえで保つか）**
  - 協力好き・勧め Q・理由なしの、終わりの協力の評価: gated > match。
  - 対称の側として、出来栄え好き・勧め C の、終わりの出来栄えの評価: gated > match。
  - 両方が基準を満たせば合格。
- **S2（速さが本当にそろったかの確認。片側。満たさなければ S1 を解釈しない）**
  - 評価の種で、変わるまでの時間（γ = 0）の中央値の比 gated / match が 1.1 以下（gated が match より遅くない）。1.1 を超えたら「遅さの寄与を排除できない」と報告し、S1 の結果は解釈しない。
  - S2 が満たされなくても、評価の種での再較正・再走行はしない。v15 は、その結果で終える。
- **S3（緩む「時」が、変わる速さに効くか）**
  - 変わるまでの時間（γ = 0）が gated < gshuf。gshuf は、同じ分布の緩みを、外れと無関係な時に起こす。
  - S3 は、門の定義からほぼ決まる（誤差が大きいときに開く門は、でたらめに開く門より、誤差が大きいときに速く学ぶ）。排除できるのは「門の効果は可塑性の平均の問題だ」という説明で、それも変わる速さの側だけである（批評 問い 3-a）。確認の量として扱う。
- **S4（緩む「時」が、保ち方に効くか。解釈を先に決める）**
  - gated > gshuf が合格基準を満たさず、gshuf ≥ gated も 20/40 に届かないときは、「時の決め方が保ち方に寄与したという証拠は無かった」と書く。
  - 協力好き・勧め Q・理由なしの、終わりの協力の評価を、gated と gshuf で比べる。
  - 試作では gshuf のほうが保った種が多かった（8 種中 5〜6 種）。gshuf ≥ gated の種が 20/40 以上なら、「驚きによる時の決め方は、保ち方には寄与せず、変わる速さだけに寄与した」と結論する。gated > gshuf が 30/40 以上かつ p < 0.01 のときだけ、「保ち方にも寄与した」と書く。
- **健全性**（満たさなければ、S1〜S3 を解釈しない）
  - 形成の直後の協力の評価が 0.5 以上（gated・協力好き）の種が 36/40 以上。
  - gated・協力好き・勧め Q の終わりの出来栄えの評価が 0.5 以上の種が 36/40 以上。
- **記述**（本文で報告する要約を先に決める）
  - D1: 8 つの点を、「理由なしの保ち方（協力の評価の平均）× 変わるまでの時間の中央値」の平面に置いた表。5 つの条件と、普通のネットワークの学習率 0.003・0.005・0.007 である。none・plain0.007・plain0.005・plain0.003・slow の 5 点が「普通のネットワークの学習率の曲線」になる。gated がこの曲線より上にあるかどうかを、S1 の対の検定と並べて報告する。
  - D2: 勧め Q に最後の 1000 回で従う割合の差（出来栄え好き − 協力好き）。gated と match の値と、正の種の数。
  - D3: 理由と勧めが同時にあるとき（γ = 4）の、変わるまでの時間の中央値（6 条件）。
  - D4: やり取りの最初の 100 回と全体の、門の平均（gated・gshuf）。
  - D5: 実際の歩幅の比の平均（6 条件）。

## 7. 評価の結果を見た後に変えないもの
評価は 1 回だけ走らせ、最初の結果を結果とする（別の VM での再走行はしない）。κ = 1、ρ_s = 0.01、LR_MATCH（`npn_gate.py` の定数として凍結し、結果のファイルにも書く）、v14 から引き継ぐすべての値（λ、ρ、相対化、窓、γ、τ、β、学習率、長さ、初期化、信頼の学習率）、6 つの条件の定義、変わるまでの時間の定義、すべての閾値、本文で報告する要約。S1 で match に負けたら、そのまま失敗として報告する。

## 8. この版が答えないこと
- 何が快か（o）は、開発者が決めている。評価の的は α · o に閉じている。
- 相手は数で勧めるだけである。言葉も、反応する相手も無い。勧めの加点は 0 未満にならない。
- 特徴は 3 つの固定トークンである。「学習の層が薄い」問題は残る。
- 「理由」は予測の大きな外れで、相手との関係から来る理由ではない。
- 驚きは「良い方への外れ」と「悪い方への外れ」を区別しない。新しく良いものに出会っても守りが外れることは、試作で分かっている。

## 9. 予想
- S1: 試作では gated > none が 8 種中 7 種（1 種は同じ）だった。match = none なので、通る見込みはある。ただし S1 だけでは主張にならない（§1）。
- S2: 分からない。開発の種では比 1.08、試作の種では約 1.5 だった。満たさない見込みも小さくない。
- S3: 試作では 8/8 で gated が速かった。通る見込みが高い（構成からほぼ決まる）。
- S4: gshuf ≥ gated が多い見込み（試作では 8 種中 5〜6 種）。つまり、驚きの時の決め方は保ち方には寄与しない見込みである。
- 健全性: 満たす見込みが高い。
