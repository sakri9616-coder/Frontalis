## 0. 位置づけと、第 1 版からの変更
- 土台は v16（`DESIGN-acquire.md`、P66）。物の属性のうち何が快を予告するかを経験から獲得し、相手の言葉の効きを当たり外れから学ぶことを、評価の水準で示した。
- 第 1 版の「従う割合の育ちの差」は、相手の好みと自分の好みの一致を測るだけで、相手の言葉を取り除いても同じ結果になった。鏡でも線形モデルでも同じ向きに通った。理由のある変化は、選択の温度 τ で決まっていた（批評 問い 2・3）。
- 第 2 版は、批評の「先に決めるべきこと」1〜6 に従って直した。
  1. **主張の操作的な定義**: 相手の言葉の効きを、「同じ評価のネットワークの写しで、学習を止め、ほめ言葉 E だけを取り除いた選択確率」との差で定義する（§3）。比べる相手の物を、分野をまたいで揃える。

  4. 結果・個体・条件をすべて書く（§2）。
  5. τ は 3 に固定し、試行の見込みの回数を先に書く（§5）。理由のある変化は、観察の回があるので、試す回数だけでは決まらない形にした。

## 1. どこがニューラルネットワークで、何を経験から学ぶか
- **評価のネットワーク V**: v16 と同じ（MLP D24 → 32 → 32 → 1、ReLU、学習率 0.01、勾配の上限 1.0、経験の後の生得の快 o への 2 乗誤差）。入力は物のベクトル。相手が勧めた物には E を足す。
- **行動**: 毎回 3 つの物が出され、相手がそのうち 1 つを勧める。softmax(τ · V(x_k)) で 1 つを選ぶ（τ = 3）。相手の影響は、学んだ E の重みと、E と物の相互作用だけを通る。従う加点のような手書きの項は無い。
- **学習**: 選んだ物の結果で V(x_選んだ物) を学ぶ。観察の回では、加えて、相手が勧めた物（選んでいなければ）の結果で V(物 + E) を学ぶ。
- 選択的な信頼（E の効きが物の種類で変わること）は、ネットワークの中の E と物の相互作用として学ばれる。開発者は指定しない。線形モデルでは E の重みは物によらず 1 つなので、評価の水準では分野ごとに割り引けない。
- 基準線: **線形モデル**（評価だけを線形回帰にし、選択と学習は同じ）。**鏡**（E のある出来事では、目標を o + 1 にする）。

## 2. 世界、個体、手順
- 物と生得の快は v16 と同じ。育ち X: 赤 → P+（0.8）、丸 → P−（0.8）。赤くて丸い物と音「中」の物は、出さない（音は高・低のみ）。
- 「どちらでもない物」= 緑か青で、四角か三角（音は高・低）。8 個。
- **個体**（1 種につき、同じ初期化から）: X·T0r。育ち 3000 回、受け身。特徴の出来事 0.8、相手の出来事 0.2。相手は「どちらでもない物」だけをほめ、その後に P+（0.8）が来る。**丸い物はほめない。** X·T0r を、ネットワーク・線形モデル・鏡の 3 通りで育て、同じやり取りをする。
- **やり取り（1500 回）**: 毎回 3 つの物を出す。
  - 衝突の回（確率 0.5）: 丸い物（赤でない）1 つ、赤い物（丸でない）1 つ、どちらでもない物 1 つ。相手は丸い物を勧める。
  - 静かな回（確率 0.5）: どちらでもない物を 3 つ。相手は 1 つを等確率で勧める。
  - 結果: 赤 → P+（0.8）、丸 → P−（0.8）。どちらでもない物は、相手に勧められた物なら P+（0.8）、勧められなかった物なら何も無し。つまり、**相手は静かな分野では当たり、丸の分野では外れる**。
  - 観察の回: 毎回、確率 0.3 で、相手が勧めた物の結果も見て学ぶ（選んだ物と同じなら 1 回だけ）。
- **理由のある変化（flip）**: 同じ X·T0r の初期状態から、やり取りの 500 回目以降、丸い物の後に P+（0.8）が来る（相手の丸の勧めが当たるようになる）。flip と flip なしは、全 40 種で両方作る。500 回目までは同じ乱数で同じ軌道になる。

## 3. 言葉の効きの定義（批評の指摘 (i)〜(iii)）
- **e(勧めた物, 比べる物)**: その時点の V の写しで、学習を止めて計算する。2 つの物の選択確率（softmax(τ V)）で、P(勧めた物を選ぶ ∣ 勧めた物に E あり) − P(勧めた物を選ぶ ∣ E なし)。物は雑音なしで入れる。実現した選択は使わない（選択の乱数の揺れが混ざらない）。
- **比べる物を、分野をまたいで揃える**: 比べる物は、どちらの分野でも「どちらでもない物」8 個とする。
  - e_conf = 勧めた物が丸い物（赤でない 4 個）× 比べる物 8 個、の 32 組の平均。
  - e_quiet = 勧めた物がどちらでもない物 × 比べる物（自分以外の 7 個）、の 56 組の平均。
  - 2 択で、比べる物が同じなので、赤い物による飽和（床の効果）は入らない。
- **評価の水準の効き（記述）**: boost(物) = V(物 + E) − V(物) を、丸い物 4 個とどちらでもない物 8 個で平均する（boost_conf、boost_quiet）。選択確率の差が、評価の差から来ているか、softmax の形から来ているかを見分ける。
- 測る時点: やり取りの直前（t = 0）と、最後（t = 1500）。

## 4. 量（評価の種 40 種。同じ種で対にする。合否は「30/40 以上、かつ 0 を除いた符号検定で p < 0.01」）
- **A1（選択的な信頼。主）**: ネットワークで、(e_quiet − e_conf) の t = 1500 の値 − t = 0 の値 > 0。
  - 意味: 相手の言葉の効きが、外れる分野（丸）でだけ下がり、当たる分野（静か）では保たれる（または上がる）。
- **A2（ネットワークに固有か）**: t = 1500 の (e_quiet − e_conf) が、ネットワーク > 線形モデル。
- **A3（迎合しない）**: t = 1500 の e_conf が、ネットワーク < 鏡。鏡の定義（+1 を加える）から通りやすいので、確認の量として扱う。
- **A4（耳をふさがない。証拠を見たら変わる）**: 衝突の回で丸い物を選んだ割合（最後の 500 回）が、flip > flip なし。
  - 観察の回で、試さなくても証拠が届く（flip の後の 1000 回 × 0.5 × 0.3 ≈ 150 回、丸の結果を見る）。
  - 記述: flip の後に丸い物を自分で選んだ回数と、t = 1500 の V(丸) を、flip・flip なしで並べる。
- **健全性**: t = 0 で、V(赤・四角・高) > 0 かつ V(青・丸・高) < 0（ネットワーク）が 36/40 以上。t = 0 の e_quiet > 0（相手の言葉は、当たる分野で効いている）が 36/40 以上。
- **記述**: e_conf・e_quiet・boost_conf・boost_quiet の t = 0 と t = 1500 の平均を、ネットワーク・線形・鏡で並べる。flip なしの衝突の回の従う割合（最初と最後の 500 回）。

## 5. 計算の前に決まっている部分（先に書く）
- t = 0 では、育ちで E は「どちらでもない物」とだけ出たので、E の重みは物によらず正の見込み。丸に対する e_conf も正で始まる見込み（線形なら boost は同じ）。
- A1: 線形モデルでは、E の重みは物によらず 1 つなので、評価の水準の効き（boost）の差は 0 のまま。選択確率の差は、V(物) の違いによる softmax の傾きの違いからだけ生じる。ネットワークで E と物の相互作用が、やり取りの中で新しく学ばれるかは決まっていない（v16 の G4b は、育ちの中の S_round で学ばれ、32/40 だった）。
- A2: A1 と同じ理由で、決まってはいない。
- A3: 構成から通りやすい。
- A4: 観察の回で丸 → P+ の証拠が届くので、どの予測誤差の学習器でも、V(丸) は上がる見込みが高い。決まっていないのは、それが選択に表れる大きさである。
- **τ = 3 での試行の見込み**: t = 0 で V(丸 + E) を −0.5、V(赤) を 0.8、V(どちらでもない) を 0 とすると、衝突の回で丸を選ぶ確率は約 exp(−1.5)/(exp(−1.5) + exp(2.4) + 1) ≈ 2%。flip なしでは、1500 回 × 0.5 × 2% ≈ 15 回。
- 何を快とするか（P+・P−）、世界の確率、相手の勧め方は、開発者が決めている。

## 6. この版が答えないこと
- 未見への移転、除去・入れ替えは測らない（v16 で測った）。
- 何を快とするかの獲得は扱わない。
- 相手は決まった規則で勧めるだけで、AI の行動に反応しない。言葉は 1 つのベクトルである。
- 「自己」とは書かない。書けるのは「相手の言葉の効きを、経験と食い違う分野でだけ下げ、当たる分野では保つことを、やり取りの中で学び、選択に表れた（または、表れなかった）」までである。

## 9. 第 2 版への批評の 4 点への追記（コードの前）

### 9.1 「自分の経験」の因果を試す対照（批評 問い 6 の 1）
- **N·T0r**（育ちで快を経験していない個体）を加える。育ち 3000 回の特徴の出来事の結果をすべて 0 にする（どの物の後にも何も来ない）。相手の出来事は X·T0r と同じ（どちらでもない物をほめ、その後に P+ が 0.8）。同じやり取り（flip なし）をする。
- **先に決める読み**:
  - A1 の量が N·T0r でも同じ向きで通る（Δe_conf < 0 が 30/40 以上）なら、主張の文の「自分の経験と食い違う分野で」を「**結果が外れる分野で**」に書き換える。A1 の報告は「E と物の相互作用を、やり取りの結果から獲得した」（v16 §10 と同じ範囲）に限る。
  - 通らないなら、X·T0r との差が、育ちの経験の寄与である。そのときだけ「自分の経験と食い違う分野で」と書く。
  - 記述として、Δe_conf の平均を X·T0r と N·T0r で並べ、種ごとの差 (X − N) の符号の数を報告する。

### 9.2 A1・A2 の判定の量の固定（批評 問い 6 の 2）
- **A1（主）**: ネットワークの X·T0r（flip なし）で、Δe_conf = e_conf(t = 1500) − e_conf(t = 0) < 0 の種が 30/40 以上、かつ符号検定 p < 0.01（量は −Δe_conf > 0）。
  - 加えて、**A1′**: e_quiet(t = 1500) > 0 の種が 36/40 以上（当たる分野では、まだ聞いている）。A1 と A1′ の両方で「選択的な信頼」とする。
  - 報告では、boost_conf が下がった種の数を必ず並べる。e_conf の低下は、boost の低下（評価の水準の割り引き）からも、丸の評価 V(丸) 自体の低下による softmax の床からも起きうるからである。
- **A2（ネットワークに固有か）**: **評価の水準（boost）**で判定する。t = 1500 の (boost_quiet − boost_conf) が、ネットワーク > 線形モデル。線形モデルは構成上 0 なので、これは **v16 G4b を、やり取りの段階で再確認する量**と位置づける。e（選択確率）での同じ比較は、softmax の形で決まるので記述にする。

### 9.3 A4 の見込みの大きさと、落ちたときの読み（批評 問い 6 の 3）
- 見込み: v16 G4c ではほめの出来事約 80 回で boost が平均 +0.05 しか動かなかった。この版では訓練した入力そのもの（丸 + E）を測るので、より大きく動く見込みだが、flip の後の観察約 150 回で V(丸 + E) が −0.8 から −0.3 まで動くとすると、衝突の回で丸を選ぶ確率は約 2% → 3%。最後の 250 回の衝突の回で、約 5 回対 8 回の差になる。差が 0 の種が多くなる見込みが高い。
- **判定の読み**: A4 は、0 を除いた符号検定の母数（差が 0 でない種の数）が 30 未満なら、「判定不能」と記録する。A4 が落ちても判定不能でも、**「耳をふさぐ」とは書かない**。書けるのは「観察の回の証拠が、この回数と τ = 3 では、選択に表れるほど評価を動かさなかった」までである。
- **A4′（評価の水準。記述）**: t = 1500 の V(丸 + E) と V(丸)（E なし）を、flip と flip なしで並べる。§4 の「t = 1500 の V(丸)」は、この 2 つを指す。

### 9.4 §0 の 2 と 3 が両立していないこと（批評 問い 6 の 4）
- 観察の回は、相手が勧めた丸い物の結果（P−）を、選ばなくても見せる。つまり、やり取りの中で「丸 + E → 悪い」を直接教えている。T0r は、**育ちの中の**この契約を除いただけで、やり取りの中の契約は除いていない。
- したがって、A1 が通っても、「自分の基準が相手の言葉に勝った」とは読めない。読めるのは、§9.1 の N·T0r との比較で育ちの寄与が出た場合だけである。

### 9.5 その他（批評 問い 3 の穴）
- 選択の乱数は、1 回につき 1 つの一様乱数を引き、選択肢の累積確率と比べて選ぶ。flip と flip なしで、乱数の消費はずれない。
- 記述として、t = 0 の e_conf と boost_conf の分布（平均と範囲）を報告する。t = 0 の V(丸 + E) は、育ちで見ていない組み合わせの外挿である。

## 10. 試作（種 0〜7、Colab）で分かったことと、それを見て足したもの
- 健全性は 8/8。開発の種 79400〜79401 は有限。
- **t = 0 の見込みが外れた**: V(丸 + E) は −0.5 ではなく平均 −0.15（E の効きは丸にもほぼそのまま移っていた。boost_conf 0.81、boost_quiet 0.94）。e_conf は平均 0.34（範囲 0.21〜0.55）。
- **A1**: ネットワークの e_conf は 0.34 → 0.04、boost_conf は 0.81 → 0.40（8/8 で低下）、e_quiet は 0.44 → 0.45。線形モデルでも e_conf は 0.37 → 0.08 に下がった（boost は 0.86 のまま。V(丸) が −1.62 に下がった softmax の床）。§9.2 のとおり、A1 だけではネットワークに固有でなく、固有なのは A2（boost の差 0.55 対 0）である。
- **N·T0r**: e_conf は 0.40 → 0.01、boost_conf は 0.70 → 0.05 と、X·T0r より大きく下がった（8 種中 7 種）。§9.1 の読みに従うと、主張の文は「**結果が外れる分野で**」になる見込みが高い。育ちの経験は、言葉を割り引く学習を助けていない。
- **A4**: §9.3 の見込み（2% → 3%）は大きく外れた。最後の 500 回の衝突の回で丸を選んだ回数は、flip 443 回、flip なし 14 回（8 種の合計。全種で flip が多い）。flip の後の V(丸 + E) は 0.67。観察の回の証拠で、選択は大きく変わった。
- **見て足したもの（A5、確認の量）**: やり取りの最初の 500 回の衝突の回で、相手の勧め（丸）に従った回数は、X·T0r 39 回、N·T0r 903 回（8 種の合計、全種で X が少ない）。言葉の効き（e_conf）は両者でほぼ同じ（0.34 と 0.40）なのに、行動が違う。違いは、育ちで学んだ自分の評価 V(丸) の差（−0.95 と −0.01）から来る。これは主題（相手の言葉に対して、自分の評価で選ぶ）を行動で直接測る量なので、A5 として事前登録に加える。ただし試作で見てから足したこと、予測誤差で学ぶどの学習器でも起きること（線形モデルでも 70 回）を、報告に必ず書く。ネットワークに固有だとは書かない。
- 鏡: t = 1500 の e_conf は 0.49、flip では最後の 500 回で丸を 1843 回選んだ（ほぼ常に従う）。
- 試作で、§7 の値と乱数の流れは動かしていない。
