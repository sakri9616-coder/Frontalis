# CRITIQUE-perception-1（Fable 5.1、API 経由、2026-10-23）

入力 22072・出力 7281。判定: 条件付きで進めてよい（条件 1〜5）。

**1. 研究の問いに答えるか**
部分的で、答える部分は「特徴」の一端と「入れ替え」（P2s）だけである。特徴は自己符号化器が x だけから学ぶ（設計 11・14 行、g6_proto 20 行 `ag.ae(x)`）。評価の的 o は開発者が固定し（17 行）、良い型・悪い型の価値の向きも DELTA=0.5 で与える（g5_proto2 6・12 行）。基準 c は H=6 の特徴上の重みで、v10・v11 と同じ範囲にとどまる。したがって「判断基準の獲得」「移転」「除去」には答えない。2026-10-22 の失敗（価値の目標が生得で指定）と同型であることは明記すべきである。答える量は、P1 の線形読み出し正答率の差（P54 で 0.02〜0.04、p53p54 21 行）と P2 の V(良)−V(悪) の対差である。

**2. すり替え**
ある。「評価上の特徴の獲得」が「接触の偏りによる知覚の解像度の差」に置き換わっている。ただしこれは思想 §1 の 1〜3（評価が接触を決め、接触が人格を更新する）に含まれる道なので、循環の一部として正当である。問題は、設計自身が 36 行で「判断が要る」と留保していることで、報告ではこれを「開発者が指定していない特徴の獲得」と呼ばず、「評価が接触を偏らせ、接触が知覚の解像度を偏らせる」までに限ることである。

**3. 計算の前に決まっていないか**
(i) **P1y は構成上の恒等である**。特徴は x の列の関数で、c は k の選択（g6_proto 18 行）を通じてしか関与しない。Pa の k 列を同じ乱数流（re）で与えれば x 列が一致し、Δ は数値まで一致する。別流にすれば標本のゆらぎしか測れない。「接触だけで説明できるか」は実験の問いではなく、設計 14 行の決定の言い換えである。記述として置いても意味がなく、判定に入れてはいけない。代わりに、循環が閉じるかを問うべきである。
(ii) 循環の閉じは P2 にかかっている。P1 は連続の特徴の線形読み出し（g6_hard 18〜20 行）で測るが、手柄と V は 0/1 の pres（g5_proto2 19・20・27 行）を通る。P54 13 行が「0/1 は天井の下の揺れを拾っていた」と認めた通り、0.02〜0.04 の差が 90 パーセンタイルのしきい値を越えて pres に残る保証はない。P1 が通り P2 が落ちる場合、それは思想の失敗ではなく知覚の表現（0/1）が循環を切っている可能性が高い。この解釈を事前に書き、P2 の予想も事前に固定すること。
(iii) β=0 で P1 が偶然の範囲になるのは、選択の偏りが消える（shares 0.29/0.26、p53p54 19 行）からであり、「評価があるが特徴は変わらない」対照ではない。β=0 は「後押しが定着しない」対照だと明記する。
(iv) 判定 28/40 は、観測 0.8（10 種）が真なら 9 割強で通り、0.7 なら五分である。自明ではないが、主世界は P54 で β=4 と β=0 の差が最大だった組（0.8 対 0.1）を選んでいる。副世界は β=0 で 0.6 と高く、新しい種で 0.7 に出ても「記述」で済む構成になっている。

**4. 分岐の道**
世界の事後選択は 17・35 行で開示されており、2 つを固定するなら許される。未固定の値がある: M の初期値 0.5 と更新率 0.05（g6_proto 14・20 行）、較正の標本数 300、o の雑音 0.1、読み出し標本で他要素に型を付けない点（g6_hard 17 行。学習時の分布と違う）。これらを 31 行に加える。種は開発用 0〜9 と評価用で分ける方針は良い。

**5. 本来の目的と欠けている量**
思想 30〜31 行の「蓄積」を見る量がない。循環が働くなら、自由選択の前半と後半で選択の偏りと Δ が増すはずである。これを時間経過の記述量として事前に置くべきである。1:1 の自己には、相手の後押しが知覚まで残るか、という形で近づくが（38 行）、まだ答えない。

**判定: 条件付きで進めてよい**
1. P1y を恒等として削り、代わりに P2 の予想と「P1 通り P2 落ちる」場合の解釈（0/1 知覚が循環を切る）を事前登録する。
2. M の初期値・更新率、較正標本数、o の雑音、読み出し標本の構成を 31 行に固定する。
3. 自由選択の前半・後半の選択の偏りと Δ を記述量に加える。
4. 主世界選択の経緯と副世界 β=0 の 0.6 を事前に書き、両世界を同じ表で報告する。
5. 報告の範囲を「評価が接触を偏らせ、接触が知覚の解像度を偏らせる」に限り、判断基準の獲得・移転・除去と、評価の的が開発者固定（2026-10-22 と同型）であることを明記する。
