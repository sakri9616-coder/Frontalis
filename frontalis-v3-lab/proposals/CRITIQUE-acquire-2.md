## 問い 2: 測りやすい代わりの問いへのすり替え

**第 1 版のような隠れたすり替えは無い。しかし、2 か所で記述が測定を越えている。**

- **G2（48〜49 行）**: 「学ぶ向き（どの属性に手柄を付けるか）が、それまでに獲得した特徴で決まる」と書くが、測るのは ΔV(緑・三角・低) の 1 つだけである。これは「三角」と「低」に付いた手柄の**和**であり、向き（三角と低のどちらにどれだけ付くか）も、赤から三角・低へ手柄が移ったことも、分からない。測っているのは「Y のほうが驚きが大きいので多く学ぶ」で、線形の数で言えば、X の誤差 ≈ 1.0 − 0.8 = 0.2、Y の誤差 ≈ 1.0 − (−0.8) = 1.8。等分なら ΔV(X) ≈ 0.13、ΔV(Y) ≈ 1.2。これは RW の超条件づけであり、62 行が自認するとおり「予測誤差で学ぶどの学習器でも」起きる。

  研究の問いの字義「同じ経験から何を学ぶかが変わる」には当たる。しかし、変えているのは獲得した**値**（赤の重みの符号）であって、獲得した**基準**ではない。「値が違えば誤差が違い、誤差が違えば学習量が違う」は、状態を持つ学習器なら何でも満たす。G2 を研究の問いへの答えとして記録するなら、「学習量の違い」としてだけ記録し、「手柄の付け方の違い」とは書かない。

- **G4（53 行）「相手の言葉を、快ではなく証拠として受け止める」**: 「証拠として」を示しているのは G4a（T+ と T− で重みが違う）だけである。鏡（E を o = +1 として学ぶ: 23 行）との違いが最も直接に出るのは G4a（鏡は T+ = T− になる）であって、G4b ではない。ところが鏡は G4b でしか対照に使われていない（56 行）。G4b での鏡との差は、線形で言えば +0.2 と 0.0 の差で、小さい。鏡の対照は G4a に置くべきである。

## 問い 3: 計算の前に決まっているか（世界の確率・育ちの組み合わせの穴を含む）

§5 の自認（G1 は通る、G2 は通る見込みが高い、G4a・G4c は通る見込みが高い）は正しい。以下、§5 に書かれていない点を指摘する。

**(a) G4b は、世界の確率が期待値を 0 ちょうどに置いている。**
- 28 行: 丸い物の後に P−（確率 0.8）→ 丸の重みの期待値 = 0.8 × (−1) + 0.2 × 0 = −0.8。
- 32 行: ほめた物の後に P+（確率 0.8）。ほめる物（緑・三角・高）はほめ無しでは o = 0（30 行）なので、差は E に帰属し、E の重みの期待値 = +0.8。
- 55 行: V(青・丸・高 + E) < 0 が合格。線形の予測は −0.8 + 0 + 0 + 0.8 = **0.0**。
- つまり合否は、MLP の非線形な相互作用と種の雑音で決まる。「分からない」（64 行）と書くのは正しいが、分からないのは**開発者が分からないように置いたから**である。0.8 と 0.8 の対称が、答えを「決めていない」のではなく「どちらにも決まらない」ようにしている。

**(b) G4b が問う「自分の基準が優先する」は、育ちの経験から導かれない。**
- 32 行: ほめる物は、育ちの特徴と重ならない組から選ぶ。したがって、相手が自分の経験と食い違う場面は、育ちの間に**一度も無い**。V が「食い違うときにどちらを採るか」を学ぶ機会は無く、G4b は訓練の外への外挿である。
- 外挿の答えを決めるのは、入力が属性の**和**であること（26 行、31 行）と MLP の形であり、これは開発者が決めた結合の規則である。したがって G4b で測れるのは「開発者の決めた和の規則で、線形が 0 を出す場面に、ネットワークがどちらに逸れるか」であって、「獲得した受け止め方」ではない。
- 加えて、T+ の相手は網の経験の範囲で常に当たっている。その相手のほめ言葉を、自分の経験（丸 ≈ −0.8）と同じ重さで足して 0 にするのは、迎合ではなく統合である。「0 未満にとどまる」ことを正解とする根拠は設計に無い。思想「合格させるためにしきい値を調整しない」は、しきい値が恣意なら、最初から立たない。

**(c) G4a の T− は、確率が期待値を 0 に置いている（33 行、半々）。** これは「当てにならない」の自然な定義なので穴ではないが、G4a の T− ≈ 0 は構成上決まる。G4a の判定は T+ > T− で、これは 0.8 対 0.0 の差であり、通る。

**(d) G3 は、選び方が符号を含まないため、結果が裏返りうる。**
- 50 行: 「赤い物と赤くない物での活性の差が最も大きい 4 個」。出力層が線形なら、出力への寄与の差は w_out × (a_赤 − a_赤以外) である。活性の差が大きくても、w_out が負の向き、または赤で活性が**低い**ユニットなら、それを 0 にすると D1 は上がる。「活性の差」が符号つきか絶対値か、どの入力の集合で測るか（見た 16 個か、全 27 個か）、寄与で選ぶかが書かれていない。
- 選び方を寄与の差（正で最大）に固定すれば、G3a はほぼ通る（32 個のうち赤を最も担う 4 個を取れば、赤の寄与が減らないことはない）。残る未決は 63 行の「どれだけ局在しているか」だけで、これは G3a の**量**である。
- **G3b は G3a からほぼ従う。** 赤の寄与が減る → V(赤・三角・低) が下がる → 共通の経験の誤差が増す → ΔV が増す。これは G2 と同じ RW である。G3b が G3a に足すものは、「誤差が増せば多く学ぶ」という自明の事実だけである。G3 の研究上の中身は G3a（学んだ特徴が特定のユニットに担われ、文字どおり外せる）にある。
- G3 の「外す」を「値を下げる」から区別したいなら、対照に「外さずに赤の値を下げた個体」（例: 赤 → 何も来ない の経験を追加）を置き、G3b の ΔV がそれと違うかを見る必要がある。今の対照（ランダムな 4 個: 50 行）は「外す位置が関係するか」しか示さない。

**(e) 育ちの組み合わせと対の作り方に、答えを左右する未指定がある。**
- 34 行: 1 種につき 4 個体（X·T+、X·T−、Y·T+、Y·T−）。44 行: 「育ちの組を同じ種で対にする」。G1・G2 は X 対 Y だが、**どの T の個体で対にするか**が書かれていない。T+ では E の相手が緑・三角・高をほめており、G2 の試験物（緑・三角・低）と緑・三角を共有する。T の選び方で G2 の値が動く。
- 32 行: 「緑・三角・音「高」の組から選ぶ」が、その 1 個の物を指すのか、緑か三角か高を持つ物の集合を指すのか、読めない。前者なら、E は 600 回すべて同じ物と同時に出る。識別はほめ無しの 150 回（2400 ÷ 16 個）に依り、ネットワークが E 単独ではなく「E かつ緑・三角・高」の結合として学べば、G4a の移転（緑・四角・中 + E）は弱まる。
- 「同じ物を同じ回数見る」（27 行）は書かれているが、特徴の出来事と相手の出来事の**混ぜ方**（37 行「混ぜる」）が書かれていない。

**(f) 健全性（58 行）は X だけで、Y の条件が無い。** 書き忘れだと思うが、Y の G1・G2 を判定に使う以上、Y にも要る。

## 問い 6: 進めてよいか

**進めてよい。ただし、コードを書く前に次の 5 点を設計に書き足す。** 第 3 版の書き直しは要らない。追記でよい。凍結前の批評で、追記が守られたかを見る。

1. **G4b を直すか、判定から外す。** 直すなら、(i) 育ちの間に、相手が自分の経験と食い違う場面を入れる（たとえば T+ の相手が、丸い物もほめ、その後に P− が来る）。これで「どちらを採るか」が経験から学ばれる状態になり、G4b が「獲得した受け止め方」を測る。(ii) 境界を 0 ではなく、線形モデルの予測との差で定義する。外すなら、G4b は記述に下げ、主題の判定は G4a（鏡を対照に加える）と G4c で行うと書く。どちらにするかを、試作の前に決める。
2. **G3 の選び方を、出力への寄与の差（正で最大）に固定し、測る入力の集合、ランダムの引き方、外したまま学習させること、外す個体の T、手順の中の位置を書く。** できれば「外さずに値を下げた対照」を加える。
3. **G1・G2 の対の T、ほめる物の集合、混ぜ方、Y の健全性を書く。**
4. **活性関数、バイアス、初期化、ベクトルと E のノルム、鏡の作り方を書き、69 行の固定値の一覧に加える。**
5. **§4 の G2・G3b の記述を測定に合わせる。** 「学ぶ向き（どの属性に手柄を付けるか）」（49 行）は、測らないなら書かない。測るなら、ΔV(緑・三角・高) と ΔV(緑・四角・低) を分けて、三角と低への手柄の配分を線形モデル（等分になる）と比べる量を足す。これは線形で出ない、ネットワークの共有の重みに固有の量になりうる。

### この版の位置づけ
上の 5 点を書けば、この版は「属性の組み合わせから、どの属性と言葉が快を予告するかを獲得し、未見の組へ移し、獲得した特徴を担うユニットを文字どおり外せる」ことを測る設計として成り立つ。それが研究の問いの「特徴」「移転」「外す」に当たる。「判断基準」「入れ替え」には答えず、G2・G3b・G4a・G4c は予測誤差の学習器として当然の振る舞いの確認である。記録・報告は、その範囲を越えない。
