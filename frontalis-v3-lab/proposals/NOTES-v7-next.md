# NOTES-v7-next: V3 の次に何を測るか（設計メモ。事前登録ではない。2026-10-22）

## 1. V3 が通ったあとに残る構造上の限界
- O3 の個人は、凍結した符号化器の上の**線形の頭**（`h.Wv`: 128 → KB）である（`diag5/sim5.py` 190 行）。
- したがって、個人の状態は「評価の関数 V」で尽きる。符号化器の特徴の張る空間の外に隠れた状態は、あっても新しい経験の学び方に効かない。
- 帰結:
  1. 「頭を入れ替える」検査は、V を入れ替える検査と同じで、後の学習が変わるのは自明である。v5 の J3v5（w だけの入れ替え）が測定の効果に留まったのと同じ型の結果になる。
  2. 「V を合わせた経歴なしの頭」との対照（形成と表出を分ける検査）は、線形の頭では構成上、差が出ない。測る前から落ちる。
- 研究の中心課題（開発者が指定しなかった評価の特徴・関係・基準の獲得。除去・入れ替えで後の解釈と学習が変わる）に進むには、**個人が経験で変えられる特徴**を持たせる必要がある。V3 は、その手前（刻印が経路の揺れに埋もれない）を示しただけである。

## 2. 候補（最小のものから）
- **B1: 個人のアダプタ**。凍結した符号化器の最後の層に、個人ごとの低ランクの差分（rank r、例 4〜8）を足し、頭と一緒に学ぶ。個人は、特徴そのものを経験で変えられる。共有の符号化器は動かさない。
- B2: 個人の符号化器を全部学習する（NN-SET）。経路の揺れが大きく、V3 の前の状態に戻る。採らない。
- B3: 個人の可塑性の状態 w（v5 の wgate）。手で計算する統計で、学習した評価ではない。採らない。

## 3. B1 で測りたい量（案）
- **刻印**: V3 と同じ H・S・E（アダプタ + 頭の 4 本平均）。V3 の o3 と比べる。
- **移転**: 経歴で形成したアダプタの特徴が、未見の文脈（nc）の評価を、アダプタ無しの o3 より予測するか（R²_nc の差）。
- **除去**: アダプタをゼロにしたとき、V の変化が、同じ大きさのランダムな差分を足したときより大きいか。
- **入れ替え**: 受け手に提供側のアダプタだけを入れたとき、新しい経験の学び方が、受け手自身の再試験の揺れより大きく変わるか（J3 の型。頭は受け手のもの）。
- 線形の頭のとき、入れ替えが自明になる問題は、アダプタ（特徴）が変わるので避けられる。ただし、V の差を通すだけの効果と区別するには、「V を合わせた対照」が要る（案: アダプタを入れ替えた後に、受け手の頭を V が元と一致するよう再学習した場合の学び方の差）。

## 4. 進め方の案
1. 開発用の種（77380〜77389）で、B1 の試運転 P39 を 1 回（mid 規模、Colab の T4 で 30〜40 分の見込み）。刻印 H／S／E と R²_nc の差だけを見る。
2. 通る見込みがあれば、最小の事前登録を書く（V3 と同じ手順: DeepSeek の査読 1 回、凍結、評価の種 77500〜77539）。
3. 通る見込みがなければ、記録して止める。しきい値は変えない。

## 5. 費用と注意
- Colab の有料プランの計算単位を使う。P39 は 1 回、評価は 4 ジョブで足りる（V3 は合計 約 30 分だった）。
- 評価の種は 77500〜77539 の 1 回きり。使い切ったら、新しい範囲を決めるときにユーザーに確認する。
- B1 はアダプタを足す機構の変更である。これを選んだ理由を、開発用の試運転の結果を見る前に、事前登録に書く。
