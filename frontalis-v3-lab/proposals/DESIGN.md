## 0. 中心課題と、この設計が答えること

> 経験によって、開発者が事前に指定していない評価上の特徴・関係・判断基準を獲得し、それらが次の経験の解釈と学習を変える仕組みを研究する。（再定義）

この設計は次の 3 つを、反証可能な形で問う。

- **Q1 形成**: NN の内部表現に、学習前には無かった特徴・関係が、経験によって現れるか。測り方は開発者の軸を前提にしない。
- **Q2 転移**: その特徴が、記憶では答えられない未知の経験の評価に作用するか。
- **Q3 循環**: その特徴を外す・入れ替えると、次の経験の解釈と学習が変わるか（研究思想 §6）。

加えて、副次の問いとして **Q4 判断基準**: 同じ予測（信念）を持つ二つの人格が、獲得した表現のせいで違う評価をするか（研究思想 §6「予測と評価の区別」）。

**この設計の立場（ユーザーの指摘の反映）**
1. 仮説そのものが、開発者が列挙していない特徴同士の複雑な重み付け（交互作用・関係・文脈による分化）の獲得を要求する。したがって主モデルは、それを表現できる NN である。「NN の優位を前提にしない」は「NN の役割を小さく扱う」ことを意味しない。
2. 線形モデルと固定の欲求モデル（v3 の価値ネット）は、勝敗を競う相手ではなく**陰性対照**である。相互作用のある世界で線形が負けるのは予想どおりで、NN がそれに勝つこと自体は成果にしない。
3. 判定の中心は Q1〜Q3 で、平均の予測誤差で勝つかは主判定にしない。
4. 記憶の継承だけなら文脈を渡せば済む（ユーザー）。したがって**記憶の対照（全履歴を検索できる評価器、LLM に全履歴を渡す評価器）**を必ず置き、NPN の主張は「記憶では出ない Q1〜Q3」に限る。

## 1. 操作的定義: 「開発者が指定していない評価上の特徴を獲得した」

人格 θ（経験史 H で学習した状態）、経験 x、評価 A_θ(x)（接近・回避・学習の制御に使われる量。第 4 節）とする。
評価上の特徴 F を、θ の内部表現の部分空間（方向の組）として定義し、次の 5 条件を**すべて**満たすとき「H から F を獲得した」と呼ぶ。

| 条件 | 内容 | 測り方（第 7 節） |
| --- | --- | --- |
| D1 形成 | F は学習前（θ_0）にも、対照の経験史（構造を壊した世界 F5 で同じ量の経験）にも無い | 表現の変化の主方向（学習前との差の特異ベクトル）として、生成器の潜在変数を参照せずに見つける。初期化・対照での分散との比 |
| D2 評価での使用 | F は評価 A に因果的に寄与する | 平均を保つ射影で F を外すと、未知の経験の評価が変わる。同じ次元数の無作為な方向を外した場合より大きく |
| D3 開発者の軸の外 | F による評価の差は、開発者の軸（v3 の 5 欲求 × 固定特徴、または生の入力の線形）では表せない | 陰性対照（FIX-K、LIN-raw）を同じ経験史で学習させ、F が担う評価の差を再現できないことを確かめる。**ここは対照が失敗することの確認であって、NN の成果ではない** |
| D4 転移 | F は、表面の記号が学習中に一度も評価と結びつかなかった経験に作用する | 未見の個体・未見の組み合わせ・未見の関係の配置・未見の系列。個体の記号を新しい乱数に置き換えても評価が保たれる（記号の記憶でない） |
| D5 循環 | F は、次の経験の解釈と学習を変える | 同じ新しい経験の列から学んだときの、評価の変化のベクトルが、F を外すと変わる。F を他の人格のものと入れ替えると、解釈（帰属・符号化）が入れ替え元へ寄る |

**関係と判断基準の扱い**
- 「関係」: 二つ以上の獲得した特徴の評価への寄与が加法でない（交互作用）こと。F_i と F_j を別々に外した効果の和と、同時に外した効果の差で測る。
- 「判断基準」（Q4）: 信念（生得信号の予測）を揃えた上で、評価が獲得した表現に依存して人格ごとに違うこと。第 4.3 節の候補機構で測る。Q4 は副次で、Q1〜Q3 が成り立たない限り意味を持たない。

**[仮説] この定義の弱点（自分で攻撃する）**
- D1〜D5 は「F が世界の構造を表し、評価に使われる」ことまでを示す。F が生得信号の予測（信念の一種）にすぎない可能性は残る。研究思想 §6 は予測と評価の区別を求めるので、**Q1〜Q3 の合格だけでは「価値の獲得」と呼ばず、「評価上の特徴・関係の獲得」と呼ぶ。** 「判断基準の獲得」は Q4 の合格を要する。
- D3 は陰性対照の表現力の限界に依存する。対照を弱く作れば D3 は自明に通る。対策: 陰性対照には、同じ生の入力、同じデータ、同じ調整の予算を与える（第 5 節「余地」）。

## 2. 生得の構造と信号（最小限）と、それが価値の種類を決めないという議論

### 2.1 置くもの

| 生得の要素 | 内容 | 根拠 |
| --- | --- | --- |
| I1 体の信号 | 経験ごとに、名前のない少数の連続信号 s ∈ R^d（d = 3）。世界がそれを作る。NPN は各成分の意味を知らない（成分の順序は人格の種ごとに並べ替える） | [仮説] 何かを「良い・悪い」と感じる最小の基礎。人の快・不快、痛みに相当する |
| I2 生得の快 | v = σ · s（σ ∈ {±1}^d は世界の種ごとに無作為。全人格に共通） | [便宜] 評価の符号の最小の基礎。これを置かないと評価の訓練信号が無い（第 2.3 節の I0 で、置かない条件も検査する） |
| I3 学習則 | 勾配法（Adam）、TD(λ)、再生の緩衝 | [便宜] 汎用の学習則。どの特徴を作るかを決めない |
| I4 符号化の形 | 経験は記号の集合（個体・文脈・出来事のトークン）。集合の上の汎用の符号化器 | [便宜] 入力の形式。第 2.3 節で攻撃する |

**置かないもの**: 欲求の名前、効果表、結果型の語彙、感情の式、名前のある埋め込みの軸。経験は「何が起きたか」の生に近い記述で届き、評価済みの語（betrayal など）では届かない（AUDIT.md E12 の反省）。

### 2.2 これらが「獲得できる価値の種類」を決めない、という議論

- **価値の内容は世界と経験史から来る。** I1 の信号は、世界の潜在変数（個体の性質、文脈、関係、直前の出来事）の無作為な非線形関数である。どの個体・どの関係・どの系列が快に結びつくかは、世界の種と経験史が決め、開発者は書かない。
- **評価の軸の数は決めていない。** v3 の 5 欲求と違い、評価に使われる特徴の数と形は学習の結果であり、測定の対象である（第 7.1 節の有効次元）。
- **符号は I2 が決めるが、何に符号が付くかは決めない。** v3 では 18/19 の結果型の符号を開発者が決めていた（AUDIT N1）。ここでは符号が付くのは名前のない信号で、どの経験がその信号を生むかは学習で見つける。

### 2.3 自分による攻撃（この議論が破れる所）

1. **I2 は「価値の種類」を一つに固定している。** v = σ·s の最大化という一種類の価値の下で、獲得されるのはその手段（道具的価値）だけではないか。→ 正しい指摘で、完全には反論できない。対応: (a) Q4 で、同じ予測でも評価が人格ごとに違う機構（第 4.3 節）を検査する。(b) 条件 **I0**（I2 を置かず、予測誤差と学習の進み具合だけを内発の信号にする）を並べ、獲得された評価の特徴が I2 にどれだけ依存するかを測る（第 7.5 節「生得による決定の指数」）。(c) 結論の言葉を制限する: I2 の下で獲得されたものは「I2 に接地した評価特徴」と呼ぶ。
2. **符号化器の帰納バイアスが、作れる特徴の種類を決める。** 集合の符号化器は、集合の要素間の関係を作りやすく、時間の関係は作りにくい。→ 対応: (a) 封印した構造族 F7（第 3.3 節）を、符号化器の設計者と別の担当が作る。(b) 符号化器を 2 種（集合 MLP、関係の注意機構）にし、どちらにも有利でない構造を含める。(c) 残る弱点として ESCAPE-AUDIT.md に書く。
3. **世界の構造族を開発者が選んでいる。** 交互作用のある世界を作れば、交互作用を見つける NN が「成功」するのは当然ではないか。→ 世界が構造を持つことは許される（再定義: 世界には構造がある。人格の価値は指定されない）。問題になるのは、その構造を NPN に教えることである。対策は第 3.4 節（規則の漏れの検査）と、事前登録の反証条件 FC1。
4. **d = 3 という信号の数が、評価の次元の上限を作る。** → 評価の次元は信号の数ではなく、信号を生む世界の関係の数で決まる（同じ 1 つの信号が、多数の関係から生じる）。ただし I0 との比較で検査する。

**判断が必要（ユーザー）**: I2（無作為な符号の和）を置くことは、再定義の「最低限の初期信号」に入るか。それとも I0 だけを主条件にすべきか。私の提案は、I2 を主条件、I0 を必ず並べる対照とすること。理由: I0 だけでは「評価」と「予測」の区別がつかず、Q4 が定義できない。

## 3. 世界と経験の生成器

### 3.1 原則
- 世界は構造を持つ。人格の価値は指定しない。生成器のどこにも「正しい評価」のラベルは無い。
- NPN が受け取るのは、観測（生に近いトークンのベクトル）と体の信号 s だけ。潜在変数、構造族の名前、生成器の行列は受け取らない。
- 観測は潜在変数の無作為な射影（名前のある軸を持たない）と、意味の無い識別子と、雑音・無関係な次元の和。

### 3.2 構造族（設計者が書く。どの族かは NPN に教えない）

| 族 | 構造 | 線形・固定軸で表せるか |
| --- | --- | --- |
| F1 性質 × 文脈 | 信号が個体の性質と文脈の潜在変数の積に依存（例: s = tanh(tᵀ B c + …)） | 表せない（AUDIT N3） |
| F2 関係 | 信号が、同席する二者の潜在的な関係（同盟・対立のグラフ）に依存 | 表せない（N4） |
| F3 時間の関係 | 信号が、同じ相手との直前の出来事に依存（例: 害の後の償い） | 表せない（N5） |
| F4 体制の変化 | 時刻 T* で一部の関係の符号が反転する | 持続と可塑性の検査 |
| F5 構造なし（陰性対照） | 信号を個体 × 文脈の表の中で並べ替える。記憶でしか当てられない | 測定の妥当性の検査 |
| F6 加法だけ（陰性対照） | 信号が潜在変数の加法 | 線形で足りる。NN の特徴の形成が「要らない」世界 |
| F7 封印した族 | 別の担当が設計し、ハッシュで封印。設計者・実装者は評価の実行まで中を見ない | 族への過適合の検査 |

各族の観測には、未見の個体（性質は観測できる）、観測できない性質（経験からしか推測できない）、無関係な次元を含める。

### 3.3 封印した族 F7 の手続き
- Stage 0 で、NPN の実装者とは別のエージェントが、F1〜F6 と異なる構造を 1 つ以上書き、生成器のコードの SHA-256 だけを記録する。評価の実行まで、実装者はそのコードを読まない。
- F7 で Q1〜Q3 が通らず F1〜F3 だけで通る場合、結論は「設計者が想定した構造族では獲得した」に限定する（反証条件 FC1）。

### 3.4 規則の漏れの検査（世界の生成規則を人格に教えていないか）
- NPN のコードは生成器を import しない（静的検査）。
- 符号化器の形・ハイパーパラメータは、開発用の族（F1・F6 の開発用の種）だけで決め、評価の族の結果を見て変えない。
- 族ごとの切り替え、族の名前、潜在変数の次元数を NPN に渡さない。
- 「族の手がかり」の検査: 観測だけから族を当てる分類器が偶然以上に当てても構わない（世界の性質）が、NPN の設定がそれに応じて変わらないことを確認する。

### 3.5 二つの入力の経路
- **経路 S（合成、主判定）**: 上のベクトルのトークン。意味の事前知識が入り込まない。
- **経路 L（言語、副次）**: 同じ潜在の出来事を、LLM が自然文に書く（第 9 節）。主判定は**造語の語彙**（意味を持たない動詞・名詞）で行う。自然な語（「裏切った」など）は人の評価を運んでしまうので（AUDIT E12）、自然な語は生態的な追加検査に限り、事前知識の漏れを測る（第 9.2 節）。
- 体の信号 s は、どちらの経路でも潜在変数から作る。LLM の出力は信号を作らない（LLM の感情判断を教師にしない、既存の原則）。

## 4. NPN の構成（価値側）

### 4.1 構成要素
- **符号化器** E_θ: 経験のトークン集合（と、個体ごとの直前の経験の記憶トークン）→ 表現 h。候補は第 5 節。
- **信念の頭** P_θ: h → 次の体の信号 s の予測（予測であって評価ではない）。
- **評価の頭** A_θ: h → 評価（スカラー v̂ と、必要なら多次元の評価ベクトル）。TD(λ) で v = σ·s の割引和へ。評価の頭は信念の頭と表現を共有する条件と、別の符号化器を持つ条件の両方を置く（予測と評価の分離の検査）。
- **解釈**: (a) 新しい経験の符号化 h（獲得した特徴の上の位置）、(b) 信号の帰属（どのトークンが評価の変化を担ったか。積分勾配で測る）、(c) 曖昧な経験（行為者が隠れている、トークンが欠けている）での推論。
- **学習の制御**: 評価が次の学習を変える経路（第 4.3 節の候補）。

### 4.2 学習の記録
v3 の台帳の考え方を引き継ぐ: 経験ごとの入力・信号・評価・損失・更新の大きさを追記専用で残し、訂正（事実の後の変更）と当時の主観を区別する（v3.3 Y5 の原則）。

### 4.3 判断基準（Q4）の候補機構 — 事前に並べて比べる。どれも価値の内容を決めない
| 条件 | 機構 | 予測と評価がずれる理由 | 文献 |
| --- | --- | --- | --- |
| C-TD | 評価の頭を TD で学ぶだけ | 選択がある経験では、回避した選択肢を再び試さないので評価が残る（サンプリングの経路依存） | 文献に基づく仮説: Denrell & March 2001（refs-verified #14。検証水準: 検索で書誌と要旨を照合、本文未読） |
| C-AUT | 獲得した特徴に、過去の予測力に応じた内発の重みが付き、ゆっくりとしか減らない（機能的自律） | 体制の変化（F4）の後も、特徴そのものが評価される | 文献に基づく仮説: Allport 1937（refs-verified #1）、Dickinson 1985（同 #2、DOI 未照合）。いずれも検索での要旨照合、本文未読。式は独自仮説 |
| C-GATE | 評価の大きさと不確実性が、表現の学習の速さと帰属を制御する（評価 → 学習の精度。v3.2 の a → R/a の一般化） | 同じ経験から、人格ごとに違う部分が学ばれる | 文献に基づく仮説: Behrens et al. 2007（refs-verified #18、要旨照合のみ）。式は独自仮説 |

**[仮説]** C-AUT と C-GATE は、価値の出力が学習に戻る経路を持つので、研究思想 §6 が警戒する自己強化になりうる。故障は計算の破綻（非有限、規則違反、記録から再構成できない、無関係な価値の崩壊、飽和）に限り、持続・偏りは故障としない（v3.4 の原則を継承）。

## 5. モデルの候補と対照（同じ「余地」を与える）

### 5.1 NN に余地を与える条件（勝敗が決まる前に固定する）
| ID | 条件 | 値 |
| --- | --- | --- |
| R1 | 入力が高次元で生に近い | トークンあたり 48〜64 次元、1 経験に 3〜12 トークン、名前のある軸なし |
| R2 | 関係の構造がある | F1〜F3、F7 |
| R3 | 文脈の分化がある | 同じ個体が文脈で逆の信号を生む組を、全体の 30% 以上 |
| R4 | 規模 | 学習する個体の数 N_ent ∈ {80, 320, 1,280}（未見の個体は別に 200）、文脈 12 以上、経験数 N ∈ {500, 2,000, 8,000, 32,000}。N_ent と N は別々に操作する（P1 の後に追加。第 11.1 節） |
| R5 | 学習 | 経験あたりの更新回数 S/N ∈ {1, 4, 16}（総更新回数を経験数と別に操作）、Adam、重み減衰の格子 {0, 1e-4, 1e-3}、再生の緩衝 4,096 |
| R6 | 調整の予算 | どのモデルにも、開発用の世界（F1・F6 の開発用の種）で同じ回数（12 設定）の調整。選ぶ指標は開発用の世界の検証損失（評価の指標とは別） |

### 5.2 モデル
| ID | 役割 | 内容 | 与える余地 |
| --- | --- | --- | --- |
| FIX-K | 陰性対照 | v3 の価値ネットの形: 個体・文脈・出来事の one-hot（＋無作為な固定の 8 次元）の加法、階層カルマン。体の信号へ回帰 | R1 の生の入力は使えない（v3 の形のため）。同じ経験数・同じ調整の予算 |
| LIN-raw | 陰性対照 | 生の入力（集合の和で潰す）の線形、オンライン | R1・R4・R5・R6 |
| RF | 対照（非線形の容量はあるが、表現を学ばない） | 固定の無作為な ReLU 特徴（幅は NN の隠れ層の総数と同じ）＋線形の読み出し | R1・R4・R5・R6。**表現の変化 D1 は定義上 0 なので、転移と介入で比べる** |
| EPI | 記憶の対照（「文脈を渡せば済む」） | 全履歴を保持する近傍・カーネル回帰（生の入力の距離）。経路 L では、LLM に全履歴の文を渡して評価させる（第 9 節） | 全履歴（NPN より多い情報） |
| NN-SET | 主候補 1 | 集合の MLP（DeepSets 型）、隠れ 2 層 × 128 | R1〜R6 |
| NN-REL | 主候補 2 | トークン間の注意（2 層、d = 64、4 頭）＋個体ごとの直前の経験の記憶トークン | R1〜R6 |

**[仮説] 予想（判定には使わない）**: F1〜F3 では FIX-K と LIN-raw の転移はほぼ 0、RF は N が大きいと一部、EPI は未見の個体で弱く、NN が Q1〜Q3 を満たすかが本当の問い。F6 では全モデルがほぼ同じ。F5 では全モデルの転移が 0。

**NN に不利な条件も入れる。** 入力層が全結合の NN は、疎な目標（少数の入力次元だけが効く）で、疎な線形のモデルより標本効率が悪いという報告がある（Warmuth, Kotłowski, Amid, ALT 2021。検証水準: 講演ページのみ、論文本文は未読、`literature/verify-T2.md`）。この設計の入力には無関係な次元が多いので、この不利は実際に効きうる。対応: (a) F6 に「少数の入力次元だけが効く加法の世界」の変種 F6s を加え、NN が負ける条件として報告する。(b) 無関係な次元の数を 2 水準（8、64）で操作し、NN の標本効率への影響を報告する。どちらも NN を有利にするための条件ではない。

### 5.3 データの規模と学習回数の分離
- 経験数 N と経験あたりの更新回数 S/N を格子で別々に操作する（v3.3 批評の検算 A: 300 回と 1,000 回で結論が逆転した反省）。
- 一回だけ通すオンライン学習（人格の自然な条件）と、再生による多回学習（「固定化」）を別の条件として報告する。

## 6. 研究思想 §6 の循環との接続、v3.4（Y 系）の扱い

- 循環: 評価状態 θ → 新しい経験の解釈（符号化・帰属・曖昧さの推論）→ 評価 → 学習（勾配の向きは、帰属と、C-GATE では評価の大きさに依存）→ 次の θ。D5 はこの循環の各矢印を介入で切って測る。
- v3.4 の M1（吸収）: 学習した表現の上では、「予測をちょうど Δ だけ動かす最小の変化」を、カルマンの Σ の代わりに Fisher 情報（または NTK）の計量で定義できる（Δθ = F⁻¹Jᵀ(JF⁻¹Jᵀ)⁻¹Δ）。表現が違えば同じ訂正の配分（向き）が違う、という v3.4 の論点を、固定軸から学習した表現へ移せる。**[仮説]**
- M2（情報源の信用）: 表現に依存しない Beta の計数なので、そのまま移せる。
- M3（罪悪感・後悔・τ）: τ を「自分の解釈（帰属・曖昧さの推論）への信頼」の温度として、学習した表現の上の推論に掛ける。
- **扱いの順序**: v3.4 は凍結した比較対象のまま残す（C-Y、固定軸）。表現の上の M1〜M3 は、Q1〜Q3 が評価の種で合格した後に、別の事前登録で行う。Q1〜Q3 が通る前に循環の機構を載せると、また固定軸の研究に戻る危険があるため。

## 7. 測定（開発者の軸を前提にしない）

### 7.1 表現の変化（Q1）
- **変化の主方向**: 学習用の入力で、学習後の隠れ表現と学習前の表現の差を取り、その上位 k 個（k = 2, 8）の特異ベクトルを「獲得した方向」とする。生成器の潜在変数は使わない。
- **対照の経験史との対比**: 同じ世界で構造を壊した経験史（F5 の並べ替え）で学習した人格の主方向と比べ、構造のある経験史だけに現れる成分を取り出す。
- **幾何の変化**: 線形 CKA（学習前との類似度）、評価に関わる部分空間の有効次元（評価の頭の勾配の、プローブの上での共分散の有効階数）。
- **事後の注釈だけに潜在変数を使う**: 獲得した方向が、生成器のどの潜在変数（例: 交互作用の項）を線形に読めるかを報告する。これは判定ではなく、どの方向が何を表すかの説明である。潜在変数で説明できない分散の割合も報告する（設計者が想定しなかった特徴の候補）。

### 7.2 転移（Q2）と記憶の排除
- プローブ: 未見の個体 × 既知の文脈、既知の個体 × 未見の組み合わせ、未見の関係の配置、未見の系列、封印した族 F7。
- 基準: R² は、観測できる情報だけを使う神託の予測（生成器から、観測できない性質について周辺化して計算する）に対して測る。神託そのものの、真の信号に対する R²（転移の上限）を並べて報告する（P1 の後に変更。第 11.1 節）。
- 記号の置き換え: 個体の識別トークンを新しい乱数に置き換えても評価が保たれるか（識別子の記憶でない）。
- F5（構造なし）で同じ手続きをしたとき、転移が 0 で、表現の主方向の除去の効果も無作為な方向と同じであること（**測定の妥当性の陰性対照**。ここで「獲得」が出たら測定が壊れている）。

### 7.3 介入（Q3）
- **除去**: 平均を保つ射影で獲得した方向を外す。対照は**分散を揃えた**同じ次元数の無作為な方向（学習後の表現の主成分のうち、獲得方向と直交する部分空間から、分散が同程度のものを選ぶ）。分散の小さい方向を外す対照は不公平（P1 の後に変更。第 11.1 節）。
- **入れ替え**: 経験史 H_A の人格の評価の頭と獲得した部分空間を、同じ世界の経験史 H_B の人格に移す（v3.4 の val-swap の一般化）。曖昧な経験の解釈（帰属の分布）が入れ替え元へ寄るか。
- **次の学習**: 全人格に同じ新しい経験の列（未見の個体について、一部の文脈だけ）を与え、学習で生じた評価の変化（未見の文脈での評価）を比べる。獲得した方向を外すと、少数の経験からの汎化が変わるか（P1 の数発学習の測定）。

### 7.3.1 測定の方法論上の制約（文献の手がかり。いずれも abstract only、`literature/verify-T4.md`）
- プローブの精度だけでは、その特徴が表現されている・使われている証拠にならない（Hewitt & Liang 2019 の control task）。→ 潜在変数の読み出し（7.1 の注釈）には、出力を無作為にした対照課題の精度を必ず並べ、差だけを報告する。判定には使わない。
- 介入の効果の大きさは、特徴の強さそのものではない。学習の順序や複雑さで表現の強さが偏る（Lampinen ほか 2024）。→ H1・H3 は、効果の大きさを特徴の「強さ」と読まず、無作為な方向の除去との差と、種の数での符号の一致で判定する。
- 解釈可能な変数と表現の方向の対応づけが見つかることは、その方向をモデルが使っている証明ではない（Geiger ほか 2021、2024）。→ 「使用」は除去・入れ替えの介入（7.3）でだけ主張する。
- これらは abstract only の手がかりであり、本文で確かめていない。設計上の対策は独自の判断として置く。

### 7.4 判断基準（Q4、副次）
- 信念を揃える: 信念の頭だけを、全人格に共通の大量のデータで学習し直して固定する（予測を揃える）。その上で評価の頭の違いが残るかを、C-TD / C-AUT / C-GATE ごとに測る。

### 7.5 生得による決定の指数
- 同じ世界・同じ生得の構造で、経験史だけが違う人格の間の、評価の部分空間の類似度（CKA）と、異なる世界の間の類似度を比べる。経験史で違いが出ない（世界と生得だけで決まる）なら、「人格ごとの評価特徴」は形成されていない。I0 と I2 の比較で、生得の符号が獲得された特徴をどれだけ決めるかを測る。

## 8. NN が獲得に失敗した場合の切り分けの手順（事前に固定）

失敗 = Q1〜Q3 のどれかが、評価の種で不合格。次の順で原因を切り分け、各段の結果をすべて報告する（途中で止めない）。

| 段 | 検査 | 判断 |
| --- | --- | --- |
| 1 | 学習データでの損失が下がったか | 下がらない → 最適化の問題（学習率・回数）。仮説の検査になっていない |
| 2 | 診断用の**神託特徴**（生成器の交互作用の項そのもの）を線形の読み出しに与えると、未知の経験に転移するか。※神託は診断だけで、どの条件の人格にも与えない | 神託でも転移しない → 世界の設計（構造が観測から推測できない）の問題 |
| 3 | 規模の曲線（N と S/N）が飽和しているか | 飽和せず上がり続ける → 規模の問題。必要な規模を外挿して報告 |
| 4 | オンラインと、再生による多回学習の差 | 多回学習でだけ成功 → 継続学習（非定常）の問題で、表現の問題ではない |
| 5 | NN-SET と NN-REL の差、封印した族での差 | 構造によって片方だけ成功 → 帰納バイアスの問題 |
| 6 | 1〜5 がすべて否定され、神託では転移する | 「この規模・この学習則では、体の信号からの勾配学習は、観測から推測できる関係を評価の特徴として獲得しない」と、仮説側の否定的な結果として報告する |

## 9. LLM を使う検査と作業（DeepSeek v4.1 flash free と、Claude のセッション内エージェント）

### 9.1 使い方の原則
- LLM の出力は**未検証のデータ**として扱う。LLM の感情判断・評価を NPN の教師にしない（体の信号は常に潜在変数から作る）。
- 呼び出しごとに、モデル名（`opencode/deepseek-v4.1-flash-free`、Claude のエージェントは使用モデル名）、プロンプトのハッシュ、出力のハッシュ、失敗（空・形式違反・時間切れ）を追記専用の記録に残す。呼び出し回数と失敗数を報告に必ず書く。
- 実測（リーダー、2026-10-17）: OpenCode CLI で 8 並列、1 本約 25〜30 秒、無料枠。温度は指定できない。**同じ入力にほぼ同じ出力が返るので、反復は独立な標本と数えない。** 標本の単位は場面（入力）とする。
- LLM に、モデル名・人物名・人格の説明を渡さない。

### 9.2 役割
| # | 役割 | 内容 | 件数の見込み | 検証の方法（LLM 以外） |
| --- | --- | --- | --- | --- |

- 選択肢ごとの NPN の評価（数値）と、獲得した方向を最も強く活性化する過去の経験の例（経路 L の文、3 件）。名前のない特徴を、例で示す。

## 10. 計算量と GPU

- 世界の生成、FIX-K、LIN-raw、EPI は CPU で足りる。
- NN-SET（約 5 万パラメータ）と NN-REL（約 10 万）の 1 人格は、N = 32,000、S/N = 16 で約 50 万更新。P1 では、CPU が他の処理と競合し、小さな MLP の 1 世界（N 2 水準 × 学習回数 2 水準）に CPU で 6 分、GPU でも 1.5〜2 分かかった（第 11 節）。主実験の規模は CPU では現実的でない。
- 主実験の格子: 族 7 × NN 2 × N_ent 3 × N 4 × S/N 3 × 種 40 = 20,160 人格（P1 の後に N_ent を加えて 3 倍になった）。種をまとめて GPU の 1 バッチで学習する（人格ごとの重みをまとめた行列演算、または torch.func.vmap）。RTX 3050（8 GB）で、NN-REL の 40 人格を 1 バッチにして、全格子で数十時間の見込み（**未計測。Stage 1 で計測して事前登録に書く**）。
- **GPU が正当な理由**: 規模（R4）と学習回数（R5）を、v3.3 の X 系のように小さく切らずに、別々に操作するため。小さく切って NN を負けさせた過去の反省（AUDIT E4）。

## 11. 実現可能性の検査（probes/）

- **P0**（`probes/p0_audit_checks.py`）: AUDIT の根拠。v3 の符号の固定、同一の行、人 × 文脈の交互作用 = 0、未見の手がかりの C = 0、既定の NPN の MLP = 0 を、既存のコードを読み取り専用で実行して確認した。
- **P1**（`probes/p1_interaction_world.py`、種 77390〜77392。当初 5 本の予定を 3 本に減らした）: 性質 × 文脈の交互作用を持つ世界（F1 相当）と、構造なしの世界（F5 相当）で、ridge・無作為特徴・近傍・MLP を比べ、第 7 節の測定（主方向の除去、CKA、数発学習）が働くか、F5 で正しく働かないかを見た。結果は下の 11.1。

### 11.1 P1 の結果と、それで変えた設計
詳細と表は `probes/README-probes.md`。CPU の競合で、種を 5 本から 3 本（77390〜77392）、N を 2 水準に減らし、GPU で回した。
- 否定的な結果: この規模（学習した個体 80）では、どのモデルも未見の個体へほとんど転移しなかった（MLP の R² は −0.14〜0.30、平均 0.01〜0.11）。経験を 4 倍にしても増えず、MLP は学習回数を増やすと悪化した。
- 無作為特徴が MLP 以上の点があった（FC5 に当たる規模）。
- 最も強い信号は数発学習: 構造のある世界で学んだ MLP は、未見の個体を 3 文脈で学ぶと残り 9 文脈の R² が 0.4〜0.74 に上がった。初期値と構造なしの世界ではそうならなかった。

**P1 を見て変えた設計（結果を見た後の変更として記録）**
1. 転移の R² の基準を、生成器の真の期待値（観測できない性質を含む）から、**観測できる情報だけを使う神託の予測**に変え、上限も報告する（第 7.2 節）。
2. **個体の数 N_ent を経験の数 N と別に操作する**: N_ent ∈ {80, 320, 1,280}（第 5.1 節 R4）。
3. 除去の対照を**分散を揃えた無作為な方向**にする（第 7.3 節）。
4. H3-a（数発学習）は、学習前の初期値・構造なしの世界・獲得方向を外した版の 3 つと比べる。
- 閾値の値は変えていない。変更は PREREG-DRAFT の改訂記録と ESCAPE-AUDIT #29〜#31 に書いた。

## 13. 研究思想と再定義の間の、曖昧な点・食い違い（決めずに提示する）

1. **評価の訓練信号**: 研究思想 §5 は「研究者が経験ごとに正しい感情ラベルを与えない」とし、再定義は「最低限の初期信号は必要」とする。I2（無作為な符号の和）が「最低限」に入るかは、ユーザーの判断が要る（第 2.3 節）。
2. **予測と評価の区別**: 研究思想 §6・§13-E は予測と評価を分ける。再定義は「NN の内部表現が変化し、既存の軸で表せない判断を獲得したか」を問う。Q1〜Q3 だけでは、獲得した特徴が予測（信念）の側か評価の側かは分からない。私は Q1〜Q3 の合格を「評価上の特徴・関係の獲得」、Q4 の合格を「判断基準の獲得」と分けて呼ぶことを提案する。
3. **人格の差の源**: 研究思想は「同じ経験から人格によって違うことを学ぶ」（§5）を求める。同じ世界で経験史が違えば違う特徴が形成される、ということを第 7.5 節で測るが、世界が同じで経験史の差が小さいと、特徴は収束しうる。これは故障ではないが、「人格ごとの形成」を主張できない結果になる。
4. **歴史上の人物（§9）**: この設計の合成の世界は、人物の経験史の抽象化を使わない。人物を参考にした経験史は、Q1〜Q3 が合成の世界で成り立った後の段階（経路 L の自然な語の版）に回すことを提案する。
