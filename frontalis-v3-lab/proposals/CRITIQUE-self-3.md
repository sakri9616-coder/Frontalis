# CRITIQUE-self-3（Fable 5.1、API 経由、2026-10-23）

入力 24753・出力 10201。判定: 条件付きで進めてよい（条件 1〜5）。条件は DESIGN-self 第 3.1 版（§6）と PREREG-v13 に入れた。


## 1. 研究の問いに答えるか
部分的に。答えるのは「判断基準」（c、v10 の再利用）と、最小の「関係」（相手ごとの信頼 T）だけである。特徴の獲得は無い（要素 3 つ固定、proto_v4b 10 行）。移転は無い。M は学ばれず、真の表（OPTS）がそのまま与えられる（v4b 26 行）ので、「新しい勧め N」の中身を AI は最初から正確に知っている（設計 25 行の「予測」は予測ではない）。除去・入れ替えも無い。

主題に対しては、「自分の基準で断る」（B1・B4）と「相手を自分の物差しで学ぶ」（B2）は実現している。しかし表題の後半「理由があるときだけ変わる」は、「だけ」の側（理由が無ければ変わらない）しか検査されていない。**理由があって変わる正の事例が、この設計には一つも無い**。協力好きに理由がある勧めは C だけで、それは元から選ぶものである。設計 13 行の「理由」の定義に照らして、変わるべき条件が存在しない。

## 2. すり替え
- **B1 は「好きなものを勧められたら従う」にほぼ等しい**。選択は τ·c·M(k) に γσ(T) を足すだけ（v4b 30〜33 行）で、σ(T) は勧めが自分の好みと一致するときだけ上がる（下記 3 節）。協力好きが Q に 0.19、出来栄え好きが 0.99 という差は、γ = 0（耳をふさぐ）でも出る形である。その証拠に、両者とも最初から N を勧められると 0.31/0.32、信頼は両方とも負（設計 53 行）。B1 の判定（64 行）は γ = 0 との差を見ていないので、通っても「育ちが選択を決める」（dyad で既出）の再演である。相手が効いた量は「同条件での γ = 0 との差」でなければ主題の量にならない。
- **B3 は「信頼の残高の減りの遅さ」**。T は上限なし（v4b 43 行）、Q を 4000 回受けた時点で T ≈ +36、N を受けると 1 回あたり約 −0.0175 減るので、2000 回では枯れない。0.94 と +19.3（設計 52 行）はこの算術で決まる。後半を 10000 回にすれば消える。「関係の記憶」と呼ぶなら、半減期として報告すべきで、合格の差 0.2（66 行）は構成上必ず出る。

## 3. 計算の前に決まっているか
- **B2 の符号は式で決まる**。T の増分は c·p − (自分の方策の平均)（v4b 43 行）。τ = 3 で方策は鋭く、平均 ≈ 最良の値なので、**自分の最良を勧められた時だけ正**になる。これは「勧めが探索の揺れを省いてくれた分」が信頼になる構造で、相手が自分を広げる可能性（思想 142 行「新しい方法への興味」）は、いまの c で評価するため構造上評価できない。全 AI が同じ保守性を持ち、慎重さ／大胆さ（思想 92 行）は学ばれず固定である。これは個性ではなく、設計が決めた性格である。
- **o からの分離は半分**。c は o の帰属分配で、O_j > 0 の要素を負には評価できない（第 2 版批評で既指摘、未対応）。「理由」が o と違い得るのは「まだ学んでいない」次元だけである。協力好きが Q を退けるのは「出来栄えが悪い」からではなく「出来栄えの価値を学ぶ前に信頼が枯れる」からで、これは思想 190 行の誤解の形成として読めるが、その旨を明記すべきである。
- B5 の τ = 1 での破れは γ/τ の算術（第 2 版批評 18 行と同型）。全組の報告があるので許容するが、「自己を失わない」が開発者の τ に依存することは §5 に明記されている（74 行）。

## 4. 分岐の道
v4 → v4b の変更は、設計が開示した「選択肢の合計をそろえた」（41 行）の他に、**開示されていないものが 3 つ**ある。
1. Q̄ の定義を「最良の値」（v4 30 行 `max`）から「方策の平均」（v4b 30 行）へ変えた。設計 28 行はこれを最初からの定義のように書いている。信頼が正に育つのはこの変更の帰結で、B3 の大きさはこれに依存する。
2. C・Q の中身を .9/.3 から .9/.1 へ鋭くした（v4 11 行 → v4b 11 行。v4b のヘッダ 3〜4 行は古いまま）。
3. Qx（出来栄えが協力を排除）と CQ を落とした。Qx は第 2 版批評 32 行が求めた「両立不能」条件そのものであり、それを結果を見た後に外した。

評価種・全組報告・事前予想が固定されている点は適切である。

## 5. 判定
(a) 相手の学習は最小の形で解かれた。理由の定義は半分解かれた（「学んでいない」のみ）。定数の綱引きは σ(T) で門が付いたが、門が「同意するほど開く」構造である。
(b) B1 は自明に近く、γ = 0 との差で定義し直す必要がある。主題の答えとして読めるのは、B4（試した後に断る過程）と、「自分と違う勧めへの信頼が自分の物差しで下がる」ことまでである。
(c) 信頼を c で学ぶことは理念に沿う。ただし現行の更新式は「同意の勘定」になっており、関係の獲得としては片面である。

**条件付きで進めてよい**（名称は「自己の仕組みの確認」。主題への答えと呼ぶのは条件 1 を満たしてから）:
1. 理由があって変わる正の条件を一つ足す（Qx と CQ を戻す、または後半で協力の o が下がる条件）。これが無ければ表題を「理由が無ければ変わらない」に改める。
2. Q̄ の定義変更、C/Q の鋭化、Qx/CQ の除去を §5 に結果後の変更として開示する。
3. B1・B4 の判定量を「同条件の γ = 0 との差」にする。
4. T に上限（または減衰）を置くか、B3 を半減期として報告し、後半を 2000 回より長く取る。
5. M が与えられた真の表であることを設計に明記する。
