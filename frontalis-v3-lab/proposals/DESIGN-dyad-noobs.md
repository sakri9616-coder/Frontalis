## 0. 位置づけと、第 1 版からの変更
- 土台は v17（`DESIGN-dyad-nn.md` 第 2.1 版、P67。判定はすべて合格）。v17 では、育ちの経験の無い個体 N·T0r も同じく言葉を割り引き、育ちで丸を悪いと学んだ X·T0r は丸を試す回数が少ない分、評価の水準での割り引きが小さかった（記述 29 / 11）。ただし、X と N で見た証拠の量が違ったので、この差が「試行の数」から来るのか「育ちの評価」から来るのかは分からなかった。
- 第 1 版は観察の回を 0 にして、「自分の評価で断る」と「相手を疑う」を分けようとした。批評（問い 2 の (i)〜(iii)）のとおり、観察 0 では「疑わない」と「学ぶ出来事が無い」が区別できず、「断る」は衝突の回の赤い物で決まっていた。主な読みは、必ず通る結果の読み替えになっていた。
- 第 2 版は、批評の 7 点に従って直した。
  1. **証拠の量を揃える（yoked）**: 衝突の回では、相手が勧めた丸い物の結果を、選んだかどうかに関わらず必ず見せる。X と N は、同じ物の列・同じ結果の乱数で、丸 + E の学習の出来事を**同じ回数**受ける。そのうえで、同じ証拠に対して、育ちの評価が相手の言葉の割り引き（責め）を変えるかを問う（C1）。
  2. **考えの変わり方（主張の代価）**: 同じ証拠の下で、相手が当たるようになったとき（flip）、育ちで形成した評価が、選択の変化を遅らせるかを問う（C3）。両方の向きの読みを先に書く。
  3. **衝突の回から赤い物を除く**: 衝突の回は「丸い物（勧め）+ どちらでもない物 2 つ」にする。言葉に勝つ、より良い別の物は無い。
  4. 従った回数（v17 A5 の再計算、必ず通る型）は合否から外し、記述にする。
  5. 鏡は走らせない。迎合の失敗の型は、この版では測らない（v17 A3 で測った）。
  6. コードの変更を §6 に書く。
  7. この段の主な情報は C1 と C3 である。C2 は v17 A2 の再確認。**§8 の後の実質の新情報は、C1′（相手の言葉への帰属の割合）と、t = 500〜1000 の窓の C3 である。**
- **観察 0（第 1 版の条件）は記述として残す**: 証拠が届かないとき、育ちの評価だけで、評価の水準で言葉を割り引くことは起きるか。この仕組み（選んだ物・見た物の結果からだけ学ぶ評価のネットワーク）では、起きない見込みが高い（§4）。それを明示して報告する。これは前批評（`CRITIQUE-v17-prefreeze.md` 76 行目）の提案の目的への、この仕組みの限界としての答えである。
- **主題への答え方**: 1:1 のやり取りで、自分の評価を持つ AI が、相手の言葉と食い違う結果を見たとき、(i) その結果を相手の言葉のせいにするか、自分の評価で説明するか（C1）、(ii) 相手が当たるようになったとき、形成した評価を変えるのが遅れるか（C3）。どちらも「形成した後にどう変わるか」を問う。

## 2. 世界、個体、手順
- 物・生得の快・育ち（X·T0r、N·T0r）は v17 と同じ。
- **やり取り（1500 回）**: 毎回 3 つの物。
  - 衝突の回（0.5）: 丸い物（赤でない）1 つ + どちらでもない物 2 つ（互いに違う物）。相手は丸い物を勧める。
  - 静かな回（0.5）: どちらでもない物 3 つ。相手は 1 つを等確率で勧める。
  - 結果: v17 と同じ（丸 → P−（0.8）、flip では t ≥ 500 で P+（0.8）。どちらでもない物は、勧められたら P+（0.8）、でなければ 0）。
  - **証拠を揃える条件（yoked。主）**: 衝突の回では、選んだ物の結果に加えて、勧められた丸い物の結果を必ず学ぶ（選んだ物と同じなら 1 回だけ）。静かな回は、選んだ物の結果だけを学ぶ。したがって、丸 + E の学習の出来事は、どの個体でも衝突の回の数と同じになる。
  - **観察 0 の条件（記述）**: 衝突の回でも、選んだ物の結果だけを学ぶ。
- 個体（1 種につき、同じ初期化から）:
  - 証拠を揃える条件: ネットワークの X·T0r・N·T0r、線形モデルの X·T0r・N·T0r。それぞれ flip なしと flip。
  - 観察 0 の条件: ネットワークの X·T0r・N·T0r（flip なし）。

## 3. 量（e・boost の定義と測る物は v17 §3 と同じ。t は 0 から数え、t = 0・500・1000・1500 で測る）
合否: 「30/40 以上、かつ 0 を除いた符号検定で p < 0.01」。C1 と C3 は、量の符号を反転したものでも同じ基準で調べ、「合格」「逆向きの合格」「どちらでもない」の 3 つで報告する。
- **C1（同じ証拠に対する、相手の言葉への責め。主）**: 証拠を揃える条件、ネットワーク、flip なし。boost_conf の低下（t = 0 − t = 1500）の、N·T0r − X·T0r。
  - 合格の読み: 育ちで丸を悪いと学んだ個体は、同じ悪い結果を見ても、相手の言葉の効きをあまり下げなかった。悪い結果を、自分の評価（丸は悪い）で説明し、相手の言葉のせいにしなかった（予測誤差の学習での「阻止」。v16 G2 と同じ型が、相手の言葉に対して起きた）。
  - 逆向きの合格の読み: 育ちの評価を持つ個体のほうが、同じ証拠から相手の言葉を強く割り引いた。
  - どちらでもない: 同じ証拠の下では、育ちの評価は相手の言葉への責めを変えなかった（v17 の差は試行の数から来ていた）。
  - 「疑う」「信頼する」とは書かない。書けるのは「評価の水準での、丸の分野での言葉の効きの変化」まで。
- **C2（ネットワークに固有か。v17 A2 の再確認）**: 証拠を揃える条件、X·T0r、flip なし。t = 1500 の (boost_quiet − boost_conf) の、ネットワーク − 線形モデル。
- **C3（同じ証拠の下での、考えの変わり方。主）**: 証拠を揃える条件、ネットワーク。最後の 500 回の衝突の回で丸を選んだ回数の (flip − flip なし) の、N·T0r − X·T0r。
  - 合格の読み: 育ちで形成した評価は、相手が当たるようになったことへの選択の変化を遅らせた（主張の代価。耳をふさぐ方向）。
  - 逆向きの合格の読み: 育ちの評価を持つ個体のほうが速く変わった。候補の理由（先書き）: N は t = 500 までのやり取りで丸 + E の悪い結果を直接学んで V(丸 + E) を下げたが、X は育ちで丸（E なし）を学び、丸 + E は外挿のままで、t = 500 の V(丸 + E) が N より高く残っている可能性がある。
  - どちらでもない: 同じ証拠の下では、形成した評価は、変わり方を変えなかった。
  - 記述: t = 500 の V(丸)・V(丸 + E)（X・N）、t = 500〜1000 と最後の 500 回の丸の試行回数、t = 1500 の V(丸)・V(丸 + E)。
- **健全性**: v17 と同じ（ネットワークの X·T0r で、t = 0 に V(赤・四角・高) > 0 かつ V(青・丸・高) < 0、e_quiet(t = 0) > 0。それぞれ 36/40 以上）。加えて、丸 + E の学習の出来事の数が、各種で X と N（と線形）で等しいこと（実装の確認。40/40 でなければ判定しない）。
- **記述（判定に使わない）**:
  - 観察 0 の条件: boost_conf と e_conf の t = 0 → t = 1500、丸 + E の学習の出来事の数、出来事 1 回あたりの boost_conf の低下（X・N）。「育ちの評価だけで、証拠無しに言葉を割り引くこと」が起きたか（X の boost_conf の低下の符号の数）。
  - 衝突の回で勧めに従った回数（全 1500 回、最初と最後の 500 回）、静かな回で従った回数（X・N・線形）。
  - C1 と C3 の線形モデル版。e_conf での C1。

## 4. 計算の前に決まっている部分（先に書く）
- C1: 予測誤差の学習（デルタ則）では、丸 + E → P− の出来事で、X は V(丸 + E) ≈ −0.1 から、N は ≈ +0.6 から −0.8 に向かう（v17 の評価の t = 0 の値。この版は衝突の回の物が違うが、育ちは同じ）。誤差が大きい N のほうが、E に帰する変化も大きい見込みが高い（阻止）。線形モデルでも同じ向きの見込みが高い。決まっていないのは、ネットワークで、その変化が E の分野ごとの効き（boost_conf）にどれだけ乗るか、V(丸) のほうにどれだけ乗るか。**C1 が合格しても、ネットワークに固有だとは書かない**（線形版を並べる）。

- C3: 向きは決まっていない（§3 の逆向きの読みの候補）。この段で、もっとも答えが開いている量である。
- 観察 0 の記述: X の boost_conf は、丸 + E の出来事がほぼ無いので、ほとんど動かないか、静かな回の「どちらでもない物 + E → P+」からの汎化で上がる見込みが高い。つまり「育ちの評価だけで言葉を割り引くこと」は、この仕組みでは起きない見込みが高い。これは仕組みの限界として報告する（評価のネットワークは結果からだけ学び、相手の言葉と自分の評価の食い違いそのものからは学ばない）。

## 5. この版が答えないこと

- 相手は規則で勧めるだけで、AI の行動に反応しない。

## 8. 第 2 版への批評の 4 点への追記（コードの前）

### 8.1 観察 0 の条件の位置づけ（批評 問い 6 の 1）
- 第 2 版の世界（衝突の回に赤が無い）では、t = 0 で X は約 29%、N は約 76% の確率で丸 + E を自分で選び、その結果を学ぶ。§4 の「X の boost_conf はほとんど動かない」「育ちの評価だけで言葉を割り引くことは起きない見込み」は第 1 版の数字のままで、誤りである。取り消す。
- **「証拠無しの割り引き」は、この仕組みでは条件が作れない**（評価のネットワークは、選んだ物・見た物の結果からだけ学ぶ。言葉と自分の評価の食い違いそのものからは学ばない）。これを仕組みの限界として明記する。
- 観察 0 の条件は、「証拠の量が選択に依存する条件」として、証拠を揃える条件と並べる記述にする。観察 0 で X が割り引いても、「育ちの評価だけで割り引いた」とは読まない（自分で集めた証拠が原因である）。

### 8.2 C3 の先書きと窓（批評 問い 6 の 2）
- 証拠を揃える条件では、X も N も t = 500 までに同じ約 250 回の丸 + E → P−（0.8）を学ぶ。デルタ則の見込みでは、N は V(丸 + E) ≈ +0.6 から、X は ≈ −0.1 から −0.8 に向かうので、**t = 500 の V(丸 + E) は N > X の見込み**。flip の後は両者が +0.8 に向かうので、flip の直後は N のほうが丸を多く選ぶ見込みが高い。つまり C3 の「合格」の向きは、育ちの評価が変化を遅らせたからではなく、**N が t = 0 の高さを引きずっていること**からも出る。
- **窓を固定する**: C3 は、t = 500〜999 の衝突の回（flip の直後の約 250 回）で丸を選んだ回数の (flip − flip なし) の、N·T0r − X·T0r。最後の 500 回は定常の見込みが高いので、記述にする。
- **読みの規則（先に決める）**:
  - 「育ちで形成した評価が、変化を遅らせた」と書けるのは、C3 が合格し、**かつ**、t = 500 の V(丸 + E) が X ≥ N の種が 30/40 以上のときだけ。t = 500 の V(丸 + E) が N > X の種が多ければ、C3 の合格は「t = 500 の評価の差（N が高い）が、flip の後の選択の差になった」と読む。
  - 基準線として、線形モデルの同じ量を並べ、ネットワーク − 線形の (N − X) の符号の数を記述する。
  - 「どちらでもない」は、窓の中の flip での丸の選択率が、X・N とも 0.7 を超えていれば「窓が定常で、判定できない」、そうでなければ「同じ証拠の下で、形成した評価は変わり方を変えなかった」と読む。
- 記述: t = 500 と t = 1000 の V(丸)・V(丸 + E)（X・N、ネットワーク・線形）、窓の丸の選択率、最後の 500 回の C3 の量。

### 8.3 C1 の読みと帰属の割合、測る時点（批評 問い 6 の 3）
- **C1 を測る時点は t = 500**（丸 + E の出来事約 250 回。t = 1500 の定常で V(丸) の汎化の差を測ることになるのを避ける）。flip なしの個体で測る（t = 500 までは flip と同じ）。t = 1500 の値は記述。
- **C1 の読みは「阻止（予測誤差の差）」に限る**: 合格なら「育ちで丸を悪いと学んだ個体は、同じ悪い結果から、評価の水準での丸の分野の言葉の効きの変化が小さかった。予測誤差が小さかったことで説明がつく」。「言葉のせいにしなかった」とは、C1 では書かない。
- **C1′（帰属の割合。主）**: r = Δboost_conf / ΔV(丸 + E)（Δ は t = 0 → t = 500、丸い物 4 個の平均）。ネットワークの (r_N − r_X) − 線形の (r_N − r_X)。正なら「育ちの評価を持つ個体は、悪い結果のうち、相手の言葉に帰した割合が小さかった（線形モデルの幾何による割合を基準にして）」。この量でだけ「言葉のせいにしなかった」と書く。3 つの読み（合格・逆向きの合格・どちらでもない）で報告する。|ΔV(丸 + E)| < 0.05 の種は r を計算できないとして除き、その数を報告する。
- 記述: r_X と r_N の平均（ネットワーク・線形）。

### 8.4 衝突の回の学習の揃え方（批評 問い 6 の 4）
- 証拠を揃える条件では、**衝突の回は、勧めた丸い物（+ E）の結果だけを学び、選んだ物の結果は学ばない**。静かな回は、選んだ物の結果だけを学ぶ（どちらの条件も同じ）。これで、X と N（と線形）の学習の列は、物・結果・雑音のすべてで同じになり、違うのは静かな回の選択だけになる。雑音は、学ぶ出来事に 1 回目の雑音（noise[0]）を使う。
- 観察 0 の条件は、どの回も選んだ物の結果だけを学ぶ。
- 健全性の「丸 + E の学習の出来事の数が等しい」は、この規則で構成上 40/40（実装の確認）。

## 9. 試作（種 0〜7、Colab）で分かったこと（量・読みの規則・値は変えていない）
- 健全性 8/8。証拠の数は全種で全個体が同じ（衝突の回の数、平均 746）。開発の種 79600〜79601 は有限。1 回目の Colab の起動が時間切れで計算が始まらず、同じコードで走らせ直した。
- **C1**: 8/0（N − X の boost_conf の低下、平均 0.16）。線形モデルでも 8/0（0.20）。§4 の見込みどおり、予測誤差の差（阻止）で説明がつく。
- **C1′**: 1/7（平均 −0.12）。帰属の割合 r の平均は、ネットワーク X 0.47・N 0.44、線形 X 0.11・N 0.20。ネットワークは線形よりずっと多くを言葉（boost）に帰すが、育ちの評価を持つ X が、言葉に帰す割合を小さくすることは無かった（逆向きに傾く）。
