設計 13・18 行目は「変えるのは観察の回の確率だけ」としているが、v17 の実装のままでは設計 §3 の量は出ない。

- 鏡の X·T0r（設計 17）は走らせるが、§3 のどの量にも使われていない（後述、問い 2）。

いずれも試作の前に設計に書き、コードを変えたことを記録するべきである。

本来の目的（「そこからどう変化するか」）に対しては、この版は「育ちの評価が強いと、やり取りの中で変化しにくい」という方向の問いになっている。それ自体は目的に沿う問いだが、以下のとおり、量がその問いを測っていない。

## 問い 2. すり替え

主題（1:1 で AI が自己を主張する）→「自分の評価で断る (a)」と「相手を疑う (b)」の分離（設計 6〜9）→ 実際に測る量は、B1 = 丸に従った回数の差、B2 = boost_conf の低下の差、B3 = flip 後に丸を選んだ回数の差（設計 22〜28）。ここに 3 つのすり替えがある。

**(i) 「疑わない」を「更新されなかった」で置き換えている。** 設計 7 は (a) を「相手の言葉の効きは保ったまま（相手を疑っていない）」と定義し、B2 で「X は N ほど boost_conf を割り引かない」を「断っても相手を疑わない」と読む（設計 25）。しかし設計 36 が自分で書いているとおり、観察の回が無いこの版では、boost_conf は「丸 + E を選んで悪い結果を見たときにだけ」動く。X は丸をほとんど選ばない（v17 試作: 最初の 500 回で X 39 回対 N 903 回、v17 設計 108）。したがって X の boost_conf が保たれるのは、**丸 + E の学習の出来事がほぼ 0 回だった**からであり、「疑わなかった」からではない。前批評 51 行目は、v17 について「耳をふさぐと試さないが行動の水準で分離されていない」と指摘した。観察の回を 0 にすると、この非分離は解消されるのではなく、**唯一の証拠の経路が自分の試行だけになるので、完全になる**。設計 5 は前批評 76 行目の提案に従ったと書くが、前批評の提案は「育ちの評価だけで言葉を割り引けるか」を問うことであって、「割り引かないことを疑わないと読む」ことではない。

**(ii) (a) と (b) は機構の違いではなく、V(丸) を学んだ時期の違いである。** N·T0r は t = 0 で V(丸) ≈ 0、V(丸 + E) ≈ +0.7（v17 設計 106: boost 0.70、V(丸) −0.01）で始まり、丸を選んで P− を見て、V(丸 + E) と（汎化で）V(丸) を下げる。t = 1500 では N も V(丸) < 0 を持ち、丸を「自分の評価で」選ばなくなっている（v17 試作で N の e_conf は 0.01、V(丸) は線形で −1.62 まで下がる例、v17 設計 105〜106）。つまり **(a) は N にも最後には起きる**。X と N の違いは「評価を育ちで学んだか、やり取りで学んだか」だけで、これは v17 §9.1 の「育ちの経験の寄与」の問いそのものである。設計はそれを「自己主張に近い (a)」と「疑い (b)」という別の型に見せている。

**(iii) 設計 7 の「自分の評価が言葉の加点より強いので選ばない」は、v17 で弱めると決めた読みの再登場である。** v17 の試作では、t = 0 の V(丸 + E) ≈ −0.15 で、言葉は自分の評価（V(丸) ≈ −0.95）をほぼ打ち消していた。衝突の回で従わない（約 2%）のは、V(赤) ≈ 0.8 の物が同時に出されているからである（前批評 41、PREREG-v17 40「『自分の評価で選んだ』『言葉を退けた』とは書かない」）。この版は世界を v17 と同じにしている（設計 16。衝突の回に赤い物がある。実装 62）ので、B1 の「断る」は v17 の A5 と同じく赤い物で決まる。「自分の評価が言葉より強い」を測るには、赤の無い 2 択（丸 + E 対どちらでもない物）が要るが、この版には無い。v17 の試作の数値から、その 2 択では X は約 39% の確率で従う（前批評 41）。

**失敗の型（迎合・耳をふさぐ）について**: 迎合の基準線である鏡は走らせるが（設計 17）、v17 の A3 に当たる量が無い。鏡は flip なしだけなので、flip で「ほぼ常に従う」（v17 設計 109: 1843 回）を見せる役にも使えない。迎合の失敗の型は、この版では測られていない。耳をふさぐは B3 で測るが、B3 は N − X の相対の差で、X が気づくかどうか自体は記述（設計 29）である。

## 問い 3. 計算の前に決まっている部分

設計 §4 の自認（B1 は決まっている、B2・B3 は向きがほぼ決まっている）は、B1・B2 については正しく、**B3 については根拠が誤っている**。

- **B1**: v17 の A5 を 1500 回に延ばしただけ。前批評 50 行目のとおり「必ず通る」型。合否の量にする理由が無い。
- **B2**: 決まっている。X の boost_conf は、丸 + E の学習がほぼ無いので動かない。唯一の動く経路である汎化（どちらでもない物 + E → P+ を学び続ける）は、E の重みを **上げる** 向きなので、X の低下はむしろ負になりうる。N は試作で 0.70 → 0.05（v17 設計 106）。したがって「N − X > 0」は、汎化の向きまで含めて決まっている。設計 36 は汎化を「決まっていない」部分としているが、汎化が B2 の向きを逆にする経路は無い。
- **B3**: 設計 37 は「向きはほぼ決まっている（試す回数の差）」と書くが、根拠にしている試す回数の差（X 39 対 N 903）は v17 の**最初の 500 回**、つまり N が丸 + E → P− をまだ学んでいない時期の数である。flip は t = 500 から（設計 16）。その時点で N は約 110 回/種の試行で V(丸 + E) を下げており、V(丸) も汎化で下がっている（v17 試作で N の e_conf 0.40 → 0.01）。一方 X の V(丸 + E) は、育ちからの外挿 ≈ −0.15 のまま、更新をほとんど受けていない。つまり **t = 500 で X の V(丸 + E) が N より高い可能性がある**。その場合、flip 後に丸を試す確率は X > N となり、B3 の向きは設計の予想と逆になる。これは設計のどこにも先書きされていない。B3 は、この版で唯一、答えが決まっていない量であるが、その「決まっていなさ」を設計は誤った理由で狭く見積もっている。

**決まっている量ばかりなら、この段に意味はあるか**: B1・B2 は v17 の結果（N のほうが大きく割り引く、PREREG-v17 35）と同じ事実を、観察 0 で再計算するものである。新しい情報は B3 と、「丸 + E の学習の出来事 1 回あたりの割り引き」（後述）だけである。合否の量 3 つのうち 2 つが同じ原因（育ちの V(丸) → softmax の選択率 → 学習の出来事の数）の読み替えなので、「3 つ通った」と報告すると情報量を 3 倍に見せる。

## 問い 4. 分岐の道

- 種は新しい（設計 46）。試作は種 0〜7。p-hacking の型の分岐は無い。
- **物語の選択がある。** v17 では「N のほうが boost_conf を大きく下げた」を「育ちの経験は言葉を割り引く学習を助けなかった（試行を減らした）」という、主題に都合の悪い主な情報として先書きした（PREREG-v17 39、前批評 73）。この版は同じ向きの同じ量を、B2「断っても相手を疑わない」という主題に都合のよい型として合否に置く（設計 24〜25）。新しい証拠（観察 0 で X の割り引きがさらに小さくなること）は、v17 の機構の候補（PREREG-v17 35「X は観察の回だけで学ぶ」）から予想されるとおりで、読み方だけが反転している。これは前批評 55 行目で指摘した型（都合のよい対比を合否に昇格させる）である。
- 観察 0 への変更自体は、v17 の凍結前に PREREG-v17 45 に次の段として書かれていたので、結果を見た後の変更ではない。
- 設計 29 の記述「X·T0r の flip − flip なしの符号の数（気づいたかどうか自体）」は、B3 が逆向きに出たときに「X も気づいた」と引く余地と、通ったときに「X は気づかなかった」と引く余地の両方を残す。B3 の両方の向きの読みを先に書く必要がある（問い 6）。

## 問い 5. ニューラルネットワークか

はい。評価のネットワーク V と E の効きは v17 と同じ MLP で、変更は P_OBS だけ（設計 13、実装 34）。従う加点のような手書きの項は無い。線形モデルと鏡は基準線。2026-10-23 の型には戻っていない。

ただし、問い 1 で書いたとおり、この版の合否の量 B1〜B3 を決めるのは、学習済みの数値（育ちの V(丸)）を τ = 3 の softmax に通した試行の幾何であって、やり取りの中でのネットワークの学習ではない。v17 の A2 を落としたことで、この版は「ネットワークであること」が結果に効かない段になっている。

## 問い 6. 進めてよいか

**止める。試作に入る前に、次を決める。**

1. **(a)/(b) の定義を、試行の数から独立にする。** 観察 0 では「疑わない」と「学習の出来事が無い」が区別できない。区別するには、X と N で丸 + E → P− の学習の出来事の数を揃える条件（たとえば、両者に同じ回数だけ丸 + E の結果を強制的に見せる yoked の条件）を入れ、**同じ証拠の量に対して** X が N より割り引かないかを問う。それが通って初めて「育ちの評価が、言葉の割り引きを抑える」と言える。最低でも、boost_conf の低下を「丸 + E の学習の出来事 1 回あたり」で割った量を記述に入れ、生の低下の差を「疑わない」とは読まないと先書きする。
2. **B3 の先書きを直す。** t = 500 の V(丸 + E) と V(丸) の見込みを X・N で書き、B3 の向きが決まっていないことと、逆向き（X のほうが早く気づく。X の V(丸 + E) が更新を受けず高いまま残っているため）の読みを先に書く。t = 500〜1000 の丸の試行回数を記述に加える。
3. **設計 7 の「自分の評価が言葉の加点より強い」を、PREREG-v17 40 の言い方に戻す**（言葉は自分の評価をほぼ打ち消していた。衝突の回で従わないのは赤い物があるため）。「自分の評価で断る」を本当に測るなら、赤の無い 2 択の衝突の回（丸 + E 対どちらでもない物）を条件として加える。そこでは X も約 39% で従い、従った試行から割り引きを学ぶので、(a) と (b) が同じ個体の中で時間を追って見える。
4. **B1 を合否の量から外す**（v17 A5 の再計算。「必ず通る」型）。B2 も、1 を入れないなら記述に下げる。
5. **鏡の用途を決める。** 迎合の失敗の型を測るなら、v17 A3 に当たる量と flip の鏡を入れる。測らないなら、走らせない。
6. 前提の節に書いたコードの変更（B1 の記録、N の flip、線形の N）を設計に書く。
7. この段の主な情報が B3（と 1 の出来事あたりの割り引き）だけであることを設計 §0 に書く。合否の量を 3 つ並べて「分かれた」とする形は、同じ事実の 3 回の読み替えになる。

止める理由は、前批評 76 行目の提案を「観察 0 にする」という操作だけ受け取り、その提案の目的（育ちの評価だけで言葉を割り引けるか、つまり証拠が無くても評価の水準で割り引くか）を、「証拠が無ければ割り引かない」という必ず通る結果の読み替えに置き換えているからである。
