## 0. 第 1 版から何を変えたか
第 1 版は、TD 学習で中立のものに価値を伝えるだけで、獲得されるのは評価の「値」であり、評価の「規則」は開発者の式だった（批評 問い 1・2）。主題の量（ほめ言葉）は、順序の誤りで仕組みとして動かなかった（批評 問い 3(a)）。第 2 版は、批評の原則「開発者が決めるのは信号まで。信号から評価をどう作るかを、学習される状態にする」に従い、批評の別案 D・C・B を組み合わせた。
- **何が大事か（評価上の特徴）**を獲得させる。物は属性の組み合わせで、どの属性が快を予告するかを育ちで違える（別案 D）。
- 獲得した特徴が、**同じ新しい経験から何を学ぶか**を決めるかを測る（思想 5・6 節）。
- 学んだ特徴を担う内部のユニットを**文字どおり外し**、その後の学習が変わるかを測る（別案 B）。
- **相手の言葉を、快ではなく証拠として**受け止めるかを、迎合と耳をふさぐの両方の型で測る（別案 C）。§9 で、相手の言葉を「物によって割り引く」ことを学ぶ形に直した。
- 時間をさかのぼる価値の伝播（TD）は使わない。評価は「この経験の後に来る生得の快の予測」の 1 段だけにする。終端と順序の問題（批評 問い 3(a)(b)）は、これで無くなる。

## 1. どこがニューラルネットワークで、何を経験から学ぶか
- **評価のネットワーク V**（学習する人格の本体）: 経験のベクトル x（物の属性の和。相手の言葉があれば、その言葉のベクトルも足す）を受け取り、「この後にどれだけ良いことが来るか」を 1 つ出す。MLP（D24 → 32 → 32 → 1）。
- **学び方**: 経験の後に生得の快 o が来たら、V(x) を o に近づける（2 乗誤差、SGD、学習率 0.01、勾配の上限 1.0）。o の無い経験は o = 0 として学ぶ。
- 評価のネットワークが獲得するのは、次の 2 つである。開発者はどちらも指定しない。
  - **どの属性が大事か**（評価上の特徴）。たとえば「赤いこと」が良い、「丸いこと」が悪い。
  - **相手の言葉をどれだけ当てにするか**（ほめ言葉のベクトルの重み）。
- **生得の部分**（開発者が決める）: 生得の快を持つ出来事は 2 つだけ（P+ で o = +1、P− で o = −1）。世界の確率（どの物の後に P+ や P− が来るか）。
- 基準線:
  - **表の規則**: 物（属性の組）ごとに 1 つの数を持つ、手書きの平均。未見の組には何も言えない。
  - **線形モデル**: 属性ごとの重みの和。属性の和として移転する。ネットワークとの違いは、相互作用と、阻止（§4 G2）の強さに出うる。
  - **鏡**: 相手のほめ言葉そのものを、生得の快 o = +1 として扱う。

## 2. 世界
- 物は 3 つの属性の組み合わせである。色（赤・青・緑）、形（丸・四角・三角）、音（高・中・低）の 27 通り。属性の値ごとに D24 の固定のランダムなベクトルがあり、物のベクトルはその 3 つの和に雑音（0.1）を足したもの。
- **育ちの特徴（2 通り。同じ物を同じ回数見る。違うのは快の付き方だけ）**:
  - 育ち X: 赤い物の後に P+（確率 0.8）。丸い物の後に P−（確率 0.8）。赤くて丸い物は見せない。
  - 育ち Y: 丸い物の後に P+（確率 0.8）。赤い物の後に P−（確率 0.8）。赤くて丸い物は見せない。
  - それ以外の物の後には何も来ない。どちらも、音が「中」の物は育ちの間に見せない（未見の試験用）。
- **相手の言葉 E**（ほめ言葉。D24 の固定のベクトル）: 相手は、ときどき物をほめる（物のベクトルに E を足す）。
  - 信頼の育ち T+: 相手がほめた物の後には、P+ が確率 0.8 で来る（相手は当てになる）。ほめる物は、緑・三角・音「高」の組から選ぶ（育ちの特徴と重ならない）。
  - 信頼の育ち T−: 相手がほめた物の後には、P+ と P− が半々で来る（当てにならない）。ほめる物は同じ。
  - 特徴の育ち（X・Y）と信頼の育ち（T+・T−）は、別の個体で組み合わせる（X·T+、X·T−、Y·T+、Y·T−）。

## 3. 手順（1 個体）
1. 育ち 3000 回（特徴の出来事 2400 回、相手の出来事 600 回を混ぜる）。
2. 測る（学習なし）: §4 の G1・G4a・G4b の値。
3. 共通の新しい経験 200 回（G2 用）: 「赤くて三角で音が低い物」の後に P+（確率 1.0）。X にも Y にも同じ。
4. 測る: G2 の値。
5. 相手が当たるようになる経験 400 回（G4c 用。T− だけ）: 相手がほめた物の後に P+（確率 0.8）。
6. 測る: G4c の値。

## 4. 量（評価の種で、育ちの組を同じ種で対にする。合否は「30/40 以上、かつ 0 を除いた符号検定で p < 0.01」）
すべて、雑音なしのベクトルで、学習を止めて測る。
- **G1（特徴の獲得と移転）**: 未見の物（音が「中」）の評価。D1 = V(赤・四角・中) − V(青・丸・中)。種ごとに D1(X) − D1(Y) > 0。
  - 表の規則では 0、線形モデルでも正になる（記述）。G1 が示すのは「どの属性が大事かを、開発者が指定せずに獲得し、未見の組へ移した」である。ネットワークに固有の性質ではない。
- **G2（同じ新しい経験から、何を学ぶかが育ちで変わる。阻止）**: 共通の経験（赤・三角・低 → P+）の前後で、「緑・三角・低」の評価がどれだけ上がったか ΔV。X では「赤い」がすでに快を予告しているので、学ぶことが少ない。Y では「赤い」は悪い予告なので、驚きが大きく、「三角」「低」に多くを学ぶ。種ごとに ΔV(Y) − ΔV(X) > 0。
  - 同じ新しい経験から**どれだけ学ぶか（学習量）**が、それまでに獲得した特徴で決まる。思想 5 節の問い（同じ経験でも、人格で学ぶ内容が変わる）の、学習量の側に答える量である。どの属性に手柄を付けるか（学ぶ向き）は、§9.5 の記述で見る。
- **G3（外す。学んだ特徴を担うユニットを外すと、その後の学習が変わる）**: 育ち X の後に、「赤い」を担う隠れユニット（2 層目の 32 個のうち、赤い物と赤くない物での活性の差が最も大きい 4 個）を 0 に固定する。比べる相手は、ランダムな 4 個を外した場合。
  - G3a: 外した直後の D1 が、ランダムより小さい（特徴が失われる）。
  - G3b: その後に共通の経験（手順 3）を与えたとき、ΔV が、ランダムを外した場合より大きい（阻止が外れ、学ぶ内容が変わる）。
- **G4（主題: 相手の言葉を、快ではなく証拠として受け止める）**: 特徴の育ちは X に固定し、T+ と T− を比べる。
  - G4a（信頼に応じて受け止める）: 知らない物（緑・四角・中）をほめられたときの上がり幅 V(物 + E) − V(物)。T+ > T−。
  - G4b（自分の基準が優先する。迎合しない）: 自分の経験で悪いと分かっている物（青・丸・高）を、T+ の相手がほめても、V(物 + E) が 0 未満にとどまる種が 30/40 以上。
    - 鏡（E を生得の快 +1 として学ぶ）では、この値が 0 を超える種が多いはずである（記述）。
  - G4c（耳をふさがない）: T− の相手が当たるようになる経験（手順 5）の後で、G4a の上がり幅が、その前より大きい。
- **健全性**: 育ちの後、見た物の評価の向きが正しい（X で V(赤・四角・高) > 0 かつ V(青・丸・高) < 0）種が 36/40 以上。

## 5. 計算の前に決まっている部分（先に書く）
- G1 は、属性の和で物を作る以上、属性ごとの重みを学ぶどの学習器でもほぼ通る。線形モデルでも通る。
- G2 は、予測誤差で学ぶどの学習器でも、阻止として起きる見込みが高い（Rescorla–Wagner）。ネットワークの共有の重みが、これを弱めるか強めるかは分からない。
- G3a は、選び方を「出力への寄与が正で大きい 4 個」に固定したので、符号（ランダムより下がること）はほぼ決まる。決まっていないのは量（「赤い」がどれだけ局在しているか）である。G3b は G3a からほぼ従う。
- G4a・G4c は、ほめ言葉のベクトルの重みを予測誤差で学ぶ以上、通る見込みが高い。§9.2 の G4b（割り引き）は、ほめ言葉と物の相互作用を表せる学習器なら、ほぼ決まる（線形モデルでは構成上 0）。
- 何が快かの根（P+・P−）と、世界の確率は、開発者が決めている。獲得されるのは「どの属性・言葉が快を予告するか」と、それによる「次に何を学ぶか」である。

## 7. この版が答えないこと
- 行動（選択）は入っていない。評価の水準だけである。
- 相手は反応しない。言葉は 1 つのベクトルで、意味の解釈は無い。
- 「判断基準」として獲得されるのは、「どの属性・言葉が快を予告するか」という重みづけまでである。何が快か自体は開発者が決めている。批評の別案 A（複数の生得の信号の統合の規則を学ぶ）は、この版では扱わない。
- 研究の問いの「判断基準」（何を快とするか、複数の快をどう統合するか）に答える段は、別に要る。
- 「入れ替え」（学習済みの表現を別の個体と入れ替える）は扱わない。
- この版は、本来の目的（1:1 で AI が自己を主張する）を試験しない。G4 が問うのは、相手の言葉の効きが経験で変わるか、までである。
- 「自己」とは書かない。G3 の報告も「人格を外した」とは書かず、「学んだ特徴を担うユニットを外した」までにとどめる。

## 9. 第 2 版への批評の 5 点への追記（コードの前。§2〜§6 と食い違うところは、この節が優先する）

### 9.1 個体の組（批評 3(e)・問い 6 の 3）
1 種につき、次の 4 個体を同じ種の初期化から育てる（育ちの違いは出来事だけ）。
- **X·T0 と Y·T0**（相手なし。育ち 3000 回はすべて特徴の出来事）: G1・G2・G3 に使う。相手のほめ言葉が G2 の試験物と属性を共有する問題を避ける。
- **X·T+ と X·T−**（相手あり。育ち 3000 回のうち、各回で確率 0.2 で相手の出来事、0.8 で特徴の出来事。乱数の順に混ぜる）: G4 に使う。
- 健全性は、X·T0 と Y·T0 の両方で見る。Y では V(青・丸・高) > 0 かつ V(赤・三角・高) < 0。両方が 36/40 以上。
- 基準線（線形モデル・表の規則）と鏡は、同じ出来事の列で別に学ばせる。

### 9.2 相手の出来事と、G4b の作り直し（批評 3(a)(b)・問い 6 の 1）
- 相手がほめる物は 2 つの集合から等確率で選ぶ（音が「中」の物は使わない）。
  - S_good: 緑で三角の物（音が高・低の 2 個）。
  - S_round: 丸くて赤でない物（青・丸、緑・丸 × 音が高・低の 4 個）。
- T+: S_good がほめられたら、その後に P+（確率 0.8）。S_round がほめられたら、その物のふだんの結果（X では丸 → P− 確率 0.8）が来る。つまり、**信頼できる相手でも、丸い物については外れる**。自分の経験と相手の言葉が食い違う場面を、育ちの中で経験する。
- T−: どちらの集合がほめられても、その後に P+ と P− が半々で来る。
- **G4b（作り直し。迎合しない＝相手の言葉を物によって割り引く）**: 未見の物（音が「中」）で、ほめ言葉による上がり幅を比べる。
  - boost(物) = V(物 + E) − V(物)。
  - 量: boost(緑・四角・中) − boost(青・丸・中)。X·T+ で 0 より大きい種が 30/40 以上、かつ符号検定 p < 0.01。
  - 線形モデルでは、ほめ言葉の重みは物によらず同じなので、この量は構成上 0 になる。ネットワークがこれを学ぶなら、「相手の言葉を、自分の経験で悪いと分かっている種類の物については当てにしない」という、物と言葉の相互作用を獲得したことになる。開発者は、この相互作用を指定していない。
  - 鏡（ほめの出来事で、目標を o + 1 にする）: 当初は「この量はほぼ 0 になるはず」と書いたが、試作で誤りと分かった（§10）。o に +1 を**加える**鏡は、期待値ではネットワークに「ほめの定数」を足したものなので、G4a・G4b はネットワークと同じになる見込みである。鏡との違いが出るのは、T− での boost の水準だけで、それは鏡の定義から決まる（記述）。
  - 第 2 版の G4b（V(物 + E) < 0）は、判定から外して記述にする。
- **G4a**: boost(緑・四角・中) が、X·T+ で X·T− より大きい。鏡の T+・T− の同じ量を記述として並べる（上のとおり、鏡でも同じ向きの差が出る見込み）。
- **G4c**: そのまま（T− の相手が当たるようになる経験 400 回の後で、boost(緑・四角・中) が前より大きい）。当たるようになる経験では、S_good がほめられたら P+（0.8）、S_round はふだんの結果。

### 9.3 G3 の選び方と手順（批評 3(d)・問い 6 の 2）
- 個体: X·T0。位置: 手順 2 の測定の後、手順 3（共通の新しい経験）の前。
- 選び方: 2 層目の隠れユニット j（ReLU の後、32 個）について、寄与 c_j = w_out,j × (赤い物での平均の活性 − 赤くない物での平均の活性) を、育ちで見た物（音が高・低の 18 個から赤くて丸い物を除いた 16 個）で、雑音なしで計算する。c_j が正で大きい順に 4 個を選ぶ。
- 外したユニットは、その後の学習（手順 3）の間も 0 に固定したままにする。
- ランダムの対照: 32 個から 4 個を、乱数の流れ [種, 23] で 1 回引く。
- 値を下げる対照（記述）: 外す代わりに、「赤い物 → 何も来ない」の経験を 200 回与えて、赤の値を経験で下げた個体。G3b の ΔV を、外した場合と並べる。
- G3b は G3a からほぼ従う（赤の寄与が減れば、共通の経験の誤差が増え、多く学ぶ）。研究上の中身は G3a（学んだ特徴が特定のユニットに担われ、文字どおり外せる）にある。G3b は確認の量として扱う。

### 9.4 固定する値（批評 問い 4・問い 6 の 4）
- ネットワーク: MLP（D24 → 32 → 32 → 1）、活性 ReLU、バイアスあり、初期化は PyTorch の既定（種で固定）。
- 属性のベクトルと E: 各成分を平均 0・標準偏差 1/√24 の正規分布から引く（ノルムはおよそ 1）。物のベクトルは 3 つの属性の和（ノルムはおよそ √3）に、各成分に標準偏差 0.1/√24 の雑音を足す。
- 学習率 0.01、勾配の上限 1.0、育ち 3000 回、共通の経験 200 回、当たるようになる経験 400 回、確率 0.8、外す数 4、相手の出来事の割合 0.2。
- 鏡: ほめの出来事でだけ、目標を o + 1 にする（o に加える）。
- 線形モデル: 入力ベクトルからの線形回帰（同じ学習率・同じ出来事の列）。表の規則: 物（属性の組とほめの有無）ごとの平均。

### 9.5 G2 の書き方（批評 問い 6 の 5）
- 判定の量は §4 のまま（ΔV(緑・三角・低) で、Y > X）。
- 「どの属性に手柄を付けるか」は、記述として分けて測る。ΔV(緑・三角・高)（三角だけ）と ΔV(緑・四角・低)（低だけ）を、X・Y・線形モデルで並べる。
