# DESIGN-criterion: 判断基準の獲得を正面から問う設計（案。2026-10-22。コードを書く前。理念批評役に通す）

## 1. 言葉の定義
- **判断基準**: 学習の目標（何を良い・悪いとして学ぶか）を作る関数。評価（V）は「この相手・場面はどれだけ良いか」、基準は「何が起きたら良いとするか」。
- **指定された基準**: 開発者が書いた関数。いまは生得の内的状態の恒常性だけ（inn = −w × (|b| − TOL)²）。
- **獲得された基準**: 経験から学ばれた関数で、生得の信号が動かない場面でも、学習の目標を作る（＝他のものの評価の根拠になる）もの。

## 2. いまの仕組みの構成上の確認（式から）
- 価値の目標は、出来事の時点で記録され、再生で作り直されない（`sim4.py` 冒頭の説明、561〜562 行）。
- 目標の式（532 行、561 行）: f_k = inn_k + ref × (inn_k − (V_e1,k + V_e2,k))、TV = r × f。ref = 0.5。
- **生得の信号が無い出来事（inn = 0）** では f = −ref × (V_X + V_Y)。Y が評価済みの X とだけ出会い続けると、Y の評価の固定点は V_Y = −ref／(1 + ref) × V_X = −V_X／3。
- 結論:
  1. 生得の信号の外に、新しい基準は無い。学べるのは「誰が・どこで、どの内的状態を揺らすか」だけ。
  2. 二次的な効果（評価済みの X に結びついた Y が評価を得る）はあるが、その符号と大きさ（−1/3）は式で決まっている。測る前から答えが決まっているので、獲得の証拠にならない。
  3. 段 1〜6 の結果は、すべてこの枠の中にある。

## 3. 提案: 結果の見え方の評価器（学ばれる基準）
**世界に足すもの**: 出来事の結果に、内的状態には一切効かない「見える結果」O（8 次元。例: 相手の表情、音、物の壊れ方の手がかり）を足す。O は世界の規則で、内的状態の変化と統計的に結びつく（O のどの次元がどの内的状態と結びつくかは、世界の種ごとに無作為。開発者は決めない）。

**網に足すもの**: 見える結果の評価器 g(O)（小さな網、個人ごと）。
- g は、O から「この出来事で内的状態がどう揺れたか」を予測するように、経験から学ぶ。ここまでは生得の基準の予測で、獲得ではない。
- g の出力を、生得の信号の代わりに、価値の目標の材料として使う道を足す: inn′ = inn + λ × g(O)。生得の信号が動かない出来事でも、O が見えれば目標が作られる。

**開発者が決めるもの・決めないもの**:
- 決める: g という部品があり、それが目標に入る、という枠（脳に、学ばれる評価の回路がある、という前提に当たる）。λ（全員共通の固定値）。
- 決めない: O のどれが良い・悪いか。それは各個人が経験から学ぶ。

## 5. 正直な弱点（批評役に特に見てほしい）
1. g は生得の信号の予測として学ばれる。だから「獲得した基準」は、生得の基準の写しにすぎない、と言われうる。写しでないと言えるのは、C3（結びつきが消えても残る）か、C4（経歴で中身が違い、それが後の学びを変える）が成り立つときだけだと考える。
2. 枠（g が目標に入る道）は開発者が作る。中身を決めないことで「指定していない基準」と言えるかは、哲学の判断が要る。
3. λ の値の選び方で C1 の大きさが変わる。λ は試運転の前に固定し、選び直さない。
4. 世界に O を足すことは、段 1〜6 の世界の変更であり、これまでの結果とは直接比べられない。
