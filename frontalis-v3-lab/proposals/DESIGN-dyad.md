# DESIGN-dyad（第 4 版）: 文脈によって同じ手がかりの意味が変わる舞台（案。2026-10-22。コードの前。理念批評役に通す）

これまでの批評は `CRITIQUE-dyad-1.md`〜`CRITIQUE-dyad-3.md`。第 3 版（73eb1a3）の意味づけ g は、自分の評価を目標にして増幅するだけだった。思想 176 行が「固定された初期評価の自己強化に留まる」と前もって書いた形である。第 4 版は、批評 3 の (i) に従って、同じ手がかりが文脈によって良くも悪くもなる舞台を足す。ねらいは思想 178 行「学習済みの人格が新しい経験を解釈することで、次の評価基準が実質的に変化するか」に、道を 1 本つくることである。反応する相手（批評 3 の (ii)）は次の版で足す。

## 1. 位置づけ（批評 3 の条件 1）
- この版は、文脈に依る意味づけの**機構の検証**である。判断基準を経験から獲得することの検査ではない。
- 特徴（手がかり x、文脈 w）は開発者が与える。生得の o は残る。基準の出発点は、生得の写しである。
- 「自己」は、生得の恒常性に根ざした、自分の経験からの見方を指す（第 2 版から変わらない）。

## 2. 舞台
- 話題 T に関わると、手がかり x（d_x 次元）と文脈 w（d_w 次元。例: 時間帯、相手の調子、場所）が見える。
- 生得の結果: o = h₀(x) + Σ_j x_j × u_j(w) + 雑音。手がかり x_j の良し悪しの向きは、文脈 w で入れ替わりうる（u_j は w の無作為の関数。開発者は話題ごとの良し悪しを決めない）。
- 文脈の点は 3 種類ある。
  - (a) 前半に見る文脈
  - (b) 後半に見る文脈
  - (c) どちらでも見ない文脈（試験用）
- 生得の向き u_j(w) が 0 の文脈（生得が黙っている文脈）も含める。
- 前半の種類:
  - P0: 前半なし
  - P1: 一部の文脈だけ
  - P3: 別の文脈の組
  - P2: 相手が与えた指向性
- 後半は全員同じ。
- 相手の発言・分野・較正 P・関わり方 q は第 3 版のとおり。**較正 P の学びの目標は o のまま**とする（批評 3 の条件 2）。したがって、関わっていない話題では、相手の言葉は生得の向きにだけ効く。

## 3. 層
- 意味づけ g(x, w): 手がかりと文脈の組に対して非線形な小さな網。学びの目標は、いまの自分の評価 Ṽ（第 3 版のとおり）。
- 経験の意味: m = o + λ × tanh(g)。V_self の目標は、関わったときは m、関わらなかったときは P。
- 第 3 版との違いは、文脈によって向きが入れ替わる世界で、g が手がかりと文脈の**組み方**（文脈に依らない／文脈ごとに分ける）を学ぶことにある。前半の経験が g の組み方を決め、その組み方が後半の新しい経験の読み方を決める。

## 4. 構成上の確認（計算の前。`probes/dyad_ctx_mf.py`）
最小の模型で確かめた。手がかりは 1 つ（z）、文脈は 3 次元で、点は A、B、C、D、E の 5 つ。生得の z の向きは、A で +1、B で −1、C で 0（A と B の中間）。D と E は 3 次元目を持つ点。P は外し、q ≡ 1 とした。λ = 0.5 を主に、λ = 1.5 も見た。学習器は 2 つ: 線形（g = a + b·w）と、小さな MLP（隠れ 16）。種は 5。
| 状況 | 線形の g | MLP の g |
| --- | --- | --- |
| 前半 A だけ（P1）／A と B（P3）、後半 A・B・C | P1 は前半の終わりに、B で +0.72 と誤って読む（文脈に依らない基準）。後半で、A で +1.45・B で −1.45 に組み替わる。後半の終わりは P3 と**完全に同じ** | 同じ。P1 と P3 の差は、A・B・C で 0、D・E で 0.02 未満。D・E の値そのものは、種（初期値）で 0.69〜1.57 と揺れる |
| 同じ、λ = 1.5 | 差 0 | 5 種のうち 1 種だけ、生得が黙る C で P1 の「良い」が鍵になって残った（差 1.97）。残り 4 種は差 0 |
| 前半 A・D（P1′）／A・E（P3′）、後半 A・B（3 次元目を後半が試さない） | 差は D で 0.52、E で 0.51。全種で同じ値（前半に付いた 3 次元目の重みが、そのまま残る） | 差は 0.09〜0.74 で、種によって大きく違う |

**ここから、計算の前に言えること**:
1. **組み替えは起きる。ただし、行き先は前半に依らない**。後半が試す文脈では、文脈に依らない基準（P1）は文脈ごとの基準に組み替わり、P3 と同じ所に行き着く（λ < 1）。前半が決めるのは、組み替えが要るかどうかと、その道筋だけである。
2. **前半の形が残るのは、後半が試さない方向だけ**。線形では、その量を前もって正確に計算できる（0.52）。MLP では、量が初期値で大きく揺れる。経験の効果と初期値の効果が、同じくらいの大きさである。
3. **λ > 1 では、生得が黙る文脈で、前半の読みが鍵になって残りうる**。MLP でだけ起き、5 種のうち 1 種と、まれだった。
4. したがって、この舞台で、前半の形が後の基準を変える場所は、自分の経験がまだ届いていない文脈と、生得が黙る文脈に限られる。どの文脈に経験が届くかは、関わり方 q（第 2 版の環）と、次の版の反応する相手で決まる。

## 6. 正直な弱点（批評役に特に見てほしい）
1. **§4 の 1・2 は、組み替えの行き先が、後半が試す範囲では前半に依らないことを示す**。この舞台で前半の形が後の基準を変えるのは、試さない文脈と、生得が黙る文脈だけである。これを「経験の解釈によって次の基準が変わる」と呼べるかは、判断が要る。後半の新しい経験は、試す範囲では、どの前半から来ても同じ所に行き着く。
2. F3 の中心の量は、段 1〜6 の「育ち（H）対 運（S）」と同じ形をしている。違うのは、測る相手が評価そのものではなく、試していない文脈への基準の広がり（移転）であること。同じすり替えの型に戻っていないか、見てほしい。
3. MLP では、試さない文脈の読み方が初期値で大きく揺れた。経験の効果を初期値の効果から分けられるかは、網の大きさや初期値の幅で変わる。網の大きさと初期値の幅は、試運転の前に固定する。
4. λ > 1 の鍵は、まれ（5 種中 1 種）で、種に脆い。
5. 発言を数で与える簡略化、判断基準の獲得が未着手なこと、学習の層の薄さは、前の版と同じである。
