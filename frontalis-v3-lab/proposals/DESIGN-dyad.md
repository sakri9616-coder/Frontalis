# DESIGN-dyad（第 3 版）: いまの見方が経験の意味を変える層（案。2026-10-22。コードの前。理念批評役に通す）

第 1 版・第 2 版への批評は `CRITIQUE-dyad-1.md`・`CRITIQUE-dyad-2.md`。第 2 版の核心の欠陥は、学習の目標がすべて生得の結果 o（またはその回帰）で、状態は「どのデータが入るか」にしか効かず、前半の形は後半の**速さ**にしか効かないことだった。第 3 版は、ユーザーの指示どおり、**学習の目標の少なくとも 1 つを、いまの見方に依る形**にする。

## 1. 目的と問い、この設計が答えること・答えないこと
- 目的（ユーザーの言葉）: AI 対人間の 1:1 で、AI が自己を主張できるか。本質は、形ができた後どう変わるか。
- 思想の目標（`FRONTALIS_PHILOSOPHY.md` 146 行）: 「経験前の NPN が持つ評価基準によって、経験の意味と価値が変わる」。
- **この版が答えようとすること**: 自分の評価から学ばれた基準（意味づけ g）が、生得の信号の写しから離れうるか。離れた基準が、同じ経験の意味を AI ごとに変え、その後の学びと関わり方を変え、相手の言葉や生得の信号とぶつかったときにどうなるか。
- **答えないこと**: 特徴（手がかり x）は開発者が与える。生得の o は残り、基準の出発点はそれの写しである。

## 2. 舞台
- 話題 T: 話題の特徴 φ(T)（相手との話・較正に使う）と、関わったときに見える手がかり x(T)（d_x = 8 次元）を持つ。
- 生得の結果: o = h(x) + 雑音。h は x の一部の次元だけに依る、特徴からの無作為の関数（開発者は良し悪しを決めない）。残りの手がかり次元は、世界の規則としては o と無関係（**中立の手がかり**）。
- 前半の話題の集まりは、前半の種類ごとに違う。たとえば中立の手がかり z が、ある前半の集まりでは、たまたま良い話題と一緒に出て、別の前半では悪い話題と一緒に出る。後半の集まりは全員同じで、z は中立のまま（または §4 E4 で、生得と逆向きにする）。
- 相手の発言 s(T) と分野の 3 種類（一致・無関係・逆）、分野数 6 以上は第 2 版のとおり。発言を数で与える簡略化（`NOTES-llm-connection.md` §3 の迂回）も第 2 版のとおり記録する。

## 3. 層
### 3.1 意味づけ g(x)（新しい部品。学ばれる基準）
- 経験の意味: m = o + λ × tanh(g(x))。g は小さな網、λ は全員共通の固定値。
- **g の学びの目標は、いまの自分の評価 Ṽ(T)**（その出来事の前の見方）。入力は手がかり x。
  - 言い換え: 「自分が良いと思っている話題は、どんな見た目をしているか」を学ぶ。良いものに似た見た目の経験は、生得の信号が動かなくても、良い意味を持つ。
- `DESIGN-criterion.md` の g との違い: あちらは g を生得の信号の予測として学ばせたので、構成上、生得の写しだった（CRITIQUE-criterion-1）。こちらは自分の評価を目標にする。自分の評価には、前半の偏った経験、相手の言葉（較正 P を通る）、過去の意味づけそのものが入っている。
- 目標が状態に依る環: Ṽ → g → m → V_self → Ṽ。

### 3.2 自分の評価・相手のモデル・較正・関わり方
- V_self の目標: 関わったときは m（o ではない）。関わらなかったときは、相手の発言の較正 P(T) = a(T) × s(T) + c(T)。
- 第 2 版で未定義だった「確かさの重み」は外す（批評 2 の条件 4）。
- 較正 P、関わり方 q(T) = ε + (1 − 2ε) × σ(β × Ṽ(T)) は第 2 版のとおり。P は「解釈」ではなく「較正」と呼ぶ（批評 2 の条件 5）。

## 4. 構成上の確認（計算の前。平均場の式から）
後半で、ある手がかり次元 z の、生得の結果に対する本当の傾きを c とする（中立なら c = 0）。g の z 成分の固定点は、g = c + λ × tanh(g) を満たす（数値で確認した。`probes/dyad_mf.py` の結果）。
| λ | c = 0（中立） | c = −0.2 | c = −0.5 |
| --- | --- | --- | --- |
| 0.5 | 0 だけ（前半の基準は消える） | −0.38 だけ | −0.84 だけ |
| 1.0 | 0 だけ（ゆっくり消える） | −0.93 だけ | −1.38 だけ |
| 1.5 | ±1.29 の 2 つ（前半の向きが残る） | −1.58 と +0.77 の 2 つ | −1.94 だけ |
| 2.0 | ±1.92 | −2.15 と +1.66 | −2.47 と +1.10 |
2 つの固定点が並ぶ範囲は、λ = 1.5 で |c| < 0.21、λ = 2.0 で |c| < 0.53。

**ここから、計算の前に決まること**:
1. λ < 1 では、固定点は 1 つ。前半の基準の違いは、いつか必ず消える（違いは速さだけ。第 2 版と同じ型）。
2. λ > 1 では、中立の手がかりについて、前半で付いた向きが残る（2 つの安定点のどちらに落ちるかを、前半が決める）。生得と逆向きの傾き c があっても、|c| がしきい値より小さければ残る。これは「保つ」が λ で決まることを意味する。
3. したがって、D3 型の「保つか、消えるか」は、λ を選んだ時点でほぼ決まる。この設計は、それを隠さない。

**計算の前に決まらないと考えること**（批評役に判断してほしい）:
- 平均場は 1 次元ずつの近似で、手がかりの次元どうしの相関、較正 P を通る相手の言葉、関わり方の環（避けた話題の手がかりは学ばれない）、雑音を無視している。網の g が未見の手がかりの組み合わせにどう広がるか（移転）は、網の汎化に依る。
- 前半の向きが、どの手がかりに、どれだけ付くか（基準の中身）。とくに、相手が言葉で与えた指向性（P2）が、P を通って Ṽ に入り、それが g に入って、相手の言葉が無くなった後も意味づけとして残るか。

## 6. 正直な弱点（批評役に特に見てほしい）
1. **保つか消えるかは、λ でほぼ決まる**（§4）。λ を 2 つとも報告し、選ばないことで、合格のために選ぶ道は塞ぐ。ただし、それで「結果が計算の前に決まっている」問題が消えるわけではない。この版の検査は、平均場の予想を網が実現するか、どこで外れるか、を見る機構の検証であり、獲得の発見ではない。
2. λ > 1 は、自分の評価を生得より強く信じる設定で、迎合の反対の失敗（妄想・頑固）に近い。E4 で、生得と強くぶつかれば反転すること（|c| > しきい値）を確かめるが、しきい値も λ で決まる。
3. g の出発点は生得の写しである（前半の初め、Ṽ ≈ o）。写しから離れるのは、前半の話題の集まりの偏り、相手の言葉、環の増幅のどれかを通るときだけ。前半の集まりの偏りは開発者が作る（§2）。
4. 「どの手がかりも学ばれうる」枠（g が m に入る道、tanh、λ）は開発者が作る。中身（どの手がかりが良い意味を持つか）は経験で決まる。これを「指定していない基準」と呼べるかは、哲学の判断が要る（DESIGN-criterion の弱点 2 と同じ）。
5. 低い次元で書いた機構は、どれも平均場で前もって計算できる。「計算の前に決まらない」を何に求めるべきか（網の汎化か、相手とのやり取りか、それとも機構の形そのものを学ばせることか）を、批評役に問いたい。
