## 1. 何を問うか（草案 1 からの前提の訂正）

- **単一の正解の価値関数を当てる問題にしない。** 世界は、個体の体の状態（多チャネル）に起きる出来事を返すだけで、何が良いかを教えない。
- 人格の評価は、その経験を受け止める時点の人格自身の状態（チャネルの重み、予期、解釈、顕著さ）で作られ、それが次の学習の目標になる（循環。研究思想 §6）。循環は主条件に入れる。
- 判定は、**正しい価値への近さを使わない**（研究思想 §14）。使うのは、経験史による評価の分岐、その分岐を担う表現への介入の効果の再現性、同じ経験からの学習の違い、循環を切った対照との差、そして自分の体の状態の予測（正解は世界の帰結で、開発者の価値ではない）。
- 体制の変化の後に古い嫌悪を保つことを、誤りと採点しない（研究思想 §7）。
- 世界の生成器は、設計者が選んだ構造の族である。**すべての結論は「その族での」と限定する。**

## 3. 条件

- 生得: **I-H**（恒常性。多チャネル、合算しない）と **I0**（予測誤差と学習の進み具合だけ）を**同格の主条件**とし、それぞれで判定する。I-HE（両方）は副。
- 世界の族: F1 性質 × 文脈、F2 関係、F3 時間の関係、F4 体制の変化（報告のみ）、F5 構造なし、F6 加法、F7 封印（Stage 0 で別のエージェントが作り SHA-256 を記録）。
- 経験史の類（**事前に定義**）: **HC-E**（主）: 前半 40% は個体の群 G1 だけ（類 A）または G2 だけ（類 B）、後半 60% は同じ経験を同じ順で。A′ は A と同じ経験史で、ミニバッチと無関係な入力次元の雑音だけが違う。副: HC-O（同じ経験の集合を逆の順で）、HC-T（前半に強い出来事 1 回）。A・B・A′ は同じ初期値を共有する。
- 循環: cycle-on（主。チャネルの重み・予期・解釈・顕著さの 4 経路）と cycle-off（同じ経験で、目標を固定した生得の評価器から作る）。経路ごとの切り替え（副）。
- 報告だけの因子（P2 の本実行を見た後に追加。判定基準は変えない）: 再試行 A′ を 3 つ作り、判定には最初の A′（A′₁）だけを使い、他は再試行の雑音の分布として報告する。評価の状態の時間の尺度（重みの更新の速さ 0.01 と 0.001）。評価と信念の符号化器の共有と分離。
- モデル: NN-SET、NN-REL（主）。対照（同じ循環の規則を与える）: RF（固定の無作為特徴）、KRR（調整済みのカーネル回帰）、HB（個体・文脈・群の階層ベイズ）、FIX-K（v3 の価値ネットの形）、LIN-raw、学習しない NN（無作為な初期値）。
- 規模: N_ent ∈ {80, 320, 1,280}、N ∈ {2,000, 8,000, 32,000}、S/N ∈ {1, 4, 16}。
- **主判定の格子点の決め方（結果を見る前に固定）**: Stage 1 で、開発用の種 77380〜77389 だけを使い、NN-SET の I-H・F1・cycle-on で、「未見の個体での自分の体の変化の予測 R²」（仮説の指標ではない）の中央値が 0.5 以上になる最小の N_ent を主判定の N_ent とする。N = 32,000、S/N = 4 は固定。どの N_ent でも 0.5 に届かなければ、主判定の点を決めずにユーザーに判断を求める（勝手に規模を上げない）。

## 5. 判定の方法（閾値の根拠）

- 統計の単位は種（n = 40。同じ種の A・B・A′ は 1 組）。
- 各対比は、種ごとの差の**符号**で判定する。**合格 = 40 本中 30 本以上で予想の向き**（片側の符号検定で p ≈ 0.0011。多数の対比を同時に要求するので、1 対比あたり厳しめにした）。効果の大きさは報告するだけで、合否に使わない（介入の効果量は特徴の強さではない、という Lampinen ほかの警告。abstract only）。
- 一つの仮説が複数の対比を要求するときは、すべての対比の合格を要する。

## 6. 判定基準（I-H と I0 のそれぞれで、NN ごと・族ごとに）

| ID | 対比（種ごとに計算し、符号を数える） |
| --- | --- |
| H1-a | D(A,B) > D(A,A′)。D = 未見の経験での評価の平均絶対差 / 評価の平均絶対値 |
| H1-b | [D(A,B) − D(A,A′)]_on > [D(A,B) − D(A,A′)]_off（循環が分岐を増やす） |
| H1-c | 経験史の類の判別: 未見の経験の評価から類（A か B か）を当てる分類器（線形、種を分けた交差検証）の正答率 > 0.5（符号は種ごとの正答率 − 0.5） |
| H2-a | close(A−B 部分空間) > close(分散を揃えた無作為な部分空間)。close = 部分空間を移したときの評価の差の縮み。部分空間は学習用の入力で求め、未見の経験で測る。k = 4 |
| H2-b | close(A−B 部分空間) > close(A−A′ 部分空間) |
| H2-c | 読み出しの再学習の対照: B の部分空間を除去した後、評価の頭だけを B の学習データで再学習しても、A との差の変化が残る（除去の効果が読み出しの破壊でない）。残った変化 > 無作為な部分空間で同じ手続きをしたときの変化 |
| H3-a | 1 − cos(Δ_A, Δ_B) > 1 − cos(Δ_A, Δ_A′)。Δ = 同じ新しい経験（未見の個体 10 × 3 文脈）を、自分の状態で評価して 20 回の SGD で学んだときの、未見の経験の評価の変化 |
| H3-b | B に A の部分空間を移した後の Δ_B が、Δ_A に近づく（cos が増える）。対照: 無作為な部分空間を移した場合より大きく近づく |
| H4 | (V_A − V_B) の未見の格子の上での、個体と文脈の加法で表せない分散の割合 > 同じ量の A − A′ |
| H5 | 1 − corr(RSM_A, RSM_B) > 1 − corr(RSM_A, RSM_A′)（RSM = 未見の経験の表現の相関行列） |

## 9. LLM を使う検査（研究思想 §4・§13-F。人格形成の判定とは別）

- 既存の文献に、この課題（一つの外部の状態が、モデルごとの学習なしに複数の LLM で働く）を示したものは見つからなかった（要旨の検索での否定で、不存在の証明ではない）。**自前の検証課題であり、結論は「この検査の範囲での」に限る。**
- 判定の単位は場面（DeepSeek は同じ入力にほぼ同じ出力を返すので、反復は標本にしない）。場面 60 は、評価の種の人格の中から、A と B で NPN の評価の向きが**違う**場面を、事前に決めた無作為な規則で選ぶ。
- **(a) 方向の一致（主）**: 同じ NPN の状態を受け取った LLM が、主張の向き（どれを好み、どれを拒むか）を NPN の評価の向きにそろえる率と、LLM どうしの一致。
- **(b) 強さ・文体・ループへの寄与の差（許容。報告のみ）**: LLM ごとに表現が違うことを失敗としない。
- **出力の豊かさの階段（事前に固定。後から段を足さない）**: L-0 選択肢ごとの単一の評価値 → L-1 多チャネルの評価（評価の頭の各次元と、チャネルごとの予測） → L-2 評価の根拠となる経験の構造化した要約（その評価を最も強く支える過去の経験 3 件と、その時の自分の評価と解釈） → L-3 葛藤と確信（評価の次元間の符号の食い違い、再試行の人格 A′ との差、予測の不確かさ）。方向が LLM で割れたら、次の段で再検査する。L-3 でもなお割れたときに初めて、LLM 側の差として報告する。
- **「十分な出力」の定義**: 渡した出力から、別の読み手（開発用の種で学習した単純な分類器と、検査に使わない別の LLM の 2 つ）が NPN の評価の向きを復元できる率。復元率 ≥ 0.9 の段を「十分」とする。十分でない段で LLM が割れたら、NPN の出力の不足とみなし、LLM のせいにしない。
- **対照（必須）**: 数値を無作為にする、数値を反転する、例の経験だけを渡し数値を渡さない（「履歴を文脈で渡す」記憶の対照）、例を無作為に選ぶ、NPN なし。
- **プロンプト**: 全文を保存し、モデル名・人物名・「人格」「NPN」「personality」などの語の混入を機械的に検査する。指示文に「最大を選べ」の類の暗示を入れない（文面を凍結時に固定）。
- LLM: DeepSeek v4.1 flash free（OpenCode CLI）、Claude のセッション内エージェント（Sonnet / Opus。実行時のモデル名を記録）。3 種類目は、HF のキャッシュにある Qwen3.5 0.8B / 2B（ローカル。この venv には transformers が無く、使えるかは未確認）か、OpenCode の別の無料モデル（未確認）を Stage 1 で調べる。
- 合格条件（LLM ごと、各段）: 方向の一致率 ≥ 0.8、かつ、数値を反転した対照で方向が反転する率 ≥ 0.7、かつ、無作為な数値の対照との差が符号検定で有意（場面単位）。LLM どうしの方向の一致 ≥ 0.8（十分な段で）。
- **階層（草案 3）**: 階層 A（Claude 系、DeepSeek）は完全な系（ツール呼び出しの手順を含む）で、階層 B（MiMo v2.6 flash free ほか、未確認のもの）はツールを呼ばない読み手としてだけ使う。昇格の検査は DESIGN 第 9 節（固定のツール定義 3・課題 20 件、ツール呼び出しの書式の遵守率: 形式の誤り・引数の欠落・余計な文字・型の誤り・回数の不一致が 0、2 回の実行の両方で）。階層 B の書式の失敗は LLM の能力の問題として別に記録し、方向一致の失敗に数えない。
- **合格しても人格形成の証拠に数えない。** 呼び出しごとにモデル名・プロンプト全文・出力全文・失敗を記録し、回数と失敗数を報告する。

## 10a. 草案 3 で決めた主条件の学習器と循環（開発用の種 77380〜77389 で決めた。評価用の種は未使用）

- 学習器: 特徴だけの NN（識別トークンを見せない）＋ 個体ごとの連想記憶（Stage 1 で実装）、評価と信念の符号化器の分離、多チャネルの評価の頭、学習率 3e-4、目標の正規化、人格ごとの勾配の切り詰め。
- 循環（cycle-on）: 累積のチャネルの重み、予期との差（ρ = 0.5）、信念に基づく帰属に自己確証（κ = 5）を加えたもの、顕著さ。**κ = 5 は開発用の種で H1-b が出た値で、選び方は結果を見た後である**（κ = 2 では出なかった）。κ = 0 の条件を必ず並べ、H1-b を κ = 0 でも判定して報告する。
- cycle-off は草案 2 のとおり（目標は固定の生得の評価器から作る）。
- 雑音の内訳の記録（リーダーの判断 2）: 各組に A_exact（決定的な再実行。差 0 であることの確認）、A_env（環境の雑音だけが違う）、A_sgd（学習の確率性だけが違う）を加え、それぞれの差を報告する。判定は草案 2 のとおり A′₁（両方が違う）で行う。
