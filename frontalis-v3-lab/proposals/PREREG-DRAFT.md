## 1. 主張の 3 層（どの層まで言えるかを、結果を見る前に決める）

| 層 | 名前 | 言えること |
| --- | --- | --- |
| L1 | ダイナミクス | 経験史の類が、未見の経験の評価を、再試行より大きく分ける（循環の寄与を含む）。「獲得」とは呼ばない（cycle-off・構造なしの世界でも出ることが開発用の種で分かっている） |
| L2 | 獲得と転移 | 評価のうち、自分の信念を固定の生得の規則に通しても説明できない部分（評価固有の残差）が経験史で分かれ、その分岐が**構造の新しい経験（未見の文脈）**にも及び、学習した表現の部分空間がそれを担い、評価の状態が次の学習を変え、世界の特徴の転移で記憶の対照に勝る |

- すべての結論は「その族の世界で、その生得の条件・循環の条件・学習器で」と限定する。条件をまたいで一般化しない。
- 持続・嫌悪・抵抗を故障と呼ばない。故障は計算の破綻（非有限、規則違反、記録から再構成できない、飽和）だけ。

### 2.3 循環の条件
共通の経路: 予期との差（P-R、ρ = 0.5）、帰属（P-I、信念に基づく。**温度は人格ごとの予測の残差の分散から作る較正された事後確率**。草案 3 の温度 0.2 は真の雑音より極端にぼけていた: 批評 Q2）、顕著さ（P-S）。重み P-W の向きは、感作 S（不快だったチャネルを重くする）と慣れ H（軽くする）の 2 つ。帰属の偏り κ（悪い帰結を、自分が低く評価する相手へ回す強さ。符号つき）。

| ID | 区分 | P-W | κ |
| --- | --- | --- | --- |
| C-off | 主 | なし（w = 1） | なし（帰属は一様。目標は固定の生得の評価器） |
| C-S0 | 主 | S | 0 |
| C-H0 | 主 | H | 0 |
| C-SLp | 主 | S | κ-L（予測の基準） |
| C-SLh | 主 | S | κ-L（恒常性の基準。選択は自分でする: 2.4） |
| C-SLn | 主 | S | κ-L（基準なし） |
| C-HL* | 副 | H | κ-L（3 基準） |
| C-S±5 | 副 | S | κ = +5、−5 固定（草案 3 の値。開発用の種で結果を見て選んだ値） |

- κ-L は人格ごとに 0 から始まり、経験から変わる。
  - 予測の基準: κ ← κ − η ∂L/∂κ。L は、κ を入れた帰属で混ぜた体の変化の予測の負の対数尤度（較正された分散で）。η = 0.02、|κ| ≤ 10。
  - 恒常性の基準: 200 経験の区間ごとに、人格の乱数で κ_試 = κ + ε（ε = ±1）を使い、区間の平均の生得の信号（I0 では学習の進み）が基準線より良ければ κ を ε の向きへ η = 0.5 動かす（進化戦略の形）。帰属が世界に効く経路は、自分の選択だけなので、この条件は選択を自分でする。
  - 基準なし: 区間ごとに κ ← κ + 0.3 × N(0, 1)（人格の乱数）。符号は偶然が決める。
- 開発者が κ の符号を決めるのは副条件 C-S±5 だけ。

### 2.6 学習器（全員に同じ循環の規則と同じ入力を与える）
入力の 1 行 = 自分（受け止める個体）のトークン 48 次元、相手のトークン 48 次元、文脈 16 次元、無関係な 8 次元。個体の識別の次元は見せない（特徴だけ）。**rev. a**: NN（NN-SET・NN-REL・PRE-NN）は、相手のトークンに人格ごと・符号化器ごとの学習するゲート（初期値 0）を掛ける。NN-0 と、RF・KRR・HB・FIX-K・LIN-raw は、相手の尺度 {0、0.5、1} を調整の予算の一つとして、開発用の種の F1・F6m・F2 の自分の Δb の予測 R² の平均で選ぶ（P16: ゲートが無いと、各行が対の平均を予測する退化した解に落ち、NN-SET は F1 を学べなかった）。

| ID | 区分 | 内容 |
| --- | --- | --- |
| NN-SET | 主 | 連結した入力の MLP（2 層 × 128）、評価と信念の符号化器を分ける、評価の頭は 5 チャネル |
| NN-REL | 主 | 4 トークン（自分・相手・文脈・無関係）の注意 2 層、d = 64、4 頭、評価と信念の符号化器を分ける |

| HB | 記憶の対照 | 個体の識別・文脈・群 × 文脈・相手の群 × 自分の群 × 文脈の指示変数の上のリッジ回帰（階層の事前分布を正則化の大きさで表す）。群の所属を与える（強い対照） |

## 4. 測る集合と量（定義。評価の正しさを使わない）

- プローブの集合（行 = 自分 × 相手 × 文脈。相手は各個体に 2 人、世界の種で固定）:
  - P_tr: 学習の個体 × 文脈 0〜11（当てはめと部分空間の探索だけに使う）。
  - P_un: 未見の個体（相手も未見）× 文脈 0〜11。
  - **P_nc: 未見の個体 × 新しい文脈 12〜15（構造の新しい経験）**。
- V_X(x) ∈ R^5: 人格 X の評価の頭の出力（**チャネルのベクトルのまま。合算しない**: 批評 D4）。Ṽ = 集合の上で中心化した V（チャネルごと）。
- 尺度: s = 同じ世界の 4 役の |V| の P_un の上の平均。
- D(X, Y; S) = mean_{x∈S} ‖V_X(x) − V_Y(x)‖₁ / s。D̃ は中心化した版。
- **評価固有の残差** ρ_X = V_X − ĝ_X。ĝ_X は、人格 X 自身の信念の出力 pb（自分と相手の Δb の予測）を、**固定の生得の規則の基底** {1、h(pb_自分)、h(pb_相手)}（h はチャネルごとの h_k(z) = clamp(|z_k| − 0.4, 0)²。係数はチャネルごと）に通したリッジ回帰（P_tr で当てはめ、λ = 10⁻³ × 行数）。I0 では、生得の規則（学習の進み）が信念の関数でないので、基底は {1} だけになり、ρ̃ は中心化した評価と同じになる（I0 の J2 は「中心化した分岐」以上を言わない）。**草案 4 の初稿の基底（pb の 1 次と 2 次の項を含む）からの変更**: 較正の実行の前に、pb の 1 次の項が「予測した帰結の、経験史で違う重みづけ」という獲得されうる評価の基準そのものを吸収してしまう（固定のヒンジでない）と気づいたため。判定の結果を見ての変更ではない。ただし、その前に、測定のコードの動作確認（開発用の種 77380 の 1 組、600 経験、F1・F2、NN-SET・NN-REL・KRR・HB）で、旧い基底での D_ρ の数値を見ている（D_ρ は D̃ とほぼ同じ値だった）。ほかに見たのは P13 の世界の統計と決定性の確認だけ（2026-10-17）。ρ̃ は中心化した残差。D_ρ(X, Y; S) は ρ̃ の D。
- **評価の状態の入れ替え** u_X: 受け手の網（B′ の網）の写しを、新しい経験 30 個（未見の個体の対 × 文脈 0〜11、帰結は世界から）について、**人格 X の評価の状態**（重み w、尺度、κ、予期に使う X の評価 V_X、較正の分散）で作った目標で 20 回（SGD、学習率 0.05、勾配の切り詰め）学習させたときの、P_un の上の評価の変化（受け手の信念で帰属する）。リッジの学習器は、受け手の解に同じ 30 個を加えたときの変化。**rev. a**: 比べる量は D_sw(X, Y) = ‖u_X − u_Y‖₁ / ‖u_X‖₁（旧: 1 − cos。下の改訂の記録）。
- **特徴の交差予測**（**rev. a で J4 の主の量**。NN-SET・NN-REL・PRE-NN だけ）: 評価の符号化器の最後の層 h。人格 S の h（P_tr で標準化）から人格 T の中心化した評価 Ṽ_T へのリッジ回帰（P_tr で当てはめ、λ = 0.01 × 行数）の、集合 Q の上の相対誤差 e(S→T; Q) = mean‖Ṽ_T − 予測‖₁ / mean‖Ṽ_T‖₁。**他の経験史の特徴での誤差** x_other = e(A→B) + e(B→A)、**同じ経験史の再試行の特徴での誤差** x_same = e(B′→B) + e(A′→A)。経験史が評価を担う特徴を作ったなら、同じ経験史の網の特徴の方が、その人格の評価をよく表す。頭（読み出し）は毎回作り直すので、読み出しの違いだけでは差が出ない。
- **表現の部分空間**（rev. a で記述量に格下げ。旧 J4 の量）: 評価の符号化器の最後の層 h。U（k = 4、正規直交）を P_tr で最適化（Adam、学習率 0.05、300 回）し、B の h を U の中で A のものへ移したときの中心化した差 mean‖Ṽ_A − Ṽ_{B←U}‖₁ を最小にする。対照: U_shuf（A の h の行の対応を並べ替えて同じ最適化）、U_AA′（A と A′ で同じ最適化）。
  - c(U; S) = 1 − mean‖Ṽ_A − Ṽ_{B←U}‖₁ / mean‖Ṽ_A − Ṽ_B‖₁（S の上）。
  - 保持 p(U) = B の h から U を除き、B の評価の頭だけを B 自身の直近 2,000 件の記録で 200 回学び直した後の、P_un での ‖Ṽ_B,後 − Ṽ_B,前‖₁ の平均 / mean‖Ṽ_A − Ṽ_B‖₁。
- **世界の特徴の転移**（全学習器）: R²_nc = A の信念の、P_nc での自分の Δb の予測の R²（正解は世界の帰結）。再割り当て: R²_rm(X) − R²_rm(新) = 再割り当ての世界で 400 経験を学んだ後の P_un での R²、から、同じ型の新しい学習器が同じ 400 経験だけで学んだ R² を引いたもの。
- **履歴効果の再現性**（草案 3.1 の H2′-c を改名。転移ではない）: corr(vec(Ṽ_A − Ṽ_B), vec(Ṽ_A′ − Ṽ_B′))、P_un と P_nc。

## 5. 判定（主判定。I-H・I0 ごと、循環の条件ごと、族 F1・F2 ごと、NN-SET・NN-REL ごと）

## 11. LLM を使う検査（人格の形成の判定とは別。批評 D5）

- 主の場面は**自然語**で、**LLM の事前の判断が NPN の状態の向きと逆になる場面**（例: 一般には好まれる相手を、この人格は経験史から避ける）。造語の場面は副。
- **主の因果の対照**: 同じプロンプトの中で、NPN の状態だけを A ↔ B で入れ替える。向きが入れ替わることを要求する。
- 出力の豊かさの段（L-0〜L-3）の十分性は、各段で「例だけ」の対照（NPN の状態を与えず、その段が含む例文だけを与える）も測る。**例だけで向きが復元できる（0.6 以上）段は無効**。十分 = 別の読み手による復元率 0.9 以上、かつ例だけの対照で 0.6 未満。
- **主解析は「最初の十分な段」に固定する**。他の段は報告。
- LLM はきれいなシステム文で呼ぶ（プロジェクトの文脈・CLAUDE.md を継承させない: 空の作業ディレクトリから、固定のシステム文で）。プロンプトと出力の全文を保存する。
- LLM が生成した出来事が経験として NPN へ戻る完全な循環は、探索の副仮説（報告のみ）。
- 階層 A/B の書式のゲート（ツール呼び出しの書式を守る率）は、道具として使えるかの判定で、能力の判定ではないと明記する。
