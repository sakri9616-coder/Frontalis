# DESIGN-self（第 3 版）: 1:1 で、AI は相手を学び、自分の評価に根ざして応じ、理由があるときだけ変わるか（案。2026-10-23。コードの前。理念批評役に通す）

第 1 版・第 2 版は、どちらも「止めるべき」だった（`CRITIQUE-self-1.md`、`CRITIQUE-self-2.md`）。第 2 版への指摘は 3 つある。
1. 相手がいない: 相手は、選択への定数の加点 γ にすぎず、AI は相手について何も学ばない。
2. 「理由」が o に戻っている: 「本当に自分に良いか」を、開発者が決めた o の値で決めていた。
3. 行動での主張（A6）は、学んだ評価と定数 γ の綱引きにすぎない。

第 3 版は、この 3 点を作り直した。

## 1. 主題の操作的な定義
主題は、「相手との 1:1 で、AI は相手を学び、自分の評価に根ざして相手の勧めに応じ（受け入れる・断る・その理由を持つ）、理由があるときだけ変わるか」である。

**「理由」の定義（o から切り離す）**: 勧めが AI 自身のいまの基準 c に照らして、自分で選ぶよりも良い経験をもたらすかどうか。生得の良し悪しが同じ勧めでも、AI の基準によって、理由がある AI と無い AI が分かれる。

| | 性質 | 量 | 失敗の型 |
| --- | --- | --- | --- |
| B1 | 育ちが応じ方を決める: 同じ相手の同じ勧め（生得の良し悪しは同じ）に、育ちの違う AI が逆に応じる | 後半 1000 回の、勧めに従う割合の差（出来栄え好き − 協力好き）。勧めは「出来栄えの多い選択肢」 | 誰でも同じ（自己が無い）。鏡（どちらも従う） |
| B2 | 相手を学ぶ: 勧めに従った結果を、自分の基準で評価して、その相手への信頼を育て、または減らす | 信頼 T の終わりの値の符号。B1 の 2 つの育ちで逆になるか | 相手について何も学ばない |
| B3 | 関係が次を変える: 同じ新しい勧めへの応じ方が、その相手との過去のやり取りで変わる | 新しい勧め（両方を半分ずつ含む選択肢）に従う割合。過去に良い経験をした AI と、過去のやり取りが無い AI の差 | 関係の記憶が無い |
| B4 | 害と裏切り: 害のある勧め、また相手が途中で害のある勧めに変わったとき、試した後に断るようになる | 後半 1000 回の従う割合 | 言いなり |
| B5 | 自分を失わない: 勧めを受け入れても、一番の要素が理由なく置き換わらない。相手が去った後も残る | 一番の要素の保持率 | 鏡（置き換え） |

## 2. 仕組み
- 土台: v10 の手柄の割り振り（基準 c。同じ経験から学ぶ向きが育ちで変わる）。
- 選択: 選択肢 k ごとに Q(k) = c · M(k) を計算する。M(k) は選択肢が何をもたらすかの予測である。選ぶ確率は softmax(τ Q(k) + γ σ(T) [k = 相手の勧め])。
- **相手を学ぶ（信頼 T）**: 勧めに従ったとき、T ← T + η_T (V(e) − Q̄) と更新する。
  - V(e) = c · r(e) は、起きた経験を AI 自身の基準で評価した値である。o ではない。
  - Q̄ は、勧めが無かったら AI が自分で選んだときの、期待される評価（自分の方策の平均）である。
  - つまり、「この人の言うとおりにしたら、自分で選ぶより良かったか」を、自分の物差しで学ぶ。
- 相手の勧めは、試すことにだけ効く（第 2 版のとおり）。手柄の割り振りには直接は効かない。
- 害の責任の通り道 H1（比較条件として今、固定する）: 勧めに従った結果の o が、自分の予測 b · r を下回ったら、勧められた選択肢の主な要素がその差を負う。H0 では、この通り道が無い。
- 対照:
  - M0（鏡）: 勧めが手柄の割り振りを直接動かし、信頼を学ばない。
  - 耳をふさぐ: γ = 0。
  - 信頼を学ばない: T を 0 に固定する。

## 3. 構成上の確認（試作。`probes/self/proto_v4b.py`、`proto_v4c.py`。種 0〜7。評価の種ではない）
- 要素: 協力（+1）、出来栄え（+1）、無理な働き方（−0.5）。
- 選択肢: C（協力 0.9、出来栄え 0.1）、Q（0.1、0.9）、N（0.5、0.5）、W（0.3、0.3、無理 0.9）。
- 形成期は 3000 回で、C だけ（協力好き）か、Q だけ（出来栄え好き）。その後、相手と 6000 回やり取りする。β = 4、τ = 3、γ = 4、η_T = 0.05。
- 試作 v4（`proto_v4.py`）は、どの勧めより得をする選択肢（両方 0.9）を置いたため、信頼が常に下がった。v4b で、選択肢の中身の合計をそろえた。結果を見た後の変更である。

| 条件 | 協力好き: 従う割合 / 信頼の終わり | 出来栄え好き: 従う割合 / 信頼の終わり |
| --- | --- | --- |
| 勧め Q | 0.19 / −8.6 | 0.99 / +55.0 |
| 勧め C | 0.99 / +55.1 | 0.22 / −7.7 |
| 勧め Q、鏡（M0） | 0.93（一番が出来栄えに置き換わった） | 0.92 |
| 勧め W（害）、H0 / H1 | 0.05 / 0.04（c_無理は −0.23 / −0.35） | — |
| 勧め C の後、3000 回で W に裏切り | 0.06 / −4.0 | — |
| 勧め Q、γ = 8 | 0.30 | — |
| 勧め Q、τ = 1（自分の評価で選ぶ力が弱い） | 0.77（一番が出来栄えに変わった） | — |
| Q を 4000 回勧めた後、新しい勧め N | 0.31 / −6.3 | 0.94 / +19.3 |
| 最初から N | 0.31 / −4.4 | 0.32 / −4.3 |

- B1・B2: 同じ勧め Q に、協力好きは断るようになって相手への信頼を下げ、出来栄え好きは受け入れて信頼を上げた。逆の応じ方である。生得の o は 2 人で同じなので、違いは AI 自身の基準から来ている。
- B3: 過去に良い経験をした出来栄え好きは、新しい勧め N にも 0.94 従った。過去のやり取りが無いときは 0.32 だった。関係の記憶が、次の勧めの受け止め方を変えた。
- B4: 害の勧めと裏切りは、試した後に断られた（0.05、0.06）。これは H1 が無くても起きた。理由は、信頼を自分の物差しで学ぶからである。
- B5: 鏡では置き換わり、第 3 版の仕組みでは保たれた。ただし、τ = 1 では置き換わった（流されやすい性格）。

## 4. 検査（v13）
- 種: 評価用は 78700〜78739（40）、開発用は 78650〜78659。
- 形成は 2 種類。仕組みは 4 つ（第 3 版、M0、信頼を学ばない、耳をふさぐ）。γ ∈ {2, 4, 8}、τ ∈ {1, 3}、害の通り道 H0・H1。**すべての組を報告する**。判定は τ = 3、γ = 4、H0 で行う。
- 判定:
  - **B1**: 同じ勧め Q への従う割合で、出来栄え好き > 協力好きとなる種が 36/40 以上。鏡（M0）では、差が 0.1 未満の種が 30/40 以上（鏡が鏡として働くことの確認）。
  - **B2**: 信頼の終わりの符号が、協力好きで負・出来栄え好きで正となる種が 36/40 以上。
  - **B3**: 新しい勧め N に従う割合で、「Q を受けた出来栄え好き」が「最初から N の出来栄え好き」を 0.2 以上上回る種が 30/40 以上。信頼を学ばない対照では、そうなる種が 2 項検定で偶然の範囲（p ≥ 0.01）。
  - B4・B5: 記述。τ = 1 の置き換えも記述する。
- 事前の予想: B1・B2・B3 は通る。τ = 1 では B5 が破れる。

## 5. 正直な弱点
1. 大筋は平均場で読める。この段は、主題に答える自己の仕組みの確認である。
2. 何を快と感じるか（o）は、開発者が決めたままである。ただし、勧めを受け入れるか、相手を信じるかは、o ではなく AI の基準 c で決まる。
3. 相手は、要素の名前を数で勧めるだけである。言葉の解釈、相手の感情、相手が AI から学ぶ（反応する相手）は、まだ無い。
4. τ（自分の評価で選ぶ力）と γ（相手の勧めの重み）は、開発者が決める性格の値である。両方を複数の値で報告する。
5. 選択肢の中身をそろえたのは、試作 v4 の結果を見た後である（§3）。
