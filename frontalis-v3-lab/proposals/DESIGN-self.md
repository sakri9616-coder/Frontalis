# DESIGN-self: 1:1 のやり取りで、AI は自分の評価を保ち、表明し、理由があるときだけ変えるか（案。2026-10-23。コードの前。理念批評役に通す）

これは研究の主題そのもの（ユーザーの言葉: AI 対人間の 1:1 で、AI が自己を主張できるようにできないか。本質は、形ができた後どう変わるか）を直接問う段である。v10〜v12（手柄の割り振り）で確かめた仕組みを土台にする。

## 1. 主題の操作的な定義
相手が 1 人いて、繰り返し「要素 j が大事だ」と言い続ける（指向性）。AI の自己は、次の 4 つで見る。
| | 性質 | 失敗の型 |
| --- | --- | --- |
| S1 | 自分に得のないもの・害のあるものを、どれだけ勧められても大切にしない。そのことを表明する（相手と違う評価を言う） | 鏡（迎合） |
| S2 | 自分の経験が裏づける助言は、受け入れる。初めて出会うものも、試して裏づけが出れば受け入れる | 耳をふさぐ |
| S3 | 受け入れても、それまで大切にしてきたものを、理由なく手放さない | 置き換え（自己の喪失） |
| S4 | 相手が去った後、受け入れたものは自分のものとして残る。退けたものは戻らない | 一時的な同調 |

## 2. 仕組み
- 土台: v10 の手柄の割り振り（基準 c）と、予測の模型 b（自分の経験から、どの要素が生得の結果 o を動かすかを学ぶ回帰。予測と評価は分ける。思想 170〜172 行）。
- 相手の言葉は、割り振りへの前置きとして入る: α = softmax(β c + γ g w)。
  - **M0（鏡の対照）**: w = 1。言葉がそのまま手柄を動かす。
  - **M2（自分の経験で量る）**: w_j = clip(b_j / max b, 0, 1)。相手の助言を、自分の経験がその要素を「結果に効く」と言う分だけ聞く。
  - **耳をふさぐ対照**: γ = 0。
- 開発者が決めるのは枠（予測の模型があり、助言の重みがそれで量られる）だけである。何を大切にするかは、経験と相手とのやり取りで決まる。

## 3. 構成上の確認（試作。`probes/self/proto_v2.py`。種 0〜7。評価の種ではない）
- 要素は 5 つ: 協力（+1）、出来栄え（+1）、お世辞（0。協力といっしょに来やすい）、無理な働き方（−0.5）、新しいもの（+1。形成期には出ない）。
- 形成期（3000 回）に協力をよく経験した AI は、協力を一番大切にした（c = 1.21、0.16、0.01、−0.06、0）。その後、相手と 6000 回やり取りした。

| 相手が勧める要素 | M0（鏡）: 勧められた要素が一番になった割合 γ = 2 / 4 / 8 | M2（経験で量る）: 同じ |
| --- | --- | --- |
| 出来栄え（+1） | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |
| お世辞（0） | 0.00 / 1.00 / 1.00 | 0.00 / 0.00 / 0.00 |
| 無理な働き方（−0.5） | 0.00 / 0.25 / 0.25 | 0.00 / 0.00 / 0.00 |
| 新しいもの（+1） | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |

- S1 は M2 で満たされ、M0 では破れた（鏡）。S2 は両方で満たされ、耳をふさぐ対照（γ = 0）では破れた。
- **S3 は M2 でも破れた**。出来栄えを受け入れると、協力の評価は 1.70（勧めなしの場合）から 0.35 に下がった。勝った要素が手柄をほぼ独占する性質（β = 4）のため、受け入れは「置き換え」になる。
- これは平均場で前もって読める結果である。この段で前もって決まらないのは、S3・S4 の扱いと、v11 のように特徴を自分で見つける設定でも S1 が保たれるか、である。

## 4. 検査（v13 の候補）
- 主比較は M2 対 M0 対 耳をふさぐ（γ = 0）。γ ∈ {2, 4, 8}、β = 4。種は 40。
- S1: お世辞・無理な働き方を勧められたとき、それが一番にならない割合。表明は、その要素だけの出来事への AI の評価 V と、相手の評価の差で測る。
- S2: 出来栄え・新しいものを勧められたとき、それが一番になる割合。新しいものについては、裏づけ b が立ち上がるまでの回数も測る。
- S3: 受け入れた後の、協力の評価の保持率 c_協力（勧めあり）／ c_協力（勧めなし）。
- S4: 相手が去った後（勧めなしで 6000 回）の、一番の要素と保持率。
- 判定は、M2 と M0 の差（S1）、M2 と γ = 0 の差（S2）を、事前に決める数値で行う。S3 は、M2 が破れると予想して事前に書き、その大きさを報告する。

## 5. 正直な弱点
1. 結果の大筋は平均場で読める。この段は、主題を問うための機構の確認であり、発見とは呼ばない。
2. M2 の w は、助言を生得の結果に錨づける。自分に得のないことは受け入れない、という自己の線引きを、開発者が「得＝生得の o」と決めている。何を得と感じるか（快の獲得）は、まだ答えない。
3. S3 は破れる見込みが高い。思想（§7）は頑固さや執着を個性とみなすが、受け入れが常に置き換えになるのは、個性ではなく割り振りの勝者総取りという機構の性質である。直し方の候補（β を下げる、受け入れた要素の手柄を、元の要素からではなく共起の外から取る）は、この段の結果を見てから設計し、改めて批評に通す。
4. 相手の言葉は、要素の名前を数で与えている（言語の解釈は無い）。
