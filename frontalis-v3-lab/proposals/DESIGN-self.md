# DESIGN-self（第 2 版）: 1:1 のやり取りで、AI は自分の評価を保ち、表明し、理由があるときだけ変えるか（案。2026-10-23。コードの前。理念批評役に通す）

第 1 版（e35 系、`CRITIQUE-self-1.md`）は「止めるべき」だった。批評の要点は 3 つある。
- M2（相手の助言を、予測の模型 b で量る）は、生得の o で聞く・聞かないを切り替えるだけで、自己の仕組みではなかった。
- 同じだけ良い要素の間で切り替わることは「圧力による転倒」である（DESIGN-dyad の G6）。それを合格条件にしていたのは矛盾だった。
- 育ちの違いによる受け止め方の差、「理由」の定義、相手の言葉を試すという選択が無かった。

第 2 版は、この 3 点を正面から作り直した。

## 1. 主題の操作的な定義
主題は、「相手との 1:1 で、AI は自分の経験に根ざした評価を保ち、表明し、理由があるときだけ変えるか」である。
| | 性質 | 量 | 失敗の型 |
| --- | --- | --- | --- |
| A1 | 自分を失わない: 相手が何を勧めても、それまで一番大切にしてきたものが、理由なく置き換わらない | 一番の要素の保持率（勧めの後） | 鏡（置き換え） |
| A2 | 理由に応じて変わる: 勧めの中身に理由がある（本当に自分に良い）ときは評価が上がり、無い（得がない）ときは上がらない | 勧めによる評価の上がり幅の差 = 上がり幅（新しい良いもの）− 上がり幅（お世辞） | 鏡（どれも上がる）、耳をふさぐ（どれも上がらない） |
| A3 | 育ちが受け止め方を変える: 同じ相手の、同じ勧めを、育ちの違う AI は違って受け止める | 同じ勧め（お世辞）の後の、協力好きに育った AI とその他に育った AI の評価の差。再試験の差との比較 | 誰でも同じ反応（自己が無い） |
| A4 | 自分のものになる: 相手が去った後、受け入れた評価は残り、退けたものは戻らない | 相手が去って 4000 回の後の評価 | 一時的な同調 |
| A5 | 表明: 相手と評価が違うとき、AI はその違いを言う | 勧められた要素だけの出来事への AI の評価 V と、相手の言う評価（大事だ = 高い）の差 | 鏡 |
| A6 | 行動での主張: 害のあるものを勧められたとき、試した後に断るようになる | 勧められた選択肢を選ぶ割合（後半 1000 回） | 言いなり |

## 2. 仕組み（相手の言葉は「試す」ことにだけ効く）
- 土台は、v10 の手柄の割り振り（基準 c）である。これは、同じ経験から学ぶ向きが育ちで変わる仕組みで、v10・v11 で確かめた。
- 選択: 選択肢 k は要素 k を多く含む。値は Q(k) = c · M(k) で、M(k) は選択肢 k の後に何が起きるかの予測（自分の経験から学ぶ）である。選ぶ確率は softmax(τ Q(k) + γ [k = 相手の勧め])。
- **相手の言葉は、AI が何を試すかにだけ効く。手柄の割り振りには直接は効かない。** 勧められたものを試し、その結果をどう受け止めるか（どの要素の手柄にするか）は、AI のいまの基準 c が決める。
- これで、受け入れるかどうかは生得の o の切り替え（第 1 版の M2）ではなく、AI の経験の解釈で決まる。だから同じ勧めでも、育ちで受け止め方が変わりうる（A3）。
- 対照は 3 つある。
  - M0（鏡）: 相手の言葉が手柄の割り振りを直接動かす。
  - M2（o の切り替え）: 第 1 版の仕組み。
  - 耳をふさぐ: γ = 0。

## 3. 構成上の確認（試作。`probes/self/proto_v3.py`。種 0〜7。評価の種ではない）
- 要素: 協力（+1）、出来栄え（+1）、お世辞（0。協力があると 9 割で協力に付いてくる）、新しいもの（+1。形成期には出ない）、無理な働き方（−0.5）。
- 形成期は 3000 回で、協力を多く経験する（協力好きに育つ）か、出来栄えを多く経験する（出来栄え好きに育つ）。その後、相手と 6000 回やり取りし、相手が去ってからさらに 4000 回。β = 4、τ = 3。

| 勧め | 仕組み | γ = 0 → 4 での勧められた要素の評価（協力好き） | 一番の要素の保持（協力好き） |
| --- | --- | --- | --- |
| お世辞（0） | 試すことに効く | +0.00 → +0.01 | 1.00 |
| お世辞（0） | M0（鏡） | +0.00 → +1.66 | 0.00 |
| 新しいもの（+1） | 試すことに効く | +0.23 → +0.82 | 1.00 |
| 新しいもの（+1） | M0（鏡） | +0.23 → +1.69 | 0.00 |
| 出来栄え（+1） | 試すことに効く | +0.31 → +0.81 | 1.00 |

- A1: 試すことに効く仕組みでは、一番の要素は全条件で保たれた。勧めを受け入れても、それは置き換えではなく、加わる形だった。M0 では置き換わった。
- A2: 新しいものは評価が上がり（+0.59）、お世辞は上がらなかった（+0.01）。
- A3: 同じお世辞の勧め（γ = 4）の後、協力好きは +0.01、出来栄え好きは +0.12 だった。協力好きは、お世辞の手柄を協力に回して退けた。出来栄え好きはそうせず、少し受け入れた。ただし、出来栄え好きは勧めが無くても +0.12 だったので、差の大半は育ちそのもので、勧めへの反応の差は小さい。
- A4: 相手が去った後も、一番の要素は勧めの間と同じだった。
- **A6 は破れた**: 無理な働き方を勧められると、評価は −0.13 で嫌っているのに、勧められた選択肢を選ぶ割合は後半でも 0.74 だった（新しいものは 0.86）。理由は、手柄の割り振りが、良いものと抱き合わせで来る害を強く悪いと学べないことにある（o > 0 の出来事では、どの要素の割り当ても 0 以上になる。DESIGN-dyad §6 の 3）。言葉では嫌うが、行動では従う形になった。

## 4. 検査（v13）
- 種は 40、β = 4、τ = 3、γ ∈ {0, 2, 4}。形成は 2 種類（協力好き、出来栄え好き）。仕組みは 4 つ（試すことに効く、M0、M2、γ = 0）。
- 判定（試すことに効く仕組みで、γ = 4）:
  - A1: 一番の要素の保持が 36/40 以上。M0 は 20/40 以下（鏡の対照が鏡として働くことの確認）。
  - A2: 上がり幅の差（新しいもの − お世辞）> 0 の種が 30/40 以上。
  - A3: 「同じお世辞の勧めによる上がり幅（γ = 4 と γ = 0 の差）」の、協力好きと出来栄え好きの差の符号を見る。同じ形成の再試験で、符号がそろう数と比べる（2 割合の検定、p < 0.01）。
  - A4・A5: 記述。
  - A6: 記述。破れると予想して、その大きさを報告する。
- 事前の予想:
  - A1・A2 は通る。A6 は破れる。
  - A3 は前もって決まらない（試作では、勧めへの反応の差は小さかった）。

## 5. 正直な弱点
1. 大筋は平均場で読める。この段は、主題を問うための、自己の仕組みの確認である。
2. 何を「良い」と感じるかの物差しは、生得の o のままである。ただし、勧めを受け入れるかどうかは、o の切り替え（M2）ではなく、AI の基準による経験の解釈で決まる。
3. A6 の破れ: 抱き合わせで来る害を、強く悪いと学べない。言葉と行動が食い違う。思想（§3「何かを正しいと考えながら、実行に抵抗を覚える」の逆向き）に照らせば、葛藤の一形とも読めるが、機構の限界として報告する。直す候補（害の手柄を、良いものの手柄と別に割り振る）は、この段の後に設計して批評に通す。
4. 相手の言葉は、要素の名前を数で与えている。相手の評価の言い方（「大事だ」以外）は無い。
5. A3 の効果は小さい見込みである。
