# CRITIQUE-dyad-1: DESIGN-dyad.md への理念批評（Fable 5.1、2026-10-22）

依頼文は `CRITIC-BRIEF.md` をそのまま使い、対象と 3 点（中心の筋、D3・D4 の構成、最初に足す層）を足した。

## 判定: 条件付きで進めてよい（条件 1 を満たせないなら止める）

## 要旨
1. **問いに答えるか**: 部分的。答えるのは「関係」（τ: 情報源の信頼度を分野ごとに学ぶ）と「解釈の変化」の一部（D3 だけ）。特徴は開発者が与える。判断基準は不在（設計 37 行が自認。良し悪しは `sim4.py` 37・511 行の TOL 恒常性のまま）。移るのは信頼の地図で、基準ではない。除去・入れ替えの検査は D1〜D4 に無い。
2. **すり替え**: (a)「AI が自己を主張する」→「相手の発言が生得の結果を外す分野では相手を無視する」。ここでの自己は生得の恒常性そのもの。報告では「自己＝生得」と明記する。(b)「解釈」→「重み」。発言は V_self と同じ尺度の数値なので、τ は Kalman 利得（観測の重み）に相当する。
3. **計算前に決まっていないか**: D1・D2 は自明。鏡と耳をふさぐは必ず落ちる対照で、証拠に数えない。**D3 は決まっている**: V_self の目標（経験した結果）も τ の目標（発言と経験の一致）も現在の状態に依らない教師信号で、経験できる確率が外生なら、相手が一貫している限り初期値に依らず同じ所へ収束する。残るのは学習率で決まる遅い忘却だけ（CRITIQUE-criterion-1 の C3 と同じ型）。D4 も学習率で速さが決まる。
4. **分岐の道**: 種と舞台の事前固定は適切。ただし D3 の 3 分類（洗い流す／保つ／組み替わる）に判定規則が無く、後半の長さ次第で残差を作れる。
5. **中心の筋**: 自他の分離は正しい最初の 1 層。ただし τ を「生得の結果の予測精度」で定義すると、自己は生得に固定され、学びは教師付き回帰に落ちる。層の数より、**状態が目標に効く環を 1 本入れること**が優先。

## 条件
1. 経験を内生にする。AI が話題に関わるかどうかを V_self（と τ）で決める。見方が経験を選び、経験が見方を作る環ができ、D3 が計算前に決まらなくなる。
2. D3 の判定規則を事前登録する。後半の長さを 1/lr の定倍で固定し、「保たれる」の残差閾値と「組み替わる」の定義（例: 分野間の τ の順位の入れ替わり）を数値で書く。
3. τ に負の値を許すか、発言を特徴ベクトルにして τ を発言→予測の写像として学ぶ（相手の「良い」を自分の「悪い」と読み替える獲得が可能になる）。
4. 鏡・耳をふさぐは参照線として残し、合格の対照に使わない。主対照は「前半なしの AI」と「別の前半の AI」。
5. 報告に「判断基準の獲得は未着手」「自己＝生得の恒常性」と明記し、DESIGN-criterion の未決を消さない。
6. 発言を数値で与える簡略化が、`NOTES-llm-connection.md` §3（評価を LLM に書かせない）の未解決問題を迂回していることを記録する。
