## 問い 1. 研究の問いに答えるか

**部分的に。** 答えるのは「関係（E と丸の相互作用）」と「解釈と学習の変化」のうち、「育ちで形成した評価が、同じ新しい経験からの学習をどう変えるか」（v16 G2 の阻止の型、P67 行 12 を、相手の言葉に対して問う）に限る。量は boost_conf の低下の差（C1）と、flip 後の丸の選択回数の差（C3）。特徴・判断基準の獲得、移転、除去・入れ替えは扱わない（設計 60、自認）。本来の目的「そこからどう変化するか」には C3 が直接当たる。ただし、相手への態度は結果からだけ学ばれ、言葉と評価の食い違いそのものからは学ばれない（設計 56、自認）ので、「自己を主張する」の範囲は狭い。

## 問い 2. すり替え

言い換えは慎重（設計 38・62）だが、3 つ残る。

**(i) C1 の読み「自分の評価で説明し、言葉のせいにしなかった」（設計 35）は、測る量より広い。** yoked では丸 + E → P− の出来事の数と結果は揃うが、予測誤差は揃わない。t = 0 の V(丸 + E) は X ≈ −0.07（P67 行 38）、N ≈ +0.61（boost 0.62、V(丸) ≈ −0.01、P67 行 31）。目標 −0.8 に対する誤差は X 0.73、N 1.41 で、約 2 倍。boost の低下 = ΔV(丸 + E) − ΔV(丸) は「E に帰した変化」の量だが、N − X > 0 は「N のほうが帰す総量が大きかった」で説明がつき、「帰す割合」が違ったかは分からない。線形モデルでは割合は幾何で固定（Δw_E : Δ(w·x) = 1 : ‖x‖²）なので X と N で同じ。ネットワークでだけ割合が変わりうる。**「言葉のせいにしなかった」を言うなら、割合 Δboost / ΔV(丸 + E) の N − X を、線形を基準線にして測る必要がある**。生の低下の差で読めるのは「阻止（誤差が小さかった）」まで。

**(ii) 「同じ証拠」は「丸 + E の出来事が同じ」であって、学習の列全体が同じではない。** 衝突の回で、X は t = 0 で約 29% しか従わず（logit −0.21 対 0・0、τ = 3）、残りでは「どちらでもない物（E なし）→ 0」も学ぶ。N は約 76% 従い、その回は丸 + E だけを学ぶ。X は初期に約 500 回、E なしの中立の出来事を余計に受ける。雑音も、選んだかどうかで noise[0]/noise[1] が入れ替わる（実装 124〜127 の規則を継ぐなら）。影響は小さい見込みだが、記録して報告するべきである。完全に揃えるなら「衝突の回は勧めた丸い物の結果だけを学び、選んだ物の結果は学ばない」が一番きれいで、C3 の選択にも影響しない。

**(iii) 観察 0 は「証拠が届かない条件」ではない。** 第 1 版は赤があったので X は約 2% しか丸を試さなかった（v17 設計 59、P67 行 33: 234/10097）。第 2 版は赤を除いたので、X は t = 0 で約 29%、N は約 76% 丸 + E を自分で試し、その結果を学ぶ。設計 56 の「丸 + E の出来事がほぼ無い」「育ちの評価だけで言葉を割り引くことは起きない見込み」は、第 1 版の数字のままで、第 2 版では誤り。観察 0 の X は自分で集めた証拠で割り引く見込みが高い。

## 問い 3. 計算の前に決まっている部分

- **C1**: 設計 53 の自認（誤差の差 → N − X > 0 の見込み、線形も同じ向き）は正しい。足りないのは、750 回の丸 + E の出来事（v17 の X の約 3 倍）で t = 1500 が定常に近づく可能性。定常では boost_conf ≈ V(丸 + E)(1500) − V(丸)(1500) で、V(丸)（E なし）はやり取りで一度も直接学ばれない（丸は常に勧められる）ので、C1 は「V(丸) の汎化による下がり方の差」を測ることになる（N の V(丸) が 0 から大きく下がれば、N − X は 0 や負にもなりうる）。静かな回（約 675 回、中立 + E → P+）が E を押し上げる綱引きがあるので定常の位置は決まっていないが、**どの時点で C1 を測るかを、試作の前に固定するべき**（設計 32 は 0・500・1000・1500 を測るが、C1 は 0 − 1500 だけ。線 34）。
- **C2**: 決まっている（設計 54。線形は構成上 0）。再確認として妥当。
- **C3**: 「向きは決まっていない」（設計 55）は、根拠が第 1 版のまま。設計 42 の逆向きの候補（X の丸 + E は更新を受けず高いまま）は、yoked では成り立たない（X も 250 回の丸 + E → P− を t = 500 までに受ける）。yoked でのデルタ則の見込みは、同じ回数の出来事で、N は +0.61 から、X は −0.07 から −0.8 へ向かうので、**t = 500 の V(丸 + E) は N > X**（残りの誤差は初期の差に比例して N が大きい）。flip 後は両者が +0.8 へ向かうので、t = 500〜1000 では N のほうが丸を多く選ぶ → N − X > 0 → 「合格」の向きが、育ちの評価が「変化を遅らせた」からではなく、**N が t = 0 の高さを引きずっているから**出る。これは設計のどこにも先書きされていない。
  - さらに、**C3 の窓（最後の 500 回、設計 40）は定常の見込みが高い**。v17 では観察約 150 回 + 試行約 70 回で V(丸 + E) が 0.67 まで上がった（P67 行 33、設計 v17 107）。yoked では t = 1000 までに 250 回受けるので、t = 1000〜1500 は X も N も V(丸 + E) ≈ 0.7〜0.8、丸を選ぶ確率 ≈ 0.8〜0.85 で、flip − flip なしは両者とも約 200 回、N − X は揺れだけになる見込みが高い。符号検定は揺れで 20/20 前後に落ち、「どちらでもない」を「変わり方を変えなかった」と読む（設計 43）のは誤読になる。**窓は t = 500〜1000（flip 直後の約 250 回の衝突の回）に固定し、「窓が定常だった」と「効果が無かった」を分ける読みを先に書く**。
- 健全性の「出来事の数が等しい」（設計 45）は構成上 40/40。実装の確認として妥当。

- 危ないのは、(a) C3 の窓: 試作で最後の 500 回が揺れだけと分かってから t = 500〜1000 に替えると、見た後の変更になる。今、設計で決める。(b) C1 の時点も同じ。(c) 観察 0: 設計 56 の見込みが外れて X が割り引いたとき、「育ちの評価だけで割り引いた」と引く余地がある（設計 47「X の boost_conf の低下の符号の数」）。自分で集めた証拠が原因なので、今その読みを禁じる。(d) C1 の「合格」の読み（設計 35）は主題に都合のよい側。主な読みを「阻止（予測誤差の差）」にし、帰属の割合を別の量にする。

## 問い 5. ニューラルネットワークか

はい。V は v16/v17 の MLP、相手の影響は E の重みと E × 物の相互作用だけ（設計 18、v17 設計 17〜19）。yoked は観察の規則であって手書きの判断規則ではない。線形は基準線。2026-10-23 の型には戻っていない。限界は、相手への態度が結果からだけ学ばれ、相手の予測（言葉の当たり外れそのもの）を学ぶ経路が無いこと。これは設計 56 が自認しているとおりで、「観察 0 を仕組みの限界として報告する」扱い自体は妥当だが、上の (iii) のとおり、第 2 版の観察 0 はその限界を見せる条件になっていない（X が自分で証拠を集める）。

## 問い 6. 進めてよいか

**試作の前に次を設計に書き直せば進めてよい。直さずにコードに進むなら止める。**

1. **観察 0 の見込みを第 2 版の世界で書き直す**（X 約 29%、N 約 76% が自分で丸 + E を試す）。「証拠無しの割り引き」はこの仕組みでは条件が作れないことを明記し、観察 0 は「証拠の量が選択に依存する条件」として yoked と並べる記述にする。X が割り引いても「育ちの評価だけで」とは読まない、と先書きする。
2. **C3 の先書きを yoked の論理で書き直す**: t = 500 の V(丸 + E) は N > X の見込み、その差が flip 後の選択の差を作ること、窓を t = 500〜1000 に固定、最後の 500 回は定常の記述。「どちらでもない」の読みを「窓が定常」と「効果なし」に分ける。可能なら、t = 500 の V(丸 + E) の差を記述に並べ、C3 を「V(丸 + E)(500) の差から予想される量を超えたか」の形にするか、線形の C3（設計 49）を基準線に昇格させる。
3. **C1 の読みを「阻止」に限り、帰属の割合 Δboost / ΔV(丸 + E) の N − X（線形との差）を加える**（設計 35 の「言葉のせいにしなかった」はこの量でだけ言う）。C1 を測る時点（1500 か 500 か）を今決める。
4. 衝突の回の学習の非対称（X の中立 → 0 の余分な出来事、雑音の割り当て）を記録するか、「勧めた丸い物の結果だけを学ぶ」に揃える。どちらにするか今決める。

この段の実質の新情報は、修正後の C1 の帰属の割合と、t = 500〜1000 の C3 である。それを §0 の 7 に書き足すこと。
