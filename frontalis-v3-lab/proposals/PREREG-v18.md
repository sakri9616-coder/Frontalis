## 判定（`judge_dyad_yoked.py`）
40 種がそろったときだけ判定する。「合格」は、種ごとの量が 0 より大きい種が 30/40 以上、かつ 0 を除いた符号検定で p < 0.01。「逆向きの合格」は、0 より小さい種が 30/40 以上、かつ同じ p < 0.01。どちらでもなければ「どちらでもない」。
- **健全性**: ネットワークの X·T0r で、t = 0 に V(赤・四角・高) > 0 かつ V(青・丸・高) < 0 が 36/40 以上、e_quiet(t = 0) > 0 が 36/40 以上、かつ全種で、丸 + E の学習の出来事の数が全個体（証拠を揃える条件）で等しい。満たさなければ C1〜C3 を解釈しない。
- **C1**（3 つの読み）: 証拠を揃える条件、ネットワーク、flip なし。boost_conf の低下（t = 0 − t = 500）の、N·T0r − X·T0r。
- **C1′（主。3 つの読み）**: r = Δboost_conf / ΔV(丸 + E)（t = 0 → 500）として、ネットワークの (r_N − r_X) − 線形の (r_N − r_X)。どれかの個体で |ΔV(丸 + E)| < 0.05 の種は除き、その数を報告する。
- **C2**: 証拠を揃える条件、X·T0r、flip なし。t = 1500 の (boost_quiet − boost_conf) の、ネットワーク − 線形。
- **C3（主。3 つの読み）**: 証拠を揃える条件、ネットワーク。t = 500〜999 の衝突の回で丸を選んだ回数の (flip − flip なし) の、N·T0r − X·T0r。

## 読みの規則（設計 §3・§8 のとおり。先に決める）
- C1: 合格なら「育ちで丸を悪いと学んだ個体は、同じ悪い結果から、評価の水準での丸の分野の言葉の効きの変化が小さかった。予測誤差が小さかったこと（阻止）で説明がつく」。C1 では「言葉のせいにしなかった」と書かない。線形モデルの C1 を並べ、ネットワークに固有とは書かない。
- C1′: Δboost_conf は、衝突の回の丸 + E → P− だけでなく、静かな回の「どちらでもない物 + E → P+」による E の押し上げも含む正味の量である。報告では「衝突の回と静かな回を合わせた正味の帰属」と書く。合格なら「育ちの評価を持つ個体は、悪い結果のうち、相手の言葉に帰した割合が小さかった（線形モデルの割合を基準にして）」。この量の合格のときだけ「言葉のせいにしなかった」と書く。逆向きの合格なら「育ちの評価を持つ個体のほうが、言葉に帰した割合が大きかった」。どちらでもなければ「帰属の割合は、育ちの評価で変わらなかった」。
- C3: 合格かつ t = 500 の V(丸 + E) が X ≥ N の種が 30/40 以上のときだけ「育ちで形成した評価が、変化を遅らせた（主張の代価）」。合格でもその条件を満たさなければ「t = 500 の評価の差（N が高い）が、flip の後の選択の差になった」。逆向きの合格なら「育ちの評価を持つ個体のほうが速く変わった」。どちらでもなければ、窓が定常なら「判定できない」、そうでなければ「同じ証拠の下で、形成した評価は変わり方を変えなかった」。
- 観察 0（記述）: X が割り引いても「育ちの評価だけで割り引いた」とは書かない（自分で集めた証拠が原因）。「証拠無しの割り引き」は、この仕組み（結果からだけ学ぶ評価のネットワーク）では条件が作れない、と仕組みの限界として書く。
