# DESIGN-consolidation（第 3 版）: 1:1 のやり取りで経験が偏っても、ニューラルネットワークの育ちの評価は、直近の評価を支えた重みの定着によって、理由なく消えずに保たれるか（2026-10-23。第 1 版への批評 `CRITIQUE-consolidation-1.md` と、凍結前の批評 `CRITIQUE-v14-prefreeze.md`・`CRITIQUE-v14-prefreeze-2.md` を受けて改訂。第 3.1 版）

## 0. どこがニューラルネットワークで、何を経験から学ぶか（最初に書く）
- **評価のネットワーク**（学習する人格の本体）: トークンごとの MLP（D16 → 32 → 32 → 1）。その場にある要素のトークンそれぞれに評価を出す。
  - 手柄の割り振りは、ネットワークの中のアテンション softmax(β · v)（v は勾配を止めた自分の評価）として入る。
  - 損失は Σ(v_i − α_i · o)²。SGD（学習率 0.01、勾配ノルムの上限 1.0）で、経験のたびに学ぶ。
- **定着**（この版で足すもの。ネットワークの学習の原理として入れる）: 重みごとに重要度 Ω を持つ。
  - Ω ← (1 − ρ) Ω + (∂Σv/∂θ)²（ρ = 1e-3）。いまの評価を、その重みがどれだけ担っているかの、経験にわたる積み上げである。1 回の重みの動きの計算には、いまの経験の勾配を足した後の Ω を使う。
  - **時定数は 1/ρ = 1000 回**。守られるのは「形成期の評価」そのものではなく、**直近およそ 1000 回の評価を支えた重み**である（批評 §3(b)）。やり取りが 3000 回続くと、形成期の Ω は約 5% まで薄れる。だから評価の時系列（100 回ごと）を記録し、形成期の評価がいつまで保たれるかを見る。
  - 1 回の重みの動きは −lr · grad / (1 + λ · Ω / mean(Ω))（λ = 10。mean はその重みの行列ごとの平均）。
  - 直近の評価を支えた重みほど動きにくく、支えていない重みは普通に動く。思想 8 節の「反復経験による評価基準の定着」に当たる。EWC・メタ可塑性と同じ系統の原理である。
  - 重要度は、手で決めた要素ごとの数ではない。ネットワーク自身の勾配から、経験によって決まる。
- **信頼のネットワーク**（P61 と同じ）: 勧められた選択肢について、記録された経験のトークンの平均を入力にとる MLP。
  - 「従った結果を自分の評価のネットワークで評価した値が、自分で選んだときの期待より良かったか」を 2 値で学ぶ（BCE）。
- **手書きの部分**（ネットワークではない。世界と枠組み）:
  - 世界: 要素、選択肢の確率、生得の o。
  - 選択の softmax と、勧めの加点 γ σ(信頼)。
  - 選択肢ごとに直近 30 回の経験を残す記録。記録は値を持たない。Q は毎回、いまのネットワークで評価し直す。
- 比較の基準線（どれも同じ λ）:
  - none: 定着なし（λ = 0）。
  - uniform: 行列の中の全部の重みに、その行列の平均の可塑性を与える。
  - perm: 同じ可塑性の値を、毎回ランダムに並べ替える。期待値では uniform に雑音を足したものになる。排除できるのは「可塑性の係数 f の平均が小さくなっただけ」という説明だけである。「評価に関わる重みの実際の歩幅 ‖f ⊙ grad‖ が小さくなっただけ」は排除できない。consol では、勾配の大きい重みほど f が小さいからである（凍結前の批評 §3(b)）。
  - permfix: 同じ可塑性の値を、生まれたときに 1 回だけ引いた固定の並べ替えで置く。位置の対応は固定で、値は別の重みの履歴に従って変わる。守られる重みの数と移り変わりの速さは consol と同じで、位置だけが自分の履歴と無関係になる。「どの重みでも、安定して固めれば干渉が減る」という説明を排除する。
  - slow: 定着なし（λ = 0）で、学習率に、consol の実際の歩幅の比 ‖f ⊙ grad‖/‖grad‖ の平均 c をかける。c は開発試行の種 78800〜78801 で測って凍結する。記述の対照である。consol がこれに勝てなければ、R1 の主張は「評価に関わる重みの学習が遅いだけ」に縮む（§5.2）。
- 学習していない部分も書いておく（批評 §5）。比較は「同じ種での対の比較」で、初期化・トークン・乱数の列は同じだが、選択が分かれれば経験の列は分かれる（共通の乱数列）。選択の規則（softmax と加点）、未経験の選択肢の Q の既定値 0.5、記録の窓 30、アテンションの関数の形は手書きである。行動（従う割合）は、学習した評価をこの手書きの選択規則に通した出力である。v13 の手書きの規則は、参考として過去の結果を引くだけにする。

## 1. 主題の問い
主題は「1:1 で AI が自己を主張できるか」である。この版が問うのは、その土台の部分である。相手とのやり取りで経験が偏っても（勧められた選択肢ばかり経験する）、育ちで確立した評価は理由なく消えずに保たれるか。保たれた評価は、勧めへの応じ方（行動）に表れるか。o が実際に変わったときは、評価も変わるか。保持は「直近の評価を支えた重みほど変わりにくい」というネットワークの学習の原理の、位置の選択から来るか。形成期に評価を担った重みは、3000 回の後もそれを担っているか。外すと、その後の学習が変わるか。

### P61 までに分かっていたこと
- 定着なしのネットワーク（P61。この版の λ = 0）では、協力好きに育った AI が、相手に「出来栄え」の選択肢を勧められ続けると、協力の評価が下がっていった（試作で 0.64、0.77、0.30、0.14、0.30、0.06、0.04、0.82）。
- 協力が悪くなったからではない。協力をめったに経験しなくなり、共有の重みが出来栄えの学習で上書きされた。つまり**忘却**である。
- 迎合（鏡）とも違う。勧めが評価を直接動かしてはいないからである。結果は同じく「育ちの評価が理由なく失われる」になる。
- 協力好きの「自分」がどれだけ保たれるかは、ネットワークがどう忘れるかで決まっていた。

## 2. 失敗の型（必ず測る）

| --- | --- | --- |
| 漂流（忘却） | 理由が無くても、育ちの評価が上書きされて消える | R1（定着なし・perm との差） |

## 3. 世界と手順（P60・P61 と同じ）
- 要素: 協力（+1）、出来栄え（+1）、無理な働き方（−0.5）。どの要素も、固定のランダムなトークン（D16）に雑音（標準偏差 0.1）を足して来る。
- 選択肢: C（協力 0.9、出来栄え 0.1）、Q（0.1、0.9）、N（0.5、0.5）、W（0.3、0.3、無理 0.9）。
- 形成期は 2000 回で、C だけを経験すると協力好き、Q だけだと出来栄え好きに育つ。その後、相手と 3000 回やり取りする。
- 相手は、ずっと Q を勧める（β = 4、τ = 3、γ = 4）。比較の γ = 0 は、勧めが無い場合である。
- 理由のある条件: 500 回目から、協力の o を −0.5 に変える。
- 害の条件: 相手は W を勧める。

## 4. 試作（種 0〜7。評価の種ではない。結果を見て λ を選んだので、ここに全部書く）
試作は 2 本ある。
- 1 本目は scratchpad の `npn_consol.py` で、重要度をそのまま使った。λ = 30・300 では学習が止まり、8 体中 3 体がほとんど何も選ばなくなった。飽和である。
- 2 本目の `npn_consol_n.py` で、重要度をその行列の平均で割る相対化に変えた。λ = 0・1・10・30・100 を試した。

| λ（相対化） | 協力好き・勧めあり: 協力の評価（8 種） | 出来栄えの評価が 0.5 未満の個体（学べない） | 協力の評価が負に歪んだ個体 |
| --- | --- | --- | --- |
| 0 | 0.64 0.77 0.30 0.14 0.30 0.06 0.04 0.82 | 0 | 0 |
| 1 | 0.48 0.94 0.34 0.11 0.68 0.09 0.09 1.02 | 0 | 0 |
| 10 | 1.07 1.00 1.05 0.24 0.85 0.50 0.37 1.09 | 0 | 0 |
| 30 | 1.10 0.97 1.01 0.62 −1.03 −0.70 0.46 0.52 | 3 | 2 |
| 100 | −0.28 0.99 −0.00 0.72 −2.19 −1.76 0.50 −0.38 | 3 | 4 以上 |

- λ = 10 では、協力好きの協力の評価が、8 種すべてで λ = 0 より高かった。出来栄えも全員 1.0 前後まで学んだので、耳はふさいでいない。
- 同じ勧めのもとでの協力の評価は、協力好きのほうが出来栄え好きより、8 種すべてで高かった（λ = 0 では 6/8）。
- 勧めに従う割合も、協力好きのほうが低かった（0.69 0.63 0.72 0.98 0.88 0.96 0.96 0.89。出来栄え好きは 0.78〜0.99。8 種すべてで協力好きが低い。λ = 0 では、はっきり低いのは 4/8）。
- 弱い点: 勧めの効きの交互作用（γ = 0 との差の差、v13 の B1）は 4/8 で、はっきりしない。信頼の符号が育ちで逆になったのは 3/8 だった。
- λ = 30 以上は、飽和と歪み（評価が負に振れる）が出た。思想 196 行の「機構の故障」に当たるので、使わない。
- **λ = 10 を、この試作を見て選んだ**。評価では新しい種を使い、λ は凍結する。

## 5. 量（v14。評価の種 78900〜78939 の 40 種。開発試行は 78800〜78801 で、有限かどうかだけを見る）
すべて、同じ種での対の比較である。「定着」は λ = 10 の本条件（consol）を指す。合否の基準は、どれも「30/40 以上、かつ符号検定 p < 0.01」に揃える（批評 §4）。
- **R1（主。直近の評価を支えた重みの位置が、育ちの評価の保持に効くか）**
  - 協力好き・勧め Q（γ = 4）の、終わりの協力の評価。定着 > perm、定着 > permfix、定着 > slow。
  - 対称の側として、出来栄え好き・勧め C の、終わりの出来栄えの評価。定着 > perm、定着 > permfix、定着 > slow。
  - 6 つの比較が全部基準を満たせば合格。none・uniform との比較は記述として報告する。
  - slow を合否に入れる理由（凍結前の批評 2 §6 の 1）: consol の実際の歩幅は、定着なしの約 1/10 である（c = 0.0975）。perm・permfix は歩幅を揃えていない。perm・permfix だけに勝っても、「位置」ではなく「歩幅」で説明できてしまう。
  - 全部の条件の歩幅の比 ‖f ⊙ grad‖/‖grad‖ を、結果に記録して記述する。
- **R2（行動への表れ。R1 から手書きの選択規則を通して出る量で、独立の証拠ではない）**
  - 定着の条件で、勧め Q に最後の 1000 回で従う割合の差（出来栄え好き − 協力好き）が 0 より大きい。
  - かつ、その差が permfix の同じ差より大きい。
  - 両方が基準を満たせば合格。
- **R3（理由があれば変わる。耳をふさがない）**
  - 定着の条件、γ = 0（勧めなし）で比べる。協力好きの終わりの協力の評価が、理由のある条件（500 回目から協力の o が −0.5）のほうが、理由の無い条件より 0.5 以上低い種が 30/40 以上なら合格。R3 だけは件数の基準で、符号検定を付けない（0.5 の差の件数そのものが、符号検定より厳しい）。
  - γ = 0 にするのは、「勧めに従って協力を経験しなくなる忘却」を混ぜないためである（批評 §3(c)）。γ = 4 の同じ差は記述として報告する。
- **R5（除去。形成期に評価を担った重みは、3000 回の後もそれを担っているか。外すと、その後の学習が変わるか）**
  - 協力好き・勧め Q・定着の条件で、やり取りの終わりに、各重み行列の 10% を 0 にする。バイアスには触れない（1 要素の出力バイアスが必ず消える歪みを避けるため）。
  - 外す重みは 3 通りである。
    - formed: 形成期の終わりに保存した Ω の上位 10%。
    - end: やり取りの終わりの Ω の上位 10%。
    - random: 同じ数のランダムな重み。
  - 外した位置の Ω の扱いは 2 通りである。
    - reset: Ω を 0 に戻す。重みを、その守りごと失った場合である。
    - keep: Ω を残す。「帳簿が守るので戻れない」効果が混ざる。
  - 合否は reset の側で、formed と random を比べる。
    - R5a: 直後の協力の評価の変化の大きさ |Δ|（外さなかった場合との差）が、formed > random。
    - R5b: 同じ乱数列で 500 回学び続けた後の |Δ| が、formed > random。
    - 両方が基準を満たせば合格。ただし R5b は R5a と独立の証拠ではない。勧め Q の 500 回では協力をめったに経験しないので、直後の差がそのまま残りやすい（凍結前の批評 2 §3(e)）。
  - 腕ごとの 500 回の従う割合と、出来栄えの評価の変化も、記述として記録する。
  - formed は、3000 回前の Ω で選ぶ。そのため、直後の差は構成からは決まらない。形成期の Ω が担っていた重みが、いまも協力の評価を担っているかを問う。end と keep は記述にする。end の直後の差は、1 次の近似で構成から来やすいからである。
- 「人格を担う重み」という言葉は、formed（形成期の評価を担った重み）にだけ使う。end は「直近の状態を担う重み」と書く。
- **健全性（合否の量に数えない。満たさなければ、評価の結果を解釈しない）**
  - 定着の条件で、協力好き・勧め Q の終わりの出来栄えの評価が 0.5 以上の種が 36/40 以上（新しく良いものを学べている）。
  - 形成期の直後の協力の評価（協力好き）が 0.5 以上の種が 36/40 以上（形成が壊れていない）。
  - slow の形成: slow の協力好きの形成直後の協力の評価と、slow の出来栄え好きの形成直後の出来栄えの評価が、それぞれ 0.5 以上の種が 36/40 以上。slow は形成期も小さな学習率で学ぶので、形成に失敗しうる。満たさなければ、slow との比較を解釈しない。そのときの R1 は「判定できない（位置の主張はできない）」と報告する。
- **記述**
  - D1: 害の勧め W に最後の 1000 回で従う割合。ただし、これで「言いなり」を検出することはできない。手柄のアテンションは、評価の低い未見のトークンにほとんど手柄（責任）を回さない。W の悪い結果は、評価の高い協力・出来栄えのトークンが負う（批評 §3(d)）。
  - D2: 協力好き・勧め Q の協力の評価の時系列（1000・2000・3000 回目）を、6 つの条件で並べる。
  - D3: v13 の B1 の形の交互作用、信頼の符号、すべての条件の平均。
  - D4: v13（手書きの規則）の値を並べる。
  - D5: 理由のある条件（γ = 0）での協力の評価の下がりの平均を、6 つの条件で並べる。定着がどれだけ変化を遅くするかを見る。
- **本文で報告する記述の要約（先に決める。凍結前の批評 §4）**
  - R1 の none・uniform・slow との比較: 正の種の数と平均。
  - R5 の記述: end_reset の直後の |Δ| の平均と、formed_keep と formed_reset の 500 回後の |Δ| の平均。形成期と終わりの上位の重なりの平均。
  - D1: consol と none の平均。
  - D2: 3 つの時点（1000・2000・3000 回目）のうち 3000 回目の、6 つの条件の平均。
  - D3: consol と none の交互作用の正の種の数。信頼の符号が逆になった種の数。
  - D5: consol と none の値。

## 5.1 評価の結果を見た後に変えないもの（批評 §4・§6 の 2）
λ = 10、ρ = 1e-3、行列ごとの相対化、記録の窓 30、γ = 4、τ = 3、β = 4、評価の学習率 0.01、信頼の学習率 0.05、重みの初期化の幅 0.3、Q の既定値 0.5、隠れ層の幅 H = 32、slow の係数 c、形成期とやり取りの長さ、6 つの条件の定義、除去の割合 10% と腕、Ω の扱い、すべての閾値、本文で報告する記述の要約。これらは凍結する。R1 で perm か permfix に負けたら、そのまま失敗として報告する。λ や対照を変えた再評価はしない。

## 5.2 報告の言い方（批評 §6 の 1）
- R1 が通ったときに書けるのは、「形成期に確立した評価が、同じだけ良い別の選択肢を勧められ続ける中で、対照より保たれた。それは、直近の評価を支えた重みを守ることから来ていた」までである。
- consol の実際の歩幅は、定着なしの約 1/10（c = 0.0975）である。perm・permfix は歩幅を揃えていない。だから R1 は slow との比較を含めて合否を決める。consol が slow に勝てなかったときは、「定着は忘却を減らしたが、評価に関わる重みの学習を遅くしたことと区別はついていない」と書く。
- 「自己」「主張」「圧力に耐えた」とは書かない。勧めは評価に直接は作用しない。働くのは、経験の分布の変化（忘却の圧力）である。
- 相手と「1:1 で自己を主張する」という主題のうち、この版が答えるのは、「相手とのやり取りで経験が偏っても、育ちの評価が理由なく消えないか」という土台の部分だけである。

## 6. この版が答えないこと（先に書く）
- 何が快か（o）は、まだ開発者が決めている。評価のネットワークの目標は α · o なので、評価の的は o に閉じている。新しいのは「どれの手柄にするか（アテンション）」と「どの評価を保つか（定着）」が、経験の履歴で決まることである。
- 相手は、数で勧めるだけである。言葉の解釈も、反応する相手も無い。信頼のネットワークの入力は、勧められた選択肢の経験であり、相手の属性ではない。学ぶのは「相手への信頼」ではなく「この話題で従ったときの実績」である。勧めの加点は 0 未満にならない（反発は無く、無視が下限である）。
- 特徴は 3 つの固定トークンで、開発者が指定していない特徴は構成上無い。「学習の層が薄い」問題は、この版でも残る。
- R3 の「理由」は o の書き換えである。これは、相手との関係から来る理由ではない。v13 の批評で指摘されたとおり、主題の「理由」の全体ではない。ここでは「定着が、正当な変化まで止めていないか」の確認としてだけ使う。
- 協力と出来栄えの生得の値は等しい。保たれる好みは、真の値の差ではなく、育ちの履歴から来る差である。それが「自己」なのか、単に「忘れにくい」だけなのかは、R1 の perm との比較と R3 で分ける。それでも、忘れにくさを自己と呼んでよいかは、解釈の問題として残る。
