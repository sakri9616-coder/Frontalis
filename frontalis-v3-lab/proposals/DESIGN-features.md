# DESIGN-features: 自分で見つけた特徴の上での手柄の割り振り（案。2026-10-23。コードの前。理念批評役に通す）

`DESIGN-dyad.md` 第 5.2 版と v10 の評価（`probes/p50_judgment.json`）の続き。v10 では、要素（協力・出来栄え…）を開発者が AI に与えた。研究の問い（2026-10-17）の「開発者が指定していない評価上の**特徴**」と、批評 5 の「特徴・関係には答えない」に向けて、この版では、AI が生の手がかりから自分で見つけた特徴の上で、手柄を割り振る。

## 1. 仕組み
- 世界: 隠れた要素 a ∈ {0,1}^K（K = 4）がある。AI に見えるのは、生の手がかり x = a A + 雑音（D = 16 次元、A は無作為）だけである。生得の o = Σ a（どの要素も同じだけ良い）。AI には a も A も渡さない。
- 特徴の獲得: 小さな自己符号化器（H = 8 個の ReLU。x を復元する。L1 の疎性）を、中立の経験（共起の偏りのない世界）で 3000 回学ぶ。教師は x だけで、要素のラベルは無い。
- 知覚: 各特徴が「ある」とは、h_j が、その特徴の普段の強さ（中立の経験での 90 パーセンタイル）の半分を超えること。
- 判断基準と割り振り: v10 と同じ規則を、知覚された特徴の上で使う。
- 前半・新しい経験・判定: v10 の G3a と同じ型にする。
  - Pa: 要素 2 が要素 1 といっしょに来る。Pb: 要素 0 が要素 1 といっしょに来る。
  - 前半の直後に、要素 0 と 2 が同時に出る同じ出来事の列を 100 回与える。
  - V(要素 0 だけの x) と V(要素 2 だけの x) の変化の差の符号を見る。
- 特徴は、中立の経験の後に固定する（前半には学び続けない）。理由: 前半の共起で特徴そのものが変わる効果と、割り振りの効果を分けるため。前半にも学び続ける条件は、次の段で比べる。

## 2. 構成上の確認（試作。`probes/credit/g4_proto_v1.py`、`g4_proto_v2.py`。種 0〜19。評価の種ではない）
- 特徴は要素とよくそろう。8 個のうち 4 個が、それぞれ 1 つの要素と相関 0.93〜1.00 を持つ（`g4_diag` の結果。AE 3000 回、L1 = 0.01）。残りの 4 個は、要素が無いときに弱く働く。
- 試作 1（知覚を強さで重みづけ、α ∝ (h/max h) exp(βc)）は失敗した。β = 4 で逆の符号は 4/20。弱く広く働く特徴が、c が大きくなると、強さに関係なく手柄をすべて取った（「いつもその場にあるもの」に手柄が行く、迷信の形）。
- 試作 2（知覚を 0/1 にする。§1）では、逆の符号が β = 4 で 19/20、β = 2 で 12/20、β = 0 で 12/20 だった。
- 読めること: 開発者が要素を与えなくても、AI が自分の経験の構造から見つけた特徴の上で、同じ新しい経験から学ぶ向きが、育ちで逆になる（β = 4）。β = 2 では、与えた要素のとき（v10 で 40/40）より弱かった。
- 試作 1 から 2 への変更は、結果を見た後の変更である。そのことを隠さない。評価は、試作 2 の規則を固定して、新しい種で行う。

## 4. 正直な弱点
1. 要素の構造（4 つの独立な二値の要素、線形の混ぜ方）は、開発者が世界に作った。AI が見つけたのは、世界にある構造である。「何が要素か」を AI が決めたとは言えない。
2. 知覚のしきい値（普段の強さの半分）と、知覚を 0/1 にすることは、試作 1 の失敗を見た後に決めた。
3. 特徴は前半に固定した。経験が特徴そのものを変える道（思想の「特徴の獲得」の本丸）は、まだ入れていない。
4. 網は小さく（H = 8）、LLM は無い。
