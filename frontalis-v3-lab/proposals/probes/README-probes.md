Python: `frontalis-phase3d-lab/.venv`（torch 2.7.0+cu128、numpy）。`PYTHONUTF8=1`、`-B`。種は 77390〜77399（PREREG-DRAFT 第 3 節で予約）。

## P0 `p0_audit_checks.py` → `p0_results.json`
既存の `npnv3` を読み取り専用で実行し、AUDIT.md の主張（符号の固定、同一の行、人 × 文脈の交互作用 = 0、未見の手がかりの C = 0、既定の NPN の MLP = 0）を確かめた。種 77399。数秒。

## P1 `p1_interaction_world.py` → `p1_results.json`、`p1_stdout.txt`
- 世界: 個体の観測できる性質 4 次元と観測できない性質 2 次元、文脈 3 次元。信号 = tanh(性質 × 文脈の双線形 + 加法の小さな項)。観測は無作為な射影（48 + 16 + 無関係 8 次元）。F5 相当の対照は信号を表の中で並べ替えたもの。
- モデル: ridge（生の入力）、無作為な ReLU 特徴 1,024 + ridge、近傍 5、MLP（128 × 2、Adam、重み減衰 1e-4）。
- 測定: 未見の個体 40 × 文脈 12 の R²、学習前と学習後の隠れ表現の線形 CKA、変化の主方向 k = 2・8 の除去と無作為な方向の除去、数発学習（未見の個体 10、3 文脈、SGD 0.05 × 20 回）の後の残り 9 文脈の R²。
- **経緯（正直な記録）**: 最初は種 5 本 × N ∈ {300, 1,500, 6,000} × S ∈ {300, 3,000} を CPU で回したが、同じ機械で別のエージェントの重い処理が CPU を 100% 使っており、1 本の種に 6 分かかり、20 分の時間切れで止まった（結果は残っていない）。種を 3 本（77390〜77392）、N を {1,500, 6,000} に減らし、MLP を GPU に移して回し直した。ridge と無作為特徴の正則化は未見のプローブで選んでおり、対照に**有利な**（楽観的な）選び方である。
- 結果（種 3 本。平均は `p1_stdout.txt`、種ごとは `p1_results.json`）。数値は小さな検査のもので、証拠ではない。

**読み（設計への入力）**
1. **否定的な結果: この規模では、どのモデルも未見の個体へほとんど転移しなかった。** 学習した個体が 80 しかなく、性質の一部が観測できない世界では、転移の上限そのものが低い。上限（観測から得られる最良の予測）を計算していなかったので、「モデルの失敗」か「世界の上限」かを区別できない。→ DESIGN を変更: 転移の R² は、観測できる情報だけを使う神託の予測（ベイズ最適の近似）を基準に測り、上限も報告する。
2. **経験の数より個体の数が効く。** N を 1,500 → 6,000 にしても転移は増えず、MLP は学習回数を増やすと悪化した（学習した個体への過適合）。→ DESIGN を変更: 個体の数を経験の数と別に操作する（80、320、1,280）。
3. **無作為特徴が MLP 以上の転移を示した点がある**（N = 1,500 の平均）。この規模なら FC5（容量で説明できる）に当たる。
4. **除去の対照が不公平だった。** 変化の主方向は分散の大きい方向で、無作為な方向は分散の小さい方向に当たりやすい。外すと R² が負になるのは、特徴の除去ではなく読み出しの破壊の可能性がある（Lampinen ほかの警告と同じ型）。→ DESIGN を変更: 対照を「分散を揃えた無作為な方向」（学習後の表現の主成分のうち、変化の主方向と直交するものから選ぶ）にする。
5. **最も強い信号は数発学習だった。** 構造のある世界で学んだ MLP は、未見の個体を 3 文脈で学ぶと、残り 9 文脈の R² が 0.4〜0.74 まで上がった（3 本とも）。初期値からでは 0.1 未満、構造なしの世界で学んだ MLP では負のまま。「獲得した表現が、次の学習の汎化を変える」（H3-a）は、測定として識別力がある見込み。ただし P1 は除去した版との比較をしていない（PREREG の H3-a は除去との比較）。
6. 潜在の交互作用 z の読み出しは学習で 0.19 → 0.43 に上がったが、出力の転移は 0 付近だった。表現に情報があることと、評価に使われることは別（Hewitt & Liang、Geiger ほかの警告と整合）。対照課題を付けていないので、この数値は判定には使えない。
7. 測定の妥当性: 構造なしの世界では、除去の差（無作為 − 主方向）は負で、偽の「獲得」は出なかった（V1 の向き）。ただし対照の不公平（読み 4）を直した後で確かめ直す必要がある。
