## 2. 不合格のまま残したもの

### T2 (c) `fixed_teacher` の更新ベクトルの cos ≥ 0.95 — **不合格（最小 cos = 0.845）**

- **変更前（＝今の結果）**: R–K 0.845、R–X 0.982、K–X 0.912。最小 0.845 < 0.95（20 本とも同じ）。
- **原因の特定**: 実装の誤りではありません。`fixed_teacher` の更新は `W[ind] += 0.1·Δu` で、人格間の差は Δu の差だけです。
  Δu は欲求の状態 h に依存します（効用の傾き `u'(h) = exp(−h/3)`）。SPEC は「h の違いで Δu がわずかに変わる」と想定していましたが、
  docs/04 の R/K/X の履歴（同じ方向の事象が 12 回続く）を M の基本の大きさ 0.30（docs/04 の玩具と同じ）で通すと、h が大きく振れます
  （履歴の後の h は R = (3.20, 2.63, 0.49, 1.00, 0.94)、K = (0.91, 2.57, 2.68, 1.00, 0.75)）。同じ新しい経験の Δu は、
  R で (R +0.098, A −0.212)、K で (R +0.211, A −0.102) と、傾きが 2 倍以上違います。つまり判定基準の前提（h の影響は小さい）が、
  この履歴と M の大きさでは成り立ちません（判定基準の想定の誤り）。
- **診断（`tests/diagnostics_m_scale.py`）**: M の大きさ gM だけを変えると、(a) f の最大差と (c) cos が同じ h 依存から決まり、同時には余裕をもって満たせません。

  | gM | (a) f の最大差（> 0.1 が合格） | (b) cos の最小（< 0.5） | (c) fixed_teacher の cos の最小（≥ 0.95） |
  | --- | --- | --- | --- |
  | **0.30（採用）** | 0.336 | 0.032 | **0.845** |
  | 0.20 | 0.163 | 0.018 | 0.930 |
  | 0.15 | 0.100（閾値すれすれ） | 0.025 | 0.961 |
  | 0.10 | 0.052 | 0.047 | 0.982 |

  f は `tanh(ΣΔu/s_f + β m)` で、学習した価値は気分を通してしか入りません。そのため (a) の f の差は主に h の差で、(c) と同じ原因を共有します。
  (a) と (c) を同時に通す gM は 0.15〜0.20 の細い窓にしかなく、そこへ合わせるのは閾値に合わせた調整になるので、**変更しませんでした**。
- **研究思想への影響**: M の大きさを変えると「状態の経路」（同じ Δh でも、欲求の状態で効用の傾きが違う。docs/04 第3.4節）が弱まります。
  この経路は人格差を作る正当な機構の一つなので、(c) のために弱めることはしませんでした。REPORT に不合格として書いてあります。

## 3. 結果を見てから変えたテストの入力・定義（閾値は不変）

いずれも「実装（モデル）」は変えず、テストの測り方を直したものです。元の版は `expectedFailure` のテストとして残し、「既知の制約」の記録にしました。

### 3.1 T1: 「無関係な経験」の選び方

- **何を**: 無関係な経験の結果を `comfort`（安全 +）＋ `achievement` から `novelty` ＋ `achievement` に替えた。
- **なぜ**: 基礎にした人格 K は安全が不足している（h_安全 = 0.75。履歴に裏切りが 8 回ある）。安全の効用は不足側だけの凸な二乗罰
  `−½(1−h)²` なので、`comfort` で h が 0.99 に戻ると、予期される害の MB 価値が大きく動く。文脈・概念・参加者が無関係でも、
  欲求の状態を通じて評価が動いたので、その経験は「無関係」ではなかった。「無関係」を、文脈・概念・参加者を共有せず、基礎の人格で不足している欲求にも触れない、と定義し直した。
- **変更前の結果**（comfort 版、20 本平均）: 状況プローブの Q の変化は関連 0.403 に対し無関係 0.0594（比 6.8、閾値 10 に届かず）。エンティティの Q は 0.219 対 0.0398（比 5.5）。
  どの本も不合格（0/20）。like（MF）は関連 0.205 に対し無関係 0（影響なし）。
- **変更後の結果**: 状況 Q 0.403 対 0.0033（比 120.6）、エンティティ Q 0.219 対 0.0018（比 122.1）、like 0.205 対 0。20/20 本が合格。
- **研究思想への影響**: なし（モデルを変えていない）。「評価が欲求の状態に結合している」ことは設計どおりの性質で、REPORT の「既知の制約」に書いた。

### 3.2 T9: プラセボの時間をそろえるための休止期間

- **何を**: 履歴の直後ではなく、履歴の後に「何も起きない経験」を 20 件挟んでからプローブを測る。判定は、Q・like・信念 P(credit_taken) のそれぞれで、
  形成期の経験（K の 4 番目の「手柄を取られた」）を除いた場合の変化が、プラセボ（「独りで成功」を 1 つ除く）より大きいか。
  Q は 64 サンプルの MB 推定の雑音が効果と同じ大きさなので、平均で判定し、本ごとの内訳は報告だけにした（like と P は決定的なので全本でも要求）。
- **なぜ**: 履歴の直後に測ると、プラセボ（12 回続く「独りで成功」の 1 回を除く）は履歴の終わりの欲求の状態 h を 0.08 ほど動かし（自律・有能感）、MB 価値を通じて Q を動かす。
  形成期の経験を除いた変化は、h の影響が時間とともに戻る（λ_h = 0.1）ので小さい。履歴の終わりからの距離がそろっていない比較になっていた。
- **変更前の結果**（休止なし、20 本平均）: Q の変化は形成期 0.0051 に対しプラセボ 0.0093（形成期の方が大きい本は 3/20）。**不合格**。
  like（MF）は 0.0011 対 0、信念 P(credit_taken) は 0.0129 対 0（どちらも 20/20 で形成期が大きい。プラセボは人の層に触れないので 0 は自明）。
- **変更後の結果**（休止 20 件）: Q 0.0059 対 0.0015（平均で合格。本ごとには 18/20）、like 0.0011 対 0（20/20）、P 0.0129 対 0（20/20）。
- **研究思想への影響**: なし。ただし注意点が 2 つある。(1) 形成期の経験 1 つの効果は小さい（like の 1%）。類の価値は個体の数に比例して形成され、
  似た経験が複数あると、1 つを除いても残りが同じ値へ収束するため。(2) 「経験の効果が、無関係な経験より大きい」ことは確かめたが、効果量そのものは小さい。

### 3.3 T4: 持続の定義の端の場合

- **何を**: 持続（後の差 / 前の差）は、前の差が 0 のとき 0 と定義した。
- **なぜ**: `flat_value` では、未見の個体に何も引き継がれないので、P1 と P2 の未見の共同作業者への評価差が最初から 0 になる。0/0 で NaN になりテストが落ちた（テストの定義の抜け）。
  「引き継ぐ差が最初からない」なら持続は 0、と定義した。
- **変更前の結果**: 持続が NaN（判定不能）。閾値は変えていない（`flat_value` で持続 < 0.5）。
- **変更後の結果**: `flat_value` の持続 0。階層版は変わらない（m = 8: 0.870、m = 32: 0.951）。
- **注意**: `flat_value` の持続が 0 なのは、特徴に類・一般がないことから自明に出る。アブレーションの定義を確認しただけで、驚きのある結果ではない。

## 4. 仕様の解釈（変更ではない。SPEC に明記がなかった点の決め）

1. 責任 φ とスコープの事前 π の計数は、観測 y = 0 の（参加者, 型）も含めて、全ての観測に対して更新する（オンライン EM の素直な形）。
2. 結果に帰属しない参加者（その経験でその人が行為者の結果がない）の人モデルも、教師 0 で更新する。
3. `fixed_teacher`（3-F 型）: 教師は帰属 φ を使わず、参加者 e には「行為者が e の結果の寄与の和」、状況には「行為者が自分・世界の結果の寄与の和」。
   更新は `W[ind:e] += 0.1·教師`、`W[ctx:c] += 0.1·教師` のみ（予測誤差も Σ も使わない）。
4. `flat_value`: 人モデルは `ind:` のみ、状況モデルは `ctx:` と `concept:` のみ（事前分散はいずれも 0.25）。
5. 文脈の層は個体と同じ κ_e = 2、世界は一般と同じ κ_g = 4・事前 Beta(1, 4)。一般 `m_gen` は、類の生の率を重み `W_cls/(W_cls+κ_c)` で集計して事前を κ_g 分足す（README）。
6. MB の分散のうち信念の不確実性の項: 個体・類・一般・文脈・世界の Beta 事後分散の和に、`g_k²`（型 k の結果 1 回の効用変化の二乗）を掛けて足す（デルタ法）。
7. 型の大きさの移動平均: 初期値 0.6、最初の観測は `1/(n+1)` の割合で取り込み、下限 0.1。
8. MB の乱数の種: `sha256(設定の種 | 経験 id)`（プローブでは正規形の JSON）。同じ状態・同じ入力で決定的。
9. 回避（optional で接近しない）: 台帳に記録し、乱数を 1 回使うだけ。欲求の状態 h・気分 m・価値・信念は変えない。
10. エンティティのプローブに文脈がないとき、事前ヘッドの文脈入力は全文脈の埋め込みの平均。個体の類は途中で変えられない（エラー）。
11. 事前ヘッドは、リプレイ緩衝が空でなければ参加者のいない経験でも毎経験 4 ミニバッチ学習する。使うのは学習した観測が 50 件以上のとき。
12. 概念プローブの好悪 Like(x) は `world + concept:x + 埋め込み` の予測の和（文脈は含めない）。エンティティの好悪は人モデルの予測の 5 欲求の和。
13. 保存の内容ハッシュは、`state.json` の内容（正規化した JSON）と `arrays.npz` の全配列（名前・dtype・形・バイト列）の SHA-256。
14. **テストでの「評価」の定義**（実装前に決めたもの）: T4 の持続・可塑性は人モデルの好悪（like）で測る（`flat_value` の階層の効果を分離するため）。
    真値は「その時点の h で、N の結果（connection, support）に帰属する効用変化の総和」。T7・T8 は未見の個体の P(credit_taken | music_session)。
    T9 は上の 3.2。T1 は状況プローブの Q。全体の評価 Q を使った持続も参考値として REPORT に載せた（m = 32 で 0.546、閾値 0.7 を下回る。これは判定の対象外）。
