### B.3 W2 C → 行動 — **不合格**（0.133 < 0.15）

- 結果: H1（褒められた後に害）の接近率 0.475、H2（褒められた後に支え）0.608、差 **0.1325**。基準 ≥ 0.15。対照 `no_conditioning` の差 0.0275（< 0.05 で合格）。
- 内訳（診断）: 最初の申し出の p(接近) は H1 0.364 対 H2 0.642（差 0.28）。C(praise) は H1 −0.147、H2 +0.071。学習なしで 40 件を評価した p(接近) の平均は 0.372 対 0.641（差 0.270）。
  つまり **C → Q → 選択は、選ぶ時点では仕様どおり大きく効いている**（差 0.27）。40 回の閉ループでは、申し出を受けると「褒められた後に何も起きない」ので C が 0 へ戻る（消去）。最初の 20 回の差 0.175、最後の 20 回の差 0.090。平均 0.1325 になる。
  8/20 本だけが 0.15 以上。
- 原因の位置づけ: 基準が前提にしていない閉ループの消去（申し出自体が C を学習し直す）。実装の誤りではない（消去は TD の設計どおり。避けると消去が止まる = 標本の偏りによる有界な正帰還）。
  C の大きさ（α_C = 0.1、γ = 0.6）や申し出の構成を、基準に合わせて調整することはしていない。参考値: 同じ類 friend の新しい個体が褒める申し出では、差 0.549（H1 0.130、H2 0.679）だが、類への一般化も通るので対照の条件（C 以外の経路を通らない）を満たさず、判定には使わない。

## D. 仕様の解釈（変更ではない。SPEC-v3.2 に明記がなかった点の決め）

1. **Σ（1.1）**: 欲求ごとの共分散 Σ_k（形 (5, n, n)）。更新は K_k = Σ_k z/(zᵀΣ_k z + R/a_k)。a_k の下限は 1e-3。a は**この経験を受け止める直前の** a（更新前）。
   予測分散は、a で重み付けた予測 Σ_k a_k (zᵀW_k) の分散を欲求の数で割った (1/5)Σ_k a_k² zᵀΣ_k z とした（a = 1 かつ Σ が共通なら v3.1 の zᵀΣz と一致。調停の ω の尺度を v3.1 と合わせるため）。
   計算量は問題にならなかった（特徴数の上限・対角近似は導入していない）。
2. **Q（1.2）**: Q = U_val + λ_CQ ΣC(手がかり)。手がかり = 概念、参加者の個体と類、`announced` の型（`concept:`、`ind:`、`cls:`、`type:`）。選択の前に分かるものだけ。
   `announced` は経験とプローブに加えた任意のキー（申し出に前もって付いている結果の型のリスト）。実際の結果は outcomes に書く。f の参照点項と驚き δ は、C を含む Q を使う（予期に C が入るので、C が f に二重に効く分は δ で相殺される）。
   `no_conditioning` では C が学習されないので C_Q = 0。プローブの `Q`（C_Q を含む）、`Q_val`、`C_Q`、`Q_person` を返す。エンティティプローブの Q にも ind・cls の C を加えた。
3. **habituate（1.3）の式**: 感作の目標 `clip(|Δu_k| / run, 0, 5)` に対し、慣れは **`clip(run / max(|Δu_k|, run / 5), 0, 5)`**（= `clip(1 / max(|Δu_k|/run, 0.2), 0, 5)`、run = mean|Δu| の移動平均）。
   大きく揺さぶられた欲求ほど重みが下がり、揺さぶられない欲求は最大 5。床 run/5 は感作の上限 5 と対称（|Δu_k| = 0 でも 5 を超えない）。a は更新後に和 5 へ正規化。どちらの方向が人に近いかは主張しない。
4. **mixture（1.4）**: ヘッド = mlp、linear、knn1、none（一般の率 m_gen）。前向きの対数尤度 = その経験の参加者の観測（観測されたセル = マスク 1 の型）について、ヘッド h を類の事前に使った人の予測確率 p_person の Σ_k [y log p + (1 − y) log(1 − p)]（参加者が複数なら平均）。
   更新の**前**の状態（計数・ヘッドの学習前）で計算し、移動平均（速さ max(1/(n+1), 0.05)、初期値 0）に入れる。重み = softmax(移動平均 / 1)。観測が 0 件のときは m_gen（どのヘッドにも実績がない）。
   mixture では ρ_h = n/(n+30) の縮約は使わない（ヘッドの未熟さは予測性能の悪さとして重みに表れる）。単一ヘッドの種類は v3.1 のまま（基線）。MLP と線形は同じミニバッチで同時に学習する（乱数の消費は単一 mlp と同じ）。
5. **ランダムな世界（1.5）**: 場面（独り・協働・学び）ごとに起こりうる結果の型を固定し（独り 6 型、協働 11 型、学び 6 型）、各（場面, 型）の確率を種ごとに Beta(1, 3) から引く。大きさは U(0.4, 1.0)。場面の配分は固定（0.30 / 0.50 / 0.20）。
   協働の相手は 70% が新しい個体（generate_history と同じ）。
6. **W の測り方の細部**（実装前に各テストファイルの冒頭に書いた）: W1 は P = R 型、Q = K 型、同じ 20 経験はランダムな世界から（協働の約 4 分の 1 が申し出）。W2 の申し出は参加者なし・studio・music・結果は praise だけ。
   W3 は 3 型 × 種 0〜59 の 180 人格（型の内 60 組・型の間 60 組）。W4 は n = 60、申し出なし、40 世界、相関はピアソン。W5 の偶然水準は、順位の並びを種の間で 10000 回並べ替えたときの一致率の平均。

## D. 仕様の解釈（変更ではない。SPEC-v3.1 に明記がなかった点の決め）

1. **a（1.1）**: `mean(|Δu|_run)` は、全欲求の `|Δu|` の平均を、速さ max(1/(n+1), 0.05) の移動平均にしたスカラー。目標 `|Δu|/mean` は [0, 5] に切る。効用変化が全欲求で 0 の経験（何も起きない）では更新しない。`r = Σ_k a_k Δu_k` の a は、その事象で使った（更新前の）a。
2. **C（1.2）**: 手がかりは `concept:<x>`、`ind:<id>`、`cls:<c>`、`type:<結果型>`（曖昧な結果は候補の型すべて）。重みはスカラー（欲求ごとではない）。最初の事象は更新しない（直前がない）。
   session が同じ（どちらも未指定でも同じ）なら連続、違えば直前の事象の手がかりを目標 0 で更新して連鎖を切る。回避した申し出は TD の連鎖を動かさない。最後の事象の手がかりは、次の事象が来るまで更新されない（`pending` として保存）。
3. **f（1.3）**: Q は a で重み付けた調停後の予期。δ = f − tanh(Q/s_f)（v3.0 のまま）。気分は δ から更新。
4. **解釈（1.4）**: `P_belief(I | actor, context)` は、行為者が参加者なら人の予測確率 `p_person[e, I]`、自分・世界なら `p_sw[I]`。曖昧な結果の帰属 φ は `Σ_I w_I φ(y_I = 1)`。型の大きさの移動平均は曖昧な結果では更新しない。
   `interpretation_counts` のときの計数は、重み w_I を y として入れる（φ の尤度は y > 0.5 の硬い閾値）。
5. **ヘッド（1.5）**: n_head は学習した参加者の観測数。`linear` は MLP と同じ入力・学習率・リプレイ・損失（隠れ層なし）。`knn1` は、既知の類（個体がいる類）のうち埋め込みの二乗距離が最小の類（自分自身を含む）の生の率 `ΣwR/Σw`。`no_head` は `head_kind = "none"` の別名。

   保存ファイルに lexicon の中身は入れない。`NPN.load(dir, lexicon=...)` は、これから初めて現れる語の供給源を替える。
7. **κ_e の推定（1.7）**: 改訂前は 1 つの類に型をまたいで 1 つの κ_e（G 節で（類 × 結果型）ごとに改訂）。正の計数が 1 つもない型は除く（その型は個体差の情報がほぼない）。類の率は、プール（事前 Beta(1,4) つき）。対数一様事前は格子上で一様。事後平均を κ_e とする。
   計数が更新された類のキャッシュを捨てる（関数の記憶であり状態ではない）。`math.lgamma` の代わりに、ベクトル化した lgamma（漸化式＋スターリング級数、math.lgamma と 3e-10 以内）を使った。文脈の層の κ_e は 2 のまま。
8. **生成器（1.8）**: 世界の真の確率表は `data/make_histories.py` の `WORLD`。協働の相手は 70% が新しい個体、場面は music_session 0.5 / project_meeting 0.25 / studio 0.25。履歴は 36 件で、連続する 2〜4 件が 1 つの session。協働の 20% が optional の申し出。

9. **保存**: スキーマ版を 2 に上げた（a、C、pending、所有する埋め込み、効果表、warnings が状態に入る）。v3.0 の保存は読み込めない（版違いの例外）。

## G. 設計の改訂 1（オーケストレーター承認。根拠 Kemp, Perfors & Tenenbaum 2007）: κ_e を（類 × 結果型）ごとに推定

- **何を**: κ_e を、類ごとに 1 つから、（類 × 結果型）ごとに推定するように改めた。`belief.estimate_kappa_by_type`。
  - 類全体の κ_c: 従来どおり、全型をまとめた周辺尤度（格子 0.3〜50 の対数 12 点、一様事前）の事後平均。
  - 型 k の κ_k: log κ の事後 ∝ 型 k だけの Beta–Binomial 周辺尤度 × N(log κ_c, σ²)。格子上で正規化し、κ の事後平均を取る。**σ = 1.0**（`kappa_prior_sigma`。結果を見る前に決めた値）。
    データの少ない型は、事前（類全体の値）に縮約される。個体間で大きくばらつく型は小さく、誰でも同じ型は大きくなる。
  - 正の計数が 1 つもない型は κ_c。個体が 2 人未満の類は、これまでどおり固定の κ_e = 2。文脈の層（κ_e = 2、κ_g = 4）、κ_c（= 4、類の事前の強さ）は変えていない。スコープ帰属 φ も変えていない。
  - `kappa_per_type=False` で改訂前の挙動（類ごとに 1 つ）を再現できる。個体の率の重み `w_i = n_i/(n_i + κ_k)`、個体の事後 `p_ind = (κ_k m_cls + n1)/(κ_k + n)` は、型 k ごとの κ_k を使う。
- **なぜ**: 改訂前の診断で、U8 の持続が低い主因は κ_e が全結果型で 1 つであること（誰でも同じ型 connection などに引かれて κ が大きくなり、人で大きく違う型 credit_taken でも 1 回ずつの観測の重みが小さくなる）と考えた。
  ばらつきは特徴ごとに学ばれる（Kemp et al. 2007 の階層の超仮説。「袋の中のビー玉は色については均質だが大きさについては不均質」）ので、これは基準に合わせた調整でなく、単一の κ という設計の欠陥の修正として承認された。
- **変更前の結果**: U8 の持続 0.564（m = 8）、0.352（m = 32）。
- **変更後の結果**: U8 の持続 **0.559、0.347**。**ほぼ動かず、不合格のまま**（B 節）。仮説（単一の κ が主因）は支持されなかった。
- **研究思想への影響**: なし。教師は外生の Δu のままで、価値ネット自身の出力は目標に入らない。変わるのは信念の階層の重み（どの型が個体間で似ているかを経験から学ぶ）だけで、全人格は同じ初期状態・同じ係数（σ = 1.0 を含む）。

## G'. 設計の改訂 2（オーケストレーター承認）: 想起・再帰属（docs/04 第 5 節 手順 7）

- **何を**: 責任 φ を経験の時点で凍結するのをやめ、信念ネットが保持する観測の記録について、K_r = 10 経験ごとに帰属をやり直す。`belief.BeliefNet.reattribute`。
  - **記録**: 参加者が行為者の観測を、参加者ごとに 1 件、個体・文脈・型ごとの y・マスク（曖昧な型は 0）・当時割り当てた φ として保持する（`rec_*`。保存・復元の対象）。
  - **掃引**（`reattribute_every = 10` 経験ごとに、全記録について 1 回）: 各観測の現在の寄与（人 φ、文脈 1 − φ、π）を、**自分の単位の計数と π からだけ**引く（retract、leave-one-out）。
    その状態の信念（個体の率 = 掃引の開始時点の類の水準 + 自分を除いた個体の計数、文脈の率、π）で φ を計算し直し、足し直す（reassign）。オンライン EM の 1 ステップ。
    掃引の中の更新は同時で（全観測の φ を同じ開始時点の計数から求める）、類・世界の水準は掃引の間は固定。最後に計数と π を記録から作り直す（浮動小数点の誤差を残さない）。
  - **不変量**: 1 観測の寄与の和は常に 1（人 φ + 文脈 1 − φ）。計数の総和と π の総和は掃引で変わらない（テストで確認）。曖昧な結果の型は記録のマスクが 0 で、掃引でも計数されない。
  - **非対称**: 価値ネット側の分割（人モデル・状況モデルの教師）は再帰属しない。教師は経験の時点の φ で分けたまま凍結され、台帳にもその φ が残る（カルマンの更新の再生は今回の範囲外）。信念の側だけが後から訂正される。
  - アブレーション `no_reattribution`（記録も掃引もしない）。台帳には掃引ごとに `kind: "recall"` の要約（記録数、φ の変化の平均・最大、π の範囲）が入る。保存のスキーマ版を 3 に上げた。
- **なぜ**: U8 の診断（B 節、`diagnostics_u8_scope.py`）で、主因は責任 φ が経験の時点で凍結されていることだと分かった。帰属理論（Kelley の共変モデル）では、同じ場面で別の人が手柄を取らなければ「場面のせい」という説明は弱まり、過去の搾取は人（共同作業者の類）のせいへ帰属し直される。
  docs/04 第 5 節の手順 7（想起: 旧寄与を台帳から引き、今の信念で帰属をやり直して足す）で設計していながら未実装だった部品で、研究思想の「後からの訂正や再解釈」にも当たる。基準に合わせた調整ではなく、欠けていた部品の実装として承認された。
- **変更前の結果**: U8 の持続 0.559（m = 8）、0.347（m = 32）。**変更後**: **0.567、0.411**（不合格のまま。B 節に原因を書いた）。信念レベルでは狙いどおりに動いた: P(credit_taken) の差の持続（m = 32）は music_session で 0.54 → 0.71、cafe_chat で 0.60 → 0.91。搾取の記録の人への帰属は平均 +0.26 増える。
- **研究思想への影響**: なし。再帰属の目標は観測 y と信念自身の率で、価値ネットの出力は入らない。価値の教師は外生の Δu のまま。1 回の観測を二重に数えない（leave-one-out、寄与の総和は 1）。全人格は同じ初期状態・同じ係数（K_r = 10）。

### G'.1 自己増幅の検査

- **想起を繰り返しても π が 0/1 に張り付かないか**（`tests/test_recall.py`）: 通常の履歴（R・K・X 型 × 8 本、36 件）で、新しいデータなしに掃引を 400 回繰り返した。π_person は全型・全軌跡で **0.095〜0.736** に収まり、最後の掃引での変化は最大 3.3e-16（固定点へ収束。振動・暴走なし）。
- **張り付く条件**（1 つの型 credit_taken の π_person。600 回掃引した後。履歴は 30 件 / 100 件）: 単一の説明に偏る長い履歴では、固定点が 0/1 に近づく。
  - 同じ相手 × 同じ場面: 0.94 / 0.98（人へ）。同じ相手 × 場面を替える: 0.96 / 0.99（人へ）。

  Δu は欲求の状態 h に依存します（効用の傾き `u'(h) = exp(−h/3)`）。SPEC は「h の違いで Δu がわずかに変わる」と想定していましたが、

## 4. 仕様の解釈（変更ではない。SPEC に明記がなかった点の決め）

1. 責任 φ とスコープの事前 π の計数は、観測 y = 0 の（参加者, 型）も含めて、全ての観測に対して更新する（オンライン EM の素直な形）。
2. 結果に帰属しない参加者（その経験でその人が行為者の結果がない）の人モデルも、教師 0 で更新する。
3. `fixed_teacher`（3-F 型）: 教師は帰属 φ を使わず、参加者 e には「行為者が e の結果の寄与の和」、状況には「行為者が自分・世界の結果の寄与の和」。
   更新は `W[ind:e] += 0.1·教師`、`W[ctx:c] += 0.1·教師` のみ（予測誤差も Σ も使わない）。
4. `flat_value`: 人モデルは `ind:` のみ、状況モデルは `ctx:` と `concept:` のみ（事前分散はいずれも 0.25）。
5. 文脈の層は個体と同じ κ_e = 2、世界は一般と同じ κ_g = 4・事前 Beta(1, 4)。一般 `m_gen` は、類の生の率を重み `W_cls/(W_cls+κ_c)` で集計して事前を κ_g 分足す（README）。
6. MB の分散のうち信念の不確実性の項: 個体・類・一般・文脈・世界の Beta 事後分散の和に、`g_k²`（型 k の結果 1 回の効用変化の二乗）を掛けて足す（デルタ法）。
7. 型の大きさの移動平均: 初期値 0.6、最初の観測は `1/(n+1)` の割合で取り込み、下限 0.1。
8. MB の乱数の種: `sha256(設定の種 | 経験 id)`（プローブでは正規形の JSON）。同じ状態・同じ入力で決定的。
9. 回避（optional で接近しない）: 台帳に記録し、乱数を 1 回使うだけ。欲求の状態 h・気分 m・価値・信念は変えない。
10. エンティティのプローブに文脈がないとき、事前ヘッドの文脈入力は全文脈の埋め込みの平均。個体の類は途中で変えられない（エラー）。
11. 事前ヘッドは、リプレイ緩衝が空でなければ参加者のいない経験でも毎経験 4 ミニバッチ学習する。使うのは学習した観測が 50 件以上のとき。
12. 概念プローブの好悪 Like(x) は `world + concept:x + 埋め込み` の予測の和（文脈は含めない）。エンティティの好悪は人モデルの予測の 5 欲求の和。
13. 保存の内容ハッシュは、`state.json` の内容（正規化した JSON）と `arrays.npz` の全配列（名前・dtype・形・バイト列）の SHA-256。
14. **テストでの「評価」の定義**（実装前に決めたもの）: T4 の持続・可塑性は人モデルの好悪（like）で測る（`flat_value` の階層の効果を分離するため）。
    真値は「その時点の h で、N の結果（connection, support）に帰属する効用変化の総和」。T7・T8 は未見の個体の P(credit_taken | music_session)。
    T9 は上の 3.2。T1 は状況プローブの Q。全体の評価 Q を使った持続も参考値として REPORT に載せた（m = 32 で 0.546、閾値 0.7 を下回る。これは判定の対象外）。
