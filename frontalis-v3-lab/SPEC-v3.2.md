# frontalis-v3-lab 実装仕様 v3.2（v3.1 への差分）

v3.1 への理念優先の再批評（`reviews/critique-v3.1.md`）の判定は「限定つきで可」でした。期待・解釈・選択の軸では循環が動きますが、**評価基準（関心の重み a、条件づけ価値 C）が次の学習を変える経路がない**ため、研究思想 §6 の中心仮説「学習の方向は、その経験を受け止める直前の評価状態によって変化する」が、評価基準の軸では成り立っていません。v3.2 はこれを閉じます。判定基準（第3節）は実装前に固定します。

## 1. 設計の変更

### 1.1 関心の重み a が学習の精度を変える（評価基準 → 学習）
- 価値ネットのカルマン更新で、欲求 k の観測雑音を `R_k = R / a_k` にする（a の和は 5 のまま）。大事な欲求ほど精度高く・速く学び、どうでもよい欲求の変化はあまり学ばない（注意の配分）。
- 欲求ごとに利得が変わるため、Σ は欲求ごとに持つ（5 つ）。計算量が問題なら、特徴数の上限や対角近似を CHANGELOG に記録して導入してよい。
- ループの確認: a の目標は |Δu|（外生）で、W に依存しない。a → W の一方向だけで、W → a はない。

### 1.2 条件づけ価値 C が予期と選択に入る（評価基準 → 行動 → 経験）
- 予期 `Q(s) = U_val(s) + λ_CQ · Σ_{x∈手がかり(s)} C(x)`、λ_CQ = 1.0。接近・回避はこの Q で決まる。
- 意味: 「褒められた後に害を受けた」人生では、褒め言葉を伴う申し出を避けるようになる。
- ループの確認: C → Q → 選択 → 経験 → C。標本の偏りによる有界な正帰還（熱いストーブ）で、v3.1 の U5・U6 と同じ検査の対象にする。

### 1.3 関心の重みの方向は実験条件にする
- `concern_direction ∈ {"sensitize", "habituate"}`（既定 sensitize）。habituate は、大きく揺さぶられた欲求ほど重みが下がる（`a` の目標を `mean/|Δu|` 側にとる。式は CHANGELOG に記録）。
- 主張は「a が経験から形成され、受け止め方と学習を変える」ことまでに限る。どちらの方向が人に近いかは主張しない。

### 1.4 事前ヘッドの重みは予測性能で決める
- ヘッドの種類（mlp、linear、knn1、none = 一般の率）ごとに、新しい観測を見る前の予測の対数尤度を移動平均で記録する（前向き評価）。
- 類の事前は、各ヘッドの予測を、移動平均した対数尤度の softmax（温度 1）で重み付けて混ぜる。これはベイズのモデル平均の簡約である。
- 意味: NN は、実際に予測が良い場合にだけ寄与する（研究思想 §10「NN が必ず優れている前提にしない」）。

### 1.5 世界の確率表をランダムにした検査を追加する
- 経験史の生成器に「ランダムな世界」を追加する。人格の型を手で書かず、種ごとに各結果型の確率を Beta(1, 3) から引く。
