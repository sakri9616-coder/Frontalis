## 1. NN の再検証（X 系）

### 1.1 問題
v3.2 では、最近傍（knn1）が自分の類のデータを含んでいました（既知類の自己参照）。そのため、類の事前に自分のデータを二重に使い、混合の重みでも有利になっていました。T8 の転移は、設計者が置いた埋め込みの類似度（バンド仲間 ≈ 共同作業者）に依存していました。

### 1.2 設計の修正
- **類を除いた事前（leave-class-out）。** 類 c の事前平均を出すヘッドは、c 自身のデータを除いて学習・計算したものに限ります。knn1 は c を除いた最近傍です。linear と mlp は、c を除いたデータで再学習したモデルを使います。再学習は想起と同じ 10 経験ごとで構いません（類は高々数十なので計算は軽い）。未見の類には、全データのモデルを使います。
- **混合の重みは転移性能で決める。** 各ヘッドの重みは、類を除いたモデルで、その類の観測を予測した対数尤度（類単位の交差検証）の移動平均で決めます。

### 1.3 合成ベンチマーク（`benchmarks/nn_transfer.py`。人格の実行とは独立）
- 類 32 個（学習 24、未見 8）。埋め込みは 8 次元の正規乱数を正規化したもの。結果型は 4 つ。
- 学習類ごとの観測数は n ∈ {5, 20}。
- 真の率の 4 つの世界:
  - (a) 線形: logit = W e
  - (b) 非線形: logit = 積の項と正弦の和（例 2·e1·e2 + 1.5·sin(3·e3)）
  - (c) 群: 類が 4 つの群に分かれ、群ごとに率が決まり、群内の埋め込みは近い
  - (d) 無関係: 率は埋め込みと無関係
- 評価は、未見の類 8 個について、真の率に対する交差エントロピー（期待対数損失）の平均です。乱数種 20 本で、ヘッドを対にして比較します。
- 比較するヘッド: mlp（隠れ層 16）、linear（ロジスティック）、knn1、knnk（k=3、距離重み）、none（全体平均）。

## 2. 価値の再帰属：事実の訂正と、当時の主観的経験を分ける（Y 系）

### 2.1 原則
- 信念（事実）は訂正されます。
- 当時の受け止め方（感じた価値 f、帰属 φ、感情の記録）は、当時のまま保存します（§5）。
- 価値（W、C）は、信念の訂正によって**自動では消去しません**（§7）。訂正は「新しい経験」として評価され、その評価が新しい学習になります。確信の高い古い嫌悪は、訂正を知っても一部残ります。これは信念の固執（belief perseverance）や、訂正後も誤情報の影響が残る現象と同じ形です。文献の照合は後で行います。

### 2.2 入力
訂正の経験は次の形で与えます。

```json
{"id": "c001", "kind": "correction", "refers_to": "e0012",
 "corrected_outcomes": [ {"type": "credit_taken", "actor": "organizer", "magnitude": 0.8} ],
 "source": "self_discovery"}
```

### 2.3 処理
1. **信念:** refers_to の経験から記録した観測（参加者・型・φ）を取り消し、訂正後の観測を加えます。台帳に correction を記録します。以後の解釈と予測は、訂正後の信念を使います。
2. **当時の記録:** 当時の f、φ、Δu、感情は台帳に残し、変更しません。
3. **価値（再評価）:** 参加者 e ごとに、寄与の差 Δ_e = contrib_訂正後(e) − contrib_当時(e)（欲求ベクトル）を計算します。人モデルの e の特徴について、「現在の予測 + Δ_e」を観測とするカルマン更新を、観測雑音 R_corr = R / w_reapp で 1 回行います。w_reapp = 0.5（再評価の強さ。全人格共通）です。
   - 確信の高い（分散の小さい）古い価値ほど、動きにくくなります。
   - 条件づけ価値 C と関心の重み a は変えません（感情的な痕跡は、新しい随伴でしか変わらない）。
4. 訂正の経験そのものの感じた価値（安堵、罪悪感などの手がかり）を読み出し、台帳に記録します。
5. アブレーション:
   - `retroactive_value`: 価値の更新を、訂正後の事実で最初から再生します（自動消去の対照）。
   - `no_reappraisal`: 価値を一切変えません。

### 2.4 判定基準

| ID | 内容 | 合格条件 | 個性か故障か |
| --- | --- | --- | --- |
| Y1 事実の訂正 | 誤帰属の履歴（A が手柄を取ったと受け止めた経験 8 回）の後に、それぞれの訂正を与える | A の P(credit_taken) が、最初から誤帰属のなかった対照の値まで 80% 以上近づく | 訂正されないなら故障 |
| Y2 自動消去しない | 訂正の直後の、A への価値の対照との差 | 訂正前の差の 30% 以上、90% 以下が残る | 残ること自体は個性。100% 残る（無視）・0%（自動消去）は故障側 |
| Y3 再学習できる | 訂正の後、A と良い経験を 10 回 | 残った差が、訂正直後の 30% 以下になる | 下がらないならロックイン（故障） |
| Y4 対照 | `retroactive_value` では、訂正直後に差の 90% 以上が消える | 満たす（違いが機構から来ることの確認） | – |

## 3. 選択による関心学習：正当化と、経験に根拠のある価値を分ける（Z 系）

### 3.1 原則
- 選択の正当化（選んだものを好きになる、選ばなかったものを嫌う）は、経験に根拠のある価値（W、C、a）とは**別のチャンネル J** に置きます。J は経験の教師になりません。
- J は迷った選択でだけ生じ、有界で、経験の裏付けがなければ減衰し、反する経験に負けます。**無条件の正帰還を作りません。**
- 関心の重み a は、自分で選んだ経験から少し多く学びます（主体性の重み）。ただし目標は経験した |Δu| のままです。効用の変化がない選択では、a は増えません。

### 3.2 入力
二択の経験です。

```json
{"id": "ch01", "kind": "choice", "options": [ {状況1}, {状況2} ], "outcomes_by_option": {"0": [...], "1": [...]}}
```

NPN は softmax(β_c · Q) で選びます。選んだ側の結果だけを観測して学びます。

### 3.3 正当化 J
- 葛藤の強さ c = exp(−(ΔQ / σ_c)²)。ΔQ は選ぶ前の Q の差で、σ_c = 0.1。
- 選んだ選択肢の手がかり（概念・類・文脈）の J を +η_J·c、選ばなかった側の J を −η_J·c だけ動かします。η_J = 0.05。その後、`J ← J_max · tanh(J / J_max)` で有界にします（J_max = 0.2）。
- 毎経験の減衰: `J ← (1 − λ_J) J`、λ_J = 0.02。
- 予期への入り方: Q に + Σ J(手がかり) を加えます。J が選択肢を引き離すほど ΔQ が大きくなり、c が小さくなるので、J の更新は自分で弱まります（自己制限的）。
- アブレーション `no_justification`。

### 3.4 主体性の重み
- a の更新の速さを `η_a · (1 + κ_ag · chosen)` にします。κ_ag = 1.0。chosen は、自分で選んだ経験（optional を受けた、または二択で選んだ）なら 1 です。目標は |Δu| のままです。

### 3.5 判定基準

| ID | 内容 | 合格条件 | 個性か故障か |
| --- | --- | --- | --- |
| Z1 迷った選択でだけ生じる | 易しい選択（\|ΔQ\| > 0.3）と、迷う選択（\|ΔQ\| < 0.05）をそれぞれ 20 回 | 易しい選択での J の総変化 < 0.01。迷う選択での選んだ側と選ばなかった側の J の差 ≥ 0.02 | – |
| Z2 有界・正帰還なし | 同じ迷う二択を 1000 回 | max\|J\| ≤ J_max。1e-3 の摂動の比 ≤ 1。後半 500 回の J の増分が前半の 10% 以下 | 発散したら故障 |
| Z3 根拠のない正当化は薄れる | J を作った後、その選択肢が現れない経験を 100 回 | J の残存 ≤ 20%。同じ期間の経験に根拠のある W の残存 ≥ 70% | – |
| Z4 経験が正当化に勝つ | J で好むようになった選択肢に、反する結果（害）を与える | 5 回以内に選好が反転する | 反転しないなら故障 |
| Z5 主体性の重み | 同じ \|Δu\| の経験を「選んだ」場合と「強制された」場合 | a の変化の比が 1.5 以上 | – |
| Z6 自己強化なし | 効用の変化がない（Δu = 0）選択を 100 回 | a の変化 < 1e-6 | 増えたら故障 |
| Z7 J は経験の教師にならない | 同じ経験列を強制で与え、J だけを入れ替える | W と C の学習がビット単位で同一 | – |

## 4. 消去の検証：嫌悪の維持・消去・再学習・再発（E 系）

### 4.1 原則
消去は忘却ではなく、新しい学習です（Bouton 2004）。消去の後に、文脈の変化（復元）、時間の経過（自発的回復）、無信号の嫌悪刺激（復位）、再獲得の速さ（節約）として、元の嫌悪が戻ることがあります。これらは個性や病理ではなく、学習の一般的な性質です。一方で、同じ文脈で十分な消去試行があっても嫌悪が全く下がらないのは、故障です。

### 4.2 設計: 潜在原因による条件づけ価値（Gershman, Blei & Niv 2010 の簡約）
- 手がかり x ごとに、最大 K = 5 個の潜在原因 k を持ちます。各原因は、価値 C_{x,k}、文脈の計数 n_{x,k}(文脈)、最後に使われた時刻 t_k を持ちます。
- 原因の事前: `p(k) ∝ N_k · Dir 予測(文脈 | n_{x,k}) · exp(−(t − t_k)/τ)`。新しい原因は `∝ α`（α = 0.5、τ = 30 経験）。
- 結果を見た後の事後: 事前 × N(r_target; C_{x,k}, σ_r²)、σ_r = 0.15。
- 学習: TD の誤差で、事後の重みに比例して各 C_{x,k} を更新します。新しい原因の事後が最大なら、その原因を作ります（K に達したら、最も古く小さい原因を再利用）。
- 応答（Q と f に入る C(x)）: 事前の重みでの期待値 Σ_k p(k) C_{x,k}。
- 復位: 手がかりなしで嫌悪の結果（害など）が起きたとき、負の価値を持つ原因の t_k を現在に更新します。
- アブレーション `single_cause`（K = 1。v3.2 の条件づけと同じ）。

### 4.3 プロトコル（`tests/test_e_extinction.py`。人格は同じ初期状態から、乱数種 20 本）
- 獲得: 文脈 A で、手がかり（例 `praise_from_X`）の後に害、を 12 回。
- 消去: 文脈 B で、手がかりの後に何も起きない、を 20 回。
- テスト: 学習しない評価（probe）で C(x) を測ります。各テストは、消去の直後の状態の写しから分岐させます。

### 4.4 判定基準（獲得直後の |C| を 1 とした比で測る）

| ID | 内容 | 合格条件 | 個性か故障か |
| --- | --- | --- | --- |

| E2 消去 | 文脈 B での消去 20 回の後、B でテスト | ≤ 0.3。`single_cause` も ≤ 0.3 | 下がらないなら故障 |
| E3 復元 ABA | 消去の後、A でテスト | ≥ 0.5。`single_cause` では ≤ 0.3 | 個性ではなく一般的な性質 |
| E4 復元 ABC | 消去の後、未見の文脈 C でテスト | ≥ 0.4。`single_cause` では ≤ 0.3 | 同上 |

## 6. 追加: 消去の改訂と、復活の機構の追跡（第1部の結果を見た後に追加）

### 6.1 経緯
第1部の実装では、SPEC 4.2 の式のままでは E3〜E6・E9 が成立しませんでした。原因は二つです。時間の重みが最後の使用時刻の指数関数なので、原因どうしの比が時間で変わりません。また、柔らかい事後で古い原因まで更新していました。オーケストレーターは、文献の元のモデルに沿った改訂を承認しました（距離依存の CRP の冪乗則の時間の重み、Gershman, Blei & Niv 2010。後から学んだ情報の文脈依存性、Bouton 2004。局所 MAP の学習、Anderson 1991。復位は嫌悪の結果の原因推論）。値は d = 1.0、α = 0.5、β_first = 5.0、β_later = 0.2 で、結果を見る前に固定しました。E1〜E9 の閾値は変えません。

### 6.2 割当の記録（ユーザーの要求）
数値が合格しても、機構として復活したのか、係数で嫌悪を強めただけなのかを区別できなければ意味がありません。そこで、手がかりの経験ごとに次を台帳に残します。

- 時刻、文脈
- 事前とその内訳（時間・文脈・新しい原因）
- 事後
- MAP で選ばれた原因（新しく作ったかどうかを含む）
- 学習前後の C_k

復位では、推論した原因を残します。学習しない評価では、応答の内訳（各原因の重み・価値・寄与と、重みの要因）を返します。

### 6.3 機構の判定基準（固定）
応答の変化を、消去の直後からテスト時点まで、Δresp = Σ_k Δp_k·C_k（重み付けの移り変わり）+ Σ_k p_k·ΔC_k（価値の変化）に分けます。

| ID | 内容 | 合格条件 |
| --- | --- | --- |
| M1 | 復活の主因が、原因の重み付けの移り変わりである | E3・E4・E5・E6 のうち合格したもので、重み付けの項が Δresp の 80% 以上 |
| M2 | 係数で嫌悪を強めていない | 全プロトコルで、テスト時点の \|C_獲得\| ≤ 獲得直後の \|C_獲得\| + 0.02 |
| M3 | 予想した要因が主に担う | E3・E4 は文脈の項、E5 は時間の項、E6 は復位で加わった試行が、獲得の原因の事前の対数比の変化の 50% 以上 |
| M4 | 消去が獲得の記憶を壊さない | 消去 20 試行で、獲得の原因が MAP に選ばれた試行が 5 以下。かつ、消去中の獲得の原因の \|ΔC\| の和 ≤ 0.05 |
| M5 | 割当の記録の再現性 | 決定的で、保存・復元で完全一致する |

E3〜E6 自体が不合格なら、M1・M3 は報告のみにします。そのうえで、割当の記録から「なぜ戻らなかったか」を説明します。

## 7. 判定の考え方の修正（ユーザーの指示。Z 系と新しい B 系の結果を見る前）

### 7.1 原則
- 微小な摂動の収縮性（W6 の比）は、数学的な安定性の指標です。人格形成の健全性そのものではありません。選択の分岐が起きた結果として比が大きくなっても、それだけでは故障と断定しません。
- 人格は、合理的な判断の積み重ねだけでなく、不合理な判断も含めた経験の積み重ねで形成されます。選択の正当化が持続し、不合理に増幅し、人格の一部になっても、それだけでは故障とみなしません。
- 故障とみなすのは、次の三つが破れた場合です。
  - 状態が有界でない。
  - 学習規則が自分の定義どおりに動いていない。
  - 分岐や変化の原因を記録から説明できない。
- 元の W6 の判定と結果は、そのまま記録に残します。

### 7.2 新しい判定基準（B 系。全機構を有効にして、W6 と同じ 2000 経験・乱数種 20 本）

| ID | 内容 | 合格条件 |
| --- | --- | --- |
| B1 分岐の因果的説明可能性 | 摂動を入れた実行と元の実行の最終状態が離れた場合（比 > 1）に、最初の分岐点を記録から特定する。分岐点は、選択や原因の割当などの離散的な決定が最初に異なった経験。(a) 分岐点より前の比を測る。(b) 分岐点以降の離散的な決定を元の実行に合わせて強制し、再生する | 比が 1 を超えた実行の 95% 以上で、(a) 分岐点より前の比 ≤ 1 + 1e-6、かつ (b) 強制再生の最終の比 ≤ 1。つまり、離れた分はすべて記録された分岐で説明される |
| B2 状態の有界性 | 全ての状態変数を全経験で監視する | 有限で、宣言した範囲内に収まる。宣言: \|W\| ≤ 10、\|C\| ≤ 2、0 ≤ a ≤ 5、\|J\| ≤ J_max、計数 ≥ 0、原因数 ≤ K、Σ は対称で半正定値 |
| B3 学習規則の整合性 | 各更新が自分の規則どおりかを、動的に検査する | 次の全てを満たす。台帳の和が状態に一致する（W、C、J）。φ の和が 1。W の教師が Δu を φ で分けたものに等しい。a の目標が \|Δu\| に等しい。J は二択の経験と減衰でしか変わらない。価値ネット自身の出力が、どの教師にも入らない |

### 7.4 既定の消去設計についての注記
既定を spec_literal に戻す判断の理由は、E1（嫌悪の維持。事前に「故障」と定めた基準）の不合格と、条件づけが行動に効かなくなったことです。W6 の比は、この判断の理由にしません。
