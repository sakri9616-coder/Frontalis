# frontalis-v3-lab 実装仕様（最小実装 v3.0）

設計の根拠は `docs/04-learning-mechanisms.md`（v3 精度配分・階層型フレーム）です。この仕様は、それを動く最小実装にするための取り決めです。**判定基準（第8節）は実装前に固定します。** 結果を見てから基準・パラメータ・設計を変えた場合は、`CHANGELOG.md` に「何を・なぜ・変更前の結果」を必ず記録します。

## 0. 原則（研究思想から）

- 人格の正本は NPN の状態です。LLM は意味抽出と言語化だけを担い、数値や感情の判断を出しません。この実装では、LLM の抽出結果に当たる**構造化された経験 JSON** を入力にします。
- 価値ネットの更新目標に、価値ネット自身の出力を入れません（docs/04 補題1）。
- 結果の予測（信念）と、結果の評価（価値）を別のパラメータと別の誤差で学びます。
- 人格の差は、ラベルや初期値ではなく、経験史から生じなければなりません。全人格は同じ初期状態・同じ係数から始めます。
- numpy のみを使い、Python 3.12 以上で動くこと。乱数は全て `numpy.random.Generator` を状態に持ち、保存・復元の対象にします。

## 2. 経験の入力形式（LLM 抽出の出力に相当）

```json
{
  "id": "e0001",
  "context": "music_session",
  "concepts": ["music", "collaboration"],
  "participants": [{"id": "friendA", "class": "collaborator"}],
  "outcomes": [
    {"type": "connection", "actor": "friendA", "magnitude": 1.0},
    {"type": "achievement", "actor": "self", "magnitude": 0.8},
    {"type": "credit_taken", "actor": "friendA", "magnitude": 0.8},
    {"type": "taught", "actor": "friendA", "magnitude": 0.6}
  ],
  "optional": false
}
```

- `actor` は `"self"`、`"world"`、または参加者の id。
- `type` は `innate.OUTCOME_TYPES` の語彙に限ります（未知の型はエラー）。magnitude は 0〜1。
- `optional: true` のとき、NPN は予期 Q に基づいて接近・回避を選びます。回避した場合、結果は観測されず学習もしません（回避したことだけを台帳に記録）。
- プローブ（学習しない評価）は、`outcomes` を持たない状況（context, concepts, participants）か、エンティティ（`{"entity": "friendA", "class": "collaborator"}`）か、概念（`{"concept": "music"}`）です。

## 3. 生得の層（innate.py、固定、全人格共通）

- 欲求 5 つ: 関係性 R、有能感 C、自律 A、刺激 S、安全 Sa。
- 効果表 M: 結果の型 → 欲求の変化（5次元）。語彙（最低限）: connection, rejection, support, betrayal, harm, praise, criticism, credit_taken, credit_given, taught, achievement, failure, autonomy_gain, autonomy_loss, novelty, monotony, safety_threat, comfort。各行の値は人が読める表で定義し、README に載せます。Δh = Σ_o magnitude_o · M[type_o]。
- 欲求の状態 h（初期値 h0 = 1.0 全次元）。毎経験の後に `h ← clip(h + Δh, 0, 6)`、続いて `h ← h + λ_h (h0 − h)`、λ_h = 0.1。
- 効用: 成長欲求（R, C, A, S）は u(h) = s(1 − exp(−h/s))、s = 3。安全は u(h) = −½ max(h* − h, 0)²、h* = 1。
- 事象の効用変化（ベクトル）: Δu_k = u_k(h_k + Δh_k) − u_k(h_k)。概念ごとに足し合わせない。
- 寄与の分解: 結果 o の欲求 k への寄与は Δu_k · Δh_{k,o} / Δh_k（Δh_k = 0 なら 0）。分離可能な効用なので経路積分と一致し、合計は Δu_k に等しい。

## 4. 信念ネット（belief.py）

### 4.1 予測対象
- 参加者 e が型 k の結果を起こす確率 P(y_{e,k} = 1 | e, class(e), context)。
- 文脈 c で自分・世界から型 k の結果が起きる確率 P(y_{c,k} = 1 | c)。
- 各経験で、各参加者 e と各型 k について y_{e,k} ∈ {0,1}（その型の結果が e を行為者として起きたか）、文脈について y_{c,k}（self・world を行為者として起きたか）を観測とします。
- 各型の平均の大きさ（magnitude）は型ごとの移動平均で持ちます（MB 価値の計算用）。

### 4.2 分布と階層（Beta–Bernoulli、経験ベイズ近似）
- 単位: 個体 ind(e)、類 cls、一般 gen（人の層）／文脈 ctx、世界 world（文脈の層）。各単位・各型に計数 (n1, n0)。
- 個体の事後平均: `p_ind = (κ_e · m_cls + n1_ind) / (κ_e + n_ind)`、m_cls は類の平均。
- 類の平均: 類に属する個体 i の率 r_i = n1_i / n_i を、重み w_i = n_i/(n_i + κ_e) で集計し `m_cls = (κ_c · prior_cls + Σ w_i r_i) / (κ_c + Σ w_i)`。**類の有効標本数は個体の数で上限が決まります。** prior_cls はニューラル事前ヘッド（4.4）の出力、ヘッドが未学習（学習標本 < 50）なら m_gen。
- 一般 m_gen は全類の同様の集計（κ_g、事前 Beta(1, 4)）。文脈の層も同じ形（ctx ← world）。
- κ_e = 2、κ_c = 4、κ_g = 4（固定。経験ベイズで学ぶのは将来課題）。

### 4.3 スコープ帰属（参加者が行為者の結果）
- 型 k ごとに、「人のせい」か「場面のせい」かの事前 π_k ~ Dirichlet(1, 1)（計数で更新）。
- 観測 y_{e,k} について責任 φ_person ∝ π_k,person · Bern(y; p_ind), φ_ctx ∝ π_k,ctx · Bern(y; p_ctx,k^person)（その文脈で誰かが k を起こす率）。正規化して和 1。
- 計数は責任で重み付けて加えます（ind 側に φ_person、文脈の「人による k」計数に φ_ctx）。π_k の計数にも φ を加えます。
- 予測: `P(y_{e,k}=1) = π̄_person p_ind + π̄_ctx p_ctx,k^person`。

### 4.4 ニューラル事前ヘッド（mlp.py を使用）
- 入力: 類の埋め込み（lexicon、8次元）と文脈の埋め込み（8次元）の連結。隠れ層 16（tanh）。出力: 人による各型の確率のロジット。
- 学習: 観測そのもの（各経験の各参加者の y_{e,k}）への二値交差エントロピー。直近 500 件のリプレイ緩衝から毎経験 4 ミニバッチ（各 16 件）、SGD 学習率 0.05。**目標は観測で、事後平均ではありません**（docs/04 第4.2節、批評 S4）。
- 用途: 類の事前平均 prior_cls。未見の類（例: 共同作業者に似た「バンド仲間」）への予測の転移を担います。
- 文脈の層も同じ形のヘッドを持ってよい（任意）。

## 5. 価値ネット（value.py）

### 5.1 二つのカルマン回帰（帰属で教師を分ける）
- 人モデル（参加者の価値）: 特徴 = `people`（一般, 事前分散 0.01）＋ `cls:<c>`（0.04）＋ `ind:<id>`（0.25）＋ 類の埋め込み 8 次元（各 0.02）。
- 状況モデル（文脈と概念の価値）: 特徴 = `world`（0.01）＋ `ctx:<c>`（0.1）＋ `concept:<x>`（各 0.1）＋ 概念埋め込みの平均 8 次元（各 0.02）。
- 重み W（特徴 × 5 欲求）、共分散 Σ（特徴 × 特徴、欲求で共有）。新しい特徴は登場時に追加し、事前平均 0・事前分散は上の値。
- 各経験で、教師を帰属で分けます:
  - 参加者 e について: `Δu_person(e) = Σ_{o: actor=e} φ_person(o) · contrib(o)`（contrib は第3節の寄与ベクトル）。人モデルを e の特徴で更新。
  - 状況について: `Δu_situation = Σ_{o: actor∈{self,world}} contrib(o) + Σ_{o: actor=参加者} φ_ctx(o) · contrib(o)`。状況モデルを更新。
- カルマン更新（観測雑音 R = 0.01、過程雑音 q は層ごとに固定: ind 1e-4、cls 2e-5、people/world 5e-6、ctx・concept 2e-5、埋め込み 5e-6。関与した特徴だけに加える）:
  `K = Σ z / (zᵀ Σ z + R)`、`W += K (Δuᵀ − zᵀ W)`（5 欲求同時）、`Σ ← Σ − K zᵀ Σ`、続いて関与した対角に q を加算。
- **新しい個体は類の価値を継承します**（加法の階層なので自動。ind の偏差の事前平均は 0）。

### 5.2 モデルベース価値と調停（状況単位）
- `V_MB(s | h)`: 信念の予測確率で結果の集合を M_mc = 64 回サンプルし（乱数は経験 id から作る種で決定的に）、各サンプルで U(h + Δh) − U(h) の総和を平均。分散 σ²_MB = サンプル間の分散 / M_mc ＋ 信念の事後の不確実性（各単位の Beta 事後分散の和に効用の尺度を掛けた近似。式を README に書く）。
- `V_MF(s) = Σ_e person_value(e) + situation_value(s)`、各 value はカルマン予測の 5 欲求の和。σ²_MF は対応する zᵀΣz の和。
- 調停 `ω = σ²_MB / (σ²_MB + σ²_MF)`、`U_val(s) = ω V_MF + (1 − ω) V_MB`。
- 予期 `Q(s) = U_val(s)`（社会・関心・評価条件づけは v3.0 では未実装。README に明記）。

### 5.3 感じた価値・気分・感情の読み出し（目標にはしない）
- `f = tanh(Σ_k Δu_k / s_f + β m)`、s_f = 0.5、β = 0.3。
- 驚き `δ = f − tanh(Q / s_f)`。気分 `m ← 0.8 m + 0.2 δ`。
- 感情の読み出し（言語化用の手がかり。学習には使わない）: 喜び（f>0）、失望（δ<0 かつ Q>0）、安堵（δ>0 かつ Q<0）、怒り（人に帰属した負の寄与）、悲しみ（関係性の負の寄与）、興味（刺激の正の寄与）。強度の式は README に書く。

### 5.4 選択（optional な経験）
- 接近確率 `σ(β_c · (Q + b))`、β_c = 4、b = 0.05（小さな探索ボーナス）。乱数は状態の Generator。

## 6. 統合（npn.py）

```
experience(exp) の順序:
 1. schema 検証
 2. 予期: belief の予測 → V_MB, V_MF, ω, Q（結果を見る前）
 3. optional なら接近・回避を選ぶ。回避なら記録して終了
 4. Δh, Δu（ベクトル）, 寄与の分解, f, δ, 感情
 5. 信念の更新（責任 φ を計算 → 計数、π、型の大きさ、リプレイ緩衝 → 事前ヘッドの SGD）
 6. 価値の更新（φ で教師を分け、人モデル・状況モデルのカルマン）
 7. 欲求の状態 h と気分 m の更新
 8. 台帳に記録（経験 id、各特徴の ΔW、φ、Δu、Q、f、δ）
 戻り値: appraisal dict（Q, V_MB, V_MF, ω, f, δ, Δu, 寄与, φ, 感情, 価値の変化の要約）
appraise(exp): 2〜4 を計算するが、状態を一切変えない（学習しない）
probe(p): 学習しない評価（状況・エンティティ・概念）
save(dir) / NPN.load(dir): 全状態（設定、計数、π、特徴の索引、W、Σ、ヘッドの重み、リプレイ緩衝、h、m、乱数の状態、台帳）を state.json＋arrays.npz に。スキーマ版番号と内容のハッシュを持ち、改ざん・版違いは例外にする
```

アブレーション（テスト用の切り替え。既定はすべて OFF）:
- `flat_value`: 価値の階層を外す（ind 特徴だけ、事前分散 0.25）
- `fixed_teacher`: 3-F 型。予測誤差もカルマン利得も使わず、`W[ind] += 0.1 · Δu`（期待に依存しない固定教師）
- `no_head`: ニューラル事前ヘッドを使わない（prior_cls = m_gen）
- `no_scope`: スコープ帰属を切る（φ_person = 1）

## 7. CLI

```
python -m npnv3 init  STATE_DIR [--seed 0]
python -m npnv3 feed  STATE_DIR experiences.jsonl      # 学習し、各経験の要約を表示し、保存
python -m npnv3 probe STATE_DIR probes.json            # 学習せずに評価
python -m npnv3 show  STATE_DIR                         # 価値の上位・信念の要約
```

## 8. 事前に固定する判定基準（tests/）

数値は乱数種 0〜19 の 20 本での平均（または全本）です。ここに書いた閾値は結果を見て変えません。変える場合は CHANGELOG に理由と変更前の結果を書き、REPORT で「事後変更」と明示します。

| ID | 検証内容 | 合格条件 |
| --- | --- | --- |
| T1 ループ | 経験→評価→学習→次の評価: 同じプローブの評価が、関連する経験の後で変わり、無関係な経験の後ではほぼ変わらない | 関連後の変化 > 10 × 無関係後の変化 |
| T2 履歴差 | 同じ初期状態から3つの経験史（協働に救われた R、手柄を取られた K、探索者 X）を通し、同じ新しい経験を与える | (a) 新しい経験の感じた価値 f が3人格で異なる（最大差 > 0.1）。(b) 同じ新しい経験による価値の更新ベクトル（全特徴×欲求）の人格間 cos の最小値 < 0.5。(c) `fixed_teacher` では cos ≥ 0.95（差は機構から生じる。固定教師でも欲求の状態 h の違いで Δu がわずかに変わるため 1 にはならない） |
| T3 学習の向き | T2 の新しい経験で、相手 A への評価の更新の符号が、少なくとも1人格で他と逆になる | 符号の不一致あり |
| T4 継続学習 | P1（8人の共同作業者に1回ずつ搾取された）と P2（普通に協働）に、新しい共同作業者 N との良い経験を m = 8, 32 回 | 持続（未見の共同作業者への P1−P2 の評価差の残存率）≥ 0.7 かつ可塑性（P1 の N への評価が真値に近づいた割合）≥ 0.7。`flat_value` では持続 < 0.5 |
| T5 保存・復元 | 経験 A を学習→保存→復元→経験 B、と、A+B を連続で学習 | 全状態と全出力が完全一致（np.array_equal）。改ざん・版違いで例外 |
| T6 自己増幅なし | (a) 価値の状態写像の W に関するヤコビアンのスペクトル半径（有限差分、T2 の全経験）。(b) 同じ良い経験を 5000 回 | (a) ≤ 1 + 1e-6。(b) 価値が有界で、経験の真の効用変化に収束（相対誤差 < 10%） |
| T7 信念の一般化（H4） | 「手柄を取る」を同じ相手から8回 vs 8人から1回ずつ | 未見の共同作業者への予測の上昇が、8人の方が大きい |
| T8 NN の転移 | 共同作業者（手柄を取る率が高い）と、師・見知らぬ人（低い）を学習した後、共同作業者に埋め込みが似た未見の類「バンド仲間」への予測が、共同作業者の傾向へ寄る | ヘッドあり: 未見の類の予測と共同作業者の予測の差が、`no_head` より 30% 以上小さい |
| T9 反事実 | 形成期の経験を1つ除いて学び直すと、後のプローブの評価が変わる | 変化が、同じ数の無関係な経験を除いた場合（プラセボ）より大きい |
| T10 決定性 | 同じ種・同じ入力で同じ結果 | 完全一致 |

## 9. 理論上の成立と実装上の成立

REPORT.md では、各項目について次の三つを区別して書きます。
- 設計（docs/04）で主張していること
- この実装で実際に動かして確かめたこと（テスト ID と数値）
- 確かめていないこと・実装していないこと（社会、関心、評価条件づけ、後悔、コミットメント、事前の経験ベイズ学習、LLM 抽出の接続、など）
