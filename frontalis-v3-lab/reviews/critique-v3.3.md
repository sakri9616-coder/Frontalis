- 決定則は (ii) になりやすい設計だった。「5% 差」は交差エントロピーに対する比で、エントロピー床（0.53〜0.58）を含むため、超過損失で 30% 以上勝っても通らない。さらに学習類 24、mlp は 300 回固定・正則化なし。実装者の操作ではなく SPEC 側の設計だが、検出力が低い。

## 2. Y 系（事実と主観の分離）
- §5 には沿っている。台帳の当時の f・φ・Δu・感情は不変、信念だけ訂正、価値は自動消去せず、`retroactive_value` を対照にした。ただし Y5 は追記専用の台帳が壊れていないことの検査（回帰ガード）、Y7 は「無関係な経験で変わらない」でほぼ恒等。C は履歴で A に付かず 0 のままなので、「感情の痕跡は訂正で動かない」は単体テストにしか現れない。
- §6・SPEC 2.1 とのずれ。SPEC は「訂正は新しい経験として評価され、その評価が新しい学習になる」と書く。`_correct` は、当時の欲求の状態 h_before で教師の差 Δ_e を作り、精度 a·w_reapp のカルマン更新を 1 回するだけ。訂正の f・安堵・罪悪感は読み出しで、学習に入らない。現在の評価状態が効くのは精度 a だけ。「受け止める直前の評価状態が学習の方向を変える」（§6）を Y 系は検査していない。
- w_reapp の全人格共通は、「差は経験史から」という規則とは整合する。代償は、固執の強さが 1 つの定数に集まり、Y2 が「この定数が 0.3025 を与える」確認になったこと。感度は w=0.25→0.58、0.5→0.30、1.0→−0.08。種ごとの値は 0.29〜0.31（個人差ゼロ）。
- 検算 B: 誤帰属の本数 N を変えると、価値の残る割合は 0.60（2）/0.52（4）/0.30（8）/−0.01（12）/−0.34（16）。「確信が高い（履歴が長い）ほど残る」の逆向きで、16 では対照を超えて反対側へ行く（§7 の固執ではなく過剰訂正）。Y2 の合格は N=8 と w=0.5 の組の産物で、機構（確信）による保持とは識別できない。
- Y1 の不合格（0.772）は、個体の信念が 0.97〜0.99 まで直り（検算 B でも N=4〜16 で 0.96 以上）、文脈の部分が読み出し p_person に残るため。故障ではなく「誤解が解かれ切らない」側の性質に近いが、事前登録の「故障側」なので不合格のまま報告したのは正しい。20 本は独立標本でない（値の幅 0.01）。

## 3. Z-orig・Z-persist・P 系
- Z-orig の合格の多くは係数の恒等式。Z3 の J の残存 0.1326 は 0.98^100、Z5 は 1+κ_ag、Z6 は |Δu|=0、Z7 は J を教師に入れない設計そのもの。Z2 は平均どうしの読みで合格（種ごとの後半/前半は −0.95〜+4.9）。Z3 の W の「残存」は平均 1.30 で、保持でなく増加。Z4 の不合格（10/20）は性質の記録として正しく扱われた。既定が Z-orig（減衰 2%・上限 0.2）のままなのは、SPEC 8.1 が「合理性を押し付けた」と診断した設計が既定ということ。
- P 系は構造上自明に合格する。P1 は台帳の源の和と J がどちらも同じ出来事の列から作られる。P2 は二択以外に J を書く経路がコードにない。P3 は cap が J_num を強制する。P4 は ΔJ=全出来事の和で、spread・counter・cap の差が小さければ 99.9% になる。P5 は台帳の割り引き×カルマン利得の再計算（1.8e-14）。P6 は葛藤を c<1e-7 に固定し、正の源が reaffirm だけ。合理性を押し付けない点は良いが、問えているのは台帳の完全性まで。
- 台帳の源は係数（η_J・η_r・η_ov・ρ_dis）そのものなので、源に分解しても「機構か係数か」は分からない。反事実の対照（係数を 0 にする）があるのは P5 の ρ_dis=0 だけ。
- 検算 C: 反証なしで満足する再選択だけを 30 回繰り返しても、J(fav) は η_ov=1 で 0.078→0.254（reaffirm +0.87 の約 77% を overwhelm が消す）。η_ov=0 なら 0.085→0.783、0.1 なら 0.46。J が Q を押し上げ、f が追いつかず δ<0 になり overwhelm が J を消す。時間の減衰を外した設計の裏口に、減衰に相当する負の帰還が残っている。η_ov=1 は S#9（試走後）の選択。
- P4 の符号は逆（再選択 10 回の方が反証後の J が小さい: 0.030 対 0.050）。抵抗の効果は学習の 1.1%。この既定の係数では、コミットメントの自己強化も合理化もほとんど出ず、P 系は出ても出なくても合格する。反証が選択の形なら overwhelm が働き、通常の経験なら J に届く経路がない（Z4 を persist に当てると 16/20 が 10 回でも反転しない）。持続性は経路の設計の非対称で決まる。

## 4. E 系・M 系・分類
- 分類の定義（非有界／規則違反／原因が記録で説明できない）はユーザー原則に沿い、E1・E8(b)・W6 最大比を「破綻でない」と読む根拠（Σp·C の恒等式、重みの項 100%、強制再生 0.37〜0.46）も筋は通る。ただし逃げ道になる点が 3 つある。
- (a) 定義が「台帳で説明できる」なので、決定的で台帳を持つ系は定義上破綻しない。「破綻は見つからなかった」は反証可能でなく、検出力も未検証。検算 D: Kalman ゲインを 3 倍にして台帳に一貫して記録する変異体で、B1〜B3 は全合格（seed 0、比 0.485）。この変異は T6 のスペクトル半径などが拾った。「破綻なし」は B 系の結論でなく単体テストとの合成。B 系に変異テストを置くべき。B 系は 19 分の約半分を使い、B1 は 80 実行中 3 本でしか中身がなく、B2 の宣言は |W| で実測の 34〜53 倍緩い。
- (b) 「モデル化された性質」は個性を示唆するが、履歴で変わることが示されていない。経験史で再発しやすさが変わる E9 は両設計で不合格（−0.026／0.000）。E1 の縮み、Y2 の 3 割、割り引き 1% は全人格に共通の係数の値。個性と呼ぶには履歴依存の証拠が要る。第三の区分「設計仮説と矛盾する性質」も要る。
- (c) 分類が選択に使われていない。E1 の不合格は M.1 では revised を退ける「故障の基準」、M.6 では「性質」。両立しない。
- 既定 spec_literal の実質。M4 は 20/20 で不合格（消去 20 試行のうち 18 試行が獲得の原因を更新し、C_k が −0.193→−0.058。消去が忘却になっている）。E2・E1・E7 の合格は、前提の Bouton 型（消去=新しい学習）と別の理由で通っている。E3−E2=0.299−0.273=0.026（文脈による復元はほぼゼロ）。E7 の合格は delta 則の節約と区別できない（B.1 の自認）。
- M1・M3 は既定では E3〜E6 が全て不合格で報告のみ。revised でも E6 のみ判定で、プロトコルが C を動かさないため構造的に満たされる（J.5 自身が認める）。機構か係数かの識別は、既定の設計では実質的に検査されていない。§8「消去と文脈による再出現」は、どちらの設計でも実現していない。
