## 1. P1 と S1 は解消したか

### S1（C が行き止まり）: 解消（open-loop）。閉ループでの持続は未達
- C は Q に入り、接近確率が変わる。検算 c2（H1/H2 の履歴後、praise を含む申し出の接近確率、種 0〜9）:
  H1 0.244、H2 0.717、差 0.473。C を 0 にすると 0.401 / 0.642、差 0.240。差の約半分（0.23）が C に由来する。
- 残りの 0.24 は C 以外の状態の差（harm の信念、a）による。REPORT の open-loop 0.27 は「C だけ」の効果ではなく、H1/H2 全体の差である点に注意。
- 閉ループ 40 回の判定は 0.1325（基準 0.15）で不合格。原因は C の消去（praise の後に何も起きない）。消去は研究思想 §8「学習と消去」から期待される性質で、実装の誤りではない。
  ただしこれは「C が持続する回避を作る」ことを示せなかったという意味で、W2 の不合格は軽くない。

### P1（評価基準 → 学習）: 部分的に解消
- 因果性は確認できた。v3.1 では a/C を入れ替えても W が差 0（ビット単位で同一）だった。v3.2 では 0.113 で、両方を切ると厳密に 0（W1）。この対比が最大の成果。
- ただし 0.113 は C → 選択 → 経験の経路を含む合計。純粋な a → 観測雑音 R_k の経路（申し出なし）は 0.040 で、基準 0.05 を単独では満たさない（REPORT の表に数値あり）。
- 検算 c1（a だけを R 型と K 型で入れ替え、申し出なし、種 0〜7）: W の相対差は 20 経験後 0.045、100 経験後 0.024、300 経験後 0.022。半減して小さく残る。
- 解釈: a は欲求ごとの学習の配分（速さ）を変えるが、教師は同じ Δu なので到達点は変えない。研究思想 §6 の「学習の方向」を変えるのは、現状では信念経由の解釈（U4）であって、a ではない。
- a の更新は曝露統計（|Δu| の移動平均）のまま。方向を実験条件にしたのは正しい対応だが、馴化で U5 の差が 0.52 → 0.23 に変わる（REPORT §7 が開示）以上、a の方向は人格の中身を左右する未決の仮説である。

## 3. 最終判定: 「動く NPN の最小フレーム」と呼んでよいか

**限定つきで可。** v3.1 の判定を一段強められる。理由は、評価基準が学習に作用することが、因果的に非ゼロとして示されたため（W1、切ると厳密に 0）。

呼べる範囲: 「期待・解釈・選択に加えて、評価基準 a, C が評価（f, Q）、学習の配分、open-loop の選択に作用する、決定的で保存可能な最小フレーム」。

条件（README と REPORT §0, §9 に書くこと）:
1. 「評価基準が次の学習を変える」は、a が学習の欲求ごとの配分を小さく変える（a 単独 0.040、300 経験で 0.022）という意味に限る。何を学ぶか（教師 Δu）は変えない。
2. 「C が持続する回避を作る」とは書かない（W2 閉ループ 0.13、消去）。
3. 「人格が形成された」「循環が成立した」とは書かない。a の方向（感作／馴化）、効果表 M、手書きの世界、8 次元の埋め込みが前提であることを §0 に明記する。
4. 次の版の優先課題: (i) a の目標に、人格自身の選択（接近・回避の履歴）を入れて、曝露だけでなく選択が基準を変える経路を作る、(ii) 価値側の想起による再帰属（現在は非対称）、(iii) U8/W2 の不合格を基準に合わせて直さず、消去を含む新しい基準を別 ID で事前に固定する、(iv) NN と knn1 の leave-class-out 比較。
