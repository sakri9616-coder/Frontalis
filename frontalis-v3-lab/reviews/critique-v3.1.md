## 【理念違反】

### P1. 評価基準の軸で循環が閉じていない（a は曝露統計、C と f は行き止まり）
- 重大度: 理念違反（§1 手順 2→3、§6、§13C）。前回 V3 の縮小した残り。
- 根拠:
  - Concern.update(du)（value.py）は |Δu| の移動平均だけで a を動かす。a の更新は a にも W にも C にも依存しない。a が変える先は f, Q, like, C の目標だけ。
  - e11: 同じ K の状態に R の a と C を載せ替えて同じ次の 20 経験を与えると、max|ΔW| = 0, 信念の計数差 = 0。評価基準は次の学習を変えない（README の「その変わった基準が次の経験の…学習を変える」は、解釈と選択の経路を除くと成り立たない）。
  - 曖昧な結果（U6 の長い履歴で 8%、候補は 2 型のみ）と optional を除く経験列では、a と C は W と信念の学習から完全に独立。
- 最小の修正案:
  1. 有界な価値→学習の経路を 1 本実装する。例: 教師の帰属 φ の事前を、その人にとっての重みづけた害（a·Δu の符号）で傾ける自己奉仕的な帰属（上限つき、ON/OFF 条件、影の信念との乖離を台帳で報告）。
  2. 判定を足す（T13）: 状態の入れ替え（a, C だけ）の後、同じ非選択の経験列での ΔW・Δ信念が、入れ替えなしと「0 より有意に違う」。現状は 0 で不合格になる。
  3. a の変化のうち、人格の解釈（信念で決まる Δu の混合）に由来する分と、曝露に由来する分を台帳で分けて記録し、前者が 0 でないことを示す。

### P2. 新しい評価基準 a は設計者の仮説と M×世界表の閉形式で、f の差の担い手としての妥当性が示されていない
- 重大度: 理念違反（§5, §14, §16）。前回 V1/V2 の形を変えた残り。
- 根拠:
  - e6: 学習した a と、履歴の「欲求ごとの平均 |Δh|」（M の列の負荷）を正規化した表の cos は R 0.95、K 0.97、X 0.91（偏差の cos 0.96〜0.98）。a は M × 世界表の曝露頻度の言い換え。
  - 方向（感作）は設計者の仮説。e1: 更新則を馴化（強く打たれた欲求ほど軽い）に反転しても U1(a) の gap は 0.279 で合格し、順序が反転する（f: R 0.62 / K 0.89 / X 0.71。感作は R 0.85 / K 0.61 / X 0.73）。負の揺さぶりだけ・正だけの変種でも gap は 0.21 / 0.14。U1 は「a が f の差を運べる」ことを示すが、「どの方向が正しいか」には無力。
  - U3 は M の各要素に ±30% の乗法ノイズを掛ける。零の要素は零のままで疎構造が保たれ、a の更新則の向きは動かない。
  - 正負を区別しない |Δu| は、効用の逓減（飽和）と両方で馴化を二重に扱う。K の a_A が 1.61 なのは、盗まれる損失と独り作業の自律の獲得の両方が効くため。
- 最小の修正案:
  - a の更新則の向きを実験条件にする（感作 / 欠乏だけ / 充足だけ / 馴化）。U1 と U3 を全条件で報告し、研究思想 §8 に従い「知見・仮説・便宜」の欄に感作を仮説として載せる。
  - 方向を人格が決める経路を足す: a の目標を、その欲求について自分が選んだ接近・回避の履歴（閉ループ）で補正する。曝露だけでなく選択が基準を変える。
  - M0 を乱数化・疎構造ごと置換した世界（行の入れ替え）でも、人格差が経験史の関数として残るかを測る（U3 を強化する）。

## 【重大】

### S1. C（条件づけられた価値）が行き止まり: 形成された価値が人格の判断に使われない
- 根拠:
  - e2: H1（praise → harm）後の C(praise) = −0.146。praise を含む申し出の Q = −0.1677、接近確率 0.3845。C を 0 にしても Q と接近確率は小数 4 桁まで同じ。C を 0 にして 1 経験を追加しても W と a の差は 0.0。差が出るのは f（−0.528 対 +0.050）と δ だけ。
  - npn.py では C が入るのは `felt_value` の `cond` だけ（Q, 調停, 教師, 接近に入らない）。
  - 「praise を嫌う」と学んだ人格が、praise を避けも、praise の後の害を予期もしない。f の表示が変わるだけで、人格の判断としては何も変わらない。
  - 信念側は結果型を事象ごとに予測し、系列を予測しないので、「praise の後に害が来る」ことは Q のどこにも出ない。
- 最小の修正案: C を予期に入れる（Q ← Q + λ_Q ΣC(手がかり)、λ_Q は有界）。U2 に「H1 で praise を含む申し出の接近率が H2 より低い」を足す。

### S2. U1 の判定が識別力を欠く（トートロジー、閾値が null の内側、方向に無力）
- 根拠:
  - U1(b): 殻（h, m）を揃えた後に「全部の学習状態」を移すので、f_swap は f_d に恒等的に等しく、移った割合は 1.000（min も 1.000、118 対）。構造上必ず通る。意味があるのは部品別の入れ替え（a 1.01、C 0.36、W −0.06、信念 −0.32）で、これは判定に使われていない。
  - U1(a): 同じ型の 3 人格（別の経験史）の null の f の gap は R 型 0.064、K 型 0.152（最大 0.333）、X 型 0.076（e13）。閾値 0.10 は null の内側にあり、型間の gap 0.240 も null の 1.6〜3.7 倍にすぎない。「別の人生」と「同じ世界の標本ばらつき」の区別が判定にない。
  - U2 の no_conditioning は C を使わないので差が 0 になるのは定義。U5 の「回避した申し出から信念が更新されない」、U6 の a < 5（a の和が 5 に正規化される）、|C| < 10（C の最大は 0.34）も構成上自明。
  - U3 の順位一致 0.80 は閾値ぎりぎり。元の順位の周辺分布（K<X<R が 13/20 → 17/20）で独立と仮定した偶然の一致率は 0.585（U03.json の順位分布から計算）。
- 最小の修正案: U1(a) を「型間 gap が同型 null の 95 パーセンタイルを超える」に変える。U1(b) を部品別の入れ替えに置換し、「f の差の 50% 以上が a 以外の部品に移る」ではなく、移り先の分布を報告して合否にしない。U3 は偶然の一致率との差（リフト）で判定する。

### S3. 世界の確率表が対比を作る構造で、独立なのは 3 つの手書きの世界の内部だけ
- 根拠:
  - make_histories.py の WORLD: K の協働は credit_taken 0.75, betrayal 0.5, credit_shared 0.03、R は credit_taken 0.08, credit_shared 0.25, connection 0.95。M の A・R・Sa の列を直接叩く確率を、人格の型ごとに正反対に手で置いている。独り作業も K は achievement 0.85, autonomy_gain 0.9、R は failure 0.75 と対にしている。
  - U4 の曖昧なペアは credit_taken / credit_shared で、まさに K と R の表が最大に違う項。対照のペアでは差が消える（e13）: taught/novelty は K 0.58 / R 0.60、achievement/failure は 0.50 / 0.50。U4 の 0.80 対 0.34 は、機構の検証としては正しいが、「人格が解釈を変える」の一般性は示さない。
  - U5 の接近率の差（0.31 対 0.79）は、K の表の Q が負である帰結。U2 の H1/H2 は 100% 決定的な「praise → harm / support」の 24 回の対で、対照（praise → 何も起きない、50/50）の C は 0.000 と −0.017（e10）と機構は正しく動くが、確率的で弱い随伴の下での感度は未測定。
  - 表そのものを動かす対照（ランダムな世界、同一の世界を 3 人格に与える全体の null 以外）がない。U 系の 20 本は同じ表からの抽出で、結論は 3 つの設計を前提にする。
- 最小の修正案: 世界の表を事前分布（ディリクレ）から乱数に引く「ランダム世界」を 20 本作り、U1/U4/U5 を全て再測定する。U4 に「両候補が表で差のないペア」を対照として足し、差が 0.2 未満であることを要求する。

### S4. κ_e の経験ベイズ（型ごと）への設計改訂: 前提が実験で否定され、事後調整の疑いが強い
- 根拠:
  - 原因の診断「単一の κ_e が原因」を検証した。κ を固定して U8 の持続（Q、種 0〜9）を掃引（e4）: 全型 κ = 0.3 で m = 8: 0.695 / m = 32: 0.508、κ = 2: 0.643 / 0.420、κ = 50: 0.611 / 0.343。credit_taken だけを 0.3 にしても 0.682 / 0.473。**κ の全範囲を動かしても m = 32 の持続は 0.34〜0.51 で、基準 0.7 に届かない。**
  - 型ごとの κ の試作（belief.py に Beta–Binomial の周辺尤度を型ごとに適用、e3, e5）: U8 の持続は 0.579 / 0.346 で単一 κ（0.582 / 0.370）と同じ。P1 の credit_taken の κ は 14.3（範囲 13.7〜15.1）と大きい。小さな κ（個体差が大きい）ではない。
  - 識別性: 36 経験の人格で推定できる型は 3〜5 個（19 型のうち）、sd(log κ) = 1.0〜1.4 で事前（1.6）とほぼ同じ。格子上の事後平均（線形尺度）は事前だけで 9.7 になり、上端に偏る。docs/04 第4.3節の「8 人未満は事前固定」に反して、情報のない型の κ を実質的に事前の上端で決めている。
  - 不合格の主因は CHANGELOG の診断どおり φ の分割（no_scope で 0.988 / 0.724）と、状況プローブが共有する文脈・概念の特徴が N の経験で書き換わること（可塑性の経路）。
  - 超仮説（Kemp et al. 2007）は特徴ごとの変動性を持つので原理は妥当。しかし事前に固定した U8 に不合格になってから設計を変えると、通っても「基準に合わせた調整」になる。
- 最小の修正案:
  - 改訂を U8 の解決として扱わない。CHANGELOG に「原因の仮説は掃引で否定された」と書き、U8 は不合格のまま残す（閾値は変えない）。
  - 型ごとの κ は独立に正当化する: κ の既知の合成データで回復試験（型ごとに κ = 0.5, 2, 8 の世界を作り、20 個体で回復できるか）を行い、回復できる最小の個体数を README に書く。それ未満では事前に固定する。
  - 対数尺度の事後平均（幾何平均）に変える。T7/T4/U4 を回帰として再実行する。
  - U8 の測り方を、人格の「持続」（個体層の差）と状況の「可塑性」に分けて報告する（CHANGELOG の MB/MF 分解を判定の表に昇格）。

### S5. ニューラルネットの寄与は依然として未証明（縮小した残り）
- 根拠:
  - U7: ギャップは none 0.1105、mlp 0.0384、linear 0.0614、knn1 0.0272。mlp は knn1 に勝たない（20 本中 5% の種でのみ小さい）。judged 基準（mlp ≤ 0.7 none）は通るが、これは前回の T8 と同じ弱い比較。実装者は「勝たない」と報告している（誠実）。
  - e8: R/K/X の 36 経験の人格で、mlp と none の差は Q 0.016〜0.028（|Q| ≈ 0.25 の 6〜11%）、f 0.011〜0.024（型間 gap の 5〜10%）、P(credit_taken) 0.024〜0.045。ρ_h は 0.36〜0.47 で、学習標本 17〜27 件のヘッドを事前の半分近くの重みで混ぜている。効果は小さく、方向が良いという証拠もない。
  - NN は引き続き信念の事前にしか入らず、価値（人格）の側には入らない。
- 最小の修正案: 埋め込みの非線形関数が真の率になる課題（例: 協調高 AND 階層低）を作り、mlp が knn1 と linear の両方に勝つことを合否にする（勝てなければ「NN は寄与しない」と報告）。ρ_h の分母 30 は標本数のスケールに合わせて検証する。

## 【中】

- M1 U6 は選択経由の増幅に検出力がない。ε = 1e-3 では選択の反転が 0 回（概算の期待値は約 0.04）。e7（ε = 0.1〜0.3、信念の計数も摂動）では反転が 4〜14 回起きたが比は 0.70〜0.71 で増幅なし。性質は成り立つが、U6 の設計は保証していない。修正: ε を 0.1 まで掃引し、反転後の乖離の有無を判定に入れる。
- M2 U9 は既知語だけを比べる（SPEC どおり）。回転した lexicon で復元した後の新語は新しい座標で登録され、同じ状態に 2 つの座標系が混在する（テスト自身が期待値として確認している）。e9: 未見の類の like が、元の lexicon で評価した場合との差の絶対値で平均 0.034（like ≈ 0.1 の約 3 割）動く。LLM 交換の中心的な場面（新語）が未保護。修正: 状態に埋め込みの版・供給源の識別子を持たせ、座標系が違う供給源の新語は登録を拒否または射影（既知語から最小二乗で整合）する。結果型の語彙（19 型）も閉じたまま。
- M3 C の非対称は設計者の効用の形から来る。praise → 害 / 支えが 50/50 でも C は −0.017（75% の種で負）。安全の二乗罰が効用を非対称にしているため。「随伴だけで決まる」とは言えない。README に書く。
- M4 session 指定がない経験列は全て連続とみなされ、無関係な事象の間にも TD がつながる（旧履歴 K/R/X がそう）。session の切れ目は設計者（実運用では LLM）が決める。
- M5 U8 の可塑性が 1.13 / 1.06（真値を超える）。Q が「真値」を行き過ぎていて、可塑性 ≥ 0.7 の合格が意味する量を確認する必要がある。
- M6 前回の M2（感情 6 語の固定公式）、M4（個体の類を変えられない）、M5（密な Σ と台帳の巨大化）は未変更。感情は依然として因果的な役割がなく、f の一部として mood に入るだけ。
- M7 T1 の「無関係」の選び方（S4 の残り）と T9 のプラセボ（構成上 0）は未変更。T3 の符号反転は事前を持つ推定器なら通る（前回 M1）。

## 個別の問いへの回答

1. **a は f の差の担い手として理念上妥当か。** 機構としては妥当（§3 の価値基準・動機を「何が重要か」の重みとして持ち、外生の目標で有界、自己増幅しない）。しかし (i) a は M×世界表の言い換えで（cos 0.96〜0.98）、(ii) 方向は設計者が決めており、逆でも U1 は通る（馴化で gap 0.279、順序反転）、(iii) a の変化は人格の解釈ではなく曝露の移動平均なので §6 の循環ではない、(iv) a・C を入れ替えても W と信念の学習は不変。f の差の約 100% が a から来る（1.01）事実は、f の差が「f の公式の係数」から来ているだけという読みを排除できない。感作は「仮説」と明記したうえで、条件として比較し、人格の選択が a を動かす経路を足さない限り、理念上の妥当性は未確定。
2. **随伴 C は設計者が指定していない価値判断か。** M と無関係に符号が決まる点では「指定していない」（praise の M は 0。対照は 0.000）。しかし符号と大きさは、生成器に書かれた随伴（H1/H2 の 100% の 24 回）の閉形式（γ·a·Δu_次）で、判断として使われない（S1）。「経験から形成された価値」と呼べる最小の例ではあるが、「人格の価値判断」とは呼べない。C を Q に入れ、確率的で弱い随伴でも符号が出ることを示せば、有望な最初の一歩になる。
3. **世界の確率表は結論を作るように書かれていないか。** 機構を検証するには妥当な設計だが、結論に必要な対比を表に手で入れている（S3）。K と R の credit_taken が 0.75 / 0.08、曖昧なペアがその項、対照ペアでは差が消える。ランダム世界の対照が欠けており、型間の差は「世界の手書きの差」と区別できない。
4. **循環は今どこで閉じているか。** 閉じている: 信念 → 解釈 → 教師・a・C（e12）、Q → 接近 → 経験（U5）、W の予測誤差（v3.0）。開いている: a の更新（外生）、a/C → 学習（ビット単位で同一）、f/δ/感情/気分/C → 学習・選択（P1, S1）。

## κ_e 改訂の妥当性（要約）
原理（Kemp の超仮説）は妥当だが、U8 を直すという動機は実験で否定された（κ = 0.3 でも 0.51）。型ごとの推定は 36 経験規模では識別できず（sd(log κ) 1.0〜1.4）、上端に偏る。実装するなら、U8 の解決ではなく独立の改良として、回復試験・幾何平均・回帰テストを付け、CHANGELOG に「事後変更」と書くこと。

## 良い点
- U8 の不合格を閾値を動かさず記録し、原因の分解（MB/MF、φ）まで出した。T2(a)(c) の扱いの訂正も誠実。
- 部品別の入れ替え、アブレーション、参照点項があると gap が縮む（no_reference 0.435 → full 0.240）という、不利に見える情報も開示している。
- 解釈の経路（e12）は、既存の人格（信念）が経験を評価し、その誤読が価値に残る、という理念の核に最も近い実在の成果。
- 種ごとに別の経験史、C の対照（0.000 / −0.017）、保存・決定性の維持。

## 判定: 「動く NPN の最小フレーム」と呼んでよいか
1. 限定つきで可。「期待・解釈・選択の軸で循環が動く、決定的で保存可能な最小フレーム」とは呼べる（解釈 e12、閉ループ U5、f が学習状態に依存、種ごとの別の経験史）。
2. 「評価基準が経験から形成され、その基準が学習を変える NPN」とは呼べない: a は曝露統計で方向は仮説、a と C を入れ替えても W・信念の学習はビット単位で同一、C は行き止まり。
3. U1 の合否は識別力が弱い（(b) は恒等、(a) の閾値は null の内側）。REPORT では「機構が動く」と書き、「人格が形成された」「循環が成立した」とは書かないこと。
4. 次の一手の優先順: C を Q に入れる（S1）、a/C → 学習の経路を 1 本（P1）、ランダム世界と null で U1/U4/U5 を再判定（S2, S3）。κ の改訂は U8 の解決と呼ばない（S4）。
