## 1. データから言える結論と、言い過ぎている結論

**データで支持される結論（記述の範囲で）**
- 時間分離の機構は動いている。REPORT 表で、短期 <1% が 240/240、気分 <50% が 240/240、長期保持 240/240。ただし REPORT 自身が「独自更新則の作動確認」と限定している。設計した減衰係数が設計どおり動くという同語反復に近い。
- 主条件の「過去差 >0.01」は 0/60 で失敗。正直に残されている（REPORT L24、ADDITIONAL L39）。
- 二視点方式の「60/60」は、事後探索の構造で出た結果。構造を変えた後の再検証であり、元の主条件の成功ではない。

**言い過ぎ、または弱い点**
- 二視点の「成立」は定義上ほぼ保証されている。REPORT L34 は、cue と observed の logit を固定で半分ずつ使う構造と書いている。観測だけでは 0/60、平均 .00361（ADDITIONAL L7）なので、cue 経路が過去情報を直接持ち込む。「過去差が出る」のは読み出しの構造の帰結であり、人格形成の証拠として読むのは弱い。REPORT 自身も「追加の人格容量の効果ではない」と書いている。
- 成立後の持続性は崩れている。学習前は 60/60、現在経験を 8 回学習した後は 0/60、RMS .00694（ADDITIONAL L9）。「履歴による個性」は 8 回の経験で消える。
- 「学び直し 120/120 成立」（ADDITIONAL L31）は基準が緩い。測るのは「減衰対照との差 >.01」と「無関係波及 <.5」だけ。反復 32 と 1024 は同じ系列のチェックポイントで、独立標本ではない。
- 「飽和 0%」「先頭記録の保持」は、102 パラメータしか使わない課題（ADDITIONAL L39）での結果。能力の証拠ではなく、課題が単純なことの結果かもしれない。
- 事後の機構点検（ADDITIONAL L35）の「自己学習目標の変化 RMS .0001675」は 1 つの保存例（seed7901）の数字。「5 容量で同じ値」は 5 標本ではない。
- 容量比較は無効。5 容量すべてで使用パラメータが 102、反応差が 0（REPORT L40-49、ADDITIONAL L39）。容量について言えるのは「分からない」だけ。
- 線形 ridge に勝てていない。MSE は ridge 0.1592 に対し RBF 0.2618〜0.2878（REPORT L43, L48）。
- 人間評価は未実施（HANDOFF の「84 対は未採点」）。

## 2. 運用上のリスク

- **反駁への抵抗、持続、嫌悪を故障扱いする危険**
  - PREREG は「極端な値や頑固さ自体を失敗としない」と明記しているが、成功基準の一部には逆の方向のものがある（「学び直し変化 >0.01」「過去差 >0.01 が 80% 以上」）。前者は「反駁されにくい人格」を落第にする方向に働く。
  - 基準が「変化したか」だけで、「なぜ変化しなかったか」（計算上の故障か、人格としての頑固さか）を区別していない。
- **開発者が「正しい値」を決めてしまう危険**
  - 固定 8 軸写像と固定の初期写像は、開発者が価値の座標系を決めている。経験が動かせるのは RBF 残差だけ。
  - 自己学習目標の「更新前の同じ NPN の解釈された結果の logit ×1.1」「±4 上限」は開発者の選択。係数だけを変える変更は人格形成の証拠にならない、という研究方針と衝突する。
  - 減衰則の選択基準は「保持率最大」。保持を良しとする基準が入っている。
  - LLM は意味抽出で 8 軸を埋める。抽出誤差（haiku MAE 0.40、deepseek 0.53）が学習信号になる。教師でないとは言えても、入力の質を左右する。
  - gold は単独著者の合成データで、二重注釈がない。

## 3. 次フェーズ 4 項目（当時の提案）

1. **価値の再帰属と再学習**
   - リスク: 「再帰属が成功した」の判定を、開発者が期待する向きで定めてしまう。減衰対照との差だけでは、再帰属と単なる上書きを区別できない。
   - 検査: 再帰属先の軸を事前に固定せず、軸ごとの変化量を方向中立に記録する。無関係軸への波及と、元の事実記録の不変性を同時に報告する。
2. **消去と記憶の再出現**
   - リスク: 再出現しないことを故障、再出現することを成功と一方的に決めると、開発者の理想像になる。
   - 検査: 再出現の予測値を数式で事前固定し、「中心を消した条件」と「係数だけ消した条件」を比較する。
3. **NN の実際の役割**
   - リスク: 線形 ridge に負けている。比較条件を後から増やすと、NN が勝つ条件探しになる。
   - 検査: ベースライン（線形、Kalman）、データ分割、勝敗基準を実装前に固定し、負けた条件も同じ表に残す。
4. **検証の独立性**
   - リスク: 同じ作者が実装と検証を両方書くと、検証が仕様をなぞるだけになる。P6 の基準を結果後に改訂した疑い。
   - 検査: 変異テストを意図的に入れ、検証が落とすかを確認する。P6 は改訂履歴をハッシュで残し、事前登録版と改訂版を並べる。

## 4. 実測ではなく LLM 生成テキストにしか支えられていない主張

- 「匿名 LLM 補助点検: 感情付加 1 件、省略 7 件、反転 0 件」（REPORT L72）。自己評価を含むと REPORT 自身が認めている。
- 抽出精度の gold は単独著者の合成データ。人間の正解ではない。
- 実際の Haiku→NPN→Haiku 往復 10/10（REPORT L68）は、gold の意味を直接与えた条件。自然文理解の証拠にはならない。
- 選択一致 40/40 でも態度一致は 9/20〜16/20（REPORT L70）。本文が信号に忠実だとは言えない。
- 言語入力の実験 ID に状態名が含まれていた（REPORT L17）。LLM が状態名から推測した可能性を除けていない。
- 文献に基づく設計仮説（REPORT L84）。心理学の知見を再現した主張ではない。
- 「新規 33＋既存 128 テスト成功」（HANDOFF L16）はテスト結果の記録であり、全系列の独立再実行ではない。
