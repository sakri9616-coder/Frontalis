# 研究の再定義（ユーザー提示、2026-10-17）

> 出典: ユーザーが 2026-10-17 に提示した文面を、そのまま保存する。v3.4 の事前登録（SPEC-v3.4.md、凍結済み）は変更しない。
> v3.4（Y 系）は、この再定義の下では「比較対象」として扱い、本来の NPN 研究の達成とは混同しない。

## 何を間違えたのか

現在の frontalis では、次のような設計になっている。

| 本来研究したかったこと | 現在の実装 |
| --- | --- |
| 何を価値とみなすかを経験から獲得する | 5 つの欲求と効果表を開発者が定義 |
| 経験から新しい評価の観点を形成する | 既存の特徴空間でカルマン更新 |
| 価値観同士の関係も学習する | 主に設計済みの相互作用で処理 |
| 予想外の人格構造が形成される | 設計済みの状態と更新則の範囲で変化 |
| NN で柔軟な評価表現を獲得する | NN は信念予測の補助に後退 |

これは性能が不足しているだけではない。研究すべき問題を、解きやすい別の問題へ置き換えてしまっている。そして私自身、その置き換えを何度も承認してきた。

特にひどかったのは、前の回答で「NN が不要なら名前を変えればいい」と言ったこと。違う。NN が必要かどうかを判断する以前に、NN を採用した理由である「価値表現そのものの獲得」を、まともに研究できていなかった。信念予測で MLP が線形モデルに負けたところで、本来の仮説への反証にはならない。

## 研究をどこへ戻すべきか

frontalis の中心課題を次のように定義し直すべきだと思う。

> 経験によって、開発者が事前に指定していない評価上の特徴・関係・判断基準を獲得し、それらが次の経験の解釈と学習を変える仕組みを研究する。

ここで重要なのは、NN を使用したという事実ではない。NN の内部表現が本当に経験によって変化し、既存の価値軸では表現できなかった判断を獲得しているかどうか。さらに、単に新しい特徴を記憶しただけではなく、その特徴が別の未知経験の評価にも作用することを確かめなければならない。

もちろん、学習のために最低限の初期構造や信号は必要になる。しかし、その初期構造が獲得可能な価値観の種類そのものを決め切ってしまうなら、研究目的を満たさない。

現在の v3.4 で検証している循環や再評価の機構は、比較対象として残せる。だが、それを本来の NPN 研究の達成と混同してはいけない。
