## 0. 先に結論: 循環（研究思想 §1）の実在マップ

| 循環の段 | この実装での実体 | 判定 |
| --- | --- | --- |
| 1 既存の人格が経験を評価する | Q（予期）、φ（帰属）、予測誤差 Δu−zᵀW は学習状態に依存。f（感じた価値）・Δu・感情は依存しない | 一部 |
| 2 評価と結果で人格が更新される | 教師 = 固定の Δu(h, M) を φ で分けたもの。f・δ・感情・気分・ω・Q は更新に入らない（grep: mood は felt_value/next_mood のみ、Q は _p_approach のみ） | 評価は更新に入らない |

人格が学習状態から実際に影響を受けるのは、Q・δ・φ・更新方向（h と気分を揃えても残る: 後述の swap 実験）。これは実在する成果。

## 【理念違反】

### V1. 評価基準が形成されない。f（受け止め方）は学習状態に依存せず、T2(a) は h を測っている
- 重大度: 理念違反（研究思想 §1 手順 3、§5、§13A/C）
- 根拠:
  - value.py:286-288 `f = tanh(Σ_k Δu_k / s_f + β m)`。Δu は innate.delta_u(h, M)（全人格共通）。学習した W・信念は f の引数にない（気分 m を除く）。
  - 実験 exp1: R/K/X の履歴後に同じ new_event を appraise。f = R 0.224 / K 0.560 / X 0.324（差 0.336）。h と気分を H0, 0 に揃えると 0.559 / 0.559 / 0.559（差 0.000）。
    学習していない空の NPN に各人格の h と気分だけを入れても f 差は 0.3362 で完全に一致。
  - 12 人のランダム履歴人格（exp15）でも max|f_実 − f_空NPN(h,気分同じ)| = 0.0000。f の差は 100% が欲求の状態 h（時定数約 10 更新）。
  - CHANGELOG の診断表自身が証拠: M の大きさ gM を下げると (a) の f 差が 0.336→0.052 と単調に減る。学習とは無関係。
  - 欲求の重みは全て 1（value.py: `pred.sum()`、docs/04 第3.3節の a_k が実装にない）。同じ結果は全人格で同じ Δh・同じ重みで評価される。
  - docs/04 第3.2節は「状態は人格差の担い手にしない」と決めたのに、gM=0.30 と 12 回続く同方向の事象で h が 0.49〜3.2 に振れ、h が人格差の担い手になっている。
- 最小の修正案:
  1. 人格ごとの欲求重み a（5 次元、初期 1、有界）を、外生の量（経験した |Δu_k| の遅い移動平均＝各欲求の顕著さ。W に依存しない）から更新し、f・V_MB・like（a·W）の読み出しに使う。教師は重みなしの Δu のままなので T6 の半径は 1 以下のまま。
  2. 判定の再定義（T11 swap）: h と気分を固定し、同じ経験 JSON に学習状態だけを入れ替えて f・Q・φ・更新ベクトルがどう動くかを測る。f の人格差が（空 NPN との差として）0.1 を超えることを要求。現状は 0.000 で不合格になる（それが正しい）。
  3. probe に `at="baseline"`（h=H0, m=0 で評価）を足し、T1/T2/T9 の測定から h の混入を外す。

### M1. T3 の符号反転は「継承した期待との差」の性質で、事前を持つ推定器なら構成上通る
- 根拠: 反転は K（+0.205）対 R, X（−0.065, −0.065。3 桁一致で、実質 2 群）。new_event から credit_taken を除くと K +0.235 / R +0.082 / X +0.029 で全員正（exp14）。K の履歴で場面を 8 種に変えると like −0.130、更新後 +0.112。差の符号は設計者が組んだ事象に依存。

### M2. 感情・気分が固定の 6 語で、因果的な役割がない（§3）
- 根拠: value.py emotions(): 喜び・失望・安堵・怒り・悲しみ・興味を固定公式で出す。「怒り = 人に帰属した負の寄与」等は設計者の定義。学習にも選択にも使われない。§3「特定の感情語一覧を、そのまま普遍的な内部構造とみなさない」。
- 修正案: 感情は語でなく (δ の符号, Δu のどの欲求, φ の帰属先) の組として保存し、言語化時に LLM が語を当てる。気分 m を接近確率の事前（b）か φ の事前に入れ、因果的な役割を持たせる。

### M3. 履歴 K が docs/04 第4.3節の要請（相手と場面を独立に変える）に反している
- 根拠: K の「手柄を取られた」8 回は相手が毎回新規、場面は 2 つ交互。φ_person(credit_taken) は 0.50 → 0.32（exp13）、場面を 8 種にすると 0.55 に上がる。人格 K の性質（類の価値、like −0.102 対 −0.130）が、設計者の場面の配置で動く。帰属の摂動への利得は約 1.1 で暴走はない（exp16）。
- 修正案: 形成史の生成器で相手と場面を直交に割り当て、共線な履歴を ablation として別に報告する。

### M4. 個体の類を途中で変えられない（ValueError）
- 根拠: belief.check_class。stranger が friend になる、といった関係の発達を表せない（長期の連続性、§13B。docs/04 第8節 5 も類を確率的に持つと提案）。
- 修正案: 個体を類の事後分布で持ち、類の変更を台帳上の事象にする。当面は個体 id を新規発行する運用を README に書く。

### M5. 計算量と状態サイズ（コンパニオンの長期運用に耐えない）
- 根拠（exp10）: 新しい個体ごとに特徴が増え、Σ は密行列（n²）。累計の処理時間は 100/500/1000/1500 経験（各 新個体）で 0.3/3.5/14.8/38.5 秒（後半は n^2.4 で悪化）、save 16.5 秒、state.json 72 MB（台帳が支配）、arrays.npz 19 MB。
- 修正案: 個体特徴を疎なブロック（個体の偏差は個体ごとの 1 次元の独立なガウス）にして Σ を対角＋共有ブロックに分解する。台帳は追記専用の別ファイル（JSONL）にして、state にはハッシュだけを持つ。

### M6. Q の定義がプローブ種別で非可換
- 根拠: situation は 64 サンプル MC（Q の SD 0.031）、entity は線形化した V_MB（npn.py probe）。T1 は両方を使い、T4 の persistence_Q は situation 版。初期（空）の Q は −0.08〜−0.13（Beta(1,4) と M の非対称による全人格共通の悲観）で、設計者の既定の気質。
- 修正案: Q の算出を 1 本にし（MC は同じ種で共通乱数）、初期期待の符号が M の行の和から来ていることを README に書く。

## 【軽】

- L1 保存（npn.py save）: 書き込みが非原子的（in-place）。途中で落ちると唯一の正本が壊れる。SHA-256 は完全性だけで真正性はない（改ざん者がハッシュも再計算できる。テストは再計算なしの改ざんしか見ていない）。修正: 一時ファイルに書いて os.replace、HMAC か外部署名。
- L2 T6: Jacobian は教師を固定し、信念側の φ ループを含まない（摂動実験では利得約 1.1 で問題なし）。全状態（W, 計数, π, h, m）の写像で測るのが望ましい。
- L3 回避した optional 経験では h と気分が時間経過しない（SPEC に規定なし）。長く回避を続けると状態が古いまま。
- L4 tests が tests/results/*.json をリポジトリに書き込む（テスト実行が作業ツリーを汚す）。README は REPORT.md にリンクするが未保存。
- L5 回避の決定が Q の符号に弱くしか依存しない（β_c=4, Q ∈ ±0.3 → 接近確率 0.29〜0.69）。「回避で反証が来ない」効果（熱いストーブ）を測るには強さが足りない。
- L6 同一性: 経験 id が同じなら MB 雑音も同じ（appraise と experience で同じ種）。意図どおりだが、同じ id の再利用で雑音が相関する旨を README に。

## 良い点（過小評価しないために）
- 教師が価値ネット自身の出力に依存しない設計は台帳テストで確認でき、W は台帳の総和に厳密に一致する（test_ledger_and_purity）。
- appraise/probe の純粋性、保存・復元の厳密な一致、CHANGELOG による事後変更と不合格（T2(c)）の誠実な記録。
- h と気分を揃えた swap 実験でも Q（R 0.285 / K −0.267 / X 0.030）、δ、φ、更新方向（cos 0.13〜0.45）、A への学習の向きは人格間で違う。人格の期待・帰属・更新方向が経験史に因果的に依存することは確かめられた。ただしこれは §1 の「評価基準が変わる」ではなく「期待が変わる」の確認。

## 判定: 「動く NPN の最小フレーム」と呼んでよいか
1. 呼べない。現状は「階層ベイズ型の結果期待学習と帰属の、決定的で保存可能な最小フレーム」で、NPN の核である評価基準の形成と循環が欠けている。
2. f（受け止め方）は学習状態に依存せず（h と気分を揃えると人格差 0.000）、非指定の価値判断はゼロ（like が M の履歴平均と cos 1.000）、評価は更新に戻らない。
3. NN は R/K/X の全テストで未使用（差 0.0）、使われる T8 でも 1-NN・線形と同等。20 種は実質 1 標本。
4. 基盤（台帳、純粋性、保存、決定性、不合格の誠実な記録）は再利用に値する。V1（欲求重み a と M の個人偏差）と V3（閉ループ・価値→信念の有界な経路）を足し、swap テストを判定の中心にすれば「最小フレーム」に近づく。
5. それまでは REPORT で「機構の骨格が動く」と書き、「人格が形成された」「循環が成立した」とは書かないこと。
