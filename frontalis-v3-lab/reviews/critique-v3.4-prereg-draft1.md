## 1. 思想適合 (§6)
[確認] 学習に入る主観的評価は罪悪感だけ。安堵と f_c は気分 m を介してのみ作用し (SPEC 4.1, 4.4)、τ には入らない。f_c の内部に βm があるため、気分と罪悪感の経路が RA3 の ratio に混ざる。f-clamp が「違ってよい」のは τ と気分の両方 (RA3(1))。
[確認] M3 の実体は「P_belief^τ」という指数 1 本。M1 は D_i に g_i というスカラーを掛けるだけ。
[推論] §6 が「証明にならない」と述べる係数変化に近い。RA3 は「効果の符号は問わない」で、ノルムの比 ≥0.10 しか見ない。向きが人格ごとに変わるかは RA3 では測らず、BG×clamp の交互作用も検定しない。
[推論] 向きの差は RA1 が担うが、その源は M1 の D_i と Σ（信念由来）で、v3.3 の C-v33 でも出うる。したがって RA1 と M3 は結ばれていない。さらに「評価状態」が信念なのか価値 (W・a・C) なのかを分離する検査が主判定にない。hm-eq は h と m だけを揃え、swap-G は「報告のみ」。
[推論] 罪悪感は like_前<0 かつ上昇した場合に限る。ERR-interp では A の好悪が負から上がるのは設計上ほぼ確実なので、RA3 はほぼ機械的に通る。

## 2. 開発者による答えの埋め込み (§7, §9)
- g_i∈(0,1) [確認 4.2]: 過剰な反省・過剰吸収を構造的に禁じる。§7 が研究対象とする現象そのもの。「他の経路で起きたら故障」(4.2末尾) とあり、再構成できなければ F2/F3 扱い。性質ではなく故障に分類されうる点が問題。
- D_i は「訂正後の事実で再生した教師」の差 (4.2-1)。吸収の目標が「合理的含意」に固定され、その分率しか動かせない。誤解を解かない方向（拒絶、正当化）が入らない。
- τ は単調に下がるだけ (4.5)。回復も上昇もない。§6 が挙げる「正当化の方向」「探索の方向」は構造上出ない。罪悪感は必ず自己信頼を下げる、という方向をすでに固定している。「方向を固定しない」(4.4) という文との矛盾。
- τ_min=0.2、η_τ=0.5、Beta(1,1) は全人格共通の定数。κ の更新は σ(LLR_ver) で、検証が規範的ベイズ的。信頼の歪みや恨みは入らない。
- 罪悪感は「誤って嫌っていたものを好きに戻す」方向だけ。誤って好んでいたものを嫌いに直す場合の後悔は定義がない。

## 3. 合否基準
- RA1 [推論]: (a) 8成分のどれか1つの符号逆転、または (b) cos<0.5。BG が信念と LLR を変えるので、正規化後の大きさ差だけでも (b) は通りうる。多重比較の補正は主判定の Bonferroni (97.5%) のみ。標準偏差が極小（v3.3 は種ごとに 0.29〜0.31）なら信頼区間が無意味に狭くなる。ERR-report は J8 で自ら「失敗しやすい」と予想しながら、RA1 は「両方で合格」を要求。設計時点でほぼ部分合格止まり。
- RA3 [推論]: ratio の分母は ‖CE_imm‖ で、CE_imm が小さい個体で ratio が膨らむ。Wilson の独立仮定は、同一種の9セルが共有する履歴で崩れる。実効 n は 360 ではなく ~40 (種)。RA3(3) の負の対照は own_i=0 で厳密に 0 になる設計なので情報が少ない。
- 種の独立性 [確認]: 評価種 3400〜3439 は tests/helpers の SEEDS=range(20) とは別。ただし CHANGELOG U.8 は批評者の grep で該当を拾えず、v3.3 の「種で手柄の大きさだけ変わる」は未再確認。
- 手続きの矛盾 [確認]: SPEC 5.1 は評価種を「実装中は実行しない」とするが、PLAN Stage 1(c) は評価種で C-v33 の Y1〜Y7、N 掃引、RC1〜RC3 を実行する。M1〜M3 の実装より前に結果が見えるので、評価種が汚染される。
- 抜け道 [確認]: RA11 は「検出できない変異体があれば、評価の前に検査を足してよい」。J7 は凍結後に M2/M3 を直してよいか尋ねる。ともに事後的な柔軟性。RA7(b) は v3.3 の 0.8 閾値を残し、J5 の議論と食い違う。RA4(c) の 0.005 と「18 中 12」は根拠なし。

## 4. F1〜F6
概ね機構の破綻に限られており、固執や抵抗は故障にしていない。
- F6/RA8 [確認]: 更新の符号が sign(教師−予測) と一致する、というだけ。どんな delta 則でも成り立ち、Σ が縮んで更新が実質ゼロでも（0 でない欲求のみ対象）通る。飽和の検出になっていない。
- 欠落 [推論]: τ が τ_min に張り付く（MU6 で変異体にはあるが基準がない）、κ の Beta 計数の単調増加による固定化、気分の βm→f→m のループの有界性。
- F5/RA12: 同じ類の B の好悪が、類の共有特徴で動いた場合は転移であって崩壊ではない。閾値 (max(50%,0.05)) は恣意的。上昇も「崩壊」に数える点が不自然。

## 5. 因果設計
- 分離できていないもの: (i) f-clamp は気分と τ を同時に切る。気分だけを切る条件、罪悪感だけを切る条件がない。(ii) C-v34 と C-v33 は M1/M2/M3/時計/気分を同時に変える。4.1 だけの A-clock-off がない。(iii) 信念の差（事実モデル）と評価状態の差が RA1 で混ざる。(iv) τ は類×文脈キーで、FOL(b) の A2 が同キーを共有するため、転移と直接効果が分かれない。(v) 全条件を C-v34 の SD で正規化。
- 追加すべき: 信念を固定して W・a・C だけ入れ替える条件、気分/罪悪感の個別 clamp、プラセボ τ（別人の罪悪感を同量で）。

## 6. §4 と J6
Y 系の入力は構造化 JSON で、q_LLM は U(0.4,0.6) の合成値。形成側の検証としては許容できるが、「NPN の状態だけを替えて判断が変わる」という §4 の検査は未実施。保留は許容、ただし期限を事前登録に書くこと。Stage 5 の後、かつ既定モード変更の判断と X 系の事前登録より前に、同一 LLM・同一プロンプトで τ/κ の状態だけを入れ替える試験を置く。LLM に渡す読み出しの定義を今決めておく。結論には「形成」「人格」を書かない（既にそうなっている）。

## 8. 凍結前に必須の3変更（重要度順）
1. 循環の検査を向きで定義し直す。RA3 を大きさの比から「人格間で L_fol の向きが変わるか (BG×clamp)」へ。気分経路と罪悪感経路を分離。W・a・C だけを入れ替える条件を主判定にする。τ を双方向に動かせるようにする (J1)。
2. 評価種の汚染を断つ。PLAN Stage 1(c) を開発種に変えるか、別の予約種を設ける。RA11 の「検査を足す」、J7、RA4(c) の閾値に期限と記録義務を課す。統計の単位を種 (n≈40) に明記。
3. g_i<1 と単調 τ を「過剰な反省」の研究から締め出さない。g を上限なしにした条件や、拒絶・正当化の方向をもつ τ の条件を、故障でなく性質として事前登録する。RA8 は更新量の下限（飽和）と τ_min 張り付きを検出するよう強化。
