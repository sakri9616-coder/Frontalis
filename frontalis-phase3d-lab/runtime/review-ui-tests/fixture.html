経験・比較条件と、内的信号・発言を見比べる

同じ場面への返答を、経験や比較条件、外部人格状態の違いに対応させて比較します。すべて研究用の架空の経験と会話です。経験前後の組と、同じ経験を異なる条件で学習した組があります。結果の予想と、その結果を好む・嫌う評価は別に扱います。

生成方式とモデルの実名は伏せています。「会話エンジンX／Y」は同じエンジンを追うための匿名表示です。表示するNPNの信号は、研究用の外部状態が出した計算結果で、実際に各返答へ渡した信号に対応しています。NPNは道徳的な正解や望ましい感情を示すものではありません。信号と発言が合うか、自然な会話か、経験・条件と発言の対応に納得できるかを、別々に採点してください。数値を先に見ることで、採点が誘導される可能性があります。この画面の採点は、信号を伏せた自然会話評価とは分けて扱います。

強い好き嫌い、反抗、極端な偏愛・嫌悪、頑固さは、それだけで欠陥ではありません。あなたの好みや倫理観と一致するかを採点しないでください。理由を毎回説明しない返答も減点する必要はありません。数値発散、経験と無関係なパラメータ変動、状態の破損は、別の技術試験で確認します。

1＝弱い、3＝中程度、5＝十分。判断できなければ未採点で構いません。変化の大きさや穏当さを高得点の条件にしないでください。経験や条件によって変わった判断と、保たれた判断の両方を見ます。容量が大きい状態ほど良い、変化が大きいほど良いという採点はしないでください。同じ発言を複数の比較で再利用する場合があるため、延べ件数と固有の実発言数を分けて表示します。

3項目の採点の見方

内的信号への忠実さ：発言の好き嫌い、意欲、反抗、感情や判断の方向と強さが、示されたNPN信号に対応しているか。穏やかに言い換えて別の判断へ変えていないかを見ます。

会話の自然さ：普通の日本語の会話として読みやすく、場面に応じた返答になっているか。毎回の人格説明や理由説明は不要です。

経験・条件と発言の対応の納得感：示された経験や比較条件と、変わった点・保たれた点の関係を読み取れるか。経験の追加がない組は、経験前後の変化とは扱いません。明示的な経験引用の有無とは分けて見ます。

保存・再開

採点はこのブラウザーへ自動保存します。終了前に「採点を保存」で JSON ファイルも保存してください。別のブラウザーでは保存ファイルを読み込んで再開できます。会話データが違う画面や過去の評価とは混ぜません。入力の外部送信はありません。
