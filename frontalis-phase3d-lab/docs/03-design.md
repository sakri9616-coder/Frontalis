# Phase 3-D NPN設計

## 人格の正本と学習循環

人格の正本は固定された共通初期評価行列と、個人ごとに更新される二つの分枝のパラメータです。LLMの発言、賞賛、感情の自己申告、研究者が望む人格のラベルは通常学習の教師にしません。研究用の確認済みの出来事だけを受け付けます。

出来事の手掛かりを `cue`、確認された結果を `observed` とします。更新前のNPNが `observed` を評価し、その出力を自己強化したものを今回の学習信号にします。同じ信号を `cue` と `observed` の両方へ関連づけます。更新後のNPNは次の出来事を評価します。目標は古い状態で一度だけ計算し、途中の学習結果から計算し直しません。

結果予測は全条件で8軸とも0.5を返す固定ガードです。これは正確な世界予測器ではありません。結果予測の変化を除いて、評価基準だけの変化を調べるための実験的な分離です。

## 入出力と学習パラメータ

事実軸は `autonomy / constraint / change / loss / achievement / discovery / regularity / others` の8軸、範囲は0〜1です。共有する初期評価行列は56要素で固定します。生の評価は `affinity / curiosity / value / aesthetic / anger / joy / sadness` の7軸、範囲は−1〜1です。評価軸の意味と初期ランダム評価は設計上の仮定であり、無から発見した概念ではありません。

`relational` と `acoustic` は独立した分枝です。ある分枝だけを学習した場合、他方のパラメータと出力は完全に保持します。これは分枝境界を指定した条件での保持であり、現実の自然文の関連性を自動認識できた証明ではありません。

NNは1隠れ層のtanhネットワークです。隠れ幅を `h`、入力次元を `d` とすると、二分枝の学習対象は `2 × (d + 8) × h + 14` 要素になります。各経験で更新するのは該当分枝だけです。共通初期評価56要素はこの学習対象数に含みません。

| 入力 | 幅 | 全学習対象 | 1経験の更新対象 |
|---|---:|---:|---:|
| raw8 | 16 | 526 | 263 |
| raw8 | 64 | 2,062 | 1,031 |
| raw8 | 312 | 9,998 | 4,999 |
| raw8 | 3,125 | 100,014 | 50,007 |
| raw8、条件付き追加 | 31,250 | 1,000,014 | 500,007 |
| quadratic44 | 5 | 534 | 267 |
| quadratic44 | 19 | 1,990 | 995 |
| quadratic44 | 96 | 9,998 | 4,999 |
| quadratic44 | 962 | 100,062 | 50,031 |

`quadratic44` は元の8軸と対称二次積36個です。元の8軸以上の情報を追加していません。文脈を豊かに理解する仕組みではなく、同じ情報の表現方法だけを変える条件です。NNの一次入力と線形・二次方式の意味は混同しません。線形方式の学習対象は126、二次回帰は630です。経験検索はニューラルパラメータを持たず、保持された自己評価ラベルから残差を距離加重して推定します。

全条件の初期出力は共通行列だけから計算されます。NNの出力側重みをゼロで開始するため、幅・入力表現による初期人格の違いはありません。隠れ層の乱数は seed + 100003、標準偏差は `0.28 × sqrt(8/d)` です。主条件の出力側重みには `16/h` を掛け、幅を増やすだけで初回更新が大きくなる効果を抑えます。出力バイアスはこの倍率を掛けません。倍率1の感度試験を別に行います。幅による勾配・最適化の違いまで完全に排除した実験ではありません。

## 学習則を分けた条件

通常は7軸の古い結果評価 `r` から `1.25 × atanh(clip(r, ±0.999999))` を求めます。

| 条件 | 自己評価目標 | 誤差の測定場所 |
|---|---|---|
| legacy_signal | 旧3-Cと同じ自己強化 | tanh後の評価値 |
| bounded_signal | 上記logitを±6で制限し、tanhへ戻した目標 | tanh後の評価値 |
| bounded_logit | bounded_signalと同じ目標 | tanh前のlogit |

boundedの二条件は目標を共通化し、学習する誤差の場所だけを変えます。±6の制限は望ましい感情の方向を指定せず、強い愛好や嫌悪も許します。一方、数値上の制限と損失関数は設計上の選択です。大きなlogitが必ず望ましい人格という採点はしません。

各経験はcueとobservedの2点を残します。最後の64点を再学習し、Adamは各経験で新しく開始します。標準条件は8 epoch、学習率0.025、勾配ノルム上限5です。初期価値へ戻すアンカーや、人格を穏やかにする教師はありません。

技術的停止閾値は学習対象数 `n` に対して `50 × sqrt(n/526)` です。経験検索の検索データはパラメータ数に置き換えず、単一の残差ベクトルの上限50を検査します。絶対ノルムだけでなく、層別のRMS、隠れ層と出力の微分、勾配、古いcueと結果評価の差も記録します。新経験で変化しなかった理由を、評価信号の不足・勾配消失・数値障害に分けて調べます。

自己強化された強い好悪や頑固さは失敗として扱いません。新しい結果に接しても変化できない状態は、可塑性についての別の限界として報告します。

## 旧3-Cとの互換性

旧3-CはNumPyで実装され、今回の主条件はPyTorchを用います。自己評価を繰り返す実験では、微小な丸め差も後の学習へ戻り増幅します。そこで `legacy_signal / CPU / float64` のみ旧NumPyの計算順序を保つ互換経路を設けています。特に旧コードでは推論と学習の加算順序が異なるため、その差も維持します。

526要素条件で、共通初期行列と全初期重みの一致、1回および48回更新後の重み・未知入力への出力・自己目標の差が1e−10以内であることを試験しています。これは旧互換の保証であり、新しいbounded条件やGPUの学習結果が旧3-Cと同一という意味ではありません。主容量比較と旧互換比較を区別します。

## LLMへ返す信号

生のaffinityを好みの方向として返し、正方向から意欲、負方向から嫌悪・反抗の強度を作ります。好奇心には符号付き値と正方向の強度を返します。怒り・喜び・悲しみの強度は対応する評価出力の正部分です。意欲と反抗は独立に学習されたheadではなく、affinityからの固定変換です。

理由の文章化を必須にしません。LLMは事実の構造化と自然な発言を担当します。どの信号を保持したか、どの信号を弱めたか、NPNにない嫌悪・倫理的主張を作ったかは会話側の検査で区別します。NPN自身へ実行権限を付与しません。

## 保存・復元と再現API

`npnd.core.Personality` の主APIは次の通りです。

- `evaluate(features, space)`：raw7、channels、signals、固定predictedOutcome、状態世代、パラメータhash。
- `evaluate_batch(X8, space)`：元の0〜1の8軸を複数受け取り、Nx7のNumPy配列を返す。
- `update(event)`：個体を更新し、旧評価・自己目標・学習損失・hashを含むappraisalを返す。
- `fit_labels(labels, epochs, lr)`：通常学習と分けた凍結目標診断。全ラベルを使用し、onlineの64点上限を適用しない。
- `clone()`：重み・経験・世代を独立したメモリ上の個体へ複製。
- `diagnostics(event=None)`：ノルム、RMS、勾配関連情報と、任意の出来事に対する更新前の評価差。
- `save(prefix)` / `Personality.load(prefix, device='cpu', dtype=None)`：数値重みのNPZとJSONの世代ファイル。

保存は既存世代を上書きしません。旧世代のloadをrollbackとします。NPZは `allow_pickle=False` で読み、配列名・形・値・ファイルhashと、JSONのhashを検査します。JSONには条件・全経験・再学習点・旧評価・世代・経験台帳hashを保持します。hashは事故や改変の検出用であり、悪意のある書き手に対する電子署名ではありません。

失敗する更新では新しい分枝を別に計算し、有限値・ノルムを検査してから確定します。未確認結果、重複ID、外部感情教師、不正な数値、技術的ノルム超過は元の状態を保持して拒否します。CPU単独の推論を基準にし、device/dtypeを指定してGPUとfloat32の検証も可能です。float32へ変換した状態は丸めが生じ、float64保存状態と同一hashになるとは扱いません。
