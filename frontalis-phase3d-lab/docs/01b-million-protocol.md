# 100万版：条件付き追加試験の固定

2026-10-15。336セルの検証のみを終え、事前ゲート `capacity-gate.json` が成立した後、100万版の結果と最終評価を見る前に固定する。ゲートの改善率は25.6007%、3環境とも改善。これは人格形成全般の成功ではなく、既存評価関数の近似診断における拡張条件である。

追加モデル：raw8、隠れ幅31,250、1,000,014学習パラメータ、固定初期評価56個。読み出し16/h、CPU float64、1スレッド、初期seedと学習条件は既存系列に合わせる。入力や層数を同時に変更しない。

1. 同一教師診断：訓練192・検証64・最終256、3物理条件×4教師出自×plain/composed＝24セル。すべて既存5学習率候補・128epochで選択する。全24セルを保持し、NNが勝ちそうな部分だけを選ばない。独立CPU1thread workerによる並行実行は処理順を変えるだけで、各モデルのデータ・精度・学習率は変えない。
2. 通常の人格形成：seed4311、4経験系列×信号/logit損失＝8条件、同じ96経験と24/48/96測定、反対結果12・別枝12の介入。主192状態とは分けて報告し、この1seedだけで一般性を主張しない。
3. 長期自己強化：seed4311系列0、2損失、同じ1,000反復と反対事実12/48/96を計測。主24ストレス条件とは混ぜない。
4. 性能：CPU64/GPU64/GPU32を実測。GPU32は精度の異なる補助試験。GPU保存→CPU復元と独立再学習を区別する。
5. 会話：信号損失、seed4311系列0/1、約束/トロッコ各2＝4発言×既存無料2モデル、計8発言を追加。生成前に追加live-planを固定する。初期・526・2k・10k・100kの既存回答は上書きしない。20件の重点採点画面は事前選択のまま維持し、追加8発言は別資料として示す。
