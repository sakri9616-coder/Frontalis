# 数値実験：容量・入力表現・学習則を分けて調べる

この資料は実験方法と結果の読み方を示す。主たる比較条件は結果を見る前に固定し、実行後の数値は `reports/numeric-summary.json` と対応させて追記する。

## 何を「改善」と呼べるか

人格には共通の感情的正解を置かない。4系列は同じ初期評価から始まり、同じ出来事について異なる結果を経験する。各モデルが自分の以前のパラメータでその結果を評価し、それを学習信号にする。このため、異なるモデルが作った学習結果を一つの感情教師との誤差で順位づけることはしない。

代わりに、経験前からの変化、系列間の分化、選好と好奇心の逆方向の反応、尺度間の関係、追加経験への変化、無関係な枝の保持、勾配と数値の安定性を別々に測る。変化が大きいほど良い人格、分散が大きいほど高度な人格、極端な好悪ほど悪い人格、という採点はしない。

NN固有の表現能力は、共通の凍結評価関数を各方式がどこまで近似できるかという別実験で調べる。これは人格の正解率でも、次の物理的結果を予測する能力でもない。

|---|---:|---:|

二次展開は8軸とその自己積・交差積であり、新しい経験情報は加わらない。容量をほぼ揃えた比較で、同じ情報の表現方法の効果を調べる。44入力は自然言語の理解が豊かになったという意味ではない。

全NNで共有の初期評価56係数は固定。関係領域と音領域の2枝の隠れ層・出力層が人格ごとの更新対象となる。隠れ層幅による最初の更新幅の増大を抑えるため、出力の残差に `16 / 隠れ幅` を乗じる。これは学習の尺度を揃えるための事前仮定であり、容量に対して完全に等価な最適化を保証しない。

損失の比較は、同じ旧NPN評価・同じ増幅1.25・同じ目標logit範囲±6から、(1)有界信号の誤差を学習する方式と(2)logit誤差を学習する方式を使う。後者は出力tanhの微分が小さくなる問題を避けるが、隠れ層の微分や、既存の評価基準自体が新しい結果を同じものと評価する問題まで解消するとは限らない。

CPU、float64、1計算スレッド、経験ごと8反復、Adamを経験ごとに初期化、学習率0.025、直近64学習点（概ね32経験）を再生する。物理的結果の予測は全条件で常に0.5の固定値であり、価値の分化は予測器の更新によるものではない。この固定値に予測精度があるとは主張しない。

線形126係数、二次回帰630係数、経験検索も3初期乱数×4系列の36条件で同じ循環を実行する。検索にはニューラルパラメータはないが、保存する経験残差が変わる。方式の比較は8軸そのまま・logit損失のNN列と行う。線形方式と二次方式はこの列と同じオンライン損失・更新回数を使う。有界信号損失の列はNNの容量・損失の切り分けに用い、損失が異なる単純方式との優劣には使わない。

## 分化・複雑さ・継続性

- 形成：初期状態から未知入力の7尺度がどれだけ変わったか。学習停止対照ではパラメータ・出力が完全に一致するか。
- 分化：同じ乱数の4系列に同じ未知入力を提示し、系列間の平均絶対差を測る。
- 機能分化：選好・好奇心の双方の絶対値が0.05を超え、符号が逆になる入力を数える。命名された7尺度は開発上の仮定であり、感情概念の自然発生とは呼ばない。
- 複雑さの手がかり：入力ごとの7尺度の共分散と有効ランクを示す。これは出力関数の多方向の変化の指標であり、人間の人格の豊かさを直接測る尺度ではない。
- 判断：未知の8場面、選好・関心・価値による4組の選択肢を記録する。選択肢には望ましい倫理の正解を置かない。トロッコの例は変更の程度と死者数の葛藤を8軸へ注釈したもので、同意・行為責任・普遍倫理の推論能力を実証するものではない。
- 保存復元：同じCPU精度でパラメータhashと未知入力出力が完全に一致するか。

## 追加経験による介入

全主条件で、異なる物理的結果を伴う関係領域の12経験を加え、未知入力への変化を測る。同じ枝で追加経験の特徴から近い入力と遠い入力を同数で比較する。近傍距離と変化量の対応は記録するが、近い経験が引用されたことを因果性の証拠にはしない。

別に、音領域の12経験を加え、関係領域のパラメータと出力が完全に保持されるかを測る。これは事前に領域の枝を分けた構造による保持であり、現実の出来事が意味的に無関係であるとモデルが自律判定した証拠ではない。

1・10・100・1,000回で出力・パラメータのnorm/RMS・飽和率・勾配・出力と隠れ層の微分を保存する。反対結果の前に、旧NPNが場面と結果をどれほど違うものと評価したかと、その自己評価が更新信号を残しているかも記録する。

出力が極端になったことや変化しないこと自体で失敗としない。新しい事実に対して更新信号があるのに勾配が消えて動けない場合、既存評価自体が二つの結果を同じものとして扱う場合、経験への頑固な反応が保たれる場合を区別する。有限値・非常停止norm・無関係枝の保持は技術的検査として扱う。

## 共通の凍結関数による容量診断

Phase 3-Cの線形・二次・非線形の物理環境で形成したNN・線形・二次・検索の各評価関数を凍結する。教師の方式由来の有利さを隠さず、全4由来を等しく重みづけする。

後者は入力の軸を数学的に入れ替える診断課題であり、自然な経験の意味は持たない。容量の効果を見えやすくする可能性があるため、単一評価の結果と併記し、NNが得意な課題だけを人格形成の成功例にしない。

訓練48件と192件、検証64件、最終評価256件を分離する。各方式で5個の候補を検証誤差だけで選ぶ。

三つの現象を分ける必要がある。

1. **旧基準が新しい事実を似た意味に評価すること。** 反対事実を初めて受ける時の「旧場面評価と新結果評価の差」は100k信号で0.01680、100k logitで1.99608。学習信号の絶対差も0.00579と1.99905で違う。物理的な結果が反対でも、感情の方向まで反対になる正解は設定していない。旧基準が似たものと捉えたことは人格の循環の結果であり、単独で技術的故障と呼ばない。
2. **更新できるが未知判断が変わらないこと。** 10k信号の反対12後は勾配norm平均0.000835、実更新RMS平均0.02815であり、全学習が停止したわけではない。それでも未知入力変化は0.00323。状態の更新と未知状況への転移を混同しない。
3. **信号損失で勾配が小さくなること。** 100k信号の反対12後の勾配normは平均1.24e-8、実更新RMSは0.000470。96後は5.24e-10と0.0000466まで下がった。出力tanh微分は96後平均3.28e-5だが、隠れ層微分は0.849で、隠れ層全体が飽和して動けなくなったわけではない。出力飽和・幅規格化・小さい自己信号が重なった条件である。極端な好悪自体を不具合にせず、更新信号・勾配・実更新・出力変化を個別に記録した。

保存状態を変えない層別勾配の追加観測を `reports/numeric-stress-gradient.json` に保存した。これは保存後の固定replay損失に対する探索的診断であり、更新当時の最終勾配とは異なる。100k信号の1,000反復後、w1/w2の勾配RMSはseedにより約3.6e-15〜1.2e-14、bias出力は約1.9e-12〜2.6e-12だった。反対96後もw1/w2は約3.2e-13〜6.1e-13。全層の勾配は有限値で、完全なゼロではなかった。Adamの分母にある1e-8との尺度差を含む更新の弱さを確認できるが、これだけで一つの原因に限定しない。

**この研究系列では、容量増加より学習則と自己評価の循環が長期可塑性を左右した。** 強い好悪が残ることは許容するが、望んだ場合にも変化できる構造が全条件で成立したとは言えない。Phase 3-Cの無制限信号条件とは目標範囲±6と反復条件が違うため、過去の数字を今回の改善率に直接使わない。

#### 装置・実装環境の校正

最初に、完成済みCPU100万の非線形環境・線形教師・単一課題をGPUで再計算した。5候補の検証MSE差は最大5.20e-18、選択学習率は両方0.025、検証出力の最大差4.16e-15だった。GPU計算18.84秒に対し、保存済み並行CPUセルは223.03秒だった。これは当時の負荷を含む診断処理時間であり、専用性能試験のCPU/GPU速度比へ転用しない。

完成後には全24CPU100kと保存済みCPU100万6セル、計30セルを校正した。選択学習率変更は0/30。検証MSE差は最大3.89e-16、検証出力差は最大1.18e-13。原CPU100kの最終MSEとGPU100kの最終MSEの差は24セルで最大1.74e-16、同じ保存モデルを新環境CPUで読んだ最終出力とGPUの出力差は最大1.17e-13だった。

CPUの主学習はTorch2.14.1+cpu、GPU追加は新ラボ専用Torch2.7.0+cu128であり、装置とライブラリ版が両方異なる。小さい校正差はこの固定ラベル近似診断で確認されたものである。自己評価を反復するオンライン学習の完全なbit一致を仮定しない。CPU100万の診断24セルが完了したという報告もしない。GPU全48の最終出力を、CPU途中の6セルへ混ぜて集計していない。
