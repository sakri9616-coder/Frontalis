## 0. 結論（先に）

- 検討した方式は P0（既存案: 判別的な予測ネット）に加え、A 階層ベイズ、B 潜在原因（CRP混合）、C 帰属の事後推論、D 後継特徴、E 逆計画（心の理論）、F 階層的ガウスフィルタ（変動性推定）、G 自己モデル（情動予測）の8つ。
- **最有望は「スコープ帰属つき階層ベイズ信念」（以下 SAHB）**。結果型ごとに、その確率を「相手個人」「場面」「一般（人は皆）」のどの単位が担うかを推論し（C）、各単位の確率は上位から事前分布を受け取る階層ベイズ（A）で持つ。更新量は変動性に応じて割引く（F の簡約）。価値ネットとの界面は、予期 Q = 結果型の確率 × 予報価値の双線形形式（D の γ=0・2次特徴版）にする。
- 理由は四つ。(1) H4 の3つの符号（少数で広い・同じ相手で狭まる・多様な相手で広いまま）を同一原理（証拠は交換可能な単位ごとに数える＝部分プーリング＋スコープ推論）から出せる。(2) 履歴差の持続と新経験への可塑性を「評価する単位」を分けることで両立できる。toy では、未見の相手への履歴差が新経験8回後に 89% 残る一方、新しい相手自身の推定は 0.68 → 0.09 まで動いた。比較として、単層の計数学習は新しい相手への推定が 0.68 → 0.43 で止まり、固定率 α=0.25 の単層学習は履歴差が 10% しか残らない（3-F の「8回で消滅」と整合）。(3) 信念と価値を別パラメータ・別誤差（世界の誤差 vs δ_V）にでき、H7 を数学的に満たす条件が明示できる。(4) H5・H6 は「価値→信念チャネル」のON/OFFに還元でき、E4 の入れたり切ったりする設計と一致する。
- **残る最大の弱点**は、離散的な足場（結果型辞書・関与者の同一性・行為者タグ・場面クラス）をLLM抽出に依存し、足場の誤りが系統的な信念として学習されること、および足場の外（未知の結果型）へは一般化できないこと。H4 の大きさも、設計者が置く事前（人は互いに似ている度合い κ、人か場面かの事前）に左右される（toy で 0.30〜0.70 の幅）。SAHB 全体の数値実験は未実施で、根拠は A・B の toy と理論である。
- 他方式の位置づけ: B は急な反転時にスコープを割る拡張、D は価値との界面だけ採用、E は意図の推定として第2段階、F は学習率の簡約版、G は自己予報誤差の診断のみ。

## 1. 前提と共通の枠組み

### 1.1 入力（LLMが取り出すもの）と信念ネットの出力

```
イベント t
  c_t     状況（凍結文埋め込み→人格ごとの概念射影）
  E_t     関与者の集合（匿名ID。人格ごとに学習する関与者ベクトル x_e）
  O_t     結果の部分集合 {o_tj}（LLMが分割。各部分は文埋め込み z(o)）
  a_tj    各部分の行為者タグ（LLM抽出: 自分／関与者 e／世界）   ← 誤りうる入力
  I_t     曖昧な出来事の解釈候補 {I} と重み q_LLM(I | 文)   （LLMは信念を知らない「素の読み」）
結果型辞書 D = {μ_k}, k=1..K   凍結埋め込み上のオンライン原型（DP-means 風。K は増える）
  結果部分 o の型への割当  g_k(o) = softmax_k( −‖z(o) − μ_k‖² / 2σ_D² )
```

信念ネットの出力は、方式により次のどれかになる。共通するのは「測定時に候補文を型に割り当てて確率を読む」点である。

```
候補文 s_cand の確率（測定専用）  b(s_cand | c, e) = Σ_k g_k(s_cand) · P(y_k = 1 | c, e)
```

注意: 候補文の確率は、プローブが選んだ候補集合に依存して相対化される。外れ値文（無関係な結果文）を同時に提示し、その確率を基準に較正する。辞書 D の外の結果は最近傍型に吸われるため、辞書の粒度が読み出しの上限になる。

### 1.2 価値ネットとの共通界面（全方式で共通。予期と驚きの分解）

価値ネットは2つの読み出しを持つとする。

```
V̂_φ(o | c, e)      予報ヘッド: 事前に分かる情報（結果の型と関係の文脈）だけで「どう感じるはずか」
f_t = V_φ(o_t | c_t, e_t, 気分, 帰属)   実際に感じた価値（事後評価。学習則は問1の領分）
予期     Q(c, e) = E_{o ~ P_θ(・|c,e)} [ V̂_φ(o | c, e) ]      （集合値の結果は予測分布から m=16 個サンプルして平均）
驚き     δ = f_t − Q  =  δ_V + δ_W
   δ_V = f_t − V̂_φ(o_t | c,e)                         価値の誤差（結果は想定どおりでも感じ方が違った分）
   δ_W = V̂_φ(o_t | c,e) − E_{o~P_θ}[ V̂_φ(o | c,e) ]     世界の誤差を価値の単位に射影した分
```

恒等式なので常に成り立つ。後継特徴の TD 誤差（γ=0）や、状態予測誤差と報酬予測誤差の分離（Gläscher et al. 2010）と同じ構造である。

重要な点が2つある。

1. **信念ネットの学習誤差は δ_W ではなく結果そのものの対数損失** L_B = −log P_θ(o_t | c_t, e_t)（適正スコア則）にする。δ_W = 0（結果が予測と違うが価値は同じ）でも世界の予測は外れており、それは学習されるべきだからである。これが「信念だけ変わる経験」を作れる理由になる（2.2）。
2. 価値ネットに渡す誤差は δ_total ではなく **δ_V に限る**。δ_total を使うと信念の変化が価値の更新に漏れ、H7 が崩れる（2.2 の条件 S2）。

### 1.3 学習率の決まり方の分類（各候補で使い分ける）

| 型 | 学習率 | 性質 |
| --- | --- | --- |
| 固定率 | α = 一定（3-F、試作） | 縮小写像。履歴を (1−α)^n で忘れる |
| 計数（ベイズ） | α = 1/(κ + n_eff + 1) | 安定。n が増えると可塑性を失う |
| 不確実性（カルマン利得） | α = Σ/(Σ + R) | 事後分散で決まる。観測が増えると下がる |
| 変動性（HGF 等） | α = 1/(予測分散の逆数に変動性を足したもの) | 履歴が学習率自体を決める |
| 責任配分 | α = r_x/(n_x + η) | 原因単位 x への責任 r_x を掛ける |
| 価値依存（V→B） | α± 、尤度の冷却 w(f) | 望ましさ・感情価で変わる |

### 2.2 H7（価値と信念を独立に変えられる）の数学的条件

経験 x（結果、相手、場面、気分の組）を1回与えたときの、信念プローブ群 B(h) = [P_θ(y_k=1 | c_p, e_p)]_p と価値プローブ群 W(h) = [V_φ(o_q | …)]_q の変化を ΔB = G_B(x)、ΔW = G_W(x) と書く。H7 が成り立つとは、同じ人格状態から

- **信念のみ**の経験 x_B（‖ΔW‖ ≤ ε‖ΔB‖）
- **価値のみ**の経験 x_V（‖ΔB‖ ≤ ε‖ΔW‖）

が両方作れることである。必要条件は、x に関する (ΔB, ΔW) のヤコビ行列の階数が2であること。信念と価値が1つの量の関数（例: 信念＝予測された価値、TD 価値のみの学習）なら階数1で H7 は偽になる。十分条件は次の5つ。

| 条件 | 内容 | 破る例 |
| --- | --- | --- |
| S1 パラメータの分離 | θ ∩ φ = ∅。共有する概念射影は、片方の損失の勾配が他方の読み出しを動かさないようにする（stop-gradient、または別射影） | 信念と価値が同じ射影を共同で学習 |
| S2 誤差の分離 | 信念の損失は φ に依存しない（∂L_B/∂φ = 0）。価値の損失は予期 Q を含まず δ_V だけ（∂L_V/∂θ = 0） | δ_total で価値を更新する（信念の変化が価値に漏れる）。VB4 の重みに f を使う |
| S3 信念のみを作れる | 価値の零空間が非自明: V̂(o) = V̂(o′) かつ o ≠ o′ の結果対がある（結果特徴の次元 d > 価値チャネル数 K、または V̂ が中立域を持つ）。例: 「頼りにはならないが優しい」と「頼りになるが冷たい」を同じ価値にしておく | 価値が1次元で結果が1次元（結果の同一性と価値が同じ） |
| S4 価値のみを作れる | 信念が飽和（P(o∣c,e) ≈ 1、categorical の対数損失の勾配 p − 1_o ≈ 0）しているのに δ_V ≠ 0 を生む経験。完全に予期した出来事を、価値観・気分が変わった後で再経験または想起して再評価する | 信念が常に平滑で、どの結果も驚きを含む（平滑化 ε が大きい） |
| S5 横結合が小さい | VB2〜VB6 と BV5・BV6 のうち有効にしたものを記録し、E4e では切った対照を置く。漏れ指数 L_V←B = ‖ΔW‖/‖ΔB‖（信念のみの履歴）と L_B←V = ‖ΔB‖/‖ΔW‖（価値のみの履歴）を報告する | 結合を全部ONにして「両方動く」と報告する |

読み出しの注意: 予期 Q = E_p[V̂] は信念が変わっても価値が変わっても動く（同じ選択データからは確率と価値は識別できない、というリスク下の選択の古典的問題）。H7 は Q ではなく、信念プローブ（候補文の確率）と価値プローブ（評価の直接読み出し）を別々に読むことで検証する。

### 2.3 結合の暴走を測る（影の信念と正帰還の利得）

- **影の信念（shadow belief）**: 同じ観測済みイベント列を、V→B のチャネルを全部切って再生した信念 θˢ を並走させる（回避された未観測の試行は再現できないので、シミュレーション環境では反事実の再生を併用）。乖離 D = KL(P_θ ‖ P_θˢ) をプローブ上で測り、証拠が増えていないのに D が増え続けたら暴走とみなす。
- **正帰還の利得**: V→B と B→V の連鎖（例: 悪い結果 → 他者に帰属（VB5）→ 他者の価値が下がる → 次の曖昧な出来事をその他者のせいにする（VB3））を線形化した利得 g = α · ρ · η · ∂Q/∂θ。g < 1 なら収束、有界な正帰還で g > 1 なら双安定（履歴で選ばれる吸引域＝ヒステリシス＝良性の持続）、非有界で g > 1 なら暴走。オーケストレーターの解析メモ N4（dv = α(−v + g tanh v + u)）と同じ構造で、信念側でも「有界な正帰還がヒステリシスを作る」ことが持続の候補になる。

## 3. 履歴差の持続と可塑性: なぜ 3-F で消え、何が解消するか

### 3.1 単層・固定率の学習は縮小写像である
θ_{t+1} = θ_t + α(x_t − θ_t) では、2つの履歴の差 Δ は Δ_{t+n} = (1−α)^n Δ_t で縮む。α = 0.25、n = 8 なら 0.100（toy: 10% しか残らない）。3-F で「新経験8回で履歴差が消えた」ことと整合する。α = 0.10 でも 43% で、持続させようと α を下げると新経験への可塑性が下がる。

### 3.2 計数（1/n）は持続するが、可塑性を失う
ベイズの計数学習は履歴を保つ（toy: 64% 残る）が、新しい相手に対する推定が履歴に引きずられる。本来 0 に近いはずの推定が、過去に手柄を取られた人格では 0.68 → 0.43、取られなかった人格では 0.07 となり、十分に動かない。持続と可塑性は同じ1つのパラメータで両立できず、これが「安定性と可塑性のジレンマ」である。

### 3.3 解の3族（候補方式との対応）
1. **階層分割（A, C）**: 持続は上位（一般・場面）、可塑性は下位（相手個人）が担う。上位の有効標本数は経験の数でなく「交換可能な単位の数」（相手の数）なので、1人の新しい相手と8回やり取りしても上位は 1/(N+1) 程度しか動かない。
2. **構造分割（B）**: 反証を旧い原因の上書きでなく新しい潜在原因として保存する。旧い痕跡は残り（再発、自然回復、節約）、新しい原因が可塑性を担う。代償はコンパートメント化（旧い文脈では旧い信念が訂正されないまま）。
3. **メタ学習率（F）**: 履歴は点推定ではなく学習率（変動性の推定）に残る。安定な履歴の人格は遅く、変動の多い履歴の人格は速く更新する（頑固さの個人差）。

### 3.4 測り方の提案（持続と可塑性を別の単位で測る）
- **持続** = 未見の相手（または未見の場面）に対する予測の履歴差の保持率。
- **可塑性** = 反証を受けた相手（文脈）自身の予測の更新量（真値への近づき）。

同じ人格について両方を報告し、どちらか一方だけが基準を超えても両立とは言わない。この定義は E4d の「その相手への獲得価値が追いつくか残るか」と整合する。

### 3.5 検証できる予測（toy から）
同じ8試行でも、履歴が1人の相手由来か8人由来かで、未見の相手への履歴差の保持率が変わる（A 方式 toy: 1人 70%、2人 75%、4人 82%、8人 89%）。「経験の数でなく相手の多様さが持続を決める」は、flat な計数や固定率の方式では出ない（交換可能性により多様さは無関係になる）。H2・H9 の判別にも使える。

## 4. 候補方式（各8項目）

判定記号: ◎ その方式から自然に出る ／ ○ 追加の仕組みやパラメータで出る ／ △ 弱い・条件付き ／ × 出ない。H4（少数経験の過剰一般化と、同じ相手で狭まり多様な相手で広いまま）、H5（熱いストーブ）、H6a（曖昧な出来事の確証バイアス）、H6b（多様な反証は反復より速い）、H7（価値と信念の分離）。

### 候補 P0: 判別的な予測ネット（既存案のベースライン）

1. **予測対象**: P_θ(k | c, e)。条件は状況の概念ベクトルと関与者ベクトル。k は結果型（または測定用の候補文集合）。
2. **分布の形**: softmax(MLP(c, x_e))の categorical。最も単純で、埋め込みの類似度で一般化する。不確実性（どれだけ確かか）は持たない。
3. **学習誤差と学習率**: 交差エントロピー −log P_θ(k_t | c_t, e_t)、固定の最適化率。学習率は経験にも履歴にも依存しない。
4. **価値との相互作用**: BV1（Q = Σ p V̂）のみ。V→B は既定でなし。H7 は別ネット・別誤差なら成り立つ（S1〜S2）。
5. **経験例**: 手柄を取られる経験は、似た関与者ベクトルの相手へ滑らかに広がる（H4 の「広がる」は出るが、同じ相手を重ねても幅は変わらない）。H5 は接近方策を付ければ出る。H6 は出ない（非対称は追加パラメータ）。
6. **破綻条件と検出**: softmax の飽和（確信が 1 に張り付き更新停止）、少数データでの過信、新経験による干渉。検出は期待較正誤差、反転テスト（全証拠を反転して何回で追従するか）、プローブ集合の層別。
7. **持続と可塑**: 固定率なら 3.1 の縮小写像、共有重みなら干渉。× 。
8. **文献**: 較正は Guo et al. 2017 [記憶]。忘却は French 1999 [記憶]。

### 候補 A: 階層ベイズ（相手ごとの潜在特性 × 集団の事前分布）

1. **予測対象**
   - 結果型 k が起きる確率 P(y_k = 1 | c, e)。条件は場面クラス c（概念空間での soft なクラス）と関与者 e。
   - 結果は複数の部分が同時に起きるので、型ごとのベルヌーイの集合（マルチラベル）で持つ。型間の相関は、B（潜在原因）と 7 節の共起出力で扱う。

2. **分布の形とその理由**
   ```
   θ_{e,c,k} ~ Beta( κ_{c,k} μ_{c,k},  κ_{c,k}(1 − μ_{c,k}) )      相手 e の型 k の発生確率
   (μ_{c,k}, κ_{c,k}) ~ Beta(a₀, b₀) × logUniform[κ_min, κ_max]      集団の平均 μ と「人々が互いに似ている度合い」κ
   y_tk | e_t, c_t ~ Bernoulli(θ_{e_t,c_t,k})
   類似拡張:  logit θ_{e,k} = logit μ_k + g_k(x_e) + η_{e,k},   g_k ~ GP(0, s² R_ℓ(x, x′))
   ```
   - 理由: 相手は交換可能（部分プーリング）、個人差の大きさ κ を経験から学べる（overhypothesis。Kemp et al. 2007）、一般化の勾配は類似度カーネルで表せる（Shepard 1987; Tenenbaum & Griffiths 2001）。共役なので厳密に更新でき、各経験が何を動かしたかを分解しやすい。
   - 予測は新しい相手なら E[μ | D]、既知の相手なら E[(κμ + k_e)/(κ + n_e) | D]（(μ,κ) の事後で平均）。
   - ニューラルでの実現: 相手×型の計数 (α_{e,k}, β_{e,k}) を信念メモリに持ち、μ(c)、κ(c) を状況の概念ベクトルから出す小さなヘッドで経験ベイズ（周辺尤度の勾配）により学習する。結果型辞書と概念射影だけがニューラルな部分になる。

3. **学習誤差と学習率**
   - 誤差は周辺予測尤度の対数損失（適正スコア則）。更新は厳密なベイズ。
   - 相手レベルの学習率 α_e = 1/(κ + n_eff,e + 1)。κ が小さい（人は違う）人格ほど、相手ごとの証拠で大きく動く。n_eff は割引計数 n ← λn で有限に保つ（計数が無限に増えて学習率が 0 に落ちるのを防ぐ。λ は F の変動性で決める）。
   - 集団レベル (μ, κ) の更新は周辺尤度 ∏_e BetaBin(k_e | n_e, κμ, κ(1−μ)) で決まり、有効標本数は経験数でなく相手の数になる。

4. **価値ネットとの相互作用**
   - 信念→価値: BV1（Q = Σ_k E[θ] V̂_k）、BV4（相手ごとの情報利得 EIG_e ≈ Beta の事後エントロピーの期待減少）。
   - 価値→信念: VB1（接近・回避）、VB2（計数の増分に w(f)）、VB3（解釈の硬さ γ_h）。VB4 は既定でOFF。
   - H7: S1〜S2 は構造的に満たされる（計数と価値ネットは別パラメータ）。S3 は価値中立の結果型対で、S4 は信念の飽和（κ 大・n 大の相手）での再評価で作れる。

5. **経験例と H4〜H7（toy 数値。事前 Beta(1.5, 4.5)、平均 0.25）**

   「共同作業者に手柄を取られる」を、同じ相手から n 回、または別々の相手から1回ずつ n 人経験したあとの、初対面の相手への P(手柄を取る)。

   | n | 同じ相手 n 回 | n 人から1回ずつ | 単層の計数（参考） |
   | --- | --- | --- | --- |
   | 1 | 0.357（経験した相手自身 0.509、転移比 0.41） | 0.357（0.41） | 0.357 |
   | 2 | 0.400（0.648、0.38） | 0.438（0.59） | 0.438 |
   | 4 | 0.434（0.803、0.33） | 0.550（0.74） | 0.550 |
   | 8 | 0.447（0.912、0.30） | 0.679（0.85） | 0.679 |

   転移比 = （新しい相手への予測の移動量）÷（経験した相手自身の予測の移動量）。単層の計数は同じ相手でも別々の相手でも同じ値になる。階層ベイズはこれと違い、同じ相手の反復で転移を狭め、多様な相手では広いまま残す。同じ相手の場合、新しい相手への予測の絶対値は 0.357 → 0.447 とわずかに上がるが、経験した相手自身の予測が 0.509 → 0.912 と大きく上がるため、相対的な転移は狭まる。

   事前への感度（n=1 の転移比）: κ を「人は互いに似ている」側（[5, 50]）に置くと 0.70、「人は違う」側（[0.5, 5]）だと 0.30、広い事前（[0.5, 50]）で 0.41。つまり E4a の「似ていない相手でも半分以上」は事前が決める（H4 の方向は頑健、大きさは事前依存）。事前を固定せず経験から κ を学ぶ（過去に多様な相手がいた人格ほど κ が小さくなる）ようにすれば、これも履歴由来の個性になる。

   - H4 ◎（方向）、H5 ○（VB1 の標本の偏り。大きさは探索ボーナスで動く。数値は 5 節）、H6a △（厳密なベイズでは曖昧な出来事で偏らない。5 節の Sim4。VB3 の硬さ γ_h か近似推論が必要）、H6b ◎（相手を軸にした多様さ。同じ反証の反復は1人の例外として吸収され μ が動かず、多様な反証は μ を動かす。軸が相手でなく場面なら別の予測になる。ここは理論的な見込みで、未シミュレーション）、H7 ◎。

6. **破綻条件と検出**
   - 過信で更新停止: n_eff が増え続け α_e → 0。検出: 有効学習率の下限監視、反転テスト、予測較正（Brier 分解）。対策: 割引 λ、学習率の下限。
   - 回避で永久に誤信（H5 の極端形）: VB1 で標本が取れず事後が固まる。検出: (e,k) ごとの最終観測からの経過数、標本被覆率。
   - κ の識別不能: 1人しか相手がいない履歴では κ と μ が分離できず、事前が結論を決める。検出: κ の事後幅、事前を変えたときの予測変化。
   - 外れた相手による集団の汚染（ステレオタイプ）: 検出: 相手を1人抜いた (μ, κ) の変化。
   - 関与者同一性のLLM誤り（別人を同一視/同一人を別人扱い）: 検出: ID のランダムな併合・分割への予測の感度。

7. **持続と可塑性への寄与**: 部分プーリングで両立（3.3 の1）。toy では、8人の履歴で未見の相手への履歴差が新経験8回後に 89% 残り、1人の新しい相手への推定は 0.68 → 0.09 に動いた。履歴の多様さで保持率が変わる（1人 70% … 8人 89%）。

8. **根拠文献**: Kemp et al. 2007; Tenenbaum & Griffiths 2001; Shepard 1987; Hackel et al. 2015（特性の学習は報酬の学習と別）; Yamagishi & Yamagishi 1994（一般的信頼）; Gelman et al.『Bayesian Data Analysis』第3版 2013 [記憶]; Garnelo et al. 2018 [記憶]（ニューラルプロセス。階層推論の償却）。

### 候補 B: 潜在原因推論（文脈・消去・再発。CRP 混合）

1. **予測対象**: 「いま起きている出来事を生成している潜在原因 z（出来事の型・局面）」と、その下での結果型 y の同時分布 P(z_t, y_t | x_t)。x_t は関与者と場面の特徴。原因の数は決めない。

2. **分布の形とその理由**
   ```
   z_t ~ CRP(α) ［距離依存: P(z_t=k) ∝ Σ_{t′: z_t′=k} K_time(t,t′)·K_ctx(x_t,x_t′)、新原因は α］
   x_t | z_t=k ~ N(m_k, s_k² I)        原因が関与者・場面の特徴も生成する（これが「この原因の適用範囲」を作る）
   y_tk | z_t=k ~ Bernoulli(θ_{k,k′})   事前: (m, s²) ~ NIG、θ ~ Beta
   予測: P(y_k | x) = Σ_z P(z | x) E[θ_{z,k}],  P(z | x) ∝ n_z p(x | z)（既存）、α p(x | 事前)（新）
   ```
   理由: 反証を旧い信念の上書きでなく新しい原因として保存でき（消去・再発・自然回復・節約）、適用範囲が経験から決まる（Gershman et al. 2010）。推論は粒子フィルタ（粒子数 P）か局所 MAP。

3. **学習誤差と学習率**
   - 誤差は周辺尤度の対数損失。更新は責任 r_tz = P(z_t = z | x_t, y_t, 過去) による soft 計数: 各原因の十分統計量に r_tz·(1, x, x², y) を足す。
   - 実効学習率は r_tz/(n_z + a + b)。**驚きが大きいほど新しい原因の責任 r_new が上がり、旧い原因は更新されない（保護される）**。驚きが小さければ旧い原因が更新される（上書き）。Gershman et al. 2013 の「漸進的な消去は再発を防ぐ」と同じ論理。
   - メタパラメータ α（新しい原因への開放性）は、履歴（安定か、局面が変わるか）から学ばせられる。

4. **価値ネットとの相互作用**
   - 信念→価値: BV1（Q = Σ_z P(z|x) Σ_k E[θ_{z,k}] V̂_k）。BV4（原因の事後エントロピー＝状態の不確実性の低減を認識的価値にする）。
   - 価値→信念: VB1（原因ごとの接近・回避）、VB3（曖昧な出来事の原因の割当を事前に引き寄せる。粒子数が少ないほど硬い）。再評価（想起時）は新しい原因に保存する形にでき、再固定化の条件（旧い原因に帰属される小さな予測誤差なら更新、新しい原因なら別の記憶）を満たす（Gershman et al. 2017）。
   - H7: **価値を結果型に紐付け、原因 ID には紐付けない**ことが条件。原因 ID に価値を付けると、原因の再分割が価値を変えてしまう（S2 違反）。

5. **経験例と H4〜H7（toy。α=0.5、全結果が「手柄を取られる」）**
   相手の特徴を1次元 x で置き、経験した相手の x=0.5 から距離 d の初対面の相手への P(手柄を取る)（事前 0.25）。「遠い÷近い」は d=0.45 と d=0 の移動量の比。

   | 条件 | d=0 | d=0.45 | 遠い÷近い |
   | --- | --- | --- | --- |
   | 同じ相手 ×1 | 0.330 | 0.320 | 0.87 |
   | 同じ相手 ×4 | 0.523 | 0.470 | 0.81 |
   | 同じ相手 ×8 | 0.666 | 0.535 | 0.69 |
   | 多様な相手 ×8（x=0.3〜0.7） | 0.659 | 0.603 | 0.87 |

   - 少数では原因が1つしかないので全域に広がる（H4 の過剰一般化）。同じ相手の反復では原因の特徴分布が絞られ、遠い相手は新しい原因に割り当てられやすくなる（狭まる）。多様な相手では特徴分布が広いまま。方向は H4 と一致するが、大きさは特徴の尺度の事前 s₀ に強く依存する（s₀ を 0.3² → 0.15² → 0.05² に締めると、同じ相手 ×8 の「遠い÷近い」は 0.69 → 0.07 → 0.01）。
   - H4 ○、H5 ○（観測のない原因は凍結）、H6a ○（粒子数 1 の局所 MAP は硬い割当で、Sim4 の硬い割当と同様の分極を生むと見込まれる（B 自体では未シミュレーション）。「近似推論の資源」で偏りの個人差を表せる。Sanborn et al. 2010; Dasgupta et al. 2017 [記憶]）、H6b ◎（旧原因は残り、反証の多様さに応じて新原因が根づく。理論的な見込み）、H7 ○（価値を結果型に紐付ければ）。

6. **破綻条件と検出**
   - 潜在原因の乱立（α 過大、尺度の事前が狭すぎる）: 事象ごとに新しい原因ができ、一般化が消える。検出: 原因数の増加率、割当エントロピー、予測の較正。
   - 原因の collapse（α 過小）: 1つに潰れ、単層の上書きと同じになる。
   - 補助仮説による保護（反証が「特別な事情の原因」に吸われ、主たる信念が永久に更新されない。Gershman 2019）。検出: 反証の新原因への割当比率と、主原因の信念の更新量の比。
   - 旧い信念の不適切な再発（自然回復）: 良性の場合もあるので、E4d の持続の指標と区別して記録する。
   - コンパートメント化: 旧い文脈では訂正が届かない。検出: 同じ旧文脈への反証の提示後に旧原因の予測が動くか。

7. **持続と可塑性への寄与**: 旧い原因が保存され（持続）、新しい原因が可塑性を担う（3.3 の2）。反転までの経験数は、旧原因の事前計数 n_z に対し概ね対数的に増えると見込まれる（理論的な見込みで、未検証）。代償は旧い文脈での訂正不能。H5・H6 と相性が良く、SAHB の拡張候補（急反転時にスコープを割る）。

8. **根拠文献**: Gershman et al. 2010; Gershman et al. 2013（Frontiers in Behavioral Neuroscience 7, 164）[記憶]; Gershman et al. 2017; Gershman et al. 2015（Current Opinion in Behavioral Sciences 5, 43–50）[記憶]; Anderson 1991 [記憶]; Sanborn et al. 2010 [記憶]; Bouton 2004; Redish et al. 2007 [記憶]; Collins & Frank 2013; Heald et al. 2021; Niv 2019 [記憶]; Gershman 2019。

### 候補 C: 帰属（原因）の事後推論と責任配分学習

1. **予測対象**: 結果の各部分 o_j が「誰（何）のせいで起きたか」z_j ∈ {自分, 関与者 e₁…e_m, 場面 c, 世界（偶然）} の事後分布（責任）と、各原因の「何を引き起こしやすいか」。条件は出来事全体（関与者の集合、場面、LLM が報告した行為者タグ）。

2. **分布の形とその理由**
   ```
   z_j ~ Categorical(π_t)                       責任の事前（人か場面かの事前を含む）
   型 k_j | z_j = x ~ Categorical(ω_x)          原因 x の「因果的な力」の分布（Dirichlet 事前、階層的: 相手は一般の人々 ω̄ から）
   LLM 報告 a_j | z_j ~ Categorical(Λ[z_j, ・])    抽出の混同行列 Λ（誤りを明示的にモデル化）
   責任  r_j(x) ∝ π_t(x) · ω_x(k_j) · Λ[x, a_j]
   ```
   理由: 「手柄を取られた」は結果の事実だけでなく誰が起こしたかで意味が変わるため、原因そのものが推論対象。共変原理（Kelley 1967 [記憶]）、因果の力の学習（Cheng 1997 [記憶]; Griffiths & Tenenbaum 2005 [記憶]）、反事実（Gerstenberg et al. 2021）の系譜。noisy-OR にして複数の原因が同時に働く形にもできる。

3. **学習誤差と学習率**
   - 誤差は完全データの期待対数尤度（EM）または ELBO。Dirichlet 計数 N_x(k) に責任 r_j(x) を足す。
   - 学習率は r_j(x)/(N_x + η)。責任の正規化により **原因同士の競合（説明の割引き、遮蔽）** が自然に生じる。既にその型をよく起こすと知られた原因が責任を取り、新しい相手には残りだけが割り当たる（カルマン利得の cue competition と同型。Dayan et al. 2000 [記憶]; Gershman 2015 の統一的な確率的見方）。

4. **価値ネットとの相互作用**
   - 信念→価値: **BV3**（相手 e への価値の更新量 ∝ r_j(e)·f_j。再設計案の帰属経路の信念版）。反事実の比較から後悔・安堵の価値（Mellers et al. 1997 [記憶]）。BV1。
   - 価値→信念: **VB5**（自己奉仕: 望ましい結果は自分に、望ましくない結果は他者に帰属しやすい事前。Mezulis et al. 2004 のメタ分析。Dorfman et al. 2019 は、隠れた主体の介入を信じるかどうかで良い結果と悪い結果からの学習が非対称になることを、合理的な因果推論として示した）、VB3。
   - H7: 帰属のルーティングが価値の更新先を決めるので結合は強いが、分離は可能。信念のみ: 「手柄を取ったのは実は共同責任者だった」という再帰属（f は変わらず r が動く）。価値のみ: 同じ責任配分で結果の評価が変わる。S2 のため、責任 r は信念側の量で、価値の損失は δ_V のみ。

5. **経験例と H4〜H7（理論予測。この方式単独の数値シミュレーションは未実施）**
   - 同じ相手 A から手柄を取られる経験を繰り返す: 一貫性が高く合意（他の相手も同じ）が低い → A の ω_A(手柄取り) が増え、**相手への帰属**。別々の相手から経験する: 合意が高い → **場面（共同作業という状況）への帰属**で、初対面の相手にも広がる。つまり H4 の「同じ相手で狭まり、多様な相手で広いまま」が共変原理から出る。
   - 少数経験の過剰一般化: 事前 π_t が「人（個人）への帰属」寄りなら、**場面を越えて同じ相手に**広がる（基本的帰属錯誤・対応バイアス。Ross 1977; Gilbert & Malone 1995 [記憶]）が、新しい相手には広がらない。「新しい相手への過剰一般化」を出すには事前を「状況・集団」寄りにする必要がある。H4 の軸（相手か場面か）を分けて測らないと、方式間で符号が逆になる。
   - H4 ◎（軸を明示すれば）、H5 ○、H6a ○（補助仮説・外的帰属に吸われて反証が無効化される）、H6b ◎（多様な反証は場面レベルの帰属を動かす）、H7 ○。

6. **破綻条件と検出**
   - **価値と信念の暴走的結合（スカポゴート循環）**: 悪い結果 → 他者へ帰属（VB5）→ 他者の価値が下がる → 次の曖昧な出来事もその他者のせいにする。検出: 影の信念との乖離 D、帰属の事前を価値に依存させない対照との差、証拠が増えないのに D が増加。
   - 反証が補助仮説に吸われて信念が更新されない（Gershman 2019）: 検出: 反証の「偶然・世界」への責任比率の推移。
   - 識別不能: 同じ相手が同じ場面にしか現れない履歴では、人か場面かが分離できず事前が決める。検出: 事前を振ったときの予測の変化幅。
   - LLM の行為者タグの誤り: 誤帰属が相手への誤った好悪を作る。検出: 混同行列 Λ の感度分析、言い換え3通りでの責任の安定性（既存計画）、誤抽出と本人の誤解の区別。

7. **持続と可塑性への寄与**: 新証拠は責任の再配分として入るので、旧い特性（人への帰属）は場面への再帰属で弱められるが、補助仮説で保護もされる。持続は帰属の事前（人か場面か）と ω に、可塑性は多様な証拠による再帰属に宿る。

8. **根拠文献**: Kelley 1967 [記憶]; Kelley & Michela 1980 [記憶]; Weiner 1985 [記憶]; Cheng 1997 [記憶]; Griffiths & Tenenbaum 2005 [記憶]; Gerstenberg et al. 2021; Jocham et al. 2016; Mezulis et al. 2004; Dorfman et al. 2019（2023 年に訂正が出ている。統計量を引用するときは訂正版を確認）; Alicke 2000 [記憶]; Gershman 2019。

### 候補 D: 後継特徴（予測と価値の線形分解）

1. **予測対象**: 後継特徴 ψ(c, e) = E[ Σ_{τ≥0} γ^τ φ(o_{t+τ}) | c, e, 方策 ]。結果特徴 φ(o) ∈ R^d の割引期待（将来の「何が起きるか」を特徴の期待で表したもの）。指示子（indicator）特徴なら割引された期待発生回数。物語的な出来事は軌道でなくエピソード単位が多いので、現実的には γ = 0 の1ステップ版 ψ = E[φ(o) | c, e] になる。

2. **分布の形とその理由**: 平均ベクトルの回帰（分布は持たない）。不確実性が必要なら、重みのガウス事後を持つカルマン TD（Geist & Pietquin 2010 [記憶]）。選んだ理由は、価値が V = w·ψ と**双線形に分解**でき、w だけを変えれば ψ を再学習せず即座に再評価できる（Momennejad et al. 2017）から。Jensen のずれ（E[V(o)] ≠ V(E[o])）を避けるため、価値が結果部分の相互作用を持つ（H3）なら、2次特徴 φ₂ = φ ⊗ φ の期待（共起の期待）を持たせる。次元 d² は低ランクで近似する。

3. **学習誤差と学習率**
   ```
   δ_ψ = φ(o_t) + γ ψ(c′,e′) − ψ(c,e)         特徴の TD 誤差（ベクトル）
   L_ψ = ½ ‖δ_ψ‖²（またはカルマン形の周辺尤度）
   学習率 α_ψ: カルマン利得 Σ/(Σ+R)、または連合性 (Pearce & Hall 1980; Mackintosh 1975 [記憶])
   ```
   価値の TD 誤差は δ = f + γQ′ − Q = w·δ_ψ + (f − w·φ(o_t)) と分解され、第1項が世界の誤差（δ_W）、第2項が価値の誤差（δ_V）になる。1.2 の分解と一致する。

4. **価値ネットとの相互作用**
   - 信念→価値: Q = w·ψ（予期）。再評価は ψ を学び直さず w の更新だけで反映される。
   - 価値→信念: VB1（ψ は方策依存の期待なので、回避すれば更新されない。H5 が自然に出る）。VB4（価値で重み付けした予測損失 Σ_k (1 + λ|w_k|) δ_ψk²）は、価値等価の原理（Grimm et al. 2020）が正当化するが、**H7 を弱める**。
   - H7: **最も厳密**。ψ と w が別パラメータで、Q = w·ψ は双線形。信念のみ: ψ を w の零空間方向に動かす（toy: dψ の大きさ 0.384、dV = w·dψ = 0.000、dQ = 0.000）。価値のみ: w だけを再重み付け（toy: dw = 0.806 で dQ = 0.500、ψ は不変）。条件: 特徴基底 φ を固定（または自己教師の予測目的でのみ学習）し、価値のための共同学習をしないこと。ただし**価値が φ の張る空間に入っている**という前提があり、問1で新しい価値の次元が生まれる場合は φ を拡張する必要がある。

5. **経験例と H4〜H7**
   - ψ = Ω x(c,e)（埋め込み x の線形/浅い写像）なら、手柄を取られた経験は x が近い相手に滑らかに広がる（H4 の「広がる」は出る）。しかし delta 則では共有成分と相手固有成分が同じ誤差を分け合うので、同じ相手の反復で幅が狭まる（階層ベイズ的な説明の割引き）は自然には出ない。
   - H4 △、H5 ◎（on-policy）、H6a ×（非対称な学習率を足すなら ○ だが、曖昧さの解釈は別機構）、H6b ×、H7 ◎。

6. **破綻条件と検出**
   - 方策が変わると ψ が古くなる（SR の方策依存）: 検出: 方策変更後の再評価テスト（w を変えたときの予測 Q の誤差）。
   - 物語イベントはマルコフ連鎖でない: 次の状態の定義が曖昧で、γ > 0 の追加の定義がLLM頼み。γ = 0 に縮退すると単なる平均特徴の回帰になる。
   - Jensen のずれ: 分布が二峰（協力的か裏切りか）のとき、平均は「半分の手柄」という実在しない結果になる。検出: E[V(o)]（サンプル）と V(E[o]) の差。
   - 価値が φ の外に出る: 新しい価値次元が表せない。検出: 価値プローブの残差を φ の張る空間へ射影した割合。
   - off-policy TD の発散（deadly triad）: γ を小さくすれば軽減。

7. **持続と可塑性への寄与**: ψ は新経験で上書きされる（可塑）が、履歴差は w（価値）に宿る。つまり「信念は可塑、価値は持続」という分業で、E4d（反証で信念は更新され、形成史の痕跡は価値に残る）には合う。信念側自身の持続（H4 の過剰一般化の残存）の仕組みは持たないため、速い ψ と遅い ψ の2つの時間スケールを持たせる（McClelland et al. 1995 [記憶] の相補学習系の考え方）必要がある。

8. **根拠文献**: Dayan 1993; Barreto et al. 2017; Momennejad et al. 2017; Russek et al. 2017 [記憶]; Gershman 2018 [記憶]; Stachenfeld et al. 2017 [記憶]; Lehnert & Littman 2020 [記憶]; Gläscher et al. 2010; Grimm et al. 2020; Farahmand et al. 2017 [記憶]; Rabinowitz et al. 2018（ToMnet が他者の SR を予測）。

### 候補 E: 心の理論としての逆計画（相手の意図・価値の推定）

1. **予測対象**: 相手 e の行為 a と、その結果 o の同時分布 P(a, o | s, e)。相手の効用 u_e（手柄、公平、協力、私への配慮 ω_me などの重み）という潜在変数を推定し、相手が選びそうな行為から結果を予測する。条件は状況 s、相手 e、相手の選択肢集合 A_t。

2. **分布の形とその理由**
   ```
   u_e ~ N(μ_pop, Σ_pop)                       集団の事前（階層。初期は自分の価値の重み＝VB6、経験で置換）
   a | s, u ~ π_u(a | s) ∝ exp( β u·φ_a(s) )     Boltzmann 合理（選択肢集合 A_t 上）
   o | s, a ~ P(o | s, a, 他者)
   予測: P(o | s, e) = Σ_a E_{u|D_e}[π_u(a | s)] P(o | s, a)
   事後: p(u | D_e) ∝ p(u) ∏_t π_u(a_t | s_t, A_t)       （Laplace または変分）
   ```
   理由: 結果の統計でなく**相手が何を望んでいるか**を推定するので、未知の場面にも通用する（原因の抽象化）。意図的か偶然かの区別、戦略的な親切の割引ができる。他者の選好は逆の意思決定として推定される（Baker et al. 2009; Jara-Ettinger 2019; Jern et al. 2017）。ニューラルな近似としては、相手の過去から性格ベクトルを作って次の行動と後継表現を予測する ToMnet（Rabinowitz et al. 2018）がある。

3. **学習誤差と学習率**
   - 誤差は観測行為の負の対数尤度 −log π_u(a_t | s_t, A_t)。勾配は ∇_u = −β(φ_{a_t} − E_π[φ_a])（最大エントロピー逆強化学習の特徴期待マッチング。Ziebart et al. 2008 [記憶]）。
   - 学習率は事後精度 Σ_post = (Σ_pop⁻¹ + Σ_t I_t)⁻¹。Fisher 情報 I_t = β² Cov_π[φ_a] が行為の**診断性**を測る: 選択肢が1つなら I = 0 で更新なし。予想外の行為（まれに選ばれる行為）ほど大きく動く。価値による重み付けなしで、証拠の重みが原理的に決まる点が他方式にない特徴。

4. **価値ネットとの相互作用**
   - 信念→価値: **BV5**（相手の意図の信念が結果の感じ方を変える。同じ手柄の喪失でも、故意なら f が悪化、偶然なら軽い。Cushman 2008 [記憶]; Rabin 1993 [記憶]）。BV3（意図の事後で相手への価値を割り当て）。信頼・愛着を「相手の私への配慮 ω_me の事後平均」として価値化できる。
   - 価値→信念: VB6（自分の価値を他者の事前にする自己投影。偽の合意効果）、VB1（回避すれば相手の選択を観測できない）、VB3（曖昧な行為の意図の解釈）。敵意帰属バイアス（Dodge 1980 [記憶]）は、過去に敵意のある相手が多かった履歴から μ_pop の ω_me が低くなる形で履歴由来に出る。
   - H7: BV5 により f が θ に依存し ∂f/∂θ ≠ 0 なので S2 を直接は満たさない。V(o; û) = V₀(o) + W·h(û)（û: 意図の信念、W: 意図への価値）と分け、価値プローブでは û を固定して読む必要がある。構造は分離可能だが、**実験での分離は最も難しい**。

5. **経験例と H4〜H7（理論予測。未シミュレーション）**
   - A が共同成果を単独名義で発表した。選択肢は {共同名義, 単独名義}。単独名義が選ばれ、A の u_credit が上がり ω_me が下がる。共同名義にできない事情（上司の指示）が文に含まれれば、その選択肢が消え I ≈ 0 になり、A についての更新が小さい（意図的か偶然かの区別）。
   - 初対面の B への予測は μ_pop（過去の相手の平均）から出る。過去に似た相手が多様なら Σ_pop が大きく、B への一般化は弱い（A の階層ベイズ版と同型）。
   - 悪い相手の親切は戦略かもしれないので割り引かれ（親切な相手の悪行は割り引かれない）、否定的な事前の相手ほど肯定的な反証の効きが弱い。この診断性の非対称（Reeder & Brewer 1979; Skowronski & Carlston 1987）が H5・H6 を、更新則でなく推論から出す。
   - H4 ○、H5 ○（回避での観測欠落＋診断性の非対称。ただし否定的な信念は揮発しやすいという反例、Siegel et al. 2018 もある）、H6a ○、H6b ○、H7 △。

6. **破綻条件と検出**
   - 過剰な心的帰属（偶然を意図に読む、パラノイド吸引域）: VB6＋BV5＋回避のループ。検出: 影の信念、相手の次の行為の予測精度を基準率と比較、善意の証拠を与えて回復するか。
   - 選択肢集合 A_t は観測されない反事実: LLM に生成させるため、幻覚と恣意が入る。検出: 選択肢の言い換え・欠落への感度。
   - β と u の尺度不定性（u/β しか識別できない）: β を固定、または相手の集合で共有する。
   - 再帰の深さ: 1次（相手の意図）に限定。
   - 計算量とLLM呼び出し: 大きい。

7. **持続と可塑性への寄与**: 持続は集団の事前 μ_pop（人はどういうものか）と自己投影に、可塑性は診断的な1回の証拠（自己を犠牲にした親切のような高コストの信号）での急変にある。「経験の量でなく質（診断性）が動かす」という性質。

8. **根拠文献**: Baker et al. 2009; Baker et al. 2017（Nature Human Behaviour 1, 0064）[記憶]; Jara-Ettinger 2019; Jern et al. 2017; Ong et al. 2015; Rabinowitz et al. 2018; Ziebart et al. 2008 [記憶]; Ng & Russell 2000 [記憶]; Geanakoplos et al. 1989 [記憶]; Rabin 1993 [記憶]; Cushman 2008 [記憶]; Reeder & Brewer 1979 [記憶]; Skowronski & Carlston 1987; Dodge 1980 [記憶]; Ross et al. 1977 [記憶]; Yoshida et al. 2008 [記憶]。

### 候補 F: 階層的ガウスフィルタ（変動性を推定して学習率を決める）

1. **予測対象**: 相手 e（または場面）ごとの、結果型 k の発生確率の対数オッズ x₂（時間とともに変わる）と、その変動性 x₃。出力は P(y_k = 1 | e, t) = σ(x₂) とその不確実性。

2. **分布の形とその理由**
   ```
   x₃_t ~ N(x₃_{t−1}, ϑ)                         変動性の変動
   x₂_t ~ N(x₂_{t−1}, exp(κ x₃_t + ω))            対数オッズのランダムウォーク（相手は変わりうる）
   y_t ~ Bernoulli(σ(x₂_t))
   ```
   理由: 「人は変わる」という世界観を明示して、学習率を環境の変動性の推定から決める（Behrens et al. 2007; Mathys et al. 2011）。観測のない期間は不確実性が自動で戻る。

3. **学習誤差と学習率**（2階層目の更新は Mathys et al. 2011 と同形。係数の詳細は原典で要確認）
   ```
   予測分散  σ̂₂ = σ₂_{t−1} + exp(κ μ₃_{t−1} + ω)
   予測誤差  δ₁ = y − σ(μ₂_{t−1})
   精度      π₂ = 1/σ̂₂ + σ(μ₂_{t−1})(1 − σ(μ₂_{t−1}))
   更新      μ₂ = μ₂_{t−1} + δ₁ / π₂      ← 学習率 α_t = 1/π₂
   3階層目:  変動性の予測誤差 δ₂（観測された更新の大きさ ÷ 予想された大きさ − 1）で μ₃ を更新
   未観測の期間: σ₂ ← σ₂ + exp(κ μ₃ + ω)      （分散膨張）
   ```
   学習率は予測分散が大きい（観測が少ない、または変動性が高い）ほど大きく、観測の確率的な揺れ（期待された不確実性）が大きいほど小さい。変動性と確率性の分離は Piray & Daw 2021、非定常性の検出は Nassar et al. 2010 [記憶]、期待と予期せぬ不確実性は Yu & Dayan 2005 [記憶]。

4. **価値ネットとの相互作用**
   - 信念→価値: BV4（EIG ≈ ½ log(1 + σ₂·σ(μ₂)(1−σ(μ₂)))）。不確実性や変動性そのものを不安や関心の源にできる（変動性への過敏さは不安と関連。Browning et al. 2015 [記憶]）。
   - 価値→信念: VB1 と、**回避中の分散膨張**（未観測期間に σ₂ が増え、探索ボーナスが働いて再接近する）、VB2（型の感情価ごとに ω を変える。悪い相手についての信念は揮発しやすい。Siegel et al. 2018）。Joffily & Coricelli 2013 は、否定的な感情価が学習率を上げ、肯定的な感情価が下げると論じる。
   - H7: ◎。信念側のパラメータ (x₂, x₃, ω) と価値ネットは別。VB2 を使うと結合する。

5. **経験例と H4〜H7**
   - A から手柄を取られる経験を 20 回、一貫して受けた履歴（安定）と、A が協力的な期間と手柄を取る期間を交互に繰り返した履歴（不安定）では、後者の μ₃ が高くなり、新しい反転で α が大きい（速く動く）と見込まれる（理論的な見込みで、F 単独の数値実験は未実施）。履歴は推定値でなく学習率に残る。
   - 単層なので H4（スコープ）は出ない。階層（相手の事前を集団から受ける）と組み合わせる必要がある。回避時の分散膨張は H5 の非対称を小さくする（5 節 Sim2 の「探索ボーナス＋分散膨張」で比が 9.6 → 約 2〜3）。
   - H4 ×、H5 ○、H6a △、H6b △、H7 ◎。

6. **破綻条件と検出**
   - 過信で更新停止: ω が小さすぎ、または確率性を誤って低く見積もると α → 0。逆に確率的な揺れを変動性と誤認すると α が暴走（Piray & Daw 2021）。検出: α の軌跡、変化点を人工的に入れたときの追従の遅れ。
   - パラメータ（ϑ, κ, ω）の識別性が弱い。検出: パラメータ回復実験。
   - 確率が極端な型では σ(x₂) が飽和。
   - 型ごと・相手ごとに独立で、型間の相関（手柄の喪失と裏切りの共起）を持たない。

7. **持続と可塑性への寄与**: 履歴が学習率（変動性の信念）に宿る（3.3 の3）。安定な履歴の人格は頑固（持続）で、変動の多い履歴の人格は開放的（可塑）。持続の中身が「何を信じているか」でなく「どれだけ動かされやすいか」になるため、H4 の過剰一般化の残存は説明できない。

8. **根拠文献**: Mathys et al. 2011; Mathys et al. 2014（Frontiers in Human Neuroscience 8, 825）[記憶]; Behrens et al. 2007; Nassar et al. 2010 [記憶]; Piray & Daw 2021; Yu & Dayan 2005 [記憶]; Iglesias et al. 2013 [記憶]; Browning et al. 2015 [記憶]; Siegel et al. 2018; Joffily & Coricelli 2013; Pearce & Hall 1980 [記憶]; Mackintosh 1975 [記憶]。

### 候補 G: 自己モデル（自分の反応の予測・情動予測）

1. **予測対象**: 自分が感じる価値のベクトル f_t（チャンネル K 個）と対処可能性の分布 P(f_t | c, e, 自己状態)。世界でなく自分の反応を予測する。

2. **分布の形とその理由**: ガウス混合（混合密度ネットワーク）。f の多峰性（嬉しいが苦い）を表すため。対処可能性は Beta（自己効力感。Bandura 1977 [記憶]）。

3. **学習誤差と学習率**: −log p(f_t | c, e, 気分)（ガウスなら ½(f−μ)ᵀΣ⁻¹(f−μ) + ½ log|Σ|）。学習率は逆分散に比例。予測誤差は情動予測の誤差（Wilson & Gilbert 2005 [記憶]; Gilbert et al. 1998 [記憶] の免疫無視）。

4. **価値ネットとの相互作用**: 信念が価値の関数なので結合が定義から強い。予期 = μ（直接）。予期的な感情（Loewenstein 1987 [記憶]; Caplin & Leahy 2001 [記憶]）と参照点（BV6）で感じた価値を変える。**H7 は成り立たない**（階数1）。1.2 の価値ネットの予報ヘッド V̂ は実質この方式の μ なので、**信念ネットの候補でなく価値ネット側の予報ヘッドとして吸収する**のが適切。

5. **経験例と H4〜H7**: 手柄を取られた人格が A との共同作業を「つらい」と予報し（μ = −0.6、広い）、回避して予報の検証が起きない（情動の熱いストーブ）。予報が感じ方を悪化させ（BV6）、それが予報を下げる自己成就ループになりうる。H4 △（埋め込みの滑らかさだけ）、H5 ○、H6a ×、H6b ×、H7 ×。

6. **破綻条件と検出**: 自己成就ループによる暴走（learned helplessness の構造。Maier & Seligman 2016 [記憶]）。検出: BV6 を切った影の予報との乖離。対処可能性の予報が低く回避が続き、効力の証拠が取れない。自己確証への偏り（Swann 1987 [記憶]）。

7. **持続と可塑性への寄与**: 自己概念が安定化して持続を強めるが、可塑性は弱い。△。

8. **根拠文献**: Wilson & Gilbert 2005 [記憶]; Gilbert et al. 1998 [記憶]; Loewenstein 1987 [記憶]; Caplin & Leahy 2001 [記憶]; Kőszegi & Rabin 2006 [記憶]; Bandura 1977 [記憶]; Swann 1987 [記憶]; Maier & Seligman 2016 [記憶]; Joffily & Coricelli 2013。

## 7. 推奨方式: スコープ帰属つき階層ベイズ信念（SAHB）

### 7.1 構成（A を骨格に、C の責任配分、F の簡約、D の界面を組み合わせる）

```
スコープ単位 X = { 相手 e, 場面 c, 一般 g }   各単位 x が各結果型 k の確率 θ_{x,k} を持つ
  θ_{g,k} ~ Beta(a₀, b₀)
  θ_{c,k} ~ Beta(κ_c θ̄_{g,k}, κ_c(1 − θ̄_{g,k}))        場面は一般から
  θ_{e,k} ~ Beta(κ_e θ̄_{g,k}, κ_e(1 − θ̄_{g,k}))        相手は一般から（κ_e = 「人は違う」度合い。経験ベイズで学習）
スコープ事前  π_{x,k} = P(型 k を担う単位 = x) ~ Dirichlet(ξ_k)     型ごとの「人のせいか、場面のせいか」（経験から学ぶ overhypothesis）
予測  P(y_k = 1 | c, e) = Σ_x π_{x,k} · E[θ_{x,k}]
責任  r_{tjx} ∝ π_{x,k_j} · Bern(y_tk; E[θ_{x,k}]) · Λ[x, a_tj]        Λ: LLM 行為者タグの混同行列（明示的にモデル化）
更新  α_{x,k} += r·y,  β_{x,k} += r·(1−y),  π の Dirichlet 計数 += r          （オンライン EM）
      各単位の割引 λ_x = 1/(1 + ν_x)、ν_x: 予測誤差の移動平均と期待ばらつきの比（F の簡約。HGF 全体は採用しない）
超パラメータ (θ̄_g, κ_c, κ_e, ξ) は、単位の数（相手の数、場面の数）を標本数とする周辺尤度で学習（格子またはニューラルヘッド）
予期  Q = Σ_k P(y_k=1 | c,e) · V̂_k     （価値が結果部分の相互作用を持つなら共起 P(y_k y_k′) を出し、2次特徴の期待で評価。D の界面）
```
- 混合は「その型を担う単位は1つ」という仮定。複数の単位が同時に働く場合は noisy-OR にし、E4 で比較する。
- ニューラルな部分は、結果型辞書、概念射影、(κ, ξ) を出すヘッド。信念の本体は計数の共役更新で、経験を1つ除いて学び直す E5 の反事実再実行が安価。

### 7.2 価値ネットとの結合（既定の設定）
- 信念→価値: BV1 予期、BV2 驚きの分解（信念は対数損失、価値は δ_V のみ）、BV3 責任で相手の価値を配分、BV4 単位ごとの EIG と固定プローブ上の学習進捗 LP。
- 価値→信念: VB1 接近・回避（探索ボーナス λ と分散膨張 ρ は事前固定）、VB3 解釈の硬さ γ_h（既定は厳密、E4b で上げる）。VB2・VB4・VB5 は既定でOFF にして E4 の条件として入れる。
- H7: S1〜S5 の条件を満たす構成（別パラメータ、δ_V のみ、価値中立の結果対、信念の飽和した相手での再評価、結合のON/OFF の記録）。
- 診断: 影の信念（V→B を切った並走）、有効な相手数、学習率の下限、予測較正、スコープの割当エントロピー。

### 7.3 他方式の取り込み方
- B（潜在原因）: 驚き（予測誤差）が閾値を超えたとき、既存の単位を上書きせず新しい単位（スコープ）を作る拡張。反証で旧い痕跡を消さず、E4d の「痕跡は残る」を構造で保証する。
- D（後継特徴）: 価値との界面のみ（双線形の予期）。
- E（逆計画）: 第2段階。「相手」単位の中身を結果の確率から意図の事後（u_e）に置き換える。BV5 の結合が強いので、SAHB で H7 を確かめた後に導入する。
- F: 割引 λ_x の簡約版。
- G: 価値ネット側の予報ヘッド V̂ に吸収。自己予報誤差を診断量として使う。

### 7.4 なぜ最有望か
1. **H4 の3つの符号を同一原理から出せる**: 証拠は交換可能な単位ごとに数え（部分プーリング）、型ごとに人か場面かを推論する。toy（Sim1a・1b）で、同じ相手の反復では転移が狭まり、多様な相手では広いまま残った（単層の計数では区別されない）。
2. **持続と可塑性を単位の分離で両立**: 上位（一般・場面）の有効標本数は相手や場面の数であり、1人の新しい相手との8回では 1/(N+1) 程度しか動かない（Sim3: 89% 保持、N 自身の推定は 0.68 → 0.09）。固定率の単層（10%）や 1/n の計数（N への推定が 0.43 で止まる）では両立しない。履歴の多様さが持続を決めるという検証可能な予測も出る（1人 70% → 8人 89%）。
3. **H7 を満たす条件を数学的に明示できる**: 信念は対数損失、価値は δ_V のみ、パラメータは別、結合は ON/OFF で記録。D の双線形界面で Q = ψ·w の分離が厳密になる。
4. **H5・H6 が価値→信念チャネルの ON/OFF に還元される**: E4 が「入れたり切ったりする」設計と合う。Sim2・Sim4 が示すように、偏りの大きさは探索ボーナス・分散膨張・解釈の硬さといった**明示的なパラメータ**で決まるので、事前登録できる。
5. **信念側にも履歴由来の個性が育つ**: κ_e（人は違うと思うか）、π（人のせいにするか場面のせいにするか）、一般の平均 θ̄_g は経験から学習され、持続する。「一般的信頼」（Yamagishi & Yamagishi 1994）、帰属スタイルという、設計者が指定しない信念の個性になる。
6. **問1との接点**: BV4（情報利得 EIG、学習進捗 LP）は、価値ネット自身の出力に依存しない**外生の価値の源**になり、自己評価の増幅だけに留まらないための候補になる（オーケストレーター解析メモの N3・N5 と対応）。ただし生の予測誤差は noisy-TV で破綻する（Burda et al. 2019）ので、固定プローブ上の LP と EIG だけを使い、機能的自律（Allport 1937）として価値に取り込まれうることは問1側で扱う。

### 7.5 残る最大の弱点
- **離散的な足場（結果型辞書、関与者の同一性、行為者タグ、場面クラス）への依存**: これらは LLM 抽出と辞書の粒度で決まり、誤りは系統的な信念として学習される。また足場の外（辞書にない未知の結果型）へは一般化できない。対策の方向は、型間の類似度カーネル（型の確率を埋め込み上のガウス過程にする）と、混同行列 Λ の明示的モデル化。
- 次点: スコープの識別可能性と事前依存（H4 の大きさが κ の事前で 0.30〜0.70 に動く）。対策: 共通の発達期の合成経験で超事前を経験ベイズにより学習し、人格差は発達期の後の経験からのみ作る。E4a には事前を振る感度分析を付ける。
- 次点: 帰属を介した価値と信念の暴走ループ（VB5＋BV3）。2.3 の影の信念で監視する。

### 7.6 最小の検証セット（実験計画の修正ではなく、この方式を判定するための提案）
1. スコープ推論の除去（人だけ／場面だけ／両方）と、単層の計数・固定率・階層のみ（A）の比較で、H4 の3つの符号と持続・可塑の2指標。
2. 解釈の硬さ γ_h と粒子数の掃引で H6a の偏りの大きさ。厳密なベイズでは偏りが出ないことの確認。
3. 探索ボーナス λ × 分散膨張 ρ の掃引で H5 の比（Sim2 の再現）。
4. 影の信念との乖離 D と正帰還の利得 g（2.3）。
5. E5 の除去実験を、計数メモリの再計算で安価に実行。

## 8. 実験計画（03-experiment-plan.md）への含意（修正提案ではなく注意点）

1. **H4 の軸**: 「他の関与者や場面へ」の一般化は2つの軸で、方式により予測が逆になる（人への帰属は場面を越えて広がるが新しい相手には広がらない）。E4a は相手の類似度と場面の類似度を分けて測ると方式を判別できる。
2. **H6 後半の「多様な反証」の軸**: 相手の多様さか、場面の多様さか、結果の種類の多様さか。flat な計数や固定率では多様さは無関係なので、階層・帰属方式を判別する実験になる。軸を事前登録する。
3. **E4c の基準は設計パラメータに依存する**: 探索ボーナスと分散膨張を強めると否定÷肯定の比が 9.6 から 2 以下に落ちる（Sim2）。λ、ρ の値は結果を見る前に固定する。
4. **H6a の偏りは厳密なベイズでは出ない**（Sim4）: 偏りの源（解釈の硬さ、近似推論、事前の二重数え）を、仮説の側で名指しして切り替えられるようにする。
5. **H7 は予期 Q でなく、信念プローブと価値プローブを別々に読んで測る**。予期は両方で動く。
6. **履歴差の持続の定義**: 「未見の相手」への差と「反証を受けた相手自身」への差を別々に測る（3.4）。同じ人格で両者が別々に動きうる（Sim3）。
7. **更新則の非対称（否定的信念は更新されにくい）と標本の非対称（回避で標本が取れない）を混ぜない**: 悪い相手についての信念が揮発的だという結果（Siegel et al. 2018）は、更新則の非対称を入れると H5 と逆の効果を生む。E4c の「選択なし」対照がその切り分けになる。
