# Frontalis 学習機構：価値ネットと信念ネットは何から何を学ぶか

Oct 15, 2026

## 結論

価値ネットの学習の「教師」は、すべて人格の外に置きます。具体的には、出来事が欲求をどう変えたか、他者が何を評価したか、世界の予測がどれだけ上達したか、です。人格が決めるのは、その教師を「何に・誰に・どれだけ」配分するか、何を経験しに行くか、曖昧な出来事をどう解釈するかです。こうすると、経験前の人格によって同じ出来事から学ぶ向きが変わり、しかも自己評価の増幅にはなりません。本書ではこの構成を**配分型フレーム**と呼びます。

ここで「人格の外」「外生の教師」は、**価値ネット自身の出力に依存しない量**という意味です。LLM や研究者が正解の感情を与えるという意味ではありません。欲求の状態は NPN の内部状態で、その変化は出来事の事実から計算します。他者の評価は、LLM が「誰が何をどう評価したか」という出来事として取り出すだけです。研究思想の「LLMの感情判断を教師にしない」はそのまま守ります。

信念ネットは、出来事の結果の確率を予測します。その確率を「この相手のせい」「この場面のせい」「人一般の傾向」のどれが担っているかも推論し、階層ベイズで学びます。誤差は結果そのものの対数損失です。こうすると、少数の経験の過剰一般化と、反証による個別の訂正が同じ原理から出ます。新しい経験を重ねても過去の形成史の痕跡は上位の層に残ります。

この結論に至った理由は三つです。

1. **現行の再設計案の学習則は、構造的に自己増幅します**（第1節）。学習目標「感じた価値」の中に、更新される獲得価値自身が利得1で入っているためです。結果にだけ現れる概念（作者性、達成など）では正帰還、手掛かりにも現れる概念では有限の不動点がなく ½ log t で増え続けます。大きさを止めているのは減衰係数です。
2. **教師を生得価値だけにすると安定しますが、3-F と同じ失敗に戻ります**（第1節）。スカラーの誤差に人格によらない特徴を掛ける更新では、学習の向きが全人格で同じになります（玩具で人格間の向きの cos = 1.00）。さらに縮小写像なので、新しい経験を重ねると履歴差が指数的に消えます（玩具の TD で新経験8回後に51%、32回後に11%）。
3. **両方を避ける条件は特定できます**（第2節・第5節）。教師は外生に置き、感じた価値は読み出しに留めて目標にしません。人格依存性は教師の配分・欲求状態・信頼・事前の側に入れます。履歴の持続は縮小しない遅い変数（設定点、過訓練で固まるキャッシュ、階層の上位）に担わせます。

「新しい価値観」の範囲も明示します。このフレームで作られる新しい価値は、(a) 生得価値を持たない対象・相手・概念の組み合わせへの価値、(b) 欲求の設定点（何をどれだけ必要とするか）の移動、(c) 元の強化子が消えても残る自律した価値、(d) 他者から取り込んだ価値、(e) 学習の進み具合から生じた関心、の五種類です。**欲求の種類そのもの（最上位の価値の軸）が経験から生まれる仕組みは、このフレームでも未解決**です（第8節）。

本書の数値はすべて玩具の計算（`learning-mechanisms/toys/`）で、手で置いたパラメータによる機構の確認です。実験結果ではありません。候補の詳細な比較は付録 [04a 価値ネットの候補](04a-value-net-candidates.md) と [04b 信念ネットの候補](04b-belief-net-candidates.md) にあります。

## 1. 出発点：現行案の学習則はどこで自己増幅するか

再設計案（`redesign/prototype.py`）の学習則は次のとおりです。

```
感じた価値  f = tanh( i·o + v·o + β·m )      i: 生得価値（固定）, v: 獲得価値, o: 結果の特徴, m: 気分
予期        q = tanh( v·c )                  c: 状況の手掛かり
驚き        δ = f − q
更新        v += α′ δ c  （状況）,   v += γ α′ δ o  （共起）,   帰属・減衰
```

### 補題1：自己増幅の条件

更新を `θ ← θ + α (T(θ) − P(θ)) g` と書くと（T: 目標、P: 予測、g: 更新の方向）、不動点の安定性は `(T′ − P′) g < 0` で決まります。

| 概念の現れ方 | T′（目標の感度） | P′（予測の感度） | 結果 |
| --- | --- | --- | --- |
| 結果にだけ現れる（作者性・達成・損失など） | sech²(i+v)·o > 0 | 0（予期は v_o を含まない） | **常に正帰還**。1次元では不安定点 ≈ −i、外側の安定点 ±α/d（玩具で ±37.5）。減衰 d=0 なら線形に発散 |
| 手掛かりと結果の両方に現れる（音楽、つながりなど） | sech²(i+v) | sech²(v) | 局所的には安定。ただし不動点は a=i·o≠0 のとき存在せず、v ≈ ½ log t で増え続ける。減衰を入れると止まるが、止まる値は d で決まる |

数値確認（玩具）：手掛かりと結果の両方に現れる概念で、減衰なしの v は t = 10, 100, …, 10⁵ で 1.23, 2.43, 3.59, 4.75, 5.90 と、1桁ごとに ½ln10 ≈ 1.15 ずつ増えます。減衰 d = 0.002 では 2.449 で止まりますが、生得価値を i = 0.05 から 1.0 まで20倍にしても不動点は 1.67 から 2.58 にしか変わりません。**人格の価値の大きさは、経験ではなく減衰係数で決まっています。**

試作の3人格の値が有界に収まったのは、手掛かり側の予期が同時に育って驚きを打ち消したためです。長い経験史で常に打ち消される保証はありません。試作初版の「音楽 −6.73」はこの正帰還の実例です。

### 補題2：教師を外生にしただけでは、学習の向きが人格で同じになる

更新が `Δθ = α δ φ(出来事)` の形（δ はスカラー、φ は人格によらない特徴）なら、更新の向きは符号を除いて全人格で同一です。人格ごとに向きを変えるには、次のどれかが必要です。

- (a) 人格に依存する前処理: `Δθ = α δ K_人格 φ`（帰属、注意、カルマン利得など）
- (b) ベクトル値の教師: 欲求ごと、チャンネルごとの誤差
- (c) 人格に依存する特徴: 人格ごとに学習した概念射影

玩具での測定（同じ新経験に対する3人格の更新ベクトルの cos）：生得だけを教師にする TD で 1.00、手段の目的化（後述 E）で 0.96。3-F の学習目標差が RMS 0.00014〜0.016 だったのは、この補題と同じ構造です。

### 補題3：縮小写像は履歴を忘れる

`θ_{t+1} = (1−α)θ_t + α T(θ_t)` で `|T′| = g < 1` なら、二つの履歴の差は `ρ^t`（ρ = 1−α(1−g)）で縮みます。同じ統計の経験を与えれば同じ値に収束し、順序・初期状態・人格差は指数的に失われます。

玩具：履歴差 3.0 の2人格に同じ新経験を8回（学習率 0.3）与えると、利得 g = 0 で差 0.17、g = 0.5 で 0.82、g = 0.9 で 2.35 が残ります。持続させようと g を 1 に近づけると、生得価値の増幅 a/(1−g) も同時に大きくなります。**持続と可塑性を両立させるには、縮小しない方向が要ります。**

### 補題4：零空間には教師が届かない

いつも一緒に現れる冗長な特徴を外生の教師で回帰すると、教師が決めるのは予測の和だけです。特徴間の配分は初期値・順序・配分の重みで決まり、教師からの復元力を受けません。玩具：冗長な2特徴で w₁+w₂ = 1 は常に守られ、配分は乱数種によって (0.61, 0.39)、(0.31, 0.69)、(0.63, 0.37)、(0.77, 0.23) に分かれました。

「いま大事にしているものに多く帰属する」という自己参照をこの零空間に閉じ込めれば、当てはまりを壊さずに履歴依存の個性が作れ、発散もしません。

### 1.5 この節の帰結

| 方式 | 自己増幅 | 学習の向きの人格依存 | 履歴の持続 |
| --- | --- | --- | --- |
| 自己参照する目標（現行案） | あり（大きさは係数が決める） | あり | 強すぎる（飽和でロックイン） |
| 外生の教師だけ（3-F、TD） | なし | なし（補題2） | なし（補題3） |
| 本書の配分型フレーム | なし（教師は外生） | あり（配分・欲求・信頼・事前） | あり（縮小しない遅い変数） |

## 2. 「新しい価値観が形成された」の判定

経験史 h を経た人格の、プローブ x への評価を U_h(x)、生得価値を I(x) とします。比較の基準を二つ置きます。

- Ref_EC(x; h): I と「何と何が一緒に起きたか」の統計だけから作る最良の予測（評価条件づけで説明できる範囲）
- Ref_TD(x; h): I と「何の後に何が起きたか」の統計から作る予測（手段としての価値で説明できる範囲）

| 記号 | 条件 | 意味 |
| --- | --- | --- |
| NV0 獲得 | I(x) = 0 の対象で U_h(x) が初期と異なる | 対象の新しさ |
| NV1 連合超過 | U_h − Ref_EC に再現性のある残差 | 共起の統計を超える |
| NV2 統計超過 | U_h − Ref_TD に残差 | 世界の統計を超える（源が生得以外） |
| NV3 自律 | 元の強化子を取り除いても価値が残る | 手段が目的になった |
| NV4 構造差 | 同じ出来事の集合で、順序・帰属・信頼・選択・当時の解釈だけが違う履歴が、異なる U を生む | 経路依存 |
| NV5 信念からの分離 | 信念ネットを人格間で入れ替えても残る評価差の割合 | 予測の違いでなく価値の違い |
| NV6 転移 | 学習に使っていない概念や組み合わせに効く | 暗記でない |
| NV7 反事実 | その経験を除いて学習し直すと消える | 因果 |

残差だけでは「新しい価値」と「増幅の歪み」を区別できません。現行案は Ref_EC との R² が 0.33 と残差が大きいのですが、その残差は減衰係数を変えると大きさが変わります。そのため次のガード検査を併用します。

- G1 係数不変: 学習率や減衰を2倍・1/2にしても、符号と順位が変わらない。
- G2 内容依存: 結果の特徴を出来事間で入れ替えると値が変わる。
- G3 再現: 乱数種や言い換えを変えても再現する。
- G4 教師の独立: 更新目標の分散のうち、価値ネット自身の出力で説明される割合が 0 であることを静的に確認する。
- G5 反転可能: 有限の反対経験で反転する（ロックインでない）。

「新しい価値観あり」と言う基準は、NV0 ∧（NV1 ∨ NV3 ∨ NV4）∧ G1〜G5 とし、NV5 の分解を併記します。「設計者が指定していない価値」という強い主張は、NV2、NV3、構造差の NV4 のいずれかを満たす場合に限ります。

## 3. 問1：価値ネットは何を学習信号にするか

### 3.1 候補の比較

（–：玩具で同じ指標を測っていない。保持と cos の数値は玩具で、手置きのパラメータによる。）

読み取り：

- 生得だけを教師にする B と E は、向きが人格でほぼ同じです（補題2）。
- 縮小する B と I は履歴を忘れます（補題3）。
- 向きを分けるのは、配分（A′）、欲求の状態（C）、信頼（G）、事前（I）です。
- 生得以外の価値の源を持つのは C（欲求の状態の履歴）、D（自分の学習の力学）、F（自分の選択とコスト）、G（他者）だけです。

### 3.2 推奨：アンカー付き多源価値学習

単一の方式では補題1〜4のどれかを満たせないため、役割を分けて組み合わせます。

**設計原則**

| 原則 | 内容 |
| --- | --- |
| P1 教師は外生 | 価値の更新目標に価値ネット自身の出力を入れない。入れる場合は凍結コピー、γ < 1、外生の報酬によるアンカーを必須にする |
| P2 感じた価値は読み出し | 感じた価値は感情・選択・学習率の調整に使うが、更新の目標にはしない |
| P3 自己参照は零空間へ | 「いま大事なものに多く帰属する」配分は、外生の教師が決められない自由度だけで働かせる。総量は教師が決める |
| P4 持続は縮小しない遅い変数に | 設定点（アンカー付き）、過訓練で固まるキャッシュ、精度つきの記憶、配分の零空間 |
| P5 源ごとに別のチャンネル | 欲求の充足、社会的な評価、関心を別々に持つ。「嫌いだが知りたい」「正しいと思うが抵抗がある」を一つの状態で持てる |

**生得の層の作り直し。** 現行案の生得価値はスカラー（成果 +0.5、損失 −0.6 など）でした。本書では、生得の層を**少数の欲求に対する効果のベクトル**にします。欲求の候補は、関係性、有能感、自律、刺激、安全です。結果 o が欲求 h をどれだけ変えるか（Δh = M(o)）を固定の関数とし、価値は「欲求のずれがどれだけ減ったか」で測ります（ホメオスタシス強化学習の形）。これで補題2の (b)（ベクトル値の教師）が満たされます。M と欲求関数 D は設計者の所与で、学習しません。

**状態変数と時間スケール**

| 時間スケール | 変数 | 意味 |
| --- | --- | --- |
| 速い | 欲求の状態 h、気分 m | いま何が足りないか |
| 中 | 概念ごとの欲求効果 û(x)、キャッシュ V_MF(x)、社会的な価値 w_soc(x)、相手への信頼 τ_j、関心 ι(d) | 獲得した価値の本体 |
| 遅い | 設定点 h*、精度 n_x、配分の零空間 | 何をどれだけ必要とするか、どの価値が固まったか |

**評価（読み出し。目標にはしない）**

```
モデルベースの価値   V_MB(x | h) = E_{o ~ 信念 p(·|x)} [ D(h; h*) − D(h + M(o); h*) ]
調停                 U_hed(x) = ω_x V_MF(x) + (1 − ω_x) V_MB(x | h),   ω_x = n_x / (n_x + n_h)
感じた価値           f = tanh( Σ_x z_x [ U_hed(x) + λ_s w_soc(x) ] + β m )
関心                 ι は接近・探索の誘因として別に読み出す
```

**更新（教師はすべて外生。計算グラフ上は勾配を止める）**

```
[欲求効果]  û_x ← û_x + α s_x z_x ( Δh_観測 − Σ_x′ z_x′ û_x′ )
            s_x ∝ ( |U_hed(x) z_x| + ε )^ρ,  Σ_x s_x = 1         ← 配分は零空間（P3）。教師は観測された欲求の変化
[キャッシュ] V_MF(x) ← V_MF(x) + a_x ( V_MB(x | h) − V_MF(x) ),   a_x = max( 1/(n_x+1), a_min )
[社会]      w_soc(x) ← w_soc(x) + η τ_j ( u_{j,x} − w_soc(x) )     u: 相手 j の表明した評価
            τ_j = (1 + b_j) / (2 + b_j + h_j)                      b_j, h_j: 相手が欲求を満たした・予測が当たった回数／害した・外れた回数
[関心]      ι_d ← ι_d + η_ι ( LP_d − ι_d )                         LP_d: 信念ネットの領域 d での予測誤差の減少
[設定点]    h* ← h* + η_h · r(o) · (h − h*) + ρ_h ( h⁰* − h* )      r(o): その出来事が欲求に関わった度合い
[予報]      V̂(o | c, e) ← δ_V = f − V̂(o_実際)                      自分の反応の予測。価値の本体は更新しない
[学習率]    a_x, η は精度と |δ_V|（自分にとっての意外さ）、気分で調整
```

設定点の更新に `r(o)` を掛けたのは、玩具で見つかった破綻（無関係な経験が200回続くと設定点が崩れ、3人格が同じ基準に収束した）への対処です。欲求に関わらない経験では設定点を動かしません。時間の単位は経験の更新回数なので、「何も起きない時間」は「関係のない更新」と同じ意味になります。

**経験前の人格は、どこで学習の向きを変えるか。** 教師の大きさではなく、次の7か所です。

1. 配分 s：いま大事にしている概念に、より多くの責任が回る。
2. 帰属：その結果を誰（何）のせいにするか（信念ネットのスコープ推論）。
3. 信頼 τ：誰の評価を取り込むか。
4. 欲求の状態と設定点：同じ結果が自分にとって何を意味するか（ベクトルの教師）。
5. 解釈：曖昧な出来事を今の信念に沿って読む（実験で入れたり切ったりする）。
6. 接近・回避：何を経験しに行くか。避けた出来事からは学ばない。
7. 学習率：自分の予期に対する意外さと気分で、学ぶ量が変わる。

どの経路も、価値ネットの出力を自分の目標にしません（補題1を満たす）。それでいて人格依存の前処理・ベクトルの教師・人格依存の標本を作るので、学習の向きが分かれます（補題2を満たす）。

### 4.2 推奨：スコープ帰属つき階層ベイズ信念

A を骨格にし、C の責任配分、F の簡約、D の界面を組み合わせます。

**予測対象。** 状況 c と関与者 e のもとで、結果型 k が起きる確率 P(y_k = 1 | c, e) です。結果型は、凍結した文埋め込み上のオンラインの原型（辞書）で、必要に応じて増えます。候補文の確率は測定のときだけ読みます。

**確率分布。**

```
スコープ単位 x ∈ { 相手 e, 場面 c, 一般 g }。各単位が結果型 k の確率 θ_{x,k} を持つ
  θ_{g,k} ~ Beta(a₀, b₀)
  θ_{c,k} ~ Beta(κ_c θ̄_{g,k}, κ_c (1 − θ̄_{g,k}))      場面は一般から事前を受ける
  θ_{e,k} ~ Beta(κ_e θ̄_{g,k}, κ_e (1 − θ̄_{g,k}))      相手は一般から事前を受ける。κ_e は「人はどれほど違うか」
スコープの事前  π_{·,k} ~ Dirichlet(ξ_k)               その結果型を「人のせい」にするか「場面のせい」にするか
予測            P(y_k = 1 | c, e) = Σ_x π_{x,k} E[θ_{x,k}]
```

**学習誤差。** 結果そのものの対数損失 `L_B = −log P(o_t | c_t, e_t)` です。結果が予測と違えば、価値が同じでも学びます。これが「信念だけが変わる経験」を可能にします。

**更新。**

```
責任    r_{t,x} ∝ π_{x,k} · Bern(y; E[θ_{x,k}]) · Λ[x, 行為者タグ]    Λ: LLM の行為者タグの誤りをモデル化した混同行列
計数    α_{x,k} += r y,   β_{x,k} += r (1 − y),   π の計数 += r          （オンラインEM）
割引    各単位の計数を 1/(1 + ν_x) で割り引く。ν_x: 予測誤差の移動平均と期待されるばらつきの比（変動性）
上位    θ̄_g, κ_c, κ_e, ξ は、単位の数（相手の数、場面の数）を標本数とする周辺尤度で学ぶ
```

**ニューラルネットの役割（オーケストレーターの追加）。** 計数は、見たことのある相手と場面にしか使えません。未知の相手や場面への転移のために、埋め込み（c, e）から事前の (θ̄, κ) を出す小さなネット（事前ヘッド）を置きます。事前ヘッドは、想起（リプレイ）のたびに各単位の事後分布へ近づけて学びます。速い計数の記憶と、遅く一般化するネットを分ける構成は、補完学習系の考え方（McClelland, McNaughton & O'Reilly 1995）に対応します。研究思想 第10節の「NNが転移や文脈依存で優れるか」は、この事前ヘッドを線形・検索と比べることで検証できます。

**なぜこの方式か（玩具の数値）。**

- **持続と可塑性の両立。** 8人から1回ずつ手柄を取られた人格と、取られなかった人格を比べます。新しい相手Nと8回、手柄を取られない経験をした後も、未見の相手への予測の差は 89% 残りました（0.572→0.510）。一方、N自身への予測は 0.68 から 0.09 まで動きました。固定学習率 α = 0.25 では差が 10% しか残らず（3-F の「8回で消えた」と整合）、単層の計数では N への予測が 0.43 で止まりました。上位の層の有効な標本数は「経験の数」ではなく「相手の数」なので、1人の新しい相手との経験は上位をほとんど動かしません。
- **検証できる予測。** 同じ8回でも、1人から受けたか8人から受けたかで、未見の相手への差の保持率が 70%（1人）から 89%（8人）に変わります。固定学習率や単層の計数では、この差は出ません。
- **H4 の三つの性質が同じ原理から出る。** 転移比（初対面の相手への一般化の度合い）は、同じ相手からの反復で 0.41→0.30 と狭まり、多様な相手からでは 0.41→0.85 と広いまま残りました。
- **H7 の分離条件を数学的に書ける。** 信念と価値のパラメータを分け、信念は対数損失、価値は δ_V だけで更新し、価値中立な結果の対を作れることが十分条件です（4.3）。

### 4.3 価値ネットとの相互作用

**共通の界面。** 予期と驚きを次のように定義します。

```
予期          Q(c, e) = Σ_k P(y_k = 1 | c, e) · V̂_k(c, e)
驚きの分解    δ = f − Q = δ_V + δ_W
  δ_V = f − V̂(o_実際 | c, e)                         価値の誤差：結果は想定どおりでも、感じ方が違った分
  δ_W = V̂(o_実際 | c, e) − E_{o~P}[ V̂(o | c, e) ]    世界の誤差を価値の単位に直した分
```

δ_V は価値ネットの予報ヘッド V̂ と学習率の調整にだけ使い、価値の本体（û、V_MF、w_soc）の目標にはしません（第3節 P2）。信念は δ_W ではなく対数損失で学びます。

**信念→価値**

| 経路 | 内容 |
| --- | --- |
| 予期 | 予測分布を今の価値で評価した期待値。接近・回避の選択に使う |
| 帰属による配分 | 相手 e の価値の更新量は、その結果への e の責任 r に比例する |
| 手段価値 | V_MB は信念の予測を欲求関数で評価したもの |
| 関心の源 | 信念ネットの領域ごとの学習進捗 LP が関心 ι の教師になる。生の予測誤差は使わない（予測できない雑音に執着する「ノイズTV問題」を避ける） |
| 価値の軸を与える | 価値は信念ネットが切り出した結果型・相手・場面・領域に付く。経験で辞書や単位が増えると、価値が付く対象も増える |

**価値→信念**（どれも実験条件として入れたり切ったりする）

| 経路 | 内容 | 既定 |
| --- | --- | --- |
| 接近・回避 | 避けた出来事の結果は観測されない（熱いストーブ効果） | ON（探索ボーナスと回避中の分散膨張は事前に固定） |
| 曖昧な解釈 | 曖昧な出来事の解釈を今の信念で重み付ける。硬い割当ほど偏る | 厳密（偏りなし）。E4b で硬さを上げる |
| 望ましさによる更新の非対称 | 良い知らせほど多く学ぶ | OFF |
| 価値で重み付けた予測損失 | 価値に効く誤差を優先して学ぶ | OFF |
| 自己奉仕的な帰属 | 悪い結果を他者のせいにしやすい | OFF |

**H7（価値と信念を別々に変えられる）の十分条件**

| 条件 | 内容 |
| --- | --- |
| S1 パラメータの分離 | 信念と価値が共有する射影は、片方の損失の勾配で他方の読み出しが動かないようにする |
| S2 誤差の分離 | 信念は対数損失、価値の予報は δ_V だけ。δ（合計）で価値を更新しない |
| S3 信念だけを動かせる | 価値が等しく、結果としては異なる対がある（「頼りにならないが優しい」と「頼りになるが冷たい」） |
| S4 価値だけを動かせる | 信念が飽和した（完全に予期できる）出来事を、価値が変わった後に再経験・想起する |
| S5 結合の記録 | 価値→信念の経路のうち有効にしたものを記録し、切った対照を置く |

予期 Q は信念と価値のどちらが変わっても動きます。H7 は Q ではなく、候補文への確率（信念）と評価の直接の読み出し（価値）を別々に測ります。

## 5. 統合モデルフレーム：1回の経験で何が起きるか

```
0. 意味の取り出し（LLM）
   状況 c、関与者 E、結果の部分 O と行為者タグ、他者の表明 {(j, x, u)}、曖昧な部分の解釈候補
   LLM は数値や感情の判断を出さない

1. 予期と選択（結果を見る前）
   信念: P(y_k | c, e)。価値: Q と関心 ι
   接近・回避を選ぶ。回避した場合は「避けた」ことだけを記録し、信念も価値も結果からは学ばない

2. 解釈と帰属（信念ネット）
   曖昧な部分の解釈の重み、結果型への割当、各結果部分の責任 r（相手・場面・一般）

3. 評価（価値ネット。読み出し）
   欲求の変化 Δh = M(o)、手段価値、キャッシュ、社会的な価値、気分から、チャンネルごとの感じた価値 f
   感情（喜び、怒り、失望など）は、δ_V、δ_W、帰属、欲求のどれが動いたかの組から読み出す

4. 信念の更新
   計数（責任で重み付け）、変動性、辞書。教師は観測された結果

5. 価値の更新
   欲求効果（配分つき）、キャッシュの蒸留、社会的な取り込み（信頼で重み付け）、関心、設定点（欲求に関わった分だけ）、
   信頼の実績、予報ヘッド。教師はすべて外生

6. 気分と台帳
   気分は最近の驚きの勢い。全ての更新を「経験ID、教師の種類、配分の重み、変化量」として台帳に記録する

7. 想起・反すう（オフライン。経験の合間に）
   保存した経験を再生し、(a) 今の信念で帰属と解釈をやり直す、(b) キャッシュの蒸留を進める、(c) 事前ヘッドを学習する
   禁止: 今の感じた価値を、過去の経験の価値の教師にすること（想起による自己増幅になる）
```

**想起の扱いについて。** 再設計案は、想起のたびに過去の経験を今の価値で評価し直し、その差を学ぶとしていました。これは補題1の正帰還を想起の側で起こします。本書では、想起で変えてよいものを「誰のせいだったか」（信念）と「どこに配分するか」（零空間）に限ります。過去の意味づけは変わりますが、教師は当時記録した外生の量（欲求の変化、表明、結果）のままです。

## 6. 具体例：同じ出来事を3人格はどう学ぶか

再設計案と同じ出来事を使います。**初めて会う友人Aに誘われて一緒に曲を作った。曲は好評で、Aから新しい技法も学んだが、自分の案はほとんど採用されなかった。**

人格は、協働に救われた R、作者性を奪われた K、探索者 X です。下の表は、フレームの各経路がこの出来事で何をするかを符号で示した導出です。G の行と E の作者性の値は玩具の計算値ですが、それ以外の行は実行結果ではありません。

| 経路 | R（協働に救われた） | K（作者性を奪われた） | X（探索者） |
| --- | --- | --- | --- |
| 欲求の状態 | 関係性は満たされている | 自律の設定点が高い（一人で成功した履歴） | 刺激（新奇さ）の設定点が高い |
| 欲求の変化 Δh | 関係性 +、有能感 + | 関係性 +、**自律 −**（案が消えた） | **刺激 +**（新技法）、関係性 + |
| 帰属（信念） | 成功は「協働」に、案の不採用は場面のせい | 案の不採用を**A個人に**帰属（共同作業者に手柄を取られた履歴が、相手単位への帰属を強めている） | 新技法をA個人に帰属 |
| 配分 s | つながりに多く配分 | 作者性・自律に多く配分 | 新奇さに多く配分 |
| Aへの価値 | ＋（関係性を満たした） | **−**（自律を損なった責任がA） | ＋（刺激を満たした） |
| 信念の変化 | 「協働はうまくいく」が強まる（一般の層） | 「Aは案を通さない」は相手単位に入り、一般の層はあまり動かない | 「Aは新しいものをくれる」（相手単位） |
| キャッシュ（作者性） | ほぼ育っていない | +0.242 が残り、この出来事で信念側の価値が下がっても感じ方は高いまま（玩具: 感じる値 +0.222） | ほぼ育っていない |
| Aの「作者性は大事ではない」という表明 | 取り込む（信頼 0.94） | ほぼ取り込まない（信頼 0.10） | 取り込む（信頼 0.83） |
| 関心 | 変化小 | 変化小 | 音楽の技法の予測が上達すれば、音楽そのものは嫌いでも関心が生まれる |

現行案との違いは、K のAへの評価が下がる理由にあります。現行案では、K の獲得価値（作者性 +0.60）がそのまま学習目標の大きさに入っていました。本書では、学習目標は「自律の欲求が損なわれた」という外生の量です。K の過去が効くのは、(1) それをA個人の責任と推論すること、(2) 作者性に配分すること、(3) 自律の設定点が高いこと、の三か所です。同じ損なわれ方でも、R は場面のせいにし、つながりに配分します。だからAへの価値は下がりません。

## 7. 破綻条件と検出

| 破綻 | 起きる条件 | 検出方法 |
| --- | --- | --- |
| 自己増幅（正帰還） | 価値の出力が自分の更新目標に入る（G4 違反） | 計算グラフの静的検査。減衰係数を変えたときに大きさが比例して動くか（G1） |
| 履歴の消失 | 全ての経路が縮小写像 | 未見の相手・場面への履歴差の保持率（持続）と、反証を受けた相手自身の更新量（可塑性）を別々に測る |
| ロックイン | 有界な正帰還の利得が大きすぎる、キャッシュの学習率の下限 a_min が小さすぎる | 反転に必要な経験数。反転しない（G5 違反） |
| 設定点の崩壊 | 欲求に関わらない経験でも設定点が適応する | 無関係な経験を200回与えた後の価値の保持比と、人格間の分散 |
| 反響室 | 信頼を「自分と意見が合うか」で決める（玩具: 許容幅 s < 1 で分極） | 信頼の分布、人格間の価値の分散の縮小、情報源を除いた学び直し |
| 源の単一化 | 全人格が同じ情報源（ユーザー、LLM）から取り込む | 情報源の除去で価値がどれだけ消えるか |
| 帰属の暴走 | 自己奉仕的な帰属と、帰属による価値の配分が結合する | 価値→信念の経路を全て切った「影の信念」との乖離が、証拠が増えないのに増える |
| 熱いストーブの永久化 | 回避で反証の機会がなくなる | 誤った否定的信念が正されるまでの経験数（玩具: 選択なしなら否定と肯定でほぼ同じ 0.95 倍、貪欲な選択では 9.6 倍） |
| ノイズへの執着 | 生の予測誤差を関心の源にする | 予測できない領域での関心が下がるか（学習進捗を使う） |
| 想起による自己増幅 | 想起で今の価値を教師にする | 想起の前後で、外生の教師がないまま価値が一方向に動くか |
| 抽出の誤りの学習 | LLM の行為者タグや関与者の同一性の誤り | 混同行列 Λ を推定し、意図的に誤りを入れた履歴との比較 |
| 係数への依存 | 結果を見てからパラメータを調整する | 事前に固定し、別に感度分析を行う（G1） |

## 8. 未解決の点

1. **（最大）最上位の価値の軸は設計者の所与です。** 欲求の種類、結果から欲求への効果 M、欲求関数 D は設計者が与えます。このフレームの新しい価値は、所与の欲求の上での対象・配分・設定点・自律・社会・関心の変化です。人間の価値の源も、生得的な欲求、他者、好奇心に限られるという見方があり（Juechems & Summerfield 2019）、この範囲は研究目的と矛盾しないと考えます。ただし、「欲求そのものが経験から生まれる」ことは主張できません。
2. **検証できない価値への証言には、外生のアンカーがありません。** 美や倫理への他者の評価は、結果で確かめられません。信頼が親和に流れると反響室になります。合成の経験史で証言を設計者が書けば、設計者の価値が間接に入ります。
3. **零空間の個性は「経路が選んだもの」です。** 恣意的な個性と、意味のある個性を区別するには、再現性、反事実での因果、人間による解釈の評価が必要です。
4. **信念ネットは離散的な足場に依存します。** 結果型の辞書、関与者の同一性、行為者タグ、場面のクラスは LLM の抽出で決まり、その誤りは系統的な信念になります。事前ヘッドで未知の場面への一般化を補いますが、辞書にない種類の結果には弱いままです。
5. **統合系の数値的な確認は一部だけです。** 玩具で確かめたのは、価値側の L1・L2 と、信念側の階層ベイズ・潜在原因の部分だけです。統合したフレーム全体（欲求、社会、関心、スコープ帰属、事前ヘッド）は動かしていません。
6. **実験計画への注意点**（修正は次の段階で行います）。
   - 実験計画の E4c（熱いストーブ）の「否定的信念の持続が肯定的信念の2倍以上」という基準は、探索の強さで 9.6 倍から 1.9 倍まで動きます。λ と ρ を事前に固定する必要があります。
   - H6a（曖昧な出来事の確証バイアス）は、厳密なベイズでは出ません（玩具で偏り 0.750→0.750）。偏りの源（解釈の硬い割当、近似推論、事前の二重数え）を名指しして切り替えます。
   - H4 の「他の関与者や場面へ」の一般化は、相手と場面の二つの軸に分けて測ります。
   - 持続は「未見の相手への差」、可塑性は「反証を受けた相手自身の更新」で、別々に報告します。
