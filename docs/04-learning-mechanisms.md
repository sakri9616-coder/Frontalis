# Frontalis 学習機構：価値ネットと信念ネットは何から何を学ぶか

Oct 15, 2026

## 結論

**価値ネット（問1）。** 学習の教師は、価値ネット自身の出力に依存しない量にします。具体的には、出来事が欲求の効用をどれだけ変えたか（欲求ごとのベクトル）、他者が何をどう評価したか、信念ネットがどれだけ上達したか、の三つです。

価値は「個体（相手A、この曲）／類（共同作業者、音楽）／一般（人、活動）」の三層に置き、各層の重みをカルマン回帰で学びます。人格の過去が効くのは次の四点です。

- 新しい個体が類から**継承する予期**（欲求ごとの予測誤差の符号を決める）
- 確信の度合い（事後分散）による**責任の配分**
- 帰属
- 信頼

この構成を**精度配分・階層型フレーム**（以下 v3）と呼びます。

**信念ネット（問2）。** 結果型の確率を予測し、その確率を「この相手」「この場面」「人一般」のどの単位が担うかを推論する階層ベイズで学びます。誤差は結果そのものの対数損失です。上位の層は「経験の数」ではなく「相手の数」を標本数にします。そのため、新しい相手との経験で過去の形成史の痕跡は消えにくく、その相手自身への予測は素早く変わります。価値ネットも同じ原理で作るので、二つのネットは同じ足場（個体・類・一般）を共有します。

**玩具での確認（実験ではありません）。**

- **持続と可塑性の両立:** 新しい相手と 8〜32 回の経験を重ねた後も、未見の相手への人格差は 91〜93% 残りました。新しい相手自身への評価は真値に 100% 近づきました。階層のない版、固定学習率、1/n 計数はいずれも両立しませんでした。
- **学習の向きの分岐:** 同じ出来事から学ぶ向きは人格で逆になりました。協働に救われた人格と探索者は A を「共同作業者一般より少し下」と学び（−0.065、−0.067）、作者性を奪われた人格は「思ったより良い相手」と学びました（+0.618）。
- **自己増幅の有無:** 変動性を層ごとに固定した構成では、状態写像のスペクトル半径が全事象で 1.0000 以下で、自己増幅はありません（変動性も学習させると、大きな予測誤差の直後に一時的に最大 1.214）。

**この結論は、二度の独立した批評と検証で大きく変わりました**（第3.2節）。

- **初稿の失敗:** 「いま大事なものに多く責任を回す」配分は、それ自体が正帰還でした。証拠では区別できない 0.1% の差を配分 0.31〜0.65 まで増幅し、新しい概念（音楽）に価値が回りませんでした。
- **v2 の失敗:** 配分をカルマン利得に替えて正帰還は消えましたが、持続と可塑性を同じ単位に求めていたため、両立できませんでした。
- **v3 の解決:** 階層化で、持続と可塑性を別の単位に担わせました。

作者性を奪われた人格が A を嫌う、という再設計案の具体例の符号は、v3 からは出ません（第6節）。

「外生」という言葉の意味も先に定めておきます。本書の「外生の教師」は、**価値ネット自身の出力に依存しない量**のことです。LLM や研究者が正解の感情を与えるという意味ではありません。欲求の状態は NPN の内部状態で、その変化は出来事の事実から固定の関数で計算します。他者の評価は、LLM が「誰が何をどう評価したか」という出来事として取り出すだけです。研究思想の「LLMの感情判断を教師にしない」はそのまま守ります。

「新しい価値観」の範囲も明示します。このフレームで作られる新しい価値は、次の五種類です。実験条件として、経験と選択で形作られる反転しにくい確信（コミットメント）を加えられます。

- (a) 生得の価値を持たない対象・相手・類への、経験した効用からの価値。類の価値は、多くの個体の経験から形成される
- (b) 元の強化子が変わっても遅れて残る価値（習慣化）
- (c) 他者から取り込んだ価値
- (d) 上達できた領域への関心と、それによる価値
- (e) 無関係な共起から移った好悪（評価条件づけ）

**最上位の価値の軸（欲求の種類と効用関数）は設計者の所与で、経験からは生まれません**（第8節）。(b) の残り方が「安定した履歴ほど長い」という形成過程の性質も、まだ示せていません。

本書の数値はすべて玩具の計算（`learning-mechanisms/toys/`）で、手で置いたパラメータによる機構の確認です。実験結果ではありません。候補の詳細は付録 [04a 価値ネットの候補](04a-value-net-candidates.md)、[04b 信念ネットの候補](04b-belief-net-candidates.md) に、初稿への批評と v2・v3 の検証は [04c 批評と検証](04c-critique-and-verification.md) にあります。

## 1. 出発点：現行案の学習則はどこで自己増幅するか

再設計案（`redesign/prototype.py`、ブランチ `claude/project-thread-1vq8ai`）の学習則は次のとおりです。

```
感じた価値  f = tanh( i·o + v·o + β·m )      i: 生得価値（固定）, v: 獲得価値, o: 結果の特徴, m: 気分
予期        q = tanh( v·c )                  c: 状況の手掛かり
驚き        δ = f − q
更新        v += α′ δ c  （状況）,   v += γ α′ δ o  （共起）,   帰属・減衰
```

### 補題1：自己増幅の条件

更新を `θ ← θ + α (T(θ) − P(θ)) g` と書きます（T: 目標、P: 予測、g: 更新の方向）。`(T′ − P′) g < 0` であれば、指数的な暴走は起きません。

| 概念の現れ方 | T′（目標の感度） | P′（予測の感度） | 結果 |
| --- | --- | --- | --- |
| 結果にだけ現れる（作者性・達成・損失など） | sech²(i+v)·o > 0 | 0（予期は v_o を含まない） | **常に正帰還**。1次元では不安定点 ≈ −i、外側の安定点 ±α/d（玩具で ±37.5）。減衰 d=0 なら線形に発散 |
| 手掛かりと結果の両方に現れる（音楽、つながりなど） | sech²(i+v) | sech²(v) | 指数的な暴走はない。ただし i·o ≠ 0 なら不動点がなく、v ≈ ½ log t で増え続ける。減衰を入れると止まるが、止まる値は d で決まる |

数値確認（玩具）：手掛かりと結果の両方に現れる概念で、減衰なしの v は t = 10, 100, …, 10⁵ で 1.23, 2.43, 3.59, 4.75, 5.90 と、1桁ごとに ½ln10 ≈ 1.15 ずつ増えます。減衰 d = 0.002 では 2.449 で止まります（i = 0.5 の場合）。しかし生得価値を i = 0.05 から 1.0 まで20倍にしても、不動点は 1.67 から 2.58 にしか変わりません。d に対する弾力性は −0.27 で、証拠（i）に対する弾力性 +0.16 を上回ります。**価値の大きさは、経験より減衰係数で決まっています。**

### 補題2：教師を外生にしただけでは、学習の向きが人格で同じになる

更新が `Δθ = α δ φ(出来事)`（δ はスカラー、φ は人格によらない特徴）の形なら、更新の向きは符号を除いて全人格で同一です。玩具では、生得だけを教師にする TD で、3人格の更新ベクトルの cos が 1.00 でした。従来の NPN（Phase 3-F、以下 3-F）の学習目標差が RMS 0.00014〜0.016 だったのも同じ構造です。

人格ごとに向きを変えるには、次のどれかが必要です。

- (a) 人格に依存する前処理（帰属、カルマン利得など）
- (b) ベクトル値の教師（欲求ごとの誤差）。人格ごとの予期と比べた各成分の符号が変わる
- (c) 人格に依存する特徴

### 補題3：縮小写像は履歴を忘れる

`θ_{t+1} = (1−α)θ_t + α T(θ_t)` で `|T′| = g < 1` なら、二つの履歴の差は `ρ^t`（ρ = 1−α(1−g)）で縮みます。同じ統計の経験を与えれば同じ値に収束し、順序・初期状態・人格差は指数的に失われます。玩具では、履歴差 3.0 の2人格に同じ新経験を8回（学習率 α = 0.3）与えると、g = 0 で 0.17、g = 0.5 で 0.82、g = 0.9 で 2.35 が残りました。

この補題は、推奨部品の候補にもそのまま当てはまります。欲求の設定点は、閉ループでは時定数約170更新で初期差を忘れました（批評 S2）。キャッシュも、学習率に下限 a_min がある限り指数的に忘れます。**持続を担えるのは、精度（1/n）型の記憶、階層の上位、宣言した有界な正帰還だけです。**

### 補題4：零空間には教師が届かない（成り立つ範囲は狭い）

特徴が全事象で完全に共線で、入力が正規化され、教師が線形で実現可能な場合に限り、教師が決めるのは予測の和だけです。特徴間の配分は教師から復元力を受けません。これは個性の置き場所になりますが、成り立つ範囲は狭いです（批評 F2）。

- 部分的にしか共線でない、または教師が実現不能な場合: 配分の規則が不動点そのものを変えます。
- 配分の規則が正帰還を持つ場合: 証拠では区別できない差が増幅されます。

信念側にも同じ零空間があります。相手と場面がいつも一緒なら、どちらに帰属するかはデータでは決まらず、事前分布で決まります（第4.3節）。

### 1.5 この節の帰結

| 方式 | 自己増幅 | 学習の向きの人格依存 | 履歴の持続 |
| --- | --- | --- | --- |
| 自己参照する目標（現行案） | あり（大きさは係数が決める） | あり | 強すぎる（飽和でロックイン） |

## 2. 「新しい価値観が形成された」の判定

経験史 h を経た人格の、プローブ x への評価を U_h(x)、生得価値を I(x) とします。比較の基準を二つ置きます。

- Ref_EC(x; h): I と「何と何が一緒に起きたか」の統計から作る最良の予測
- Ref_TD(x; h): I と「何の後に何が起きたか」の統計から作る予測

| 記号 | 条件 | 意味 |
| --- | --- | --- |
| NV0 獲得 | I(x) = 0 の対象で U_h(x) が初期と異なる | 対象の新しさ（単独では自明） |
| NV1 連合超過 | U_h − Ref_EC に再現性のある残差 | 共起の統計を超える |
| NV2 統計超過 | U_h − Ref_TD に残差 | 源が生得以外 |
| NV3 自律 | 元の強化子を取り除いても残る。除去後 300 回以上での残存と、係数の 2倍・1/2 への感度を併記 | 手段が目的になった |
| NV4 構造差 | 同じ出来事の集合で、順序・帰属・信頼・当時の解釈だけが違う履歴が異なる U を生み、その差が事前登録した写像で予測できる | 経路依存 |
| NV5 信念からの分離 | 信念を人格間で入れ替えても残る評価差の割合。キャッシュが信念由来の量を含む場合は漏れ指数を併記 | 予測ではなく価値の違い |
| NV6 転移 | 学習に使っていない概念や組み合わせに効く | 暗記でない |
| NV7 反事実 | その経験を除いて学習し直すと消え、同じ情報量の無関係な経験を除いた場合（プラセボ）より大きく変わる | 因果 |

**ガード検査（初稿から強化）**

- G1′ 係数の弾力性: 価値の大きさの、係数（学習率、減衰、雑音）に対する弾力性が、証拠に対する弾力性の 1/4 以下。初稿の G1（符号と順位が変わらない）は、批判した旧案にも合格してしまうため置き換えました。
- G2 内容依存: 結果の特徴を出来事間で入れ替えると値が変わる。
- G3 再現: 乱数種、言い換え、LLM 抽出の揺れ（タグの欠落）の下で再現する。
- G4′ 利得: 経験列に沿った状態写像のヤコビアンのスペクトル半径が、宣言したコミットメント方向以外で 1 以下。さらに、閉ループ（選択あり）と開ループ（記録の再生）を比べ、状態に 1e-3 の摂動を入れて最終状態の感度を測る。初稿の G4（1ステップの静的検査）は、状態や行動を介した依存を見逃しました。
- G5 反転可能: 有限の反対経験で反転し、その閾値の係数への弾力性が小さい。
- G6 対照: 「100回の強化の後に毎回 0.98 倍で減衰する」手書きのラチェットは、NV0・NV3・NV4・G1・G2・G4・G5 をすべて満たしてしまいます。これを対照として置き、残差がそれを超えることを求めます。

**良性のヒステリシスと自己増幅の区別。** 個性の持続は、次の四つが全て成り立つ場合に限って認めます。

1. 反転に必要な反対証拠の量が有限で、係数への弾力性が小さい。
2. 観測ノイズ水準の初期差やタグの揺れによる最終状態のばらつきが、経験内容の差より小さい。
3. 利得が 1 を超えるのは、宣言した方向だけである。
4. 履歴の内容を入れ替えると、個性も入れ替わる。

### 3.2 初稿からの変更と理由

初稿の推奨（アンカー付き多源価値学習）を独立の査読にかけたところ、次の問題が見つかりました（全文は付録 04c）。

| 指摘 | 内容 | v2 での対応 |
| --- | --- | --- |
| F1 配分の正帰還（致命） | 配分 s ∝ (\|価値\|+ε)^ρ は利得 1+αρ·誤差/和 の正帰還。玩具の状態写像のスペクトル半径は ρ=3 で最大 2.45、初期差 1% が配分 0.91/0.09 まで増幅 | 事後分散による配分（カルマン利得）に置換。利得は 1 以下 |
| F2 新概念の飢餓（致命） | 価値 0 の概念に責任が回らず、真の限界効果 0.30 の「音楽」が 0.00〜0.02 に留まる | 同上。不確かな新概念ほど責任を受け取る |
| S1 評価式と更新式の不整合 | 学習した欲求効果 û が読み出しに入っていない | û を廃止。モデルベース価値は信念×固定の効用で計算する |
| S2 設定点は持続を担わない | 閉ループで約170更新の時定数で収縮。対称な欲求関数では満たされた人格に「好き」が生じない | 設定点をコアから外す。成長欲求は単調増加・逓減の効用、欠乏欲求は不足側だけの罰 |
| S3 信頼の裏口 | 実績に自分の欲求充足（称賛による関係性の充足）を入れると、迎合者を 100 回中 97 回採用 | 認識的信頼（主張と後の外生の結果の一致）と、関係価値を分ける |
| S4 想起の水増し | 帰属をやり直して計数を再加算すると、1 事象を100回再生すると確率 0.60→0.987 | 想起は「旧寄与を引いてから新しい責任で足す」に限る。1事象の寄与の総和を台帳の不変量にする |

### 4.2 推奨：スコープ帰属つき階層ベイズ信念

A を骨格にし、C の責任配分、F の簡約、D の界面を組み合わせます。

**予測対象。** 状況 c と関与者 e のもとで、結果型 k が起きる確率 P(y_k = 1 | c, e) です。結果型は、凍結した文埋め込み上のオンラインの原型（辞書）で、必要に応じて増えます。候補文の確率は測定のときだけ読みます。

**確率分布。**

```
スコープ単位 x ∈ { 相手 e, 場面 c, 一般 g }。各単位が結果型 k の確率 θ_{x,k} を持つ
  θ_{g,k} ~ Beta(a₀, b₀)
  θ_{c,k} ~ Beta(κ_c θ̄_{g,k}, κ_c (1 − θ̄_{g,k}))      場面は一般から事前を受ける
  θ_{e,k} ~ Beta(κ_e θ̄_{g,k}, κ_e (1 − θ̄_{g,k}))      相手は一般から事前を受ける。κ_e は「人はどれほど違うか」
スコープの事前  π_{·,k} ~ Dirichlet(ξ_k)               その結果型を「人のせい」にするか「場面のせい」にするか
予測            P(y_k = 1 | c, e) = Σ_x π_{x,k} E[θ_{x,k}]
```

**学習誤差。** 結果そのものの対数損失 `L_B = −log P(o_t | c_t, e_t)` です。結果が予測と違えば、価値が同じでも学びます。これが「信念だけが変わる経験」を可能にします。

**更新。**

```
責任    φ_{t,x} ∝ π_{x,k} · Bern(y; E[θ_{x,k}]) · Λ[x, 行為者タグ]    Λ: LLM の行為者タグの誤りの混同行列
計数    α_{x,k} += φ y,   β_{x,k} += φ (1 − y),   π の計数 += φ          （オンラインEM）
割引    各単位の計数を 1/(1 + ν_x) で割り引く。ν_x: 予測誤差の移動平均と期待されるばらつきの比（変動性）
上位    θ̄_g, κ_c, κ_e, ξ は、単位の数（相手の数、場面の数）を標本数とする周辺尤度で学ぶ（経験ベイズ）
```

**ニューラルネットの役割。** 計数は、見たことのある相手と場面にしか使えません。未知の相手や場面への転移のために、埋め込み (c, e) から事前の (θ̄, κ) を出す小さなネット（事前ヘッド）を置きます。

- **学習目標:** 事前ヘッドの目標は周辺尤度です。「各単位の事後分布へ近づける」と読むと、事後平均が事前に向けて縮むぶん κ が自己強化的に発散します（批評 S4。玩具で 8 → 6.8×10³¹）。
- **補完学習系との対応:** 速い計数の記憶と、遅く一般化するネットを分けるのは、補完学習系の考え方（McClelland, McNaughton & O'Reilly 1995）に対応します。
- **研究思想 第10節の検証:** 「NNが転移や文脈依存で優れるか」は、この事前ヘッドを線形・検索と比べることで検証できます。

**なぜこの方式か（玩具の数値、付録 04b）。**

- **持続と可塑性の両立。** 8人から1回ずつ手柄を取られた人格と、取られなかった人格を比べます。新しい相手Nと8回、手柄を取られない経験をした後も、未見の相手への予測の差は 89% 残りました。一方、N自身への予測は 0.68 から 0.09 まで動きました。固定学習率 α = 0.25 では差が 10% しか残らず（3-F の「8回で消えた」と整合）、単層の計数では N への予測が 0.43 で止まりました。
- **検証できる予測。** 同じ8回でも、1人から受けたか8人から受けたかで、未見の相手への差の保持率が 70% から 89% に変わります。
- **H4 の三つの性質が同じ原理から出る。** 転移比は、同じ相手からの反復で 0.41→0.30 と狭まり、多様な相手からでは 0.41→0.85 と広いまま残りました。

### 4.3 運用上の制約（批評 S8 への対応）

- **相手と場面の共線。** 相手と場面がいつも一緒の履歴では、帰属 π はデータで決まらず事前で決まります（玩具で、事前の柔軟性の差だけで 0.50 か 0.65）。π の事前は弱情報で固定し、共線の履歴では「事前のまま」と報告します。相手と場面を独立に変えた経験を、形成史に必ず含めます。
- **相手が少ないと κ_e は識別できない。** 真の κ = 3、各相手8回のとき、κ_e の 95% 区間の幅（常用対数）は、相手1人で 2.7 桁、8人で 1.7 桁、32人で 0.7 桁でした。相手が8人未満の間は κ_e を事前で固定し、区間幅を報告します。コンパニオンの実運用（ユーザー1人と少数の登場人物）では、上位の層はほぼ事前のままになることを前提にします。
- **LLM の誤りの混同行列 Λ。** 同じ LLM の1回の抽出からは推定できません。複数のプロンプトや複数の LLM の抽出で推定するか、未知として感度分析にします。

### 4.4 価値ネットとの相互作用

**共通の界面。**

```
予期          Q(c, e) = E_{o ~ P(·|c,e)} [ V̂(o | c, e) ]      同時分布からの標本平均で計算する
驚きの分解    δ = f − Q = δ_V + δ_W
  δ_V = f − V̂(o_実際 | c, e)                         価値の誤差：結果は想定どおりでも、感じ方が違った分
  δ_W = V̂(o_実際 | c, e) − E_{o~P}[ V̂(o | c, e) ]    世界の誤差を価値の単位に直した分
```

V̂ は「この結果を自分はどう感じるか」の予報ヘッドで、δ_V で学びます。予期 Q は結果型ごとの確率と価値の積の和ではなく、同時分布の期待値で定義します。V̂ が非線形なとき、積の和では分解が成り立たず、符号まで逆になる例があります（批評 M1）。δ_V は予報ヘッドだけに使い、価値の本体の目標にはしません。信念は δ_W ではなく対数損失で学びます。

**信念→価値**

| 経路 | 内容 |
| --- | --- |
| 予期 | 予測分布を今の価値で評価した期待値。接近・回避の選択に使う |
| モデルベース価値 | V_MB は信念の予測を固定の効用で評価したもの |
| 帰属 | 価値の更新でどの相手に責任を回すかは、信念のスコープ推論の責任 φ で決まる |
| 関心 | 信念ネットの領域ごとの学習進捗。生の予測誤差は使わない（予測できない雑音に執着する「ノイズTV問題」を避ける） |
| 後悔 | 捨てた選択肢の予測価値 |
| 価値の軸を与える | 価値は信念ネットが切り出した結果型・相手・場面・領域に付く |

**価値→信念**（どれも条件として記録し、切った対照を置く）

| 経路 | 内容 | 既定 |
| --- | --- | --- |
| 接近・回避 | 避けた出来事の結果は観測されない（熱いストーブ効果） | ON。探索ボーナスと回避中の分散膨張は事前に固定 |
| 曖昧な解釈 | 曖昧な出来事の解釈を今の信念で重み付ける。硬い割当ほど偏る | 解釈の硬さ γ_h を人格ごとの気質として分布から与える（初稿の「既定は厳密」から変更） |
| 望ましさによる更新の非対称 | 良い知らせほど多く学ぶ | OFF（条件として入れる） |
| 自己奉仕的な帰属 | 悪い結果を他者のせいにしやすい | OFF（条件として入れる） |

**H7（価値と信念を別々に変えられる）。** 次の条件を満たす構成で、信念の候補文確率と、価値の直接の読み出しを別々に測ります。

| 条件 | 内容 |
| --- | --- |
| S1 パラメータの分離 | 信念と価値が共有する射影は、片方の損失の勾配で他方の読み出しが動かないようにする |
| S2 誤差の分離 | 信念は対数損失、価値の本体は欲求の効用変化・表明・学習進捗。δ（合計）で価値を更新しない |
| S3 信念だけを動かせる | 効用が等しく、結果としては異なる対がある（「頼りにならないが優しい」と「頼りになるが冷たい」） |
| S4 価値だけを動かせる | 信念が飽和した出来事を、欲求の状態や表明が変わった後に再経験する |
| S5 漏れの報告 | MB 価値と調停は、設計上の信念→価値の経路です。信念のみを変えた履歴での価値の変化の比（漏れ指数）を必ず報告する |

これらは系の因果構造の十分条件ではなく、実験で信念だけ・価値だけを動かす対を作るための条件です。

## 5. 統合モデルフレーム：1回の経験で何が起きるか

```
0. 意味の取り出し（LLM）
   状況 c、関与者 E、結果の部分 O と行為者タグ、他者の表明 {(j, x, u)}、曖昧な部分の解釈候補
   LLM は数値や感情の判断を出さない

1. 予期と選択（結果を見る前）
   信念: P(o | c, e)。価値: Q と関心 ι
   接近・回避を選ぶ。回避した場合は「避けた」ことだけを記録し、結果からは学ばない

2. 解釈と帰属（信念ネット）
   曖昧な部分の解釈の重み（人格の硬さ γ_h）、結果型への割当、各結果部分の責任 φ（相手・場面・一般）

3. 評価（読み出し）
   欲求の変化 Δh = M(o)、事象単位の効用変化 Δu（ベクトル）、社会的な価値、評価条件づけ、コミットメント、気分から f
   感情（喜び、怒り、失望、安堵など）は、δ_V、δ_W、帰属、どの欲求が動いたかの組から読み出す

4. 信念の更新
   計数（責任で重み付け）、変動性、辞書。教師は観測された結果

5. 価値の更新（教師はすべて価値ネットの出力に依存しない量）
   階層 MF 価値（Δu へのカルマン回帰。新しい個体は類の価値を継承し、責任は事後分散で個体・類・一般に配分）、
   認識的信頼（主張と結果の一致）、社会的な価値（源ごとに正規化）、関心（学習進捗）、評価条件づけ（1段）、
   後悔（捨てた選択肢）、予報ヘッド（δ_V）。実験条件として、コミットメント（外生の証拠のみ）と変動性の学習

6. 気分と台帳
   全ての更新を「経験ID、教師の種類、責任、変化量」として台帳に記録する

7. 想起・反すう（オフライン）
   保存した経験を再生し、旧い寄与を台帳から引いたうえで、今の信念で帰属と解釈をやり直して足す（1事象の寄与の総和は1回分）
   禁止: 今の感じた価値を過去の経験の価値の教師にすること。計数を引かずに再加算すること
```

**想起の扱い。** 再設計案は、想起のたびに過去の経験を今の価値で評価し直し、その差を学ぶとしていました。これは補題1の正帰還を想起の側で起こします。本書では、想起で変えてよいものを「誰のせいだったか」（帰属）と「どう読んだか」（解釈）に限ります。教師は当時記録した量（欲求の変化、表明、結果）のままです。過去の意味づけは変わりますが、同じ出来事を何度思い出しても証拠は増えません。

## 6. 具体例：同じ出来事を3人格はどう学ぶか

再設計案と同じ出来事を使います。**初めて会う友人Aに誘われて一緒に曲を作った。曲は好評で、Aから新しい技法も学んだが、自分の案はほとんど採用されなかった。**

v3 では、欲求の変化 Δh は全員で同じです（関係性 +0.30、有能感 +0.24、自律 −0.24、刺激 +0.18）。A は「共同作業者」類の新しい個体で、各人格が履歴で形成した類の価値を継承します。人格で違うのは、継承した予期、精度、欲求の状態、帰属だけです。

玩具の結果（試作の R/K/X の履歴。K の「手柄を取られた8回」は8人の別々の相手から）：

| 人格 | 継承した A の価値（類の価値） | この出来事による更新の向き | 更新後の A の価値 | 類（共同作業者）の価値の変化 | 読み |
| --- | --- | --- | --- | --- | --- |
| R 協働に救われた | +0.098 | **−0.065** | +0.033 | +0.098 → +0.098 | 協働に大きく期待していたので、自律の損失は予期外。A は「共同作業者一般より少し下」 |
| K 作者性を奪われた | −0.102 | **+0.618** | **+0.516** | −0.102 → −0.078 | 「共同作業者は自律を奪う」と予期していたので、この出来事は予期より良い。誤差の 87% が A 個人に入り、A は「例外的に良い相手」になる。共同作業者一般への見方はほとんど変わらない |
| X 探索者 | +0.119 | **−0.067** | +0.052 | +0.119 → +0.114 | R と同様 |

**この結果が示すこと。** 同じ出来事から学ぶ向きが、人格の過去によって逆になりました。研究思想第6節の中心仮説「学習の方向は、その経験を受け止める直前の評価状態によって変化する」が、教師を外生にしたまま成り立っています。

再設計案は「作者性を奪われた人格は A を嫌う」と書いていましたが、この玩具の出来事ではそうなりませんでした。更新後の A の価値は「継承した価値 + A の取り分 × 誤差の和」です。K では −0.102 + 0.87 × 誤差の和 なので、A が負に留まるのは誤差の和が約 +0.12 未満のときです。つまり K は、出来事が予期を 0.12 以上はっきり上回らない限り、A を「共同作業者一般」として低く評価し続けます。この出来事は予期を大きく上回ったので（誤差の和 +0.69）、A は例外として高く評価されました。自律の損失を8倍にしても誤差の和は閾値を超えたままで、A の価値は +0.161 でした。

「傷ついた経験のある人格は、予期より良い個人を例外として高く評価し、類への偏見はほとんど変えない」というこの予測は、心理学のサブタイプ化（反証する個人を例外として切り分け、ステレオタイプを保つ。Weber & Crocker 1983）と同じ形です。これは事前に登録して検証できる予測です。研究思想第6節が挙げる「より慎重になる」「以前の判断を正当化する」「別の選択肢を探す」のどれに進むかは、予期・精度・帰属の状態から計算できます。

## 7. ループの台帳と破綻条件

| ループ | 経路 | 利得と有界性 | 判定と検出 |
| --- | --- | --- | --- |
| 配分 | 価値 → 責任 → 価値 | カルマン利得は事後分散で決まり、分散の更新は価値に依存しない。ヤコビアンはブロック三角で半径 ≤ 1 | G4′ のスペクトル半径（玩具で 1.0000） |
| 変動性の学習（実験条件） | 価値 → 予測誤差 → q → 利得 → 価値 | 大きな予測誤差（約3σ以上）で一時的に半径 > 1（玩具で最大 1.214）。整流した超過を積む規則は、雑音だけの世界でも q を押し上げる | q は層ごとに固定するのがコア。学習させる場合は整流しない推定と、半径の監視 |

| 信頼 | τ → 接近 → 実績 → τ | 認識的信頼は外生の結果との一致だけで数え、源ごとに正規化する | 迎合者テスト（玩具で 0/100）。信頼の低い相手との最低限の接触。協調した複数の源には弱い（4人で 78/100）ので、源の間の相関を割り引く仕組みが要る |

| 気分 | m → f → δ → m | β < 1 で単安定 | β の静的検査 |
| 帰属の暴走 | 自己奉仕的な帰属 → 相手の価値 → 曖昧な出来事の帰属 | 既定 OFF | 価値→信念の経路を全て切った「影の信念」との乖離 |

| 破綻 | 起きる条件 | 検出方法 |
| --- | --- | --- |

## 8. 未解決の点

1. **（最大）最上位の価値の軸は設計者の所与です。** 欲求の種類、結果から欲求への効果 M、効用関数は設計者が与えます。このフレームの新しい価値は、所与の欲求の上での対象・確信・習慣・社会・関心・評価条件づけの変化です。人間の価値の源も、生得的な欲求、他者、好奇心に限られるという見方があります（Juechems & Summerfield 2019）。この範囲は研究目的と矛盾しないと考えますが、「欲求そのものが経験から生まれる」ことは主張できません。
2. **抽出の語彙が評価を一部外注しています。** 「手柄を取られた」「案が採用されなかった」のような語彙で出来事を切ると、評価の一部が LLM の言語化に入ります。M の行と結果の語彙は、事前に固定して公開します。
3. **検証できない価値への証言には、外生のアンカーがありません。** 美や倫理への他者の評価は、結果で確かめられません。認識的信頼は事実の領域で測るので、価値の領域への流用は仮定です。
4. **形成史を書くのは設計者です。** 価値は、台本・効果 M・抽出の語彙・係数の決定的な関数です。そこで新しい価値の判定には、次の三つの条件を加えて厳しくします。係数を事前分布から引いても高い確率で成り立つこと、抽出の揺れの下でも成り立つこと、設計者が書いていない履歴（自然な対話の記録）でも成り立つこと、です。
5. **両方のネットが「個体・類・一般」の足場に依存します。** 類の抽出を LLM に頼ると、その誤りは事前の継承を直接壊します。玩具では、類の誤り 10% で搾取者と友人の事前の分離が 19% 減り、25% で 49% 減りました。ランダムなら分離は消えます。系統的な誤り（ある種の人を常に別の類にする）は、同じ類の新しい個体の全員に誤った事前を継承させ、個体の数に比例してしか訂正されません。類は、固定の分類ではなく、信念ネットの潜在原因や埋め込みのクラスタとして確率的に持つことを次の候補とします。
6. **主な相手が一人だと、類と一般の価値はほとんど動きません。** 類は個体の数に比例してしか動かず、玩具では一人の相手との8回で類の反転は 7%、32人で 72% でした。コンパニオンの実運用では、ユーザーへの価値は個体として豊かに変わる一方、人格の一般的な価値は形成期の経験史でほぼ決まります。研究思想が想定する「多様な経験史による形成期」は、この構造の前提として必須です。会話に登場する第三者や活動・場面を個体として数えることで、運用中の形成をどこまで補えるかは未検証です。
7. **習慣の残り方は、まだ形成過程の性質になっていません。** 強化子を除いた後の残存は過程雑音 q の値で決まり、「安定した履歴ほど長く残る」という履歴依存は出ませんでした。変動性の学習則を、整流しない推定（雑音だけの世界で q → 0）に直し、利得の監視と合わせて再検証する必要があります。
8. **統合系の数値的な確認は玩具だけです。** 確かめたのは、価値側の階層 MF（持続・可塑性・向き・半径・音楽・迎合者・習慣）と、信念側の階層ベイズ・潜在原因・熱いストーブ・曖昧な解釈の部分です。状況単位のモデルベース価値と調停、関心と有能感、評価条件づけ、後悔、接近・回避の閉ループ、事前ヘッドを含む全体は動かしていません。
9. **実験計画への注意点**（修正は次の段階で行います）。
   - 実験計画の E4c（熱いストーブ）の「否定的信念の持続が肯定的信念の2倍以上」という基準は、探索の強さで 9.6 倍から 1.9 倍まで動きます。λ と ρ を事前に固定する必要があります。
   - H6a（曖昧な出来事の確証バイアス）は、厳密なベイズでは出ません（玩具で偏り 0.750→0.750）。偏りの源（解釈の硬い割当、近似推論、事前の二重数え）を名指しして切り替えます。
   - H4 の一般化は、相手と場面の二つの軸に分けて測ります。相手と場面を独立に変えた経験が必要です。
   - 持続は「未見の相手への差」、可塑性は「反証を受けた相手自身の更新」で、別々に報告します。価値についても同じです。
   - 第6節の例のように、v3 は「傷ついた履歴の人格は、予期より良い個人を例外として高く評価する」と予測します。実験計画 E2（更新の向きの事前予言）に、この形の予言を含められます。
