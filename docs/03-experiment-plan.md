# Frontalis 実験計画：経験が評価基準と信念を形成するかを反証可能に確かめる

Oct 15, 2026 · @sakuri

## 結論

この計画で確かめるのは、「経験で変わった評価基準や予測が、次の経験の受け止め方を変える」ことです。台帳の記録ではなく、経験を除いて学習し直す比較で因果的に示せるかを判定します。7つの実験（E0〜E6）で、価値と信念の両方を、結果を見る前に固定した基準で判定します。

次のどれかが出たら、その部分の設計を捨てるか作り直します。

- 獲得価値を評価に戻す条件と、初期価値だけで評価する対照（3-F型）の差が、未知の出来事で出ない（E1）。
- 大きなネットワークが、線形モデルや過去の経験の検索より価値の相互作用を捉えられない（E3）。この場合、容量の大きい構造は採用しません。
- 経験を1つ除いて学習し直しても、その後の経験の評価が変わらない。つまり、評価を通じた間接的な影響がない（E5）。
- 経験の順序や解釈を入れ替えても、形成史の到達点が変わらない（E6）。

進め方は2段階です。まず、作り方が分かっている合成の経験史で構造を確かめます（段階A）。E1とE5が通った場合だけ、歴史上の人物から抽象化した形成史に進みます（段階B）。説明用プロトタイプの10概念と数値は、設計にも基準にも使いません。

## 仮説と反証条件

どの仮説も、実験前に「こうなったら誤り」を文で固定します。数値の閾値は「統計・再現性」の節でまとめて固定します。

| 仮説 | 内容 | 誤りと判定する結果 | 実験 |
| --- | --- | --- | --- |
| H1 | 経験史の異なる人格は、未知の出来事を異なって評価する。その差は獲得価値を評価に戻す経路から生じる | 初期価値だけで評価する対照との差が閾値未満 | E1 |
| H2 | 同じ出来事から何を学ぶか（更新の向き）は、経験史から事前に予言できる | 事前予言の的中率が、ランダムな経験史での的中率と区別できない | E2 |
| H3 | 価値の相互作用（例：達成は自分の手柄なら正、他人の手柄になると負）は学習可能な表現で獲得され、容量は経験史の多様さに応じて実際に使われる | 非線形モデルが相互作用課題で線形モデルや検索を上回らない。または使用パラメータが経験史を増やしても増えない | E3 |
| H4 | 少数の経験は他の関与者や場面へ過剰に一般化される。同じ相手からの経験が増えると一般化はその相手に狭まり、多様な相手からの経験では広いまま残る | 一般化の幅が、経験の数や相手の多様さで変わらない | E4 |
| H5 | 否定的な予期は回避を生み、反証の機会を減らす。そのため、同じ強さの誤った認識でも、否定的なものは肯定的なものより長く残る | 「関わるか避けるか」を選べる条件で、残り方の非対称が出ない | E4 |
| H6 | 曖昧な出来事は今の信念に沿って解釈され、確証の方向に学習が偏る。反証による更新は、同じ反証の反復より多様な反証で速い | 曖昧な証拠と明確な証拠で偏りが変わらない。または更新の速さが反証の多様さに依存しない | E4 |
| H7 | 価値と信念は別々に変化できる。予測だけを変える経験史と、価値だけを変える経験史がある | どちらか一方だけを変える経験史が作れない（常に両方が動く） | E4 |
| H8 | 経験の因果的な影響は、台帳に記録された更新量より大きい。その差は、後の経験の評価を変えた分（間接効果）である。固定教師の対照では差が出ない | 除去して学習し直した効果が台帳の記録と一致する。または対照でも同じ差が出る | E5 |
| H9 | 形成史の到達点は、経験の中身だけでなく、順序・解釈・矛盾する経験に依存する | 並べ替えや解釈の変更で、事前に固定した形成の問いへの答えが変わらない | E6 |

## 学習可能な表現と容量の検証

固定の価値軸をやめ、出来事を文の埋め込みとして受け取り、概念とその相互作用を人格ごとに学習します。容量が実際に使われるかは、同じ学習則で複数の構造を比べて確かめます（E3）。

### 構造

1. LLMは出来事を、状況、結果の各部分、関与者、「誰が何を起こしたか」の短い文に分けるだけです。数値や感情の判断は出しません。人名は匿名の記号に置き換えた後の文だけを渡します。
2. 凍結した文埋め込みモデルで各文をベクトルにします。全人格で共通です。
3. 人格ごとに学習する概念射影が、そのベクトルを人格の概念空間に移します。関与者は人格ごとに学習する関与者ベクトルを持ちます。
4. 獲得価値ネット（小さなMLP）は、結果の部分の集合を順序なしでまとめて価値を出します。部分どうしの相互作用を表せます。
5. 初期価値は全人格共通の小さな固定関数で、学習しません。感じた価値は「初期＋獲得＋気分」の和を有界化したもので、再設計案と同じです。
6. 予測ネット（信念）は、状況と関与者から起こりうる結果を予測します。詳細は次節です。

### 比較する構造

学習則、経験史、乱数はすべて同じにし、表現だけを変えます。

| 構造 | 中身 | 確かめること |
| --- | --- | --- |
| M0 固定概念の表 | プロトタイプと同じ固定軸 | 軸を手で決めた場合の上限 |
| M1 線形 | 埋め込みから価値への線形写像 | 相互作用なしでどこまで説明できるか |
| M2 経験の検索 | 似た過去の経験の感じた価値を加重平均 | 「学習」が記憶の検索で置き換えられないか |
| M3 小MLP | 約1万パラメータ | 相互作用を獲得できるか |
| M4 大MLP | 約10万〜100万パラメータ | 容量を増やすと何が増えるか |

### 相互作用課題

合成の経験史を、単独の要素では価値が決まらないように作ります。例えば「達成」は良い結果と悪い結果に同じ回数現れ、良し悪しは「誰の手柄になったか」との組み合わせだけで決まります。同じ型で、「つながり」×「自分の案の扱い」、「新しさ」×「自分で選んだか」も作ります。M1はこの課題を原理的に解けないので、M3とM4がそれを超えるかが判定になります。プローブは学習に使っていない言い回しと場面で作ります。

### 容量が使われているかの指標

3-Fでは容量を100万まで増やしても使用パラメータが102のままでした。同じ失敗を見逃さないよう、次の3つを測ります。

- **変化の実効ランク:** 多数の経験史について、初期状態からのパラメータ変化を並べた行列の実効ランク。
- **必要なパラメータ数:** 経験による変化を小さいものから消していき、プローブへの反応が保たれる最小の数。
- **経験史の識別率:** プローブへの反応だけから、どの経験史で育った人格かを当てる精度。経験史の種類を8、32、128と増やしたとき、容量に応じて精度が伸びるかを見ます。

M4がM3を上回らなければM3を採用し、「この課題では大容量は不要」と報告します。M2がM3と並ぶ場合も、学習が記憶の検索に還元できるという否定的な結果として記録します。

## 価値判断と信念形成

信念は予測ネットの予測そのものとし、独立した手作りの数値軸は作りません。測るときだけ、「共同作業者が成果を自分のものにする」のような候補の結果文に予測がどれだけの確率を置くかを読みます。候補文は測定専用で、学習には使いません。

### 評価とのつながり

- **予期は信念と価値の積:** 予測ネットが出した結果の分布を、今の価値で評価した期待値を予期とします。
- **驚きの分解:** 驚きを「世界の予測が外れた分」と「予測通りだが感じ方が違った分」に分け、前者で予測ネットを、後者で獲得価値を更新します。
- **選択:** 人格は予期に応じて「関わるか避けるか」を選びます。避けた場合は結果を見ないので、信念も更新されません。
- **解釈への影響:** 曖昧な出来事（結果文の解釈が割れるもの）では、今の信念に近い解釈に重みを置いて学習します。これは確証バイアスの候補の仕組みで、実験で入れたり切ったりします。

確証バイアスの入り口は3つあり、それぞれを別に操作します。

1. 確証的な証拠で学習率が上がる非対称。人格の気質として与える場合と、入れない場合を比べます。
2. 曖昧な出来事を今の信念で解釈すること。
3. 否定的な予期が回避を生んで反証の機会を減らすこと（「熱いストーブ」効果）。

### E4の下位実験

| 実験 | 経験史の操作 | 測るもの | 仮説 |
| --- | --- | --- | --- |
| E4a 過剰一般化 | 「共同作業者に手柄を取られる」経験を1、2、4、8回。同じ相手からか、別々の相手からか | 初対面の相手を、似ている度合いを段階的に変えて提示。予測確率の一般化勾配とその幅 | H4 |
| E4b 確証バイアス | 信念ができた後、確証と反証を同数、順序を乱数で提示。証拠が曖昧な条件と明確な条件 | 元の信念の方への正味のずれ | H6 |
| E4c 熱いストーブ | 実際には半々の環境で、誤って否定的な信念と誤って肯定的な信念から始める。選択ありと選択なし | 信念が正しくなるまでの経験数 | H5 |
| E4d 反証による更新 | 支持する経験を2、8、32回積んだ後、同じ反証の反復か、多様な反証か | 信念が反転するまでの経験数。その相手への獲得価値が追いつくか、残るか | H6 |
| E4e 価値と信念の分離 | 「頼りにはならないが優しい相手」の経験史と、「予測は同じだが大事にするものが違う」経験史 | 予測と価値を別々に読み、片方だけが動くか | H7 |

E4dは、引き継ぎで最優先とされた「履歴差の持続と可塑性の両立」も兼ねます。強い反証で信念は更新されるが、形成史の痕跡は価値に残る、という形で両立するかを見ます。

## 経験の寄与：台帳と因果の区別

台帳は「その経験のときにどれだけ更新されたか」を記録します。因果的影響は「その経験がなかったら今の判断がどう違うか」です。両者は一致しないと予想しており、その差こそが「変わった評価基準が次の経験の評価を変える」ことの測定値になります（H8）。

| 測るもの | 定義 | 分かること |
| --- | --- | --- |
| 台帳 | 経験iの更新の前後で、固定プローブへの反応がどれだけ変わったか。全経験の和は総変化に正確に一致し、学習経路ごとに内訳を出せる | その時点での直接の更新量 |
| 除去効果 | 経験iを除いた経験史で、同じ乱数から学習し直した人格との反応の差 | その経験の総合的な因果的影響 |
| 中立置換効果 | 経験iを、形式は同じだが価値的に中立な経験に入れ替えて学習し直した差 | 経験数や時間の差ではなく、中身の効果 |
| 直接効果と間接効果 | 除去した学習し直しで、後の経験の感じた価値だけを元の実行の値に固定した場合が直接効果。除去効果との差が間接効果 | 後の経験の受け止め方を変えることで生じた影響 |
| 解釈変更効果 | 同じ出来事を別の解釈で与えて学習し直した差 | 事実ではなく受け止め方の影響 |
| 順序入替効果 | 経験iを前後に動かして学習し直した差 | 同じ経験でも時期で影響が変わるか |
| 再学習への抵抗 | 全経験史の後に反対の経験を与え、経験iの影響がどれだけ残るか | 形成されたものの頑健さ |

### 予想と対照

- 提案構造では、初期の形成的な経験ほど「除去効果 ÷ 台帳」が1より大きくなります。後の経験の受け止め方を変える分だけ影響が増えるからです。
- 固定教師の対照（3-F型）では、後の経験の評価が履歴に依存しないので、間接効果はほぼゼロになるはずです。ここでも差が出れば、測定の作り方に問題があります。

### 計算量

合成の経験史（100〜300経験）では、全経験の1つずつの除去を実際に学習し直します。形成史では、人生の時期ごとのまとまりで除去します。影響関数やTracInのような安価な近似は、実際の学習し直しと一部で照合し、合う場合だけ代用します。

## 形成史データ

形成史は、同じ経験の反復ではなく、順序、矛盾、葛藤、再解釈を持つ一回ずつの経験の列として作ります。経験の回数は資料に書かれた出来事から決め、「×12」のような水増しはしません。

### 4つの層と、史実と解釈の区別

| 層 | 中身 | 書く人と根拠 | LLMに渡すか |
| --- | --- | --- | --- |
| 1 史実の年譜 | 日付と出来事。各行に出典 | 資料に書かれたことだけ | 渡さない |
| 2 解釈 | その出来事がどう受け止められたか | 誰の解釈かを必ず記す。本人の自伝、研究者、この計画の推測の3種類と確からしさ | 渡さない |
| 3 抽象化した経験 | 場所、時代、固有名を外した経験文。解釈の入れ方は層2のどれを使うかで変えられる | 層1と2から作り、利用者が確認 | この層だけを渡す |
| 4 形成の問い | 「どの経験がどの価値や信念につながるか」の問いと、その測り方 | 実行前に固定 | 渡さない |

### 経験に入れる要素

- **順序:** 同じ出来事でも、どの信念を持っている時期に起きたかで意味が変わるように並べます。
- **矛盾:** 今の信念と合わない経験（敵だと思っていた集団の人からの親切など）を、資料にある分だけ入れます。
- **葛藤:** 2つの価値がぶつかり、片方を選ぶ場面です。人格が自分で選んだ結果を学習します。
- **再解釈:** 後の時期に過去の経験を思い出し、評価し直す場面です。再設計案の想起時の再評価の経路を通ります。
- **空白の時間:** 何も起きない期間も入れ、忘却と定着を見ます。

### 対照

| 対照 | 作り方 | 答える問い |
| --- | --- | --- |
| 並べ替え | 同じ経験を乱数で並べ替える。要所の経験だけを前後させる版も作る | 順序が形成を変えるか |
| 別解釈 | 層1は同じまま、層2に別の研究者の解釈を使う | 事実ではなく受け止め方が形成を変えるか |
| 単一モチーフ | その人物の主題だけを繰り返す合成履歴 | 矛盾や葛藤が形成に必要か |
| 直接設定 | 形成史の到達状態にプローブ反応が揃うように直接合わせた人格 | 経験史は到達状態以上のものを残すか |
| 頻度を揃えたランダム | 経験の種類の頻度だけを合わせた無作為の履歴 | 人物固有の構造が効いているか |

実在の人物を再現したとは主張しません。人物は「資料が厚く、形成の形が対照的な経験史の素材」として使います。

E4の成功基準（草案）は次の通りです。

- **E4a:** 1〜2回の経験でも、似ていない相手への予測確率が似た相手の半分以上になる。同じ相手からの経験を増やすと一般化の幅が減り（順位相関≤−0.5）、多様な相手からでは減らない。
- **E4b:** 曖昧な証拠での元の信念へのずれが、明確な証拠でのずれをd≥0.5で上回る。
- **E4c:** 選択ありでは、誤った否定的信念が正されるまでの経験数が、肯定的信念の2倍以上。選択なしでは0.8〜1.25倍に収まる。
- **E4d:** 多様な反証は、同じ反証の反復より30%以上少ない経験で信念を反転させる。反転までの経験数は、支持した経験の数とともに増える。
- **E4e:** 予測が閾値以上変わる一方で価値の変化がその2割未満である経験史と、その逆の経験史が、どちらも作れる。

## 統計・再現性・実行順

各条件は、初期化の乱数10通りと、LLMによる意味抽出の言い換え3通りの組30回で実行します。意味抽出の揺れで結果が変わらないことも、これで確かめます。

- **事前登録:** 仮説、成功基準、経験史、プローブをファイルにしてハッシュで凍結してから実行します。E0の試験運転だけは凍結前に行いますが、その結果は判定に使いません。
- **報告:** 失敗を含めて全条件を報告します。事後に思いついた分析は「探索的」として分けます。
- **区間:** 効果量には、乱数と言い換えの単位で再抽出した95%区間を付けます。
