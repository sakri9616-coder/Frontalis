# Frontalis 研究思想の理解と現状監査

Oct 15, 2026 · @sakuri

## 結論

現行のNPNは「経験によって評価基準そのものが形成される」仕組みになっておらず、学習則・経験データ・人格の起源の三か所を構造から作り直すべきだと判断します。根拠は次の三点で、いずれも3-Fのコードを実際に動かして確かめました。

1. **学習の目標が経験史に依存していない。** 自己評価の目標は、乱数で決まる固定の8×7行列に結果事実を掛けて1.1倍した値とほぼ一致します（目標の大きさRMS約0.8に対し、経験史による違いはRMS約0.0002）。NPNは「固定された評価関数を、経験した手掛かりの位置に書き写す」学習をしており、経験が次の評価基準を変える循環は数値上ほぼ回っていません。
2. **経験史が「同じ1種類の出来事の24回反復」しかない。** 各人格の過去は4種類の合成出来事のうち1つを24回繰り返したものです。歴史上の人物の経験史を素材にした人格形成は、3-F以前の全ラボ（アーカイブ7件を含む）を検索しても一度も行われていません。
3. **人格差の起源が経験ではなく初期乱数にある。** 好き嫌いの方向は `PROFILES` の倍率と seed の乱数行列で決まり、経験はそれを局所的に書き写すだけです。たとえば seed 6311 の初期傾向0では、「協力して成果を得た」結果への好意の目標が −0.065 と、経験と無関係に負の値になっています。

時間分離（短期・気分・長期）、事実と解釈を分けた経験記録、LLMとのツール境界、保存復元、凍結と再現の手順は、そのまま次の研究の基盤として使えます。

## 1. 研究思想の理解

frontalisが作ろうとしているのは、「何を良いと感じるか」という物差しそのものが、その物差しで測った経験によって書き換わっていく評価主体です。研究の対象は人格の「状態」ではなく、状態が経験を通じて自分自身を変えていく「循環」だと理解しました。

私の言葉で言い換えると、次の四つが要求の核です。

- **形成されるのは物差しである。** 世界に何が起きるかの予測ではなく、起きたことをどう価値づけるかが経験で変わる。研究者が感情の正解を教えるのでも、初期設定で好みを与えるのでもない。
- **形成の素材は経験の歴史である。** 成功と失敗、信頼と裏切り、誤解と訂正、執着や後悔が、どの順番でどう受け止められたかによって、異なる価値基準が育つ。歴史上の人物は「どんな経験の積み重ねがどんな価値観を生むか」を調べるための形成史の素材であり、数値プロフィールの置き換え先ではない。
- **人格はLLMの外にあり、因果的に確かめられる。** 同じLLM・同じ場面でNPNの状態だけを変えたときに判断が変わり、その変化が過去の経験と対応していることが証拠になる。話しぶりの人格らしさは証拠にならない。
- **個性と故障を分ける。** 頑固さ、偏った好悪、誤解の残存は個性として許される。一方で、無関係な経験で全価値が崩れる、何も変わらなくなる、履歴がすぐ忘れられるのは機構の問題である。

一文で言えば、「同じ出来事を異なる人格が異なるように受け止め、その受け止め方の違いが次の人格の違いになる」ことを、LLMとは独立に実証するのがこの研究だと理解しています。

## 2. 第12節の5つの問いへの回答

根拠は3-Fの `npnf/core.py`、`npnf/data.py`、`npnf/dual_view.py` を読み、同じコードを3つの条件（seed 6311/6312/7901、容量0/2/4、初期傾向0/1/3）で動かした結果です。数値は3条件で同じ傾向でした。

### 問1. 現在のNPNは何を学習しているのか

「この手掛かりを見たら、固定の評価関数が結果に与える値を予め返す」という連想を学習しています。

- 経験ごとに、手掛かり（cue、結果を隠した44次元）の位置にRBF中心を1つ置き、その出力係数7個を学習します（`core.py` `_learn`）。
- 学習の目標は、更新前のNPNが「結果8軸＋中立化した文脈」を評価した値の1.1倍です（`core.py` `update`）。
- ところが文脈を中立化した点は学習済みのRBF中心から遠いため、RBFはほぼ寄与せず、目標は「seed乱数×`PROFILES`倍率で作った固定の8×7行列 `base` × 結果事実 × 1.1」とほぼ一致します。
- 実測では、24回の過去経験の関、目標がこの固定値からずれた幅はRMS 0.00013〜0.00036でした。目標そのものの大きさはRMS 0.73〜0.84です。

### 問2. それは経験による評価基準の形成と呼べるか

呼べません。評価基準（`base`）は一度も変わらず、経験が変えるのは「どの手掛かりにその固定評価を結びつけたか」だけです。

- 「約束を破られた」「裏切られたと思い込んだ」「自分の選択で失敗した」の3つの過去は、結果事実が同じ `LOSS` なので、学習目標が完全に同一でした。誤解か自責かという主観の違いは、価値の目標には入らず、手掛かりの位置と学習率（confidence）にしか現れません。
- 同じ現在の経験に対する学習目標の、過去4種類の間の差はRMS 0.00014〜0.016でした。つまり、異なる過去を持つ人格が同じ出来事から学ぶ内容はほぼ同じです。これは研究の中心仮説（第6節）を構造的に否定する設計です。
- 二視点方式で得た過去差（60/60）は、この「手掛かり→結果の評価」の連想を読み出したもので、価値観より「予期」に近い性質です。現在の経験を8回学ぶと差が0/60まで消えるのは、新しい経験が履歴と無関係な同じ目標で上書きするためだと説明できます（この因果は介入実験で確かめる必要があります）。

### 問3. 心理学や多様な経験史を利用する設計として何が不足しているか

- **心理学：** `LITERATURE.md` の7文献は、持続・慣性・消去・調整・多言語という「時間と減衰」の側だけを扱っています。価値や好みが経験からどう形成されるか、既存の価値が出来事の評価をどう変えるかに関する文献はありません。その上、文献から得たのは減衰係数の根拠ですらなく、本文自身が「0.45/0.9は独自設定」と明記しています。
- **経験史：** 過去は4種類の出来事のうち1つを24回繰り返すだけで、順番・組み合わせ・転機・訂正を含む「歴史」になっていません（詳細は次節）。

### 問4. 現在の構造が人格形成を妨げている可能性はあるか

あります。以下の5点は、結果が不成立だった理由としてコードから直接説明できます。

1. **評価基準が固定。** `base` は学習されず、学習目標は実質的に `base` の出力です。自己評価の循環は形式上あるものの、帰還する値が動かないため回りません。
2. **関係性の文脈を価値の目標から除いている。** 誰が、どんな意図で、信頼があったかという人格差が最も出る部分を、結果の評価では中立化0.5にしています。これは3-Eの可塑性不成立への対処でしたが、結果として「誰に何をされたか」で価値観が分かれる道を塞いでいます。
3. **容量が使われない。** 同じ種類の経験は全て同じRBF中心に入るため、容量を100万にしても使われるのは2中心（102パラメータ）です。容量比較は、このデータでは原理的に差が出ません。
4. **感情と気分が学習に影響しない。** 短期感情と気分は出力には混ざりますが、学習目標は `logits` だけから作られます。そのため「そのときの気分で同じ出来事の学び方が変わる」ことが起こりません。
5. **一つの中心の活性は最大0.5。** 活性を h/(1+Σh) で正規化しているため、過去に学んだ中心が現在の判断に与える影響は上限があり、位置が少しずれると急に小さくなります（現在の「無実の判明」「事情不明の再訪」では最大0.07）。

### 問5. どのような実験なら人格形成の成立を検証できるか

出力の差ではなく、「同じ出来事から何を学ぶか」の差を測る実験が必要です。中心になるのは次の三つで、詳細は次のステップの実験計画で示します。

- **学習方向の履歴依存性：** 異なる過去を持つ人格に全く同じ新経験を与え、学習目標とパラメータ更新の向きが異なるかを測る。学習目標を固定教師に入れ替えた対照では、この差が消えることを確かめる。
- **経験史の反事実介入：** 同じ初期状態から経験史の一部だけ（順番、一つの転機、訂正の有無）を変え、未知の場面への評価の差がどの経験に由来するかを特定する。
- **線形・検索・固定教師の対照：** 同じ経験史を与えた単純な比較モデルが同じ形成を示すなら、NPN固有の主張はしない。

## 3. 経験史による形成過程の監査

「どのような経験が、どのような価値基準の形成や変化につながるか」は、これまでのどのPhaseでもモデル化されていません。歴史上の人物を素材にした実験も一度も行われていません。

確認した範囲は、稼働中の3-D・3-E・3-Fのラボと、アーカイブ済みの7ラボ（core、NPN、Phase 3、3-A、3-B、3-B自己学習、3-C）です。文書とコードを「歴史上・偉人・思想家・historical・伝記」で検索したところ、3-Fの「歴史上の人物名はLLMに与えない」という一文以外に該当はありませんでした。

| 研究思想が求めるもの | 3-Fまでの実際 | 根拠 |
| --- | --- | --- |
| 異なる人生経験から異なる価値観が育つ過程 | 初期人格の違いは「抽象的な初期傾向」4種類で、乱数行列の行を倍率で伸縮しただけ | `core.py` `PROFILES` |
| 成功と失敗の繰り返し、信頼の変化、転機、再挑戦を含む経験史 | 過去は4種類のうち1種類を24回反復（手掛かりに±0.08の揺らぎだけ）。音の経験も1種類×8回 | `data.py` `past_event`、`acoustic` |
| どの経験がどの価値を変えたかの追跡 | 経験記録に更新前後のハッシュはあるが、価値の変化を経験へ帰属させる計測はない | `core.py` `update` |
| 特定の相手への信頼や愛着 | 行為者は「自分・親しい人・知らない人・組織」の4種類のみ。個別の相手は表せない | `meaning.py` `ACTORS`、3-F REPORTの限界 |
| 信念の葛藤、創作への執着、長期的な関心の変化 | 1経験は最大2出来事、行為は6分類、結果は8軸。目標や動機を表す欄がない | `meaning.py` `validate` |

最も豊かな経験データは3-Bの24種類の出来事（音の仕組み、共同制作、探索、約束）でしたが、そこでも当時の評価は合成環境が与えており、「既存の人格が経験を解釈して変わる」形ではありませんでした。3-Dでは8軸の事実で表した96件の経験を使いましたが、3-Fでは時間の効果を測るために経験は単純な反復に戻っています。

つまり、「豊かな経験史で多様な人格を形成する」という本来の要求は実験に反映されておらず、3-Fの不成立は「形成できなかった」というより「形成を試す条件がなかった」と読むべきです。ただし、第2節の学習則のまま経験を豊かにしても、学習目標が固定なので価値基準は変わらないと予測します。経験データと学習則は一緒に作り直す必要があります。

## 5. 使い続けるものと作り直すもの

NPN本体の学習則・価値の表現・経験データは作り直し、その周りの基盤は使い続けるのがよいと考えます。

| 対象 | 判断 | 理由 |
| --- | --- | --- |
| 事実と解釈を分けた追記専用の経験記録、訂正・想起の参照 | 使い続ける | 研究思想の「経験記録」の要求をそのまま満たす |
| 情報更新回数を単位にした時計、短期・気分・長期の分離 | 使い続ける（学習への影響は追加） | 分離は240/240で動作。ただし感情が学習に入らない点は変える |
| LLMとの読み取り専用ツール境界、JSON Schemaでの意味抽出 | 使い続ける | Haikuでschema利用16/16、実ツール往復10/10 |
| 保存・復元・ハッシュ検証、事前凍結と再現コピーの手順 | 使い続ける | 結果を見て条件を変えない文化は次の研究でも必要 |
| 操作画面、人間評価の画面 | 使い続ける（提示内容は第14節に合わせて変更） | 評価者に経験史とNPN信号を示す方針に合わせる |
| 学習目標（固定写像×1.1）と固定の評価行列 `base` | 作り直す | 評価基準が変わらないことが、過去差0/60・自己評価の帰還なし・容量差0の共通の原因 |
| 結果評価での文脈の中立化 | 作り直す | 人格差が最も出る関係性・意図・信頼を価値から外している |
| 1経験1中心のRBFと容量の予約 | 作り直す | 容量を増やしても使われず、未知場面へも届かない |
| 価値の表現（固定8軸→固定7軸） | 作り直す | 目標・動機・特定の相手への愛着や信頼を持てない |
| 合成経験データ（4種類×24回）と抽象的な初期傾向 | 作り直す | 形成史を検証できる順序・転機・複数の相手を含む経験史が必要 |

部分的な修正ではなく作り直すべきだと考える根拠は、これまでの修正の履歴にあります。3-Eの「文脈の中立化」、3-Fの「二視点の読み出し」は、どちらも読み出し方や入力を変えて一部の基準を通しましたが、学習目標が固定であることは変えていません。問題は調整ではなく「何を学習しているか」の定義にあるため、同じ構造の上での修正を重ねても、研究思想の中心仮説は検証できないと判断します。

## 6. 監査の範囲と限界

- 読んだもの：引き継ぎメモと索引、3-FのREPORT・ADDITIONAL\_RESULTS・PREREGISTRATION・LITERATURE・CLAUDE\_HANDOFF、`npnf/` の全コード、主要な実験コードと集計レポート、3-D・3-EのREPORT・HANDOFF・設計文書、アーカイブ7ラボのREADMEと報告書。
- 実行したもの：3-Fの `npnf` をこちらの環境にコピーし、PyTorchの代わりにNumPyで同じ演算をする簡易置き換えで動かしました。第2節の数値はその結果で、元の凍結成果物の再現ではありません。ただし、自己評価目標の変化の大きさ（1e-4台）はADDITIONAL\_RESULTSの事後点検（RMS .0001675）と同じ桁です。
- お使いのPC上のファイルは読み取っただけで、変更・上書きはしていません。
- 「作り直すべき」という判断は、上記の構造分析からの推論です。新しい学習則が人格形成を実現できるかは、次のステップの実験計画で検証する対象です。
