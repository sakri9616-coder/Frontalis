# 意味と人格の分離設計

文章を解釈したモデルの自己申告は人格正本にしない。`npne.meaning` が取り扱うのは出来事の事実で、`npne.core.Personality` がその表現から7つの主観値を計算する。更新時の教師は更新前のNPN自身による結果評価のみである。

semantic44はfacts8を先頭に保ち、各出来事の14要素を2組と文脈8要素を加える。各出来事は行為6分類、自己行為者、親しい行為者、自己対象、否定、不確実性、利益意図、加害意図、存在フラグを持つ。文脈は同意あり／なし、事前信頼高／低、原因／防止、事後順序、遅延。行為者と対象の自由な固有名グラフではない。3件以上の経験や任意概念の合成はこのschemaの範囲を超える。

入力のunknownは万能の中立評価ではない。facts8の0.5は不明な程度を示し、カテゴリのunknownは正負の事実フラグを立てない。否定された行為と観測不確実な行為は別の入力となる。行為が善行に見えるという理由だけで利益意図を補わない。初期判断はfacts8だけから計算するため、容量や新しいカテゴリの追加による初期人格の違いを取り除く。

cueでは第二出来事と因果・時間・遅延の事後情報を隠す。observedで初めてその結果を渡す。ただし第一出来事の意図や同意は事前に分かっているという条件である。現実の時点ごとの知識管理を一般的に解決した仕組みではない。

二分枝は意味関連性の自動発見ではなく、研究者の指定した境界である。同じ分枝の遠い入力にも学習が波及し得る。別分枝が保持されても「無関係な価値観を全て守った」とは言わない。関連・遠いprobeの分類も研究用の幾何的・話題的分類である。

保存はNPZ数値配列とhash付きJSON。pickleを許さず、形・有限値・hashを検査する。更新は複製上で学習し、有限値とノルムのゲートを通過後に確定する。旧世代のloadがrollbackになる。hashは改変検出であり電子署名ではない。履歴を含む状態と、パラメータそのもののhashを区別する。

`tools/evaluate.py` は登録済みモデルID・意味・最大4候補だけを受理する。任意ファイルpath、学習目標、コマンド、実行権限をLLMに渡さない。ホストが意味を検証してNPNを呼び、読み取り専用の構造化信号をLLMへ渡す。LLM自身にファイルアクセスさせるagent toolの試験ではない。

場面へのstanceと、候補のvalue比較によるselectionは別である。場面全体への感情と選択候補への感情を別キーで返す。意欲・嫌悪・反抗はaffinityからの固定読出し、感情強度は対応出力の正部分であり、独立した学習headを増やしたとは主張しない。
