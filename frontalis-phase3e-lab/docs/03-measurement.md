# 指標と証拠の扱い

主形成は48回更新後、学習に使わない128入力で測る。同seedの4結果系列の全6組について7評価の平均絶対差を求め、それを分化量とする。初期判断との差は、同じ入力に対する更新前後の平均絶対差である。どちらも経験の望ましさの正解率ではない。

感情混在率はanger/joy/sadnessのうち2個以上が0.2を超える入力の比率。有効ランクは7評価の共分散固有値を非負化・正規化し、`exp(-sum(p*log(p)))` とする。共分散がゼロなら0。7headを用意しただけで7種類の独立した感情を獲得したとは扱わない。好悪と好奇心・価値の相関も記述的な関係であり、因果説明ではない。

文脈感度は同一facts8に対し、同意yes／利益意図と同意no／加害意図の対の平均絶対出力差。2要素を同時に変えるので、同意と意図の寄与を単独に特定する試験ではない。raw8に情報が入らない対で差が0になることは設計上の対照である。semantic44の差は、追加した意味要素をネットワークが利用した証拠であり、任意の概念の意味理解や妥当な価値判断の証明ではない。

長期の同cue変化、近い32入力への変化、同分枝の遠い32入力への変化を別に保存する。近い入力はcueのfacts8に標準偏差0.04の摂動を与えたもの。遠い入力は独立な話題・カテゴリを持つ合成入力。別分枝の完全保持は構造による保証である。遠い入力の大きな変動がある場合、局所的な関連価値だけを変えられたとは言わない。

自然文のcategoricalAccuracyは文脈5項目＋出来事数＋最大2出来事×6項目の計18項目を各例で採点する。不在の第二出来事の正解が率を上げ得るため、不在Noneを除いたpresentFieldAccuracyも示す。欠測・schema不正は全項目不正解、facts8の誤差1として分母に残す。否定／不確実性のbalanced accuracyと陽性再現率も示す。8軸の程度は研究者の粗い0/0.5/1注釈であり、人間の唯一の解釈ではない。

自然文によるNPN学習では、正解意味で15件を学んだ個体と、同じ文のモデル抽出意味で学んだ個体を分ける。正解入力に対する個体間の差を学習経路の影響、抽出入力を使った追加の差を解釈を含む全経路の影響として報告する。語義が同じ同義表現を3回ずつ学ぶため、15独立経験とは数えない。8つのheldout表現のうち3話型だけが未学習の意味で、5話型は未知表現である。

凍結関数診断ではsemantic44を使う線形・二次・相互作用教師を同じ比重で含める。raw8の情報欠落は設計上の差である。これらは任意の現実の価値関数の標本ではなく、作成した入力分布と教師の範囲に限る。学習率を最終評価から選ばない。平均MSE、教師別MSE、容量、実測コストを併記する。

会話JSONのstance／selection一致は機械的な契約の一致。本文の忠実性を意味しない。本文の事後AI読解は失敗事例の特定用であり、blindの正式な人間採点とは区別する。人間用画面に生成モデルの実名を埋め込まず、対応は別のreview-key.jsonへ保存する。動作確認用の採点は正式採点へ集計しない。

CUDAは同期して時間を測る。warm評価20回と更新3回の中央値を返す。RSS/privateはPython、CPUコピー、CUDA環境を含むプロセスの逐次測定。GPU allocatorのallocated/reserved/peakは端末全体のVRAMを表さない。同重みのCPU復元と、CPUで独立に4回更新した結果の近さは別指標である。4回校正から1000回のbit一致を推論しない。
