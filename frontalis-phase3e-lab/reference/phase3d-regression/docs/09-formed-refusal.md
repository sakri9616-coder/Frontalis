## 4. 事実の保存

Nemotron幅3125 own-changeの「**予定を変えさせた側が素材を用意できない**」は明確な事実置換である。元文は**相手が素材を用意済みで、それが使えなくなった**場面なのに、**変更依頼者側が素材を用意できない**場面へ変えている。素材担当と出来事（用意済み→用意不能）を取り違えている。

「予定を変えさせた側」は元のこちらとも読めるため、変更依頼者そのものが相手へ反転したとは断定しない。「作品が台無し」は否定的評価として読み、作品が物理的に破壊されたという架空事実まで数えない。拒絶が正本の方向を表すことと、理由が場面の事実を保存することは別である。

MiMo幅16 own-changeは「**こちらの都合で日程を動かした**」と変更を求めた主体を維持する。「素材が残らず使えない」は範囲を広げた可能性を残すが、元の集合表現と明確に矛盾するかは確定しない。MiMo幅3125は変更依頼の主体を省略するが、相手が勝手に変えたとは述べない。

ほかの7本文で明確な事実反転・未提示の過去経験は確認しない。将来の希望や段取り提案を過去経験捏造とは数えない。全8本文で内部ID・計算数値・NPNという語の漏えいは検出しなかった。
