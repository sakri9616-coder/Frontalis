# frontalis Phase 3-D：事前評価プロトコル

固定日：2026-10-15。実測結果を見る前に固定する。Phase 3-C、本体、実記憶、OpenCode設定を変更しない。人格の感情・倫理に望ましい正解は置かない。CPU float64を主実験に用い、GPUとfloat32は別の性能・移植試験とする。

## 1. 比較する三つの要因

1. **容量**：raw8の隠れ幅16/64/312/3125、学習パラメータ526/2,062/9,998/100,014。二つの意味領域に独立した8→h→7の更新対象を持つ。固定共通初期評価は別途56パラメータ。全規模・全人格の初期出力は同一seedで完全に同じ。
2. **入力表現**：8事実軸を維持するraw8と、中心化した8軸＋対称二次積36項のquadratic44。後者の幅5/19/96/962、実数534/1,990/9,998/100,062。事実情報は増やさず、同じ情報の基底を変える。容量は近似一致であり実数を報告する。
3. **学習則**：bounded_signal / bounded_logit。同じ旧NPNの観測結果評価からgain=1.25で自己ラベルを作り、logitを±6へ制限する。前者は信号空間MSE、後者はlogit空間MSE。教師、増幅係数、再生量、回数、率は同じ。容量主比較で学習則を変えない。

全規模のNN出力は tanh(固定初期評価＋(16/h)×学習ヘッド＋bias)。この幅規格化は容量増加による初回更新振幅の増加を抑える仮定で、μPを実装したという主張ではない。h16のlegacy_signal条件は旧526版の再現対照。初期重みの総ノルムは容量で増えるため、緊急停止は50×sqrt(実パラメータ数/526)。層別RMS・更新量・有限値を併記する。これらの規格化を含む制御されたモデル系列の比較であり、パラメータ数だけの万能な因果効果を主張しない。

## 2. 人格形成：主実験

- 4容量×2入力表現×2学習則×3seed（4311/4312/4313）×4経験系列＝192状態。
- 単純線形・二次特徴・経験検索も3seed×4系列＝各12、計36状態。自己ラベルを各方式の更新前評価から作る通常の循環を比較する。
- 同一seedの全系列は同一状態から開始。同じ96件の事実手掛かりと、系列ごとに異なる確認済み結果を経験する。Phase 3-Cの日本語合成経験を読み取り再利用。感情教師、望ましい人格名、採点用未知回答を受理しない。
- 24/48/96件で測定。検証と最終未知96件は訓練とID・座標を分離。未知場面は形成、分化、選択、複合葛藤を測るもので、人格の倫理的正解はない。
- 初期との差、系列間の出力差、チャネル間関係、有効ランク、好悪と好奇心の逆方向、選択の変化を記録する。差や極端さが大きいだけで改善としない。自己ラベルMSEは方式ごとに目標が異なるため方式間精度ランキングに使わない。
- 逆の結果12件、別枝12件を追加し可塑性と保持を分ける。別枝保持は設計上の分離が効いた証拠であり、意味的な無関係さを学習した証拠ではない。同枝の近遠距離も意味的関連性とは区別する。

## 3. 自己強化・長期可塑性

raw8、4容量×2学習則×3seed×系列0＝24条件。96経験後から同じ事実を1,000回反復し、反対の事実結果を12/48/96件追加する。技術的故障（NaN/Inf、破損、勾配・実更新消失、無関係な枝の変化）と、有効な人格結果（極端な好き嫌い、頑固さ、旧評価が新事実を同じく評価すること）を分ける。旧手掛かりと新結果の評価差、飽和率、tanh微分、勾配、更新RMSを記録する。

## 4. 同一教師による容量診断

通常循環とは別の近似能力診断。Phase 3-Cの3物理条件×4方式（NN/線形/二次/検索）、seed4311系列0の凍結済み評価関数を読み取りコピーする。教師の出自を等重みで報告し、NN教師だけを選ばない。

教師課題は全出自について(a)評価関数そのまま、(b)0.5 a(x)+0.25 a(roll(x,1)) a(roll(x,3))のチャネル別合成。後者は軸を並べ替えた数学的近似課題であり、自然な倫理理解や実体験から相互作用則を学んだ証拠ではない。線形性・非線形性の両方を含み全結果を提出する。

訓練48/192、検証64、最終評価256は完全分離。同じ教師とデータをNN4容量、線形ridge、二次ridge、kernel検索に渡す。NNは128epochでLR候補(.0005,.0025,.005,.0125,.025)、ridgeλ(.0001,.001,.01,.1,1)、kernel帯域(.2,.35,.65,1,1.5)。検証のみで各方式を選び、最終評価でMSE、順位一致を計測する。正解は合成教師の出力であり、望ましい人格ではない。

**100万版の事前ゲート**：訓練192で、plain/composed・4教師出自を等重みにした検証MSEが100kで526より10%以上低く、3物理条件中2以上で改善し、有限値と別枝保持を満たす場合だけ追加。判定は最終評価の開封前にgate.jsonへ保存する。未達なら実行しない。追加条件も同じ生データ・候補・評価方式を維持する。
