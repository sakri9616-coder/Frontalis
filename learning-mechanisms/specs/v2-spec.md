# 価値ネット v2 仕様（批評 critique.md を受けた再設計）

## 変更の要点
- 価値の大きさによる配分 s ∝ (|U z|+ε)^ρ を廃止。配分はカルマン利得（事後分散）で行う。履歴は事前分散（確信度）として配分に入る。利得は ≤1（分散は証拠で減る）。
- û（概念→欲求効果）を廃止。モデルベース価値は信念×固定の効用で計算（学習パラメータなし）。
- モデルフリー価値（MF）は、経験した欲求効用の変化（ベクトル）を教師に、概念特徴へのカルマン回帰で学ぶ。キャッシュの「蒸留」ではない。
- 調停は不確実性で（Daw 2005 型）。
- 設定点は持続を担わない（縮小変数）。コアから外し、順応水準として任意。
- 正帰還はコミットメント c だけに限定し、宣言する（反転閾値は閉形式）。
- 信頼は認識的信頼（j の主張と、後に観測された外生の結果との一致）と、関係価値（MF の j の価値）に分ける。称賛による Δh は認識的信頼に入れない。
- 評価条件づけは1段のみ（共起対象の「直接の経験由来の価値」の凍結スナップショットへ、利得 γ_EC<1。EC で得た価値はさらに転移しない）。
- 後悔: 選ばなかった選択肢の信念予測 Q_b と実際の f の差で、選択肢の MF を反事実更新（教師は信念の予測）。
- 想起: retract-and-reassign。1事象の寄与の合計は1回分（台帳の不変量）。
- 学習率のゲートは価値の驚きではなく、精度（カルマン）と信念側の予測誤差。気分は β<1。

## 固定（生得）
欲求 k=1..K（例: 関係性、有能感、自律、刺激、安全）。状態 h_k は毎更新で基準へ減衰: h ← h + λ(h0 − h)。
効果 M(o) ∈ R^K: 結果部分 → 欲求の変化（固定、人格共通）。
効用 U(h) = Σ_k u_k(h_k)。成長欲求は u_k(h) = s_k(1 − exp(−h/s_k))（単調増加・逓減）、欠乏欲求（安全）は不足側だけの罰 −½ max(h* − h, 0)²。
事象の快楽価値（ベクトル）: r_k = u_k(h_k + Δh_k) − u_k(h_k)、Δh = Σ_j M(o_j)。事象単位で評価（概念ごとの加算はしない）。寄与の分解は事後（パス積分）。

## 学習される価値（状態）
1. MF 価値 W ∈ R^{|概念|×K}、事後共分散 Σ_k（欲求ごと）、過程雑音 q（変動性、学習）:
   予測 r̂_k = z·W_{:,k}、 K_gain = Σ_k z / (zᵀ Σ_k z + R)、 W_{:,k} += K_gain (r_k − r̂_k)、 Σ_k ← Σ_k − K_gain zᵀ Σ_k + q I（関与した概念のみ q を足す）
   スカラー読み出し V_MF(x) = Σ_k W_{x,k}
2. MB 価値（学習なし）: V_MB(x|h) = E_{o~P_信念(·|x)}[ U(h + M(o)) − U(h) ]
3. 調停: U_val(x) = ω V_MF(x) + (1−ω) V_MB(x|h)、 ω = σ²_MB/(σ²_MB + σ²_MF(x))（σ²_MF は Σ の対角和、σ²_MB は信念の不確実性）
4. 社会的価値 w_soc(x): w ← w + η τ_j (u_{j,x} − w)。 τ_j = Beta 平均（j の事実・効果の主張が、後に観測された外生結果と一致した回数／外れた回数）。低 τ の源にも最低限の接触確率。
5. 関心 ι(d): 信念ネットの領域 d の学習進捗 LP_d。さらに LP_d は有能感の欲求に Δh_有能感 += κ_LP·LP_d として入る（上達は有能感を満たす → MF で領域の価値が上がる）。
6. コミットメント c_x: dc = a_c(−c + g tanh c + k_e e_x + k_ch·choice_conflict_x)。e_x は外生の証拠（MF の予測誤差の符号付き要約、社会的証拠）。g∈(1, 1.5]。反転閾値 |u_c| = √(g(g−1)) − acosh√g。
7. 評価条件づけ（1段）: 対象 y（相手、音楽など）と共起した対象 x の「直接経験由来の価値」V_dir(x)（MF＋MB＋社会、EC 成分を除く）の凍結値へ、 v_EC(y) += a_EC (γ_EC V_dir(x) − v_EC(y))、γ_EC<1。
8. 後悔: 選択肢 a を選び b を捨てた場合、MF(b) を信念の予測 Q_b へ反事実更新（重み小）。f − Q_b は気分と選択に入る。

感じた価値（読み出し、目標にしない）: f = tanh( Σ_k r_k [事象の実際] の重み付き和 + λ_s Σ w_soc + λ_c Σ c + λ_EC Σ v_EC + β m )、β<1。
予期（選択前）: Q(x) = U_val(x) + λ_s w_soc(x) + λ_c c_x + λ_EC v_EC(x) + λ_ι ι(d(x))

## 経験前の人格が学習の向きを変える経路（v2）
欲求状態 h（同じ Δh でも効用の傾きが違う）、事後共分散 Σ（確信のあるものはあまり動かず、不確かなものに責任が回る）、帰属 r（信念）、認識的信頼 τ、コミットメント c（どちらの吸引域にいるか）、接近・回避（標本）、解釈の硬さ γ_h（気質の分布）。
