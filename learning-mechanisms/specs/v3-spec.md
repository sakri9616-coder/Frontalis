# 価値ネット v3 仕様（v2 検証 v2-verify.md を受けた差分）

## 中心の変更: 価値も階層にする（信念 SAHB と同じ原理）
v2 の T3 は「同じプローブで、新経験を重ねても過去を保ち、しかも新経験に合わせる」を求めていたが、これは同じ単位では論理的に両立しない。信念側で成功したのは、持続（未見の相手への差）と可塑性（新しい相手自身の更新）を別の単位に担わせたからである。価値側も同じにする。

- 特徴 z を「個体（相手A、この曲）」「類（共同作業者、音楽）」「一般（人、活動）」の3層に分ける。各事象は各層の特徴を1つずつ持つ（LLM が類を抽出。類は信念ネットの場面クラス・相手の集合と同じ足場）。
- MF の重み W は層ごとに事前分散が違う: 個体 σ²_ind（大）、類 σ²_cls、一般 σ²_gen。新しい個体は事前平均 = 類の重み（類の価値を継承）。実装は「個体の重み = 類の重み + 個体の偏差」とし、偏差の事前分散を大きく、類の重みの事前分散は小さく、過程雑音 q は層ごとに q_ind > q_cls > q_gen。
- 結果: 新しい個体との経験は主に偏差（個体）が吸収し、類の重みは「その類の個体の数」に比例してしか動かない（有効標本数が個体数）。

## 持続と可塑性の測り方（v2 の T3 を置き換える）
- 持続: 人格間の差を、**未見の個体**（同じ類の新しい相手・新しい曲）への評価で測る。新しい個体 N との経験を m 回重ねた後に、別の未見の個体 N′ への評価差がどれだけ残るか。
- 可塑性: N 自身への評価が、N との経験の真の効用にどれだけ近づくか。
- 両立の判定: 持続 ≥ 0.7 かつ可塑性 ≥ 0.7（m=8, 32）。比較: v2 core（階層なし）、固定学習率、1/n 計数。
- 追加予測: 履歴の差を作った経験が1個体からか、多数の個体からかで、未見の個体への差の保持率が変わる（多数の方が高い）。

## その他の修正
- MB は概念ではなく状況（事象の文脈全体）を評価する: V_MB(状況|h) = E_{o~信念(·|状況)}[U(h+M(o)) − U(h)]。σ²_MB = 信念の事後分布の下での効用の予測分散（Beta 事後から計算）。調停 ω は状況単位。概念ごとの「好き嫌い」のプローブは MF＋EC＋社会（＋c）で読む。→ MB 経由のブロッキング（N2）を避ける。
- 社会的価値は源ごとに正規化: w_soc(x) = Σ_j g(τ_j) ū_{j,x} / Σ_j g(τ_j)、ū_{j,x} は源 j の表明の平均（回数で重みを増やさない）、g(τ) = max(0, 2τ−1)。
- 変動性 q の学習則: 層・重みごとに q ← q + η_q (max(0, e² − (zᵀΣz + R)) − q)（予測誤差が期待より大きい分だけ増える）。NV3 の残存は「安定な履歴か変動の多い履歴か」で変わるはずで、これを証拠への弾力性として測る。
- コミットメント c はコアから外し、実験条件にする（v2 の T3 で、持続と反転が λ_c と g の一つのトレードオフにしかならなかったため）。入力は外生の証拠だけにし、選択の項 k_ch は削除する（原点が不安定で、証拠なしに c が育つ）。正当化は別の実験条件で扱う。
- 欲求状態 h の時定数は短い（気分に近い状態）ので、人格差の担い手とみなさない。

## 検証してほしいこと
V1 持続と可塑性（上の定義）: v3 と v2 core、固定率、1/n 計数を同じ表に。履歴を作った個体数 1/2/4/8 での保持率。
V2 §6（T7）: 同じ Δh で、K の A への評価の符号。A は「共同作業者」類の新しい個体とし、K の類の重みを継承する。この事象による A への更新の向き（符号）と、更新後の値の符号を、R/K/X で分けて報告。
V3 ヤコビアン半径（T1 と同じ）と 1e-3 摂動の感度。
V4 音楽の飢餓（T2）を U_val ではなく概念のプローブ（MF＋EC）で、と状況の U_val で。
V5 NV3（T4）: 安定な履歴（同じ効用の反復）と変動の多い履歴（効用が揺れる）で、強化子除去後の残存が変わるか。証拠（履歴の安定性）への弾力性と、係数（η_q, R, 事前分散）への弾力性。
V6 迎合者（T6）を、関係価値で接触を選ぶ条件で、源ごとの正規化ありで。
