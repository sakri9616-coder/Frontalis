# ローカル生成上限の輸送条件追加

主条件のQwenは16/16件の抽出がHTTP400で欠測。保存済み最初のerrorはterminated、以後はEngine protocol predict request failed: fetch failed。短いready応答は前後とも成功し、サービス全体が恒常停止したとは断定できない。
この段階でローカルの意味抽出内容は一件も得られていない。生成上限だけ6000→2048へ変えた qwen2048 条件を追加する。モデル・プロンプト・バッチ2・temperature0・データ・判定・再試行回数は固定。主条件の結果を書換えず、追加条件を別報告する。生成途切れも構文失敗として記録する。根本原因が生成上限だと事前に断定しない。
